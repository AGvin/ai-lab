# Documentation Catalog

Curated entry points into the implemented documentation. This page explains the main documentation areas; use the [Documentation Tree](../tree/) for the complete physical hierarchy.

## Canonical entity catalog

- [Agent Skills](../../../../../catalog/sub/agent-skills/) — portable instruction packages, published collections, and Agent Skill discovery/registry surfaces with verified canonical identity.
- [Datasets](../../../../../catalog/sub/datasets/) — concrete AI-relevant datasets and benchmark datasets with durable provenance and usage value.
- [Hardware](../../../../../catalog/sub/hardware/) — identifiable hardware products and product families relevant to AI workloads.
- [Models](../../../../../catalog/sub/models/) — canonical model reference plus task-oriented model-selection guidance.
- [Producers](../../../../../catalog/sub/producers/) — canonical organizations, teams, individuals, and other stable producing or publishing identities.
- [Services](../../../../../catalog/sub/services/) — externally operated AI assets, development services, infrastructure, model APIs, gateways, management, data, security, and related hosted products.
- [Software](../../../../../catalog/sub/software/) — installable or self-managed AI software, development tools, agents, frameworks, runtimes, workflow engines, model/data tooling, gateways, and related systems.
- [Specifications](../../../../../catalog/sub/specifications/) — formal or normative specification artifacts and contracts represented as canonical catalog entities.
