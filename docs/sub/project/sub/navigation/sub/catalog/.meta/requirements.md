# Documentation Requirements

## Requirements

- Present the Documentation Catalog as curated, descriptive, human-oriented navigation into the currently implemented AI Lab documentation.
- Keep the canonical entity catalog and project documentation as distinct reader groupings.
- Include the currently materialized canonical entity domains that are useful reader entry points, with concise scope descriptions rather than a mechanical descendant listing.
- Link Project Overview, Project Policies, and Documentation Tree as project-level entry points.
- Explain that non-catalog domains still under architecture/migration review are intentionally not represented as empty placeholder branches.
- Defer exhaustive physical hierarchy to Documentation Tree.

## Validation

- Every linked entry resolves to a currently materialized documentation node.
- The page is curated rather than exhaustive and does not duplicate the full physical tree.
- Placeholder-only domains are not presented as implemented reader destinations after they are removed from the physical tree.
- The page distinguishes entity-catalog navigation from project documentation.
