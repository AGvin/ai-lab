# Documentation Requirements

## Requirements

- Present Integration and Extensibility as the learning group for mechanisms that connect AI/agent systems to external capabilities or package reusable capability/procedure bundles.
- Introduce MCP, Agent Skills, and Plugins as related but non-equivalent mechanisms and route readers to the correct child based on whether they need runtime interoperability, portable procedural capability packaging, or a host/ecosystem extension bundle.
- Keep normative protocol/package/manifest contracts specification-owned; learning pages teach how to understand, use, build, test, and operate them.
- Keep concrete implementations, marketplaces, packages, versions, host support, and compatibility catalog/platform/evidence-owned.
- Render standard navigation across the materialized MCP, Agent Skills, and Plugins learning roots when rendering is activated.

## Validation

- No child is described as a subtype of another merely because they can be bundled or used together.
- The group provides a useful conceptual choice boundary and is not a purely decorative wrapper.
