# Documentation Requirements

## Requirements

- Present Agent Foundations as the entry learning group for understanding what an AI agent is, how an agent loop combines observations/state/model/tools/control, how agents differ from deterministic/staged workflows, and how autonomy remains bounded by system controls.
- Use the canonical `concepts/agents-and-autonomy/` owner for reusable agent identity and autonomy semantics; this group teaches those ideas progressively through practical mental models and design consequences rather than redefining canonical truth.
- Explain that the current materialized subset focuses on `agents-vs-workflows/` because the legacy AI Agents source contains source-backed practical guidance about when model-directed control adds value versus deterministic application logic.
- Do not imply that unmaterialized selected siblings `agent-anatomy/`, `agent-loop/`, or `autonomy-and-control/` are absent from the logical architecture; standard navigation reflects only physical children.
- Keep tool-interface design with `tools-and-actions/`, explicit agent state/memory with `context-state-and-memory/`, planning/execution with its selected group, orchestration/coordination with their selected groups, and operational controls with `operations-and-control/` rather than overloading foundations.
- Teach agent capability as a complete-system property. A model's ability to propose an action does not imply the surrounding application grants tools, credentials, permissions, persistence, budgets, or authority to execute it.
- Keep concrete framework/product agent APIs, current platform behavior, specific credentials/policies, and project workflows with catalog/evidence/project owners.

## Validation

- Agent Foundations introduces reusable mental models without becoming a second canonical agent definition.
- Model capability is not equated with system permission or operational authority.
- Current navigation exposes only materialized selected children.
- Deeper tool/state/planning/orchestration/operations topics remain with their selected owners.
