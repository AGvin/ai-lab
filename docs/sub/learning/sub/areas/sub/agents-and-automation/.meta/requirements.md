# Documentation Requirements

## Requirements

- Present Agents and Automation as the learning area for autonomous/tool-using AI processes, agent state and control, integration/extensibility, workflows, orchestration, coordination, and operational control.
- Keep generic reasoning/planning theory with the Reasoning and Decision Making learning area and broader application/infrastructure lifecycle with AI Engineering; link them as prerequisites or continuations when needed.
- Explain that the current materialized subset focuses on `integration-and-extensibility/` because MCP, Agent Skills, and Plugins have source-backed tutorial material ready for migration.
- Do not imply that unmaterialized selected agent-learning branches are absent from the logical architecture; standard navigation reflects only physical children.
- Keep concrete products, concrete skills/plugins, formal specifications, and mutable platform support with their canonical non-learning owners.

## Validation

- The area remains pedagogical rather than a catalog of agent products/extensions.
- Current navigation exposes only materialized children.
- MCP, Agent Skills, and Plugins remain distinct mechanisms with explicit conceptual/specification boundaries.
