# Documentation Requirements

## Requirements

- Teach Assistants and Conversations as the product-neutral user-facing layer for interacting with AI through messages, context, files/data, tools/actions, and multimodal inputs.
- Keep concrete product UI, feature limits, connector availability, current model names, and platform-specific behavior with catalog/evidence owners.
- This source-backed package materializes `multimodal-interaction/`; other selected assistant/conversation children remain logical until substantive content justifies physical creation.
- Link deeper prompt design and context engineering rather than duplicating their detailed methods here.
- Treat uploaded documents, screenshots, audio, and other media as inputs whose preprocessing, fidelity, provenance, and trust level can affect results.

## Validation

- The learning remains transferable across assistant products.
- User-facing interaction is not conflated with model internals or agent implementation.
- Current navigation exposes only materialized selected children.
