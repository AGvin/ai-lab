# Documentation Requirements

## Requirements

- Teach Language as the modality/task group for language and code understanding/generation, separate from architecture families and model-scale labels.
- This source-backed package materializes `language-modeling-and-generation/`; other selected language-task siblings remain logical until substantive content justifies physical creation.
- Keep post-training, prompting, retrieval, tools, state, validation, and application controls with their dedicated owners while linking them as common ways to shape language-model use.
- Treat language-model output as probabilistic generated content rather than authoritative database state or verified calculation.
- Keep concrete model identities, current context limits, provider behavior, licensing, runtime support, and benchmark results source-backed outside timeless task learning.

## Validation

- Language tasks are not equated with the `LLM` scale label.
- Generated language remains subject to source/evidence and correctness verification where material.
- Current navigation exposes only materialized selected children.
