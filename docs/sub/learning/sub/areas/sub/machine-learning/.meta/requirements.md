# Documentation Requirements

## Requirements

- Present Machine Learning as the learning area for learning systems from data: problem formulation, data roles, learning paradigms, classical methods, deep-learning principles, probabilistic/causal learning, automated search, and learning theory.
- Keep model-family/architecture/inference/adaptation/training lifecycle depth with Models; Machine Learning teaches reusable learning principles that apply across model families and applications.
- Explain that the current materialized subset includes `deep-learning/`, `fundamentals/`, and `learning-paradigms/` where source-backed migration material is available.
- Teach common supervised, unsupervised, self-supervised, and reinforcement-learning distinctions as learning-signal/process families rather than product/model categories.
- Use classification, recommendation, forecasting, anomaly detection, speech recognition, and generative modeling as application examples while keeping their task-specific depth with the applicable model/domain owners.
- Teach practical ML selection through representative data, measurable outcomes, simple baselines, out-of-sample evidence, leakage/label/data-quality checks, drift monitoring, and explicit separation of correlation from causal evidence.
- Keep concrete datasets, framework APIs, model artifacts, benchmark results, and project-specific training configurations with their applicable catalog/evidence/project owners.

## Validation

- Machine Learning is distinct from concrete model identities and from the Models lifecycle learning area.
- Training fit is not treated as evidence of out-of-sample quality.
- Current navigation exposes only materialized selected children.
