# Documentation Requirements

## Requirements

- Present Machine Learning as the learning area for learning systems from data: problem formulation, data roles, learning paradigms, classical methods, deep-learning principles, probabilistic/causal learning, automated search, and learning theory.
- Keep model-family/architecture/inference/adaptation/training lifecycle depth with Models; Machine Learning teaches reusable learning principles that apply across model families and applications.
- Explain that the current materialized subset focuses on `deep-learning/` because legacy neural-network material contains source-backed general deep-learning teaching ready for migration.
- Do not imply that unmaterialized selected Machine Learning groups are absent from the logical architecture; standard navigation reflects only physical children.
- Teach evaluation/generalization claims as evidence-dependent. Parameter count, training loss, confidence scores, or one dataset do not establish general task quality without an appropriate evaluation design.
- Keep concrete datasets, framework APIs, model artifacts, benchmark results, and project-specific training configurations with their applicable catalog/evidence/project owners.

## Validation

- Machine Learning is distinct from concrete model identities and from the Models lifecycle learning area.
- Current navigation exposes only materialized selected children.
- Evaluation claims remain evidence-dependent rather than inferred from nominal model properties.
