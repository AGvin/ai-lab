# Documentation Requirements

## Requirements

- Teach Learning Paradigms by the source and structure of the learning signal rather than by model architecture or application domain.
- Materialize only source-backed selected children in this package: supervised learning, unsupervised learning, self-supervised learning, and reinforcement learning.
- Explain that the same architecture family can participate in different paradigms and that one application can combine several paradigms across lifecycle stages.
- Keep model-specific pretraining/post-training implementation with Models and task/domain specifics with their dedicated owners.

## Validation

- Paradigm names describe learning processes/signals, not concrete model products.
- Examples do not imply exclusive ownership of an application by one paradigm.
- Current navigation exposes only materialized selected children.
