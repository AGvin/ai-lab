# Documentation Requirements

## Requirements

- Teach Unsupervised Learning as discovering useful structure or representations without explicit target labels for each example.
- Use clustering, dimensionality reduction, density/structure discovery, or representation-learning examples where appropriate without tying the paradigm to one method family.
- Explain that discovered structure still requires task-relevant interpretation/evaluation and can reflect biases or artifacts in the observed data.
- Keep concrete algorithms, datasets, and framework-specific procedures with their dedicated method/evidence owners.

## Validation

- Lack of explicit labels is not confused with absence of objectives or evaluation.
- Discovered groupings are not automatically treated as real-world causal categories.
