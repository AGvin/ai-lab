# Catalog

Canonical entry point for concrete AI Lab entities and their source-backed documentation.

Catalog nodes own stable entity identity and facts. Project policies, reader journeys, and other non-entity knowledge remain with their separate canonical owners.

## Catalog domains

- [Agent Skills](./sub/agent-skills/) — Agent Skills are portable packages of instructions and optional scripts, references, and assets that compatible AI hosts can discover and load for repeatable work.
- [Datasets](./sub/datasets/) — identifiable AI-relevant datasets and dataset families with durable provenance, composition, version, license, access, and intended-use value.
- [Hardware](./sub/hardware/) — identifiable products and product families with practical value for AI training, inference, evaluation, data processing, and related workloads.
- [Models](./sub/models/) — canonical model reference plus task-oriented model-selection guidance.
- [Producers](./sub/producers/) — organizations, teams, individuals, and other stable producing or publishing identities.
- [Services](./sub/services/) — hosted or externally operated products whose primary identity is a service.
- [Software](./sub/software/) — installable or self-managed AI software grouped by primary role.
- [Specifications](./sub/specifications/) — identifiable formal or normative artifacts whose primary identity is a specification.

The catalog is materialized incrementally from reviewed evidence. The [Documentation Tree](../project/sub/navigation/sub/tree/) owns the exhaustive implemented hierarchy.
