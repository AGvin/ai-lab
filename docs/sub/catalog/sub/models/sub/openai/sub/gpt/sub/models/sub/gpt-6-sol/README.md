# GPT-6 Sol

GPT-6 Sol is the concrete OpenAI model identified as `gpt-6-sol`, released on 2026-09-22. OpenAI positions Sol for complex coding and agentic work.

## Profile

The API profile lists text and image input, text output, a 1,050,000-token context window, 128,000-token maximum output, and a April 20, 2026 knowledge cutoff [Model reference](https://developers.openai.com/api/docs/models/gpt-6-sol).

Its documented reasoning effort settings are `none`, `low`, `medium`, `high`, `xhigh`, and `max`. Native audio and video are not supported by this model profile [Model reference](https://developers.openai.com/api/docs/models/gpt-6-sol).

## Operating boundaries

Responses is the tool-capable API surface. Chat Completions supports function calling only with reasoning effort set to none. [Model reference](https://developers.openai.com/api/docs/models/gpt-6-sol).

OpenAI’s October 7, 2026 system card distinguishes the October ChatGPT update from the September version still used in Codex and Work. That product update is not evidence that every API request uses the October version [October GPT-6 system card](https://deploymentsafety.openai.com/gpt-6-october).

Tool calls express proposed actions. The application remains responsible for permissions and for handling untrusted instructions in files, skills, and tool results [Latest-model guide](https://developers.openai.com/api/docs/guides/latest-model).
