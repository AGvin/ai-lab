# Documentation Requirements

## Requirements

- Identify GPT-Live-1 mini as the smaller GPT-Live model released alongside GPT-Live-1 and used for the Free ChatGPT Voice surface at launch.
- Preserve its full-duplex voice-model identity and keep product-plan routing separate from intrinsic model capability.
- Keep mutable availability, product assignment, voice inventory, and API exposure source-scoped.

## Validation

- GPT-Live-1 mini is not treated as an alias of GPT-Live-1.
- ChatGPT plan assignment is not presented as a permanent model property.

## Source-scoped operating boundaries

- Public release evidence for this model does not establish general API availability. GPT-Live-1’s API launch and endpoint limits should not be copied to mini [GPT-Live system card](https://deploymentsafety.openai.com/gpt-live).
- Product routing and delegated tools remain separate from intrinsic voice capability. Applications must authorize any backend actions [Voice server controls](https://developers.openai.com/api/docs/guides/voice-server-controls).
