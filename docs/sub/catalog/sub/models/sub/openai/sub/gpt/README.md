# GPT

GPT is OpenAI’s general-purpose language and multimodal model family. Its represented models support reasoning, coding, analysis, tool use, and conversational work, with capability and access details attached to exact models.

## Profile

GPT-5.6 is represented as a series with three concrete members. GPT-6 Astra, GPT-6 Sol, GPT-6 Luna, and GPT-6.1 Sol are direct concrete members of the family [OpenAI model catalog](https://developers.openai.com/api/docs/models).

## Operating boundaries

ChatGPT is a hosted product surface. Its model routing and dated model updates can differ from the releases exposed through Codex, Work, or an API identifier [October GPT-6 system card](https://deploymentsafety.openai.com/gpt-6-october).

Reasoning effort, processing modes, enabled tools, and multi-agent serving configure an application’s use of a model. They do not establish a new model identity or grant authority to execute an action [Latest-model guide](https://developers.openai.com/api/docs/guides/latest-model).
