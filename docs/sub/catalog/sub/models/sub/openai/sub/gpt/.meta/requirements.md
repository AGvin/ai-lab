# Documentation Requirements

## Requirements

- Identify GPT as OpenAI's general-purpose language and multimodal model family.
- Keep ChatGPT and other product surfaces distinct from the underlying GPT family and concrete model identities.
- Keep exact API identifiers and model aliases on concrete model pages or exact series/model owners.
- Keep mutable product routing, plan labels, pricing, availability, safeguards, and migration guidance outside the canonical family profile.

## Content Specification

- Use `GPT` as the page title.
- Link the canonical OpenAI producer page through the `produced-by` relation.
- State that GPT covers general-purpose reasoning, coding, tool use, analysis, multimodal, and conversational workloads without turning provider positioning into an AI Lab ranking.
- State explicitly that ChatGPT is a hosted assistant product and not the canonical name of the GPT model family.
- Render the GPT-5.6 series and every direct concrete GPT member from current has-member relations; do not invent a GPT-6 series solely from shared numbering.
- Preserve the identity distinction that product routing/reasoning labels are product-level configurations rather than separate GPT families.
- Include the official OpenAI model catalog as the primary research reference.

## Validation

- ChatGPT is not treated as a GPT model family or concrete model.
- Product routing labels are not represented as model identities.
- Mutable product/service properties are not presented as stable GPT-family facts.
- Every current family member resolves to its canonical node without inventing an unsupported GPT-6 series.

## Source-scoped operating boundaries

- ChatGPT is a hosted product surface. Its model routing and dated model updates can differ from the releases exposed through Codex, Work, or an API identifier [October GPT-6 system card](https://deploymentsafety.openai.com/gpt-6-october).
- Reasoning effort, processing modes, enabled tools, and multi-agent serving configure an application’s use of a model. They do not establish a new model identity or grant authority to execute an action [Latest-model guide](https://developers.openai.com/api/docs/guides/latest-model).
