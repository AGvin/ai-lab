# Documentation Requirements

## Requirements

- Identify `text-embedding-3-small` as OpenAI's current smaller/cost-efficient third-generation text embedding model.
- Preserve the current default 1536-dimensional output, 8192-token maximum input, text-only input-to-vector role, and dimension-shortening support only while current first-party documentation supports those facts.
- Present cost/size positioning as provider guidance rather than independent proof of accepted-result economics.
- Keep API pricing, rate limits, batch behavior, encoding format, regional processing, and vector-store integration freshness-sensitive.

## Validation

- The model remains distinct from `text-embedding-3-large`.
- Lower hosted price is not treated as proof of lower accepted-result cost on every retrieval workload.
