# GPT-6 Astra

GPT-6 Astra is the concrete OpenAI model identified as `gpt-6-astra`, released on 2026-09-03. OpenAI positions Astra for demanding reasoning, coding, research, computer use, and document work.

## Profile

The API profile lists text and image input, text output, a 1,050,000-token context window, 128,000-token maximum output, and a April 30, 2026 knowledge cutoff [Model reference](https://developers.openai.com/api/docs/models/gpt-6-astra).

Its documented reasoning effort settings are `low`, `medium`, `high`, `xhigh`, and `max`. Native audio and video are not supported by this model profile [Model reference](https://developers.openai.com/api/docs/models/gpt-6-astra).

## Operating boundaries

Tool use requires Responses; Chat Completions does not support tools for this model. Reasoning effort none and minimal are not supported. [Model reference](https://developers.openai.com/api/docs/models/gpt-6-astra).

Tool calls express proposed actions. The application remains responsible for permissions and for handling untrusted instructions in files, skills, and tool results [Latest-model guide](https://developers.openai.com/api/docs/guides/latest-model).
