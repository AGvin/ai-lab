# GPT-Image-2.5 Flare

GPT Image 2.5 Flare is identified by `gpt-image-2.5-flare`. OpenAI positions Flare for fast image generation and everyday editing.

## Profile

The model accepts text and image input and produces images. The documented pinned snapshot is `gpt-image-2.5-flare-2026-09-08` [Model reference](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare).

The current quality settings are low, medium, high, xhigh, max, and auto; they are output controls within this model identity [Model reference](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare).

## Operating boundaries

Use the image-model identifier at the Image API or as the Responses image tool’s model. A Responses request still uses a supported mainline model to orchestrate that tool [Image-generation guide](https://developers.openai.com/api/docs/guides/image-generation).

Service verification and filtering apply, and the output needs review for instruction fidelity and visual errors. Quality settings and pinned snapshots do not create peer model identities [Image-generation guide](https://developers.openai.com/api/docs/guides/image-generation).
