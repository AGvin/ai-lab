# GPT-5.6

GPT-5.6 is a model series in the GPT family represented by three distinct hosted models: Sol, Terra, and Luna. OpenAI states that `5.6` identifies the generation while Sol, Terra, and Luna are durable capability tiers that can advance on their own cadence.

## Shared series profile

Across the represented GPT-5.6 models, current OpenAI documentation records:

- text and image input with text output;
- multilingual and vision support;
- a 1,050,000-token context window;
- a 128,000-token maximum output;
- a February 16, 2026 knowledge cutoff;
- hosted reasoning-effort controls `none`, `low`, `medium`, `high`, `xhigh`, and `max`.

The API alias `gpt-5.6` routes to GPT-5.6 Sol in the current source. It is routing metadata, not a fourth canonical model entity.
