# GPT-5.6 Sol

GPT-5.6 Sol is the flagship hosted model in the GPT-5.6 series for complex professional work.

## Model series

- [GPT-5.6](../../../..)

## Model profile

- Model ID: `gpt-5.6-sol`
- Routing alias in the current source: `gpt-5.6`
- Input: text and images
- Output: text
- Context window: 1,050,000 tokens
- Maximum output: 128,000 tokens
- Knowledge cutoff: February 16, 2026
- Reasoning effort: `none`, `low`, `medium`, `high`, `xhigh`, `max`
- Fine-tuning: not supported in the current profile

OpenAI positions Sol for complex professional reasoning, coding, research, tool use, computer use, science, cybersecurity, and design. Those are provider claims rather than independent AI Lab acceptance evidence.

## Hosted capabilities

Current provider documentation lists streaming, function calling, structured outputs, image input, web search, file search, image generation, code interpreter, hosted shell, apply patch, skills, computer use, MCP, and tool search among supported hosted capabilities. Feature state can evolve and is not an architectural property of downloadable weights.

## Operating boundaries

gpt-5.6 is a routing alias to gpt-5.6-sol, rather than an additional concrete model [Model reference](https://developers.openai.com/api/docs/models/gpt-5.6-sol).

The August 2026 ChatGPT update is distinguished from earlier releases in the system card. Its evaluation results and deployment behavior should not be assigned automatically to every use of this model name [GPT-5.6 August system card](https://deploymentsafety.openai.com/gpt-5-6-august-update).

Reasoning effort and tool availability are API configuration. Validate tool arguments and application permissions before executing a model-proposed action [Latest-model guide](https://developers.openai.com/api/docs/guides/latest-model).
