# Documentation Requirements

## Requirements

- Identify TTS-1 HD as OpenAI's text-to-speech model optimized for higher-quality speech generation.
- Preserve text input to audio output as the intrinsic modality boundary.
- Preserve current lifecycle: OpenAI deprecated `tts-1-hd` on 2026-10-01 and scheduled API shutdown for 2027-01-06; keep replacement guidance and all service details freshness-sensitive.
- Keep voice inventory, audio formats, Speech endpoint behavior, pricing, rate limits, latency, and recommendation state freshness-sensitive.
- Present quality positioning as provider guidance rather than an independent AI Lab quality ranking.

## Validation

- TTS-1 HD remains distinct from TTS-1 and GPT-4o Mini TTS.
- Deprecated status is explicit and is not described as current recommended routing.
- Endpoint/product behavior is not generalized into permanent model architecture.
- Producer provenance resolves bidirectionally to OpenAI.
