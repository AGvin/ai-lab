# Documentation Requirements

## Requirements

- Identify TTS-1 HD as OpenAI's current text-to-speech model optimized for higher-quality speech generation.
- Preserve text input to audio output as the intrinsic modality boundary.
- Keep voice inventory, audio formats, Speech endpoint behavior, pricing, rate limits, latency, and current recommendation relative to newer speech models freshness-sensitive.
- Present quality positioning as provider guidance rather than an independent AI Lab quality ranking.

## Validation

- TTS-1 HD remains distinct from TTS-1 and GPT-4o Mini TTS.
- Endpoint/product behavior is not generalized into permanent model architecture.
- Producer provenance resolves bidirectionally to OpenAI.
