# GPT-Live-1 mini

GPT-Live-1 mini is the smaller full-duplex voice model identified in OpenAI’s July 2026 GPT-Live release and system card.

## Profile

The system card describes its use in ChatGPT and reports evaluations with the applicable backend and harness. Those conditions are part of interpreting the results [GPT-Live system card](https://deploymentsafety.openai.com/gpt-live).

## Operating boundaries

Public release evidence for this model does not establish general API availability. GPT-Live-1’s API launch and endpoint limits should not be copied to mini [GPT-Live system card](https://deploymentsafety.openai.com/gpt-live).

Product routing and delegated tools remain separate from intrinsic voice capability. Applications must authorize any backend actions [Voice server controls](https://developers.openai.com/api/docs/guides/voice-server-controls).
