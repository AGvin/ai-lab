# GLM Models

Concrete GLM model identities materialized directly under the GLM family when no separate stable series node is required.

## Models

- [GLM-5.3](./sub/glm-5-3/) — released post-trained text model with GLM-5.2 base
- [GLM-5.3-Flash](./sub/glm-5-3-flash/) — independently pretrained, natively multimodal model
- [GLM-5V-Turbo](./sub/glm-5v-turbo/) — hosted vision-oriented coding model
