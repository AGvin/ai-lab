# FLUX 3 Max

FLUX 3 Max is fal Research's separately post-trained video model, developed in collaboration with Black Forest Labs from FLUX 3 Video. fal hosts text-to-video, image-to-video and keyframes-to-video workflows for the same model.

## Model and route boundary

[fal's original announcement](https://fal.ai/blog/introducing-flux-3-max-by-fal) establishes learned post-training as well as inference optimization. The [text route](https://fal.ai/models/blackforestlabs/flux-3-max/text-to-video) calls Max a post-trained FLUX 3 Video variant. Three endpoint workflows, audio switches and reasoning controls do not establish separate learned models. The blackforestlabs API namespace does not establish exclusive BFL production.

## Access, resolution and rights

The documented access is hosted inference. Inspected sources do not establish publicly downloadable Max weights or an Apache-2.0/FLUX Kommunity weight license. API output usage remains subject to [fal terms](https://fal.ai/legal/terms-of-service). Endpoint pages describe 720p generation and optional 1080p upscaling; do not label 1080p as native. Verify current endpoint schemas, processing/privacy behavior and rights for the exact use before submitting confidential inputs or publishing outputs.

## Evidence limitations

Publisher speed and Elo claims conflict across the blog, product and endpoint pages. Do not merge their values into an intrinsic performance guarantee or apply preliminary image-to-video rankings to other workflows. Record exact source date, route, resolution and configuration before comparison; no inference or independent benchmark was performed. Announcement, page-update and promotion dates do not settle earliest public access. Mutable hosted revisions may change without new separately identified checkpoint releases. Current beneficial ownership and indirect stakes are unverified.
