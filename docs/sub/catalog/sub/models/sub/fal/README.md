# fal Models

Model-domain publishing view for fal. The canonical organization profile owns legal identity; this view navigates independently learned fal model identities without turning the hosted platform or individual API routes into models.

## Identity and boundaries

The represented separately post-trained models are FLUX 3 Max (from BFL's FLUX 3 Video) and H3 Max (from MiniMax H3). Both have their own learned identity, upstream lineage and hosted-access/rights boundary. This is not a complete fal research inventory or a hosted-provider comparison.
