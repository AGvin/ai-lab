## Ownership boundary

Reference pages answer what an entity is and what authoritative sources establish about it. They may record identity, lineage, architecture, parameter counts, modalities, context limits, training state, reasoning modes, licenses, intrinsic capabilities, and access relationships when those facts are supported.

Task-specific rankings, hardware-fit judgments, accepted-result conclusions, workload suitability, routing policy, and portfolio recommendations belong under [Model Selection](../selection/) rather than in canonical model profiles.

A provider-side feature or hosted offering is not automatically an intrinsic property of model weights. Versions, derivatives, and artifacts remain distinct identities according to the model taxonomy.
