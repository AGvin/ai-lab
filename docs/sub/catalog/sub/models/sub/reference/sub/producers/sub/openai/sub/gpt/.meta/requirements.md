# Documentation Requirements

## Requirements

- Identify GPT as OpenAI's general-purpose language and multimodal model family.
- Keep ChatGPT and other product surfaces distinct from the underlying GPT family and concrete model identities.
- Preserve the legacy family boundary that exact API identifiers and model aliases belong to concrete model pages or exact generation/tier pages.
- Keep mutable product routing, plan labels, pricing, availability, safeguards, and migration guidance outside the canonical family profile.

## Content Specification

- Use `GPT` as the page title.
- Link the canonical OpenAI producer page through the `produced-by` relation.
- State that GPT covers general-purpose reasoning, coding, tool use, analysis, multimodal, and conversational workloads without turning provider positioning into an AI Lab quality ranking.
- State explicitly that ChatGPT is a hosted assistant product and not the canonical name of the GPT model family.
- Link GPT-5.6 as the currently represented generation.
- Preserve the identity distinction that ChatGPT routing/reasoning labels such as Instant, Medium, High, Extra High, and Pro are product-level configurations rather than separate GPT families.
- Preserve the identity distinction that `chat-latest` is a mutable product/API alias rather than a stable named GPT model.
- Include the official OpenAI model catalog as the primary research reference.

## Excluded Residual Content

Preserve outside this canonical family profile:

- product-plan availability and ChatGPT model-picker behavior;
- pricing, safeguards, regional availability, and feature rollout state;
- recommendations about using `chat-latest` in production;
- migration guidance between GPT generations and reasoning settings;
- Responses API workflow advice;
- model-selection conclusions and workload-specific quality/cost judgments.

## Validation

- ChatGPT is not treated as a GPT model family or concrete model.
- Product routing labels are not represented as model identities.
- Mutable product/service properties are not presented as stable GPT-family facts.
- GPT-5.6 links resolve to the canonical generation node.
