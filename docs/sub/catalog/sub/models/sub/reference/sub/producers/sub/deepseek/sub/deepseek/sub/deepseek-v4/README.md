# DeepSeek-V4

DeepSeek-V4 is a series of Mixture-of-Experts (MoE) language models in the DeepSeek family. DeepSeek's current preview release includes DeepSeek-V4-Pro and DeepSeek-V4-Flash.

## Translations

- English
- [Українська](./l10n/uk_UA/)

## Shared series characteristics

The official V4 model material describes a hybrid attention architecture combining compressed sparse and heavily compressed attention, with million-token context support across the released V4 models.

## Models

- [`DeepSeek-V4-Flash`](./sub/models/sub/deepseek-v4-flash/) — 284B total parameters with 13B activated parameters in the current official model card.
