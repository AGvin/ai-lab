# Claude

Claude is Anthropic's hosted language-model family for conversational, reasoning, coding, and tool-using workloads.

## Family boundary

Claude is the long-lived model family. Sonnet, Opus, Haiku, and other durable Claude lines may be modeled as series when they have multiple distinct model releases. Claude Code, Claude Platform, Anthropic plans, and cloud integrations are product or deployment surfaces rather than model identities.

## Model series

- [Sonnet](./sub/sonnet/) — durable Sonnet line represented here by Claude Sonnet 5.
