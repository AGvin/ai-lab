# Gemma

Gemma is Google's open-weight model family for local, self-hosted, edge, research, and application workflows.

## Family boundary

Gemma is a model family rather than one exact deployment identity. Exact generation, concrete model, instruction variant, artifact, runtime, precision, and modality configuration must be recorded separately when evaluating or deploying a Gemma model.

Gemma's downloadable open-weight distributions are distinct from provider-hosted Gemini model identities.

## Generations

- [Gemma 4](./sub/gemma-4/) — represented multimodal generation with E2B Instruct and E4B Instruct concrete models.

## Provenance boundary

The legacy Gemma 4 source attributes that generation specifically to Google DeepMind. The current catalog does not yet model Google DeepMind as a separate producer entity, so that source-specific provenance is preserved on the Gemma 4 page rather than silently rewritten as a stronger producer relation.

## Scope boundary

This canonical page owns Gemma family identity, broad open-weight access boundary, Google producer relation, and generation navigation. Exact technical profiles, artifacts, runtime compatibility, hardware fit, model selection, and evaluation conclusions belong to generation/concrete model, deployment/workflow, decision-support, or evidence documentation.
