# Documentation Requirements

## Requirements

- List only reviewed downloadable artifacts of the canonical huihui.ai derivative model.
- Distinguish representation/quantization/package identity from trained model identity.
- Keep exact quant type, file size, split layout, runtime compatibility, memory, and quality evidence on exact artifact pages or evidence owners.

## Validation

- Every listed child is an artifact, not a separate model.
- Artifact publication does not imply independently trained weights.
