## Ownership boundary

These pages are model-domain producer views, not duplicate producer profiles. Canonical producer identity belongs under [`catalog/producers/`](../../../../producers/); model views organize only the model entities associated with each producer.

Hosted providers, API products, inference services, model platforms, runtimes, and deployment routes remain separate service/software/access concerns unless a page is specifically documenting a model identity.
