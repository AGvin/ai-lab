# Qwen3-Coder

Qwen3-Coder is a coding-specialized model series in the Qwen family developed by Qwen Team for coding agents and tool-using software-development workflows.

## Series boundary

Qwen Team publishes multiple Qwen3-Coder trained model identities with materially different Mixture of Experts (MoE) scales, architectures, context limits, reasoning modes, and serving requirements. Those concrete properties belong to exact model pages rather than to the series as a whole.

`qwen3-coder-plus` is a hosted Alibaba Cloud Model Studio deployment alias, while Qwen Code is a coding tool. Neither is a replacement identity for this model series or for a concrete downloadable model.

## Models

- [Qwen3-Coder 480B-A35B Instruct](./sub/models/sub/qwen3-coder-480b-a35b-instruct/) — 480B-total/35B-active MoE coding model with 256K native context.
- [Qwen3-Coder 30B-A3B Instruct](./sub/models/sub/qwen3-coder-30b-a3b-instruct/) — distinct 30.5B-total/3.3B-active MoE coding model with 262,144-token native context and non-thinking-only operation.
- [Qwen3-Coder-Next](./sub/models/sub/qwen3-coder-next/) — separate 80B-total/3B-active hybrid-attention MoE coding-agent model with 262,144-token native context.

Active-parameter counts are execution characteristics of these MoE models; they are not total model size, storage, or VRAM requirements and must not be used to collapse these concrete identities into dense-model equivalents.
