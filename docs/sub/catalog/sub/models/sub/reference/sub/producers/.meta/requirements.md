# Documentation Requirements

## Requirements

- Present only materialized model-domain producer views under Model Reference.
- Distinguish model-domain producer views from canonical producer-organization profiles.
- Link all currently materialized producer views without implying that the list exhausts every producer that may later be documented.
- Keep service providers, hosted access, runtimes, and model-platform concerns outside this model-reference index unless they also own a canonical model producer view.
- Mark still-provisional community-derived views descriptively rather than presenting their current control bundles as final architecture.

## Validation

- Every listed producer-view link resolves on the current branch.
- Canonical producer identity is linked to `catalog/producers/` rather than duplicated here.
- The index contains no stale pre-`reference/` model paths.
