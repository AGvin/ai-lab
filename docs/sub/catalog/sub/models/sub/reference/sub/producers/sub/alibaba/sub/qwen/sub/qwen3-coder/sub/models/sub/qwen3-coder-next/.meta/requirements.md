# Documentation Requirements

## Requirements

- Identify Qwen3-Coder-Next as a concrete open-weight coding-agent model in the Qwen3-Coder line.
- Preserve intrinsic model facts from the legacy Qwen3-Coder-Next profile.
- Keep runtime deployment instructions, hardware fit, contextual scale/frontier/ecosystem classifications, and workload-quality conclusions outside the canonical model profile unless separately owned.

## Content Specification

- Use `Qwen3-Coder-Next` as the page title.
- Link the canonical Qwen3-Coder model line.
- Describe the model as a causal language model using a hybrid Gated DeltaNet, gated-attention, and Mixture of Experts architecture.
- Preserve 80B total parameters and 3B active parameters.
- Preserve the 262,144-token native context length.
- Preserve Apache-2.0 licensing and non-thinking-only reasoning mode.
- Preserve the official `Qwen/Qwen3-Coder-Next` model page and technical report.
- State that 3B active parameters do not represent total storage, RAM, VRAM, or dense-model equivalence.
- Present coding-agent, long-horizon coding, complex tool-use, and execution-recovery suitability as provider-described intent rather than independently validated AI Lab quality.

## Excluded Residual Content

Preserve outside this canonical model profile:

- the contextual AI Lab `LLM` classification plus frontier and ecosystem status;
- direct-use and serving instructions for Transformers, SGLang, and vLLM;
- tensor-parallel deployment guidance and context-reduction advice for startup or out-of-memory failures;
- consumer-GPU fit and quantized-artifact deployment conclusions;
- task-specific coding quality, serving behavior, hardware fit, and other evaluation results.

## Validation

- 80B total and 3B active parameter counts remain distinct.
- The page does not treat the model as equivalent to a 3B dense model.
- Provider intent is not presented as benchmarked AI Lab evidence.
- Runtime and hardware guidance is not presented as intrinsic model identity.
- Internal links resolve to canonical nodes.
