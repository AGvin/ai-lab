# Documentation Requirements

## Requirements

- Introduce Qwen3-Coder as the code-focused Qwen model line represented in this catalog.
- Expose its canonical Qwen-family membership and Qwen Team producer relations.
- Preserve line-level identity boundaries from the legacy Qwen3-Coder documentation without transferring one concrete model's specifications to the whole line.
- Keep model-selection, hosted deployment, runtime, frontier, ecosystem, and workload-quality conclusions outside the canonical model-line profile unless a future architecture decision assigns them here.

## Content Specification

- Use `Qwen3-Coder` as the page title.
- Describe the line as specialized for coding agents and tool-using software-development workflows.
- Link Qwen Team through the canonical producer relation and Qwen through the canonical family relation.
- Include the official Qwen3-Coder repository and launch reference.
- Link the concrete-model index containing the represented Qwen3-Coder 480B-A35B Instruct and Qwen3-Coder-Next models.
- State that concrete descendants may have materially different total and active parameter counts, architecture details, and context limits; these must be documented on the exact model.
- Preserve the identity distinction that `qwen3-coder-plus` is a hosted Alibaba Cloud Model Studio deployment alias and Qwen Code is a coding tool rather than canonical base-model identities, without expanding this page into service or software documentation.

## Excluded Residual Content

The legacy line page also contains contextual LLM/frontier/ecosystem classifications, evaluation-resolution guidance, hosted deployment details, and model-selection conclusions. Preserve those concerns for future classification/reference, service/deployment, decision-support, or evidence ownership rather than presenting them as intrinsic line facts.

## Validation

- The page does not duplicate the Qwen Team producer profile.
- Producer and parent-family relations resolve to canonical nodes.
- Specifications for Qwen3-Coder 480B-A35B Instruct or Qwen3-Coder-Next are not generalized to every Qwen3-Coder descendant.
- Hosted aliases and coding tools are not treated as aliases of the canonical model line.
