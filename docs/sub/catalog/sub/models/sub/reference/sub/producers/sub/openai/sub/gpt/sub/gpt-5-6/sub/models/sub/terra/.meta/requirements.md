# Documentation Requirements

## Requirements

- Identify GPT-5.6 Terra as the balanced concrete tier of the GPT-5.6 generation.
- Preserve exact model/API identity and provider-documented tier capabilities from the legacy Terra page.
- Keep pricing, long-context pricing multipliers, selection guidance, and workload-specific quality/cost conclusions outside the canonical model profile.

## Content Specification

- Use `GPT-5.6 Terra` as the page title.
- Link the canonical GPT-5.6 generation.
- Preserve the model ID `gpt-5.6-terra`.
- Preserve Terra's provider positioning as the balanced capability-and-cost tier for professional hosted workloads.
- Preserve text and image input, text output, 1,050,000-token context, 128,000-token maximum output, February 16, 2026 knowledge cutoff, and documented reasoning-token support.
- Preserve provider-documented hosted capabilities including streaming, function calling, structured outputs, web search, file search, image generation, code interpreter, hosted shell, apply patch, computer use, MCP, and tool search.
- Preserve that fine-tuning is not supported in the documented model profile.
- Include the official Terra model page.

## Excluded Residual Content

Preserve outside this canonical model profile:

- token pricing and long-context pricing multipliers;
- recommendations to choose Terra for capability-cost balance, primary workloads, or fallback strategy;
- workload-specific quality, latency, reliability, escalation frequency, and accepted-result-cost conclusions.

## Validation

- Provider positioning is not presented as independent AI Lab quality evidence.
- Pricing is not treated as model identity.
- Hosted capability support is distinguished from architectural facts.
- Terra remains a separate concrete model entity from Sol and Luna.
