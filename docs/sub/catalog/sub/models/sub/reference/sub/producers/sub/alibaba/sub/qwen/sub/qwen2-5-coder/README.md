# Qwen2.5-Coder

## Line profile

The represented Qwen2.5-Coder line includes base and instruction-tuned coding models using a dense decoder-only Transformer architecture family and downloadable open-weight distributions.

Exact parameter counts, context length, training stage, and license belong to each concrete model rather than being generalized across the line.
