# AI21 Labs models

AI21 Labs models is the model-domain navigation view for model identities published by AI21 Labs. It currently links the represented Jamba2 family and the separate canonical producer profile. [Primary source](https://www.ai21.com/)

## Model scope

The represented family is Jamba2, introduced by AI21 Labs in January 2026. This page is navigation for the materialized catalog scope, not a claim to enumerate every AI21 release. Canonical producer information remains on the linked producer profile. [Jamba2 release](https://www.ai21.com/blog/introducing-jamba2/)

## Access boundary

Use each concrete model page for its published weights, license and deployment constraints.
