# K-EXAONE 2.0

K-EXAONE 2.0 is LG AI Research's 750-billion-parameter foundation model released on 31 July 2026 under Korea's Sovereign AI Foundation Model Project.

LG's official release announcement identifies Apache-2.0 as the model's license, including commercial use subject to that license's terms. This release-specific statement does not establish the license of earlier K-EXAONE checkpoints.

Published benchmark comparisons are LG's evaluations of this release, not independently reproduced measurements. Parameter count does not establish memory fit, throughput or deployment requirements. Quantized packages, runtime support and hosted access require separate, current verification.

The [official model card](https://huggingface.co/LGAI-EXAONE/K-EXAONE-2.0-750B-A37B) specifies a Mixture-of-Experts architecture with **750B total parameters**, **37B active parameters** and a **262,144-token context**. These are LG-reported specifications. Active parameters do not represent the complete weight-storage footprint. LG describes upcycling the earlier K-EXAONE model followed by further training; this does not make the two releases interchangeable.
