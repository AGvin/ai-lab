# K-EXAONE 2.0

K-EXAONE 2.0 is LG AI Research's 750-billion-parameter foundation model released on 31 July 2026 under Korea's Sovereign AI Foundation Model Project.

LG's official release announcement identifies Apache-2.0 as the model's license, including commercial use subject to that license's terms. This release-specific statement does not establish the license of earlier K-EXAONE checkpoints.

Published benchmark comparisons are LG's evaluations of this release, not independently reproduced measurements. Parameter count does not establish memory fit, throughput, active parameter count or deployment requirements. Quantized packages, runtime support and hosted access require separate, current verification.
