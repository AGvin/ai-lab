# GPT-5.6

GPT-5.6 is a GPT generation represented by three named hosted model tiers: Sol, Terra, and Luna.

## Shared model profile

Across the represented GPT-5.6 tiers, the legacy model documentation records:

- text and image input with text output;
- multilingual and vision support;
- a 1,050,000-token context window;
- a 128,000-token maximum output;
- a February 16, 2026 knowledge cutoff;
- hosted reasoning-effort controls `none`, `low`, `medium`, `high`, `xhigh`, and `max`.

The API alias `gpt-5.6` routes to GPT-5.6 Sol in the documented source. It is a mutable routing alias, not a fourth canonical model entity.
