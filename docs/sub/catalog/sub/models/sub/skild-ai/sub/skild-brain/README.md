# Skild Brain

**Skild Brain** is Skild AI's omni-bodied robotics foundation-model family, intended to generalize across different robot embodiments and manipulation, navigation and locomotion tasks. Skild describes a hierarchical high-level task policy and low-level motor-control policy; this is publisher architecture research, not evidence that every robot or task is supported without validation.

## Model hierarchy and boundaries

The concrete [S1 model](./sub/models/sub/s1/) is a separately published member whose demonstrated in-context learning capabilities are specific to S1's research scope. Robot hardware, control interfaces, deployment safety, customer integration, and NVIDIA compute infrastructure are not interchangeable with model-family identity or ownership.
