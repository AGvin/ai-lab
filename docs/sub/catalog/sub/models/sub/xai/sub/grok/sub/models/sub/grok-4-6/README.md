# Grok 4.6

Grok 4.6 is the Grok model released on August 12, 2026 for coding, agentic tasks, and knowledge work.

## Profile

The model reference documents text and image input, text output, a 500,000-token context window, tool calling, structured output, and four reasoning-effort levels: low, medium, high, and xhigh. [Model reference](https://docs.x.ai/developers/models/grok-4.6).

## Operating boundaries

Grok 4.6 remains separately documented after the release of Grok 4.7; it is not the current default recommendation in the model selector. [Model selector](https://docs.x.ai/developers/models).

Batch API support is not listed for this endpoint. The reference applies higher input pricing above 200,000 prompt tokens, so context capacity and price tier are separate limits. [Model reference](https://docs.x.ai/developers/models/grok-4.6).
