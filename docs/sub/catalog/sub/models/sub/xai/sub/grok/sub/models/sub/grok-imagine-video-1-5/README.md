# Grok Imagine Video 1.5

Grok Imagine Video 1.5 is a released Grok video-generation model. Its preview spelling remains a documented alias of the stable serving name.

## Profile

The model reference lists text, image, and preset-voice audio input with video output. Native 1080p applies to text-to-video and image-to-video; reference-to-video is limited to 720p. [Model reference](https://docs.x.ai/developers/models/grok-imagine-video-1.5); [Generation guide](https://docs.x.ai/developers/model-capabilities/video/generation).

## Operating boundaries

Generation is asynchronous and returns temporary media URLs. Video editing and extension use the older grok-imagine-video surface in the current guide; those tasks must not be generalized to Video 1.5. [Generation guide](https://docs.x.ai/developers/model-capabilities/video/generation).

Video 1.5 Lite is a separate lower-cost option for text-to-video and image-to-video. Its 1080p output is upscaled, so the two models do not share the same native-resolution claim. [Generation guide](https://docs.x.ai/developers/model-capabilities/video/generation).
