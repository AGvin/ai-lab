# Grok

Grok is the model family produced by SpaceXAI LLC, publicly branded SpaceXSI. This family covers model identities; the Grok assistant is a separate service.

## Profile

The catalog members below cover language and coding, image and video generation, speech-to-speech, and transcription. Each concrete page owns its supported modalities and limits. [Model selector](https://docs.x.ai/developers/models).

## Operating boundaries

API access is governed by the enterprise terms. Consumer Grok subscriptions and third-party application plans do not establish the same access entitlement. [Enterprise terms](https://x.ai/legal/terms-of-service-enterprise).

The API security FAQ distinguishes training from retention: inputs and outputs are not used for training without permission, but default audit storage lasts 30 days. Team-level zero data retention disables storage-dependent capabilities, including stored media outputs. [API security FAQ](https://docs.x.ai/developers/faq/security).

Current API aliases can change their target. Published release and retirement notices must be checked for the exact identifier; provider recommendation, deprecation, and shutdown are separate lifecycle states. [API release notes](https://docs.x.ai/developers/release-notes).
