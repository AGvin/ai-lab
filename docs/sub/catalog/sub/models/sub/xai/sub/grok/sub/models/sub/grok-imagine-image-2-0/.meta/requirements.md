# Documentation Requirements

## Requirements

- Identify Grok Imagine Image 2.0 as xAI's current recommended image-generation and image-editing model.
- Preserve text/image input to image output, current multi-reference editing, and current supported resolution/quality classes only while first-party documentation supports those facts.
- Keep Imagine API endpoint behavior, pricing, output storage, batch support, aspect ratios, response formats, clusters, and rate limits freshness-sensitive.
- Keep earlier `grok-imagine-image` and `grok-imagine-image-quality` variants as lifecycle/legacy context rather than peer nodes while current guidance selects Image 2.0 for primary image generation/editing.
- Attribute speed/quality positioning to xAI rather than independent AI Lab ranking evidence.

## Validation

- The entity remains a trained media model rather than the Imagine API itself.
- Legacy/superseded variants are not duplicated solely for completeness.
