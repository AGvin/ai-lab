- Identify Grok 4.7 as the concrete `grok-4.7` model released to the xAI API on 2026-09-21.
- Preserve current provider-documented 500K context, text/image input, text output, and `low` / `medium` / `high` / `xhigh` reasoning-effort support only while current first-party documentation supports those facts.
- Present coding, agentic-task, and knowledge-work positioning as xAI claims rather than independent AI Lab rankings.
