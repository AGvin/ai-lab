# Grok Imagine Video 1.5 Lite

Grok Imagine Video 1.5 Lite is a separately documented Grok video model positioned by the provider as a lower-cost choice for simple videos.

## Profile

The model reference documents text and image input with video output, availability in two US clusters, and Batch API support. [Model reference](https://docs.x.ai/developers/models/grok-imagine-video-1.5-lite).

## Operating boundaries

Text-to-video and image-to-video can deliver 1080p by upscaling 720p. Do not apply Video 1.5's native 1080p or reference-audio capabilities to Lite. [Generation guide](https://docs.x.ai/developers/model-capabilities/video/generation).

Pricing varies with resolution, and generation uses asynchronous requests. The published per-second rates are service terms rather than permanent model properties. [Model reference](https://docs.x.ai/developers/models/grok-imagine-video-1.5-lite).
