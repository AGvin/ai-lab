## Source-scoped operating boundaries

- The published migration keeps the same API endpoint, session parameters, and events. Deprecation does not by itself establish a shutdown date. [Voice migration guide](https://docs.x.ai/developers/model-capabilities/audio/speech-to-speech#upgrading-from-grok-voice-20).
