# Grok Voice 2.0

Grok Voice 2.0 is the previous-generation Grok speech-to-speech model announced on July 29, 2026. Its existing catalog path is retained for continuity.

## Profile

The official release announcement names the serving identifier grok-voice-2.0 and describes speech reasoning, conversation, and tool use. [Release announcement](https://x.ai/news/grok-voice-think-fast-2).

## Operating boundaries

Voice 2.0 was deprecated on October 14, 2026. The mutable grok-voice-latest alias now selects Voice 3.0; a pinned Voice 2.0 integration must select the newer identifier to migrate. [API release notes](https://docs.x.ai/developers/release-notes).

The published migration keeps the same API endpoint, session parameters, and events. Deprecation does not by itself establish a shutdown date. [Voice migration guide](https://docs.x.ai/developers/model-capabilities/audio/speech-to-speech#upgrading-from-grok-voice-20).
