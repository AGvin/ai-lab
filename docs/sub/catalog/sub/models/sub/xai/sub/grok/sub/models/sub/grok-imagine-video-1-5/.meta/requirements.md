# Documentation Requirements

## Requirements

- Identify Grok Imagine Video 1.5 as xAI's current recommended concrete video-generation model; current first-party model documentation uses the stable model name while retaining `grok-imagine-video-1.5-preview` as an alias.
- Preserve current text-to-video, image-to-video, reference-to-video, optional preset-voice input, and up-to-1080p support only while first-party documentation supports those facts.
- Keep Imagine API polling/storage behavior, duration/resolution options, pricing, clusters, batch support, and generation/editing/extension endpoint behavior freshness-sensitive.
- Keep earlier `grok-imagine-video` as a lower-cost older model surface rather than materializing it solely for completeness while current use-case guidance selects Video 1.5.
- Attribute quality/speed claims to xAI rather than independent AI Lab ranking evidence.

## Validation

- Preview alias naming is not mistaken for an unreleased model when current first-party documentation presents the underlying 1.5 model as available/current.
- The model is not conflated with the Imagine API service surface.
