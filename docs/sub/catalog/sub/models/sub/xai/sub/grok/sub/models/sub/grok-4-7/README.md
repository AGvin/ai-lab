# Grok 4.7

Grok 4.7 is the concrete Grok model released on September 21, 2026 for coding, agentic tasks, and knowledge work.

## Profile

The API reference specifies text and image input, text output, a 500,000-token context window, tool calling, structured output, and low, medium, high, or xhigh reasoning effort. [Model reference](https://docs.x.ai/developers/models/grok-4.7).

## Operating boundaries

Grok 4.7 Fast uses the same model and is distributed through Cursor and Grok Build rather than a separate public API model. It therefore has no additional trained-model entry. [Release notes](https://docs.x.ai/developers/release-notes).

The documented API endpoint does not support Batch API. Higher pricing begins above 200,000 prompt tokens, and Responses API reasoning-envelope behavior is an integration detail rather than a model variant. [Model reference](https://docs.x.ai/developers/models/grok-4.7).
