# xAI models

This is the model-domain view for the xAI continuity namespace. The current public brand is SpaceXSI; the canonical producer profile identifies SpaceXAI LLC. [Official terms](https://x.ai/legal/terms-of-service).

## Profile

The Grok family below groups the represented language, coding, image, video, and speech models. Model entries describe their own tasks and boundaries. [Official model selector](https://docs.x.ai/developers/models).

## Operating boundaries

The provider's API documentation describes hosted access, while the Grok assistant and Grok Build application are separate product surfaces. A model listing is not evidence of downloadable weights or an open weight license. [API overview](https://x.ai/api).
