# Tencent models

The Tencent model-domain view provides a curated entry to the [Tencent Hy family](./sub/hy/), whose publishing team is **Tencent Hy Team**. It is a catalog navigation node, not a separate corporate producer or hosted service. Hy3 and Hy4 preview are distinct trained checkpoints with different release and lifecycle status.

## Child pages

## Access and evidence boundary

Tencent's application integrations (WorkBuddy, CodeBuddy and other products), cloud TokenHub/OpenRouter API routes, quotas and prices are separate from the weights and identities represented here. Verify the exact release and serving route independently; the term *preview* on Hy4 does not mean that its published open-source weights are unavailable.
