# Tencent Hy3

**Tencent Hy3** is the stable Tencent Hy Team Mixture-of-Experts reasoning and agent model officially released on **July 6, 2026**. Its independently published checkpoint contains **295 billion total / 21 billion active parameters**, supports **up to 256K context** and is distributed under **Apache-2.0**. It is not the April 2026 **Hy3 preview** release and is distinct from August's Hy4 preview.

## Model, evaluation and service boundaries

Tencent describes a hybrid fast/slow-thinking design with improved agent and software-engineering workflows, including coding, document/office work and multi-step tools. Its enhanced quality, stability, cost-efficiency and benchmark comparisons are **publisher claims**, not independent AI Lab results.

The trained weights are separate from commercial integrations with WorkBuddy, CodeBuddy, Yuanbao, Marvis or other products, and from Tencent Cloud TokenHub, OpenRouter and other API routes. Hosted availability, quotas, pricing, inference throughput and runtime fit change independently of this trained identity. The model card's parameter counts, license and context do not establish memory or performance for any particular hardware configuration.
