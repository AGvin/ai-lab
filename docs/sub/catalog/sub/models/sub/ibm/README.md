# IBM Granite models

This node organizes the IBM Granite model families currently materialized in AI Lab. It is a model-domain view rather than a second IBM company profile.

The catalog keeps language reasoning, embeddings, safety judging, speech recognition, time-series modeling, and document vision as separate families because their inputs, operating contracts, licenses, and deployment boundaries differ. Joint IBM-NASA research models remain under the separate IBM-NASA collaborative namespace.

## Model families

- [Granite 4.2](./sub/granite-4-2/) — dense reasoning language models.
- [Granite 4.1](./sub/granite-4-1/) — instruction-tuned language models and pretrained bases.
- [Granite 4.0 Nano](./sub/granite-4-0-nano/) — compact dense and hybrid language models.
- [Granite Switch 4.1](./sub/granite-switch-4-1/) — composed chat, decision, guardian and speech checkpoints.
- [Granite Docling](./sub/granite-docling/) — document conversion model.
- [Granite Embedding English R2](./sub/granite-embedding-english-r2/) — English retrieval and reranking.
- [Granite Embedding Multilingual R2](./sub/granite-embedding-multilingual-r2/) — multilingual text embeddings.
- [Granite Guardian 4.1](./sub/granite-guardian-4-1/) — safety and criteria judging.
- [Granite Guardian HAP](./sub/granite-guardian-hap/) — compact harmful-content classifiers.
- [Granite Speech 5.0](./sub/granite-speech-5/) — automatic speech recognition checkpoints.
- [Granite Speech 4.1](./sub/granite-speech-4-1/) — speech recognition models.
- [Granite Time Series](./sub/granite-timeseries/) — forecasting and adjacent time-series tasks.
- [Granite Vision 4.1](./sub/granite-vision-4-1/) — structured visual document understanding.
- [Granite Vision 3.3](./sub/granite-vision-3-3/) — image-to-text and document retrieval.
