# Granite 4.2 30B

Granite 4.2 30B is the largest 30B-class member of the materialized IBM Granite 4.2 family, released on 25 August 2026.

Its official card documents Apache-2.0 weights, native 128K context with a supported long-context extension to 512K, built-in thinking modes, tool calling, coding, and agentic workflows. The card lists twelve tested languages and names Granite 4.1 30B Base as its source model.

Quantized and serving-specific builds remain artifacts of this model. Tool execution belongs to the application, and published benchmark or long-context claims are not treated as locally reproduced results.
