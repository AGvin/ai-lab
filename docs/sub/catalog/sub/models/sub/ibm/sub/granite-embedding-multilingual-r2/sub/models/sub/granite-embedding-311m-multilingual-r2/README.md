# Granite Embedding 311M Multilingual R2

Granite Embedding 311M Multilingual R2 is the larger member of IBM's R2 multilingual embedding family.

Its official card documents a 32,768-token maximum sequence length, 768-dimensional embeddings and Matryoshka outputs at 768, 512, 384, 256 and 128 dimensions. The 97M R2 card explicitly describes deriving the smaller model from this checkpoint by layer pruning and vocabulary selection.

The weights state Apache 2.0. Published multilingual retrieval results and supported sequence length do not guarantee quality for every corpus or throughout the full window.
