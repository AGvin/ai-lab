# Granite Vision 4.1 4B

Granite Vision 4.1 4B is IBM Research's 29 April 2026 vision-language model for structured document extraction and general image-to-text tasks.

The official card describes a 3.4B language component plus a 0.6B vision encoder and projectors, fine-tuned on Granite 4.1 3B, with Apache-2.0 weights. Supported document tasks include chart extraction, table extraction and schema-driven key-value extraction, activated through model prompting/task tags.

Docling integration, serving backends and quantized distributions are operational choices rather than additional model identities. Published extraction benchmarks are evaluation results, not guarantees for arbitrary documents.
