# Granite 4.2 8B

Granite 4.2 8B is the mid-size 8B-class member of IBM's Granite 4.2 dense reasoning family, released on 25 August 2026.

Its official card documents Apache-2.0 weights, native 128K context with a supported long-context extension to 512K, built-in thinking modes, tool calling, coding, and agentic workflows. The card lists twelve tested languages and names Granite 4.1 8B Base as its source model.

Quantized and serving-specific builds remain artifacts of this model. Tool calls require an execution harness, and supported long context does not establish application quality at every length.
