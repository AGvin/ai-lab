# Granite Embedding 97M Multilingual R2

Granite Embedding 97M Multilingual R2 is IBM's smaller R2 multilingual embedding model.

The official card documents a 32,768-token maximum sequence length and 384-dimensional embeddings. It explicitly describes deriving this checkpoint from Granite Embedding 311M Multilingual R2 by pruning layers and selecting a smaller vocabulary. The 97M model does not inherit the 311M model's Matryoshka dimension contract.

Weights state Apache 2.0. Published multilingual coverage and retrieval benchmarks are not universal guarantees for a specific corpus.
