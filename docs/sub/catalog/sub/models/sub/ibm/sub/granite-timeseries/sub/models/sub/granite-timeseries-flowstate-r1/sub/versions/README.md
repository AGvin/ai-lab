# Granite TimeSeries FlowState R1 Versions

This is the chronological release index for the single **Granite TimeSeries FlowState R1** concrete model. These releases are versions of the same model, not separately counted trained-model identities or parameter-size families.

## Releases

- [Version 1.0 — default repository release](./sub/r1-0/): the original checkpoint loaded when no revision selector is supplied.
- [Version 1.1 — explicit `r1.1` revision](./sub/r1-1/): a materially updated release selected with `revision="r1.1"`.

Release-specific context lengths, parameter counts and architecture changes belong to their respective version pages. Model-wide zero-shot forecasting, sampling-rate and seasonality scaling, and forecast-horizon guidance remain on the [FlowState R1 model page](../../).
