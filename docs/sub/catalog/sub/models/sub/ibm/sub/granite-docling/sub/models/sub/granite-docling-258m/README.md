# Granite Docling 258M

IBM image-text model for structured document conversion, including tables, layout, and equations. The checkpoint uses Idefics3, SigLIP2 and Granite components. Validate structured output and transcription on representative documents. Experimental language capabilities are not general multilingual certification.
