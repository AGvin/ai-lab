# Documentation Requirements

## Requirements

- Identify Granite Time Series as IBM's open Granite time-series foundation-model family covering forecasting and adjacent time-series tasks.
- Materialize current materially distinct PatchTST-FM, Tiny Time Mixer, TSPulse, and FlowState model identities rather than treating the family as one interchangeable checkpoint.
- Preserve revision-sensitive behavior such as FlowState r1.1 as revision state on the canonical model identity rather than inventing a separate family.
- Treat task support, context, horizons, benchmark results, revisions, Confluent/hosted availability, and runtime integrations as freshness-sensitive.

## Validation

- Producer provenance resolves to IBM.
- Hosted Early Access integrations are not conflated with model-release lifecycle.
