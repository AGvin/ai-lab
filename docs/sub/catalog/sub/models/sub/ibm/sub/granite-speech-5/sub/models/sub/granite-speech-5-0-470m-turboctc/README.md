# Granite Speech 5.0 470M TurboCTC

Granite Speech 5.0 470M TurboCTC is IBM's standard 470M-class Granite Speech 5 automatic-speech-recognition checkpoint.

The current card, updated on 21 October 2026, explicitly lists seven languages: English, French, German, Spanish, Portuguese, Italian and Japanese. An earlier English-only revision remains historical state of the same model identity.

The weights state Apache 2.0. The generic multilingual registry tag is not used to invent additional supported languages beyond the card's explicit list. Accuracy, punctuation/capitalization, latency and streaming fit still require representative audio evaluation.
