# Granite 4.0 350M Base

Granite 4.0 350M Base is an IBM dense base language model in the Granite 4.0 Nano family. This base-weight release is intended for adaptation; do not assume instruction-following behavior equivalent to the instruct release.

## Identity and deployment boundaries

This dense base checkpoint is a separate trained-model identity. Verify model-specific architecture support in the chosen runtime, and measure task quality, memory use, and latency on the target hardware. Parameter class alone does not establish deployment suitability.
