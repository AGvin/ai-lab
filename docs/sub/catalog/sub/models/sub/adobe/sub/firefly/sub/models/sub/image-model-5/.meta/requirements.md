- Identify Firefly Image Model 5 as the Adobe-trained concrete model, separate from Image Model 4, 4 Ultra, partner models and the Firefly application.
- Use the 19 March 2026 general-availability statement as current lifecycle evidence; retain October 2025 public beta only as release history.
- Record Adobe's native 4-megapixel generation and prompt-based image-editing description with correct units; do not substitute 4K, infer undisclosed parameter counts or treat planned layered editing as shipped model functionality.
- Keep custom-model training, editing UI features, API availability, plans and commercial-use conditions scoped to their product surfaces.
- Explain task-specific image/edit evaluation, input-asset rights and generated-content review; attribute safety and quality positioning to Adobe.
- Realize a complete English reader with the canonical identity, the operational boundaries above, valid internal navigation and cited official sources; do not advertise nonexistent localized readers.

## Validation

- Preserve the canonical ID, name and type; validate the complete entity against the current repository schema.
- Verify every declared outgoing relation, its exact inverse when required, and all displayed reader targets.
