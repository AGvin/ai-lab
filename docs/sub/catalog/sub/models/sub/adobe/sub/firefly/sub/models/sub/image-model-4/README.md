# Firefly Image Model 4

Firefly Image Model 4 is Adobe's image-generation model made generally available on 24 April 2025. Adobe positions it for fast ideation and everyday image work, with outputs up to 2K in the launch documentation. [Primary source](https://news.adobe.com/news/2025/04/adobe-revolutionizes-ai-assisted-creativity-firefly)

## Identity and capabilities

Adobe released Image Model 4 on 24 April 2025 and described output up to 2K. Its emphasis on fast exploration is Adobe's positioning; suitability still depends on the desired images. Image Model 4 Ultra and Image Model 5 remain separate trained-model identities. [Release and output description](https://news.adobe.com/news/2025/04/adobe-revolutionizes-ai-assisted-creativity-firefly) · [Adobe model positioning](https://blog.adobe.com/en/publish/2025/04/24/adobe-firefly-next-evolution-creative-ai-is-here)

## Access and evaluation

The current Firefly web guide lists Image 4 as a selectable Adobe model. Model-specific settings and product integrations can change. Compare prompt adherence, reference fidelity, fine detail and unacceptable outputs on your own examples, and check the selected feature's terms and reference-asset rights. Access through an Adobe product does not establish a downloadable weight release or support in every Firefly API. [Current image generation guide](https://helpx.adobe.com/firefly/web/work-with-images/generate-images/generate-images-from-text-descriptions.html) · [Usage FAQ](https://helpx.adobe.com/firefly/web/get-started/learn-the-basics/adobe-firefly-faq.html)
