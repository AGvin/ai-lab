# Firefly Image Model 5

Firefly Image Model 5 is Adobe's distinct image-generation and editing model. It entered public beta in October 2025, and Adobe explicitly announced general availability on 19 March 2026. Adobe's original specification describes native 4-megapixel output, not 4K output. [Source 1](https://news.adobe.com/news/2025/10/adobe-max-2025-firefly) · [Source 2](https://blog.adobe.com/en/publish/2026/03/19/adobe-firefly-expands-video-image-creation-with-new-ai-capabilities-custom-models)

## Release and identity

Adobe introduced Image Model 5 in public beta in October 2025 and explicitly described it as generally available on 19 March 2026. The current Firefly web model selector lists Image 5 as an Adobe model. [Original announcement](https://news.adobe.com/news/2025/10/adobe-max-2025-firefly) · [General availability](https://blog.adobe.com/en/publish/2026/03/19/adobe-firefly-expands-video-image-creation-with-new-ai-capabilities-custom-models) · [Current model selector](https://helpx.adobe.com/firefly/web/work-with-images/generate-images/generate-images-from-text-descriptions.html)

## Generation and editing

Adobe describes native 4-megapixel image generation and editing through natural-language prompts. Four megapixels is an image pixel count and must not be relabeled as 4K resolution. The original announcement's planned layered-editing feature is not evidence that every such feature is available in every surface. [Model capabilities and original feature scope](https://news.adobe.com/news/2025/10/adobe-max-2025-firefly)

## Access and evaluation

Select the exact Adobe model and product surface, then test prompt adherence, edit localization, retained details and unwanted changes on representative inputs. Verify current API or editor support and the rights to supplied images. Adobe's commercial-safety positioning and application policies do not establish a universal guarantee for generated assets or a public self-hosting weight release. [Current image guide](https://helpx.adobe.com/firefly/web/work-with-images/generate-images/generate-images-from-text-descriptions.html) · [Adobe usage FAQ](https://helpx.adobe.com/firefly/web/get-started/learn-the-basics/adobe-firefly-faq.html)
