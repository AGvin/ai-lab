# Firefly Image Model 4 Ultra

Firefly Image Model 4 Ultra is Adobe's separately named image-generation model, generally available from 24 April 2025. Adobe positions Ultra for detailed, complex scenes and photorealistic results. [Primary source](https://news.adobe.com/news/2025/04/adobe-revolutionizes-ai-assisted-creativity-firefly)

## Identity and capabilities

Adobe introduced Image Model 4 Ultra alongside Image Model 4 on 24 April 2025. Adobe describes Ultra as intended for demanding detail, complex compositions and photorealistic images. These are vendor claims to test against the intended work; the name alone does not disclose its architecture or parameter count. [General-availability announcement](https://news.adobe.com/news/2025/04/adobe-revolutionizes-ai-assisted-creativity-firefly) · [Ultra positioning](https://blog.adobe.com/en/publish/2025/04/24/adobe-firefly-next-evolution-creative-ai-is-here)

## Access and evaluation

The current Firefly web guide lists Image 4 Ultra independently from Image 4 and Image 5. Compare composition, small details, faces and reference fidelity using the same prompts and controls. Verify the selected product or API, settings, credit treatment and rights to supplied assets before use; do not assume every Adobe integration exposes the same model choices. [Current model selection](https://helpx.adobe.com/firefly/web/work-with-images/generate-images/generate-images-from-text-descriptions.html) · [Usage FAQ](https://helpx.adobe.com/firefly/web/get-started/learn-the-basics/adobe-firefly-faq.html)
