# PPLX Embed V2 Late 9B

PPLX Embed V2 Late 9B is the larger MIT-licensed multimodal retrieval artifact, with about 7.4 billion active parameters and a 128-dimensional vector for each token.

## Use and deployment boundaries

Use multivector encoding and MaxSim scoring, with the exact runtime and token-marker conventions in its model card. Keep text and image batches separate. Its shared space with the 0.6B member does not establish equal latency, memory use or retrieval quality.
