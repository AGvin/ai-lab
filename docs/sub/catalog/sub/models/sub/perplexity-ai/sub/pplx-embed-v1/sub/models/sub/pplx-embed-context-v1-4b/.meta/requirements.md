# Documentation Requirements

## Requirements

- Identify `pplx-embed-context-v1-4b` as the current 4B-class contextualized PPLX Embed V1 model for document chunks that share context.
- Preserve the current 2560-dimensional, 32K-context identity and supported reduced-output encodings only while first-party Perplexity documentation supports those values.
- Keep hosted pricing, batching/context grouping, quotas, API response encoding, and retrieval workflow recommendations freshness-sensitive.

## Validation

- The model remains the contextualized 4B member and is not conflated with standard embeddings.
- Hosted API behavior is not treated as permanent intrinsic architecture.
