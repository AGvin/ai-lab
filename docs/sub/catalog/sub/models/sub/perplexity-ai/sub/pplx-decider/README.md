# PPLX Decider

PPLX Decider groups Perplexity's distinct V1 and V1.1 decision checkpoints derived from Qwen3.8-27B. They return typed decisions and calibrated probabilities rather than representing a general text-generation service.

## Use and deployment boundaries

Choose an exact revision and reproduce its prescribed inference behavior. The V1.1 card's access instructions differ from V1's download example, so public card visibility and Apache-2.0 metadata do not by themselves establish anonymous access to every artifact.
