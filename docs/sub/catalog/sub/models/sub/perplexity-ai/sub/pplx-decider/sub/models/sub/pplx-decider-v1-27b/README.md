# PPLX Decider V1 27B

PPLX Decider V1 27B is Perplexity's Qwen3.8-27B-derived decision checkpoint. Its published card declares Apache-2.0 and provides a download/inference example for typed choices and calibrated probabilities.

## Use and deployment boundaries

Review and pin the inference code, exact weights and dependencies. The card describes a CUDA setup with substantial memory needs; evaluate the real workload before choosing hardware. Reported benchmark results use Perplexity API evaluation and are not an independent local reproduction.
