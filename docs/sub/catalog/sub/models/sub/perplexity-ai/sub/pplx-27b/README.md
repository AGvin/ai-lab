# PPLX 27B

PPLX 27B is Perplexity's post-trained derivative of Qwen 3.8 27B for local knowledge work in Portable Computer. It is separate from the PPLX Decider checkpoints and the surrounding agent software.

## Use and deployment boundaries

Select the supported local setup and exact model package before deployment. The vendor's local-work benchmark evaluates a model-and-harness combination; it does not establish a general ranking. Product availability does not establish an independently redistributable weights license.
