# PPLX Embed V1 4B

PPLX Embed V1 4B is the 4B-class standard member of Perplexity's Qwen3-derived V1 embedding family. Its current model card lists 2560 dimensions, a 32K context and MIT licensing.

## Use and deployment boundaries

Encode independent queries or texts with the standard model path. The documented loaders execute repository code, so pin and review the revision. Match unnormalized int8 output to cosine similarity; verify output encoding and the retrieval index together.
