# Documentation Requirements

## Requirements

- Identify the exact `perplexity-ai/pplx-embed-v1-late-0.6b` checkpoint as a distinct released late-interaction derivative of PPLX Embed V1 0.6B.
- Preserve source-backed token-level 128-dimensional embeddings, MaxSim scoring and MIT license boundary.
- Keep benchmark scores, optional kernels, runtime integrations and hardware acceleration contextual rather than intrinsic identity.
- Do not present this model as producing the same one-vector-per-input representation as the dense V1 members.

## Validation

- The model reciprocates both its V1 family membership and its `derived-from` base relation.
- Late-interaction indexing/scoring is not conflated with standard dense cosine retrieval.
