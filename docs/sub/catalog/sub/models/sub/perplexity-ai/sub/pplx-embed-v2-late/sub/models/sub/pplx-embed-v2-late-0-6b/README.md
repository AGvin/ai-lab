# PPLX Embed V2 Late 0.6B

PPLX Embed V2 Late 0.6B is the smaller MIT-licensed multimodal retrieval artifact, with about 340 million active parameters and 128-dimensional vectors for individual tokens.

## Use and deployment boundaries

Use the card's MultiVectorEncoder and MaxSim workflow, including separate text and image batches. A generic pooled-vector example does not establish compatible indexing. The documented shared space permits querying a 9B-built index, subject to the same token-marker and runtime conventions.
