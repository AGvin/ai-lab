# PPLX Embed V1

PPLX Embed V1 is Perplexity's Qwen3-derived family of standard and contextualized text embeddings. Four existing members cover the 0.6B and 4B sizes for the two input roles.

## Use and deployment boundaries

Select standard members for independent queries or texts and contextualized members for chunks grouped by document. Validate the matching query/document representation and retrieval metric. Hosted API settings, runtime code and model licenses must be checked at their respective boundaries.
