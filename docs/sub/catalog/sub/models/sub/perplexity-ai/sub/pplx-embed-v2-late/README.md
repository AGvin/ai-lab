# PPLX Embed V2 Late

PPLX Embed V2 Late is Perplexity's multimodal late-interaction retrieval family, with distinct 0.6B and 9B artifacts built on Qwen3.5. It scores per-token vectors with MaxSim.

## Use and deployment boundaries

Use a multivector index and the model-card inference path. Shared embedding space allows the documented smaller-query/larger-index combination, but does not make the two sizes equal in quality or resource use. The represented family contains only its two canonical Late members.
