# PPLX Decider V1.1 27B

PPLX Decider V1.1 27B is the updated Qwen3.8-27B-derived decision artifact with a separate 255-row decision readout. Its model card declares Apache-2.0.

## Use and deployment boundaries

Preserve the saved noncausal full-attention behavior and apply calibration exactly once. The card calls for authenticated repository access; access and weights were not independently downloaded here. Its evaluation uses a smaller image-resolution setting than the inference default, so those configurations must remain distinct.
