# Perplexity AI Models

This catalog view collects **trained-model identities released or post-trained by Perplexity AI**. The canonical company profile belongs to the [Perplexity AI producer](../../../producers/sub/p/sub/perplexity-ai/); this page does not duplicate the hosted assistant, workspace, Computer/Portable Computer products or API services.

## Model catalog

- [BrowseSafe](./sub/browsesafe/) — browser-agent prompt-injection detection from raw HTML.
- [PII-Tracer](./sub/pii-tracer/) — conversational PII detection and masking.
- [PPLX 27B](./sub/pplx-27b/) — separate local model associated with Perplexity's Portable Computer.
- [PPLX Decider](./sub/pplx-decider/) — typed decision models, including V1, V1.1, V1.2 and Flash V1.2.
- [PPLX Embed V1](./sub/pplx-embed-v1/) — dense, contextual and late-interaction embedding/retrieval models.
- [PPLX Embed V2 Late](./sub/pplx-embed-v2-late/) — distinct later late-interaction retrieval family.

## Ownership boundaries

Perplexity's trained models are distinct from third-party Qwen base-model identities used for fine-tuning. Hosted Decisions/Embeddings APIs, subscription offerings, model routing and deployment artifacts have their own access or product contexts. Confirm the model-specific first-party card for licensing, training lineage, access and current requirements.
