# HyperCLOVA X SEED 8B Omni

HyperCLOVA X SEED 8B Omni is NAVER Cloud's released native-omnimodal checkpoint announced on **December 29, 2025**. NAVER Cloud describes a single model jointly trained from the outset on **text, image and audio** information rather than treating independently trained modality components as interchangeable. Its official launch also describes text-guided image generation and editing; those are publisher-reported capabilities, not proof of integration, quality or supported interfaces for every public weight artifact. Keep any weight-license, quantization, hosted availability or runtime-compatibility conclusion tied to the exact release and current distribution.
