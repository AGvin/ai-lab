# Documentation Requirements

## Requirements

- Identify Sarvam as Sarvam AI's open general chat/reasoning model family and materialize Sarvam-105B as the current supported flagship chat model.
- Preserve Sarvam-30B as historical/deprecated API context; the August 2026 deprecation retired its Chat Completions route. Sarvam-105B remains the supported flagship base chat model, while newer official documentation separately lists a `sarvam-105b-conversations` post-trained conversational variant. Treat that variant as a distinct intake candidate, not a default alias or automatically accepted new node.
- Keep Saaras, Bulbul, Mayura, Sarvam Vision/Document AI, Indus, Samvaad, API pricing, and third-party beta models separate from this general model identity.
- Treat endpoint aliases, context, benchmark claims, language coverage, license, pricing, and provider availability as freshness-sensitive.

## Validation

- Producer provenance resolves to Sarvam AI.
- Deprecated Sarvam-30B is not presented as a current supported API model.
