# Sarvam

Sarvam is Sarvam AI's open general-purpose chat and reasoning model family. This catalog currently materializes its [Sarvam-105B](./sub/models/sub/sarvam-105b/) flagship model, while keeping older Sarvam-30B as historical release context.

## Release and service boundaries

Sarvam's August 2026 API changelog retired Sarvam-30B from Chat Completions. Current documentation lists `sarvam-105b` as the flagship, plus a separately post-trained `sarvam-105b-conversations` variant for real-time conversational and voice-agent tasks. The latter requires its own identity/intake review rather than automatic representation as an alias or accepted node. Endpoint availability, pricing and model IDs may change.

Saaras, Bulbul, Mayura, Sarvam Vision/Document AI, Indus and Samvaad belong to other model, product or access layers. Published language and benchmark comparisons require exact model- and date-scoped evidence.
