# Bulbul

Bulbul is Sarvam AI's **text-to-speech model family**, distinct from the [Sarvam general LLM family](../sarvam/), [Saaras speech recognition](../saaras/), Sarvam Vision and the provider's hosted API product.

## Released models

- [Bulbul V4 Flash](./sub/models/sub/bulbul-v4-flash/README.md) — explicitly released in October 2026 as a low-latency, expressive speech-generation model.

The publisher also previewed **Bulbul V4 Pro** as a future model. A preview is not a released checkpoint; it is not independently materialized or credited here.
