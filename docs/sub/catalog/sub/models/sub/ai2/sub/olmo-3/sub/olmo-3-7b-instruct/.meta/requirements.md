# Documentation Requirements

## Requirements

- Identify the exact released checkpoint and distinguish siblings, training intermediates, later releases, API aliases and artifacts.
- Render the local source-backed architecture, license, lineage uncertainties and runtime boundary without silently resolving source conflicts.
- Display PROVENANCE/OWNERSHIP REVIEW PENDING immediately below the title with a policy link; no unsupported Russian-control allegation or eligibility clearance.
- Keep all total and active parameter figures distinct; infer no hardware fit from active count.
- Link the canonical family and first-party sources; preserve reciprocal membership.
- Retain source review as 2026-11-05; no weights, code or inference were executed.

## Validation

- Identity, references and complete reader output agree with the local canonical entity.
- All local links and explicit reciprocal relations resolve to their canonical owners.
- No inference, benchmark reproduction or whole-repository validation is implied by documentation acceptance.
