# Documentation Requirements

## Requirements

- Identify Midjourney V8.2 as the released current default Midjourney model version since 2026-07-24.
- Preserve current V8.2-specific image quality, personalization, Edit Model, standard/HD behavior, and feature compatibility only while supported by first-party documentation.
- Keep V8.2 distinct from retired V8.0 alpha, V8.1, V7, Niji 7, and hosted product/UI features that may route to older models for particular operations.
- Treat GPU-time cost, resolution, feature compatibility, editor routing, style/personalization behavior, and current-default status as freshness-sensitive.
- Attribute subjective aesthetics/quality positioning to Midjourney.

## Validation

- The node represents the concrete V8.2 model version, not the Midjourney service.
- Operations that still use older models are not incorrectly attributed to V8.2.
