# Midjourney V8.2

## Relations

- Member of: [Midjourney](../../../../)

Midjourney V8.2 is the Midjourney image-generation model release introduced as the default on July 24, 2026.

## Scope and boundaries

Midjourney positions V8.2 as an update to aesthetics, image quality and personalization, and introduces the Edit Model in its product workflow. These quality descriptions are the producer's positioning.

V8.2 remains distinct from V8.0 alpha, V8.1, V7 and Niji 7. Standard/HD behavior, editor routing, feature compatibility and GPU-time costs depend on the operation and current product documentation; an interface operation that uses an older model is not a V8.2 capability. Default status is time-sensitive and does not replace the release identity.
