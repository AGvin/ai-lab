# Documentation Requirements

## Requirements

- Identify Midjourney as the image-generation model family exposed through Midjourney's hosted product.
- Preserve explicit version identities and lifecycle from first-party Midjourney documentation rather than treating the current default as one continuously mutated model.
- Keep web/Discord interfaces, subscription/GPU accounting, editor tools, personalization, styles, draft modes, and product-specific controls outside permanent family architecture.
- Keep Niji as a specialized collaborative series rather than silently folding its identity into the general Midjourney version line.
- Treat current default version and feature compatibility as freshness-sensitive.

## Validation

- Midjourney model family remains separate from the hosted product/interface.
- Version-specific behavior is not generalized across historical releases.
