# Documentation Requirements

## Requirements

- Identify the exact `deepseek-ai/DeepSeek-V4.1-Flash` model and keep it distinct from DeepSeek-V4-Flash.
- Preserve source-backed architecture, parameter, context, modality, and license facts at the concrete model level when documented.
- Keep mutable API aliases, pricing, rate limits, output limits, and other provider-side serving properties separate from intrinsic model facts.
- Treat provider benchmark claims as evidence inputs rather than AI Lab recommendations.

## Validation

- DeepSeek-V4.1-Flash is a member of DeepSeek-V4.1, not a version alias of DeepSeek-V4-Flash.
- Mutable serving facts are not presented as timeless model identity facts.
