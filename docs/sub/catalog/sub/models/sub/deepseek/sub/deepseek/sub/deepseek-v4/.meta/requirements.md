# Documentation Requirements

## Requirements

- Identify DeepSeek-V4 as a model series within the DeepSeek family.
- Preserve only source-backed characteristics genuinely shared at V4 series scope.
- Link materialized concrete V4 models without treating parameter-size variants as versions of one model.
- Keep provider pricing and mutable serving behavior outside intrinsic series facts.

## Validation

- DeepSeek-V4 is not typed as a second family.
- Flash and Pro remain distinct concrete model identities.
