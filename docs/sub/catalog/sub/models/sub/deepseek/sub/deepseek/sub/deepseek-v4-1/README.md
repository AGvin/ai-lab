# DeepSeek-V4.1

DeepSeek-V4.1 is a series in the [DeepSeek family](../../), distinct from DeepSeek-V4. Its documented member is DeepSeek-V4.1-Flash, introduced on 2026-09-10 with a Causal Encoder–Decoder architecture and native visual understanding. [Source: release announcement](https://www.deepseek.com/en/news/deepseek-v4-1-flash/).
