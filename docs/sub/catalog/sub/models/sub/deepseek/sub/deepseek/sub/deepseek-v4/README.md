# DeepSeek-V4

DeepSeek-V4 is a series in the [DeepSeek family](../../). Its Flash and Pro models were introduced as previews on 2026-04-24; subsequent dated checkpoints are described on their model pages.

The original V4 models use Mixture-of-Experts architecture and hybrid attention combining compressed sparse attention with heavily compressed attention. Both original variants document a one-million-token context. Their different parameter counts and checkpoint details belong to the individual models. [Source: original V4 model card](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro).

## Models

- [DeepSeek-V4-Flash](./sub/models/sub/deepseek-v4-flash/)
- [DeepSeek-V4-Pro](./sub/models/sub/deepseek-v4-pro/)
