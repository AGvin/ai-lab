# Documentation Requirements

## Requirements

- Identify the exact `deepseek-ai/DeepSeek-V4-Flash` model.
- Preserve source-backed architecture, total/active parameter counts, context support, and license.
- Keep the distinction between total and activated MoE parameters explicit.
- Separate mutable API aliases, modes, output limits, pricing, concurrency, and other provider-side serving properties from intrinsic model facts.
- Treat provider benchmark and agent claims as evidence inputs rather than AI Lab recommendations.

## Validation

- DeepSeek-V4-Flash is not represented as a version of DeepSeek-V4-Pro.

- Mutable API facts are visibly scoped as serving state.
