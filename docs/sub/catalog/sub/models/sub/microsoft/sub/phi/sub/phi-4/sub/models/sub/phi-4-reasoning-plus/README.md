# Phi-4 Reasoning Plus

Phi-4 Reasoning Plus is Microsoft's separately released **14B-class reasoning-focused language model** in the Phi-4 series. Microsoft identifies **Phi-4** as its base model, with an **English** language scope and **MIT-licensed** published weights.

## Model identity and lineage

Phi-4 Reasoning Plus is distinct from both the Phi-4 base model and the sibling Phi-4 Reasoning checkpoint. The published base-model metadata supports the specific lineage to [Phi-4](../phi-4/) but does not establish equivalent derivation for other Phi-4 models.

Reasoning benchmark results, sampling guidance, quantized packages, provider routes and runtime-dependent performance are not timeless intrinsic properties. Evaluate the exact checkpoint on target tasks and deployment infrastructure.
