# Documentation Requirements

## Requirements

- Identify Phi-4 Mini Reasoning as the released compact reasoning-focused Phi-4 variant rather than an alias for Phi-4 Mini Instruct.
- Preserve its own source-backed reasoning focus, model size, context, and release facts; do not inherit those facts from other Phi-4 models.
- Keep runtime packaging, quantizations, and provider routes outside intrinsic model identity.

## Validation

- Phi-4 Mini Reasoning remains a separate model within the Phi-4 series.
- It is not collapsed into Phi-4 Mini Instruct or the larger Phi-4 Reasoning model.
