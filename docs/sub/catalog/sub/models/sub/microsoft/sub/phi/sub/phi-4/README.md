# Phi-4

Phi-4 is a **model series** within Microsoft's Phi family. Its separately published models cover base and instruction-tuned text, compact and full-size reasoning, multimodal instruction and vision-reasoning workloads. Sharing the Phi-4 series name does not make these checkpoints interchangeable.

## Models

- [Phi-4](./sub/models/sub/phi-4/) — concrete base model.
- [Phi-4 Mini Instruct](./sub/models/sub/phi-4-mini-instruct/) — instruction-tuned compact text model; its official card describes a 3.8B parameter scale and 128K context.
- [Phi-4 Mini Reasoning](./sub/models/sub/phi-4-mini-reasoning/) — compact reasoning-focused checkpoint.
- [Phi-4 Mini Flash Reasoning](./sub/models/sub/phi-4-mini-flash-reasoning/) — separate compact Flash reasoning model.
- [Phi-4 Multimodal Instruct](./sub/models/sub/phi-4-multimodal-instruct/) — multimodal instruction model.
- [Phi-4 Reasoning](./sub/models/sub/phi-4-reasoning/) — reasoning-focused checkpoint.
- [Phi-4 Reasoning Plus](./sub/models/sub/phi-4-reasoning-plus/) — distinct reasoning model derived from Phi-4.
- [Phi-4 Reasoning Vision 15B](./sub/models/sub/phi-4-reasoning-vision-15b/) — vision-reasoning model derived from Phi-4 Reasoning.

[Open the complete Phi-4 model index](./sub/models/).

## Scope and relations

Phi-4 is part of the [Microsoft Phi family](../../). Architecture, license, language coverage, modalities and lineage belong to each concrete model. Provider routing, benchmarks, deployment fit and model selection are separate concerns. Do not generalize vision or reasoning capabilities across siblings.
