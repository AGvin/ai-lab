# Phi-4 Multimodal Instruct

Phi-4 Multimodal Instruct is Microsoft's released **5.6B-parameter multimodal Transformer** using a Phi-4 Mini Instruct language backbone with vision and speech encoders/adapters. Microsoft's model card specifies **text, image and audio inputs**, **text output**, a **128K-token context** and **MIT** license. Language coverage is modality-specific: the published text list includes Ukrainian, while vision is English-scoped and audio supports a smaller set of languages. Do not infer identical multilingual support across modalities or audio-generation output.
