# Phi-4 Mini Flash Reasoning

Phi-4 Mini Flash Reasoning is Microsoft's separately published **compact reasoning-focused text-generation model** in the Phi-4 series. The official model card identifies approximately **3.85 billion parameters**, the **phi4flash** architecture and an **English-language** scope.

## Identity and deployment boundaries

This is not Phi-4 Mini Reasoning or Phi-4 Mini Instruct; those are separate checkpoints. The published weights use the **MIT license**. Model-card architecture and language support are intrinsic facts, while optimized kernels, provider routes, quantizations, sampling recipes and point-in-time benchmark comparisons require separate current evidence.

Pin the official checkpoint and compatible runtime; evaluate memory, latency and reasoning quality on representative tasks rather than assuming behavior from the "Mini" or "Flash" labels.
