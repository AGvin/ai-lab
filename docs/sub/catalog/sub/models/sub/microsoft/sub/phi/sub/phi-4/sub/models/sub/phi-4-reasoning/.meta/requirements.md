# Documentation Requirements

## Requirements

- Identify Phi-4 Reasoning as Microsoft's released 14B reasoning-focused Phi-4 model and keep it distinct from base Phi-4 and Phi-4 Mini Reasoning.
- Preserve its own source-backed reasoning focus, context, release, and intended-use facts rather than inheriting them from sibling models.
- Keep inference sampling guidance, runtime packaging, and provider routes contextual rather than intrinsic identity unless separately required.

## Validation

- Phi-4 Reasoning remains a separate model within the Phi-4 series.
- It is not collapsed into base Phi-4 or Phi-4 Mini Reasoning.
