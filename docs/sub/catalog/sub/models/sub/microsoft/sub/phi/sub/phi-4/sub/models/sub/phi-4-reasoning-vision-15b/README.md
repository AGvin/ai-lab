# Phi-4 Reasoning Vision 15B

Phi-4 Reasoning Vision 15B is Microsoft's separately published **multimodal reasoning model** for image-text-to-text tasks. The official card identifies approximately **15.1B parameters**, the **phi4-siglip architecture**, an **English** language scope and **MIT** weight license.

## Modality and lineage

Microsoft names [Phi-4 Reasoning](../phi-4-reasoning/) as the base model for this checkpoint. The multimodal vision/reasoning capabilities must not be inherited by Phi-4 text-only or Multimodal Instruct siblings without separate evidence. OCR, GUI grounding and computer-use claims are checkpoint- and source-scoped; validate task behavior and supported runtime interfaces on real inputs.

Keep benchmark results, hosted routes, runtime packaging and hardware-fit claims distinct from model identity.
