# Documentation Requirements

## Requirements

- Identify Phi-4 Multimodal Instruct as the released Phi-4 variant with text, vision, and audio input capabilities.
- Preserve its own source-backed modality, context, language, and release facts instead of inheriting claims from text-only Phi-4 siblings.
- Keep modality adapters, runtime packaging, quantizations, and provider deployment routes separate from intrinsic model identity unless independently materialized.

## Validation

- Phi-4 Multimodal Instruct remains a separate multimodal model within the Phi-4 series.
- Text-only sibling facts are not generalized onto this model without evidence.
