# Documentation Requirements

## Requirements

- Identify Phi-4 as a model series within the Phi family.
- Explain that series members differ in modalities, architecture, reasoning specialization, training lineage, and operating characteristics.
- Link only materialized concrete models backed by first-party Microsoft model repositories; keep exact facts on each concrete model page.
- Keep model-selection recommendations, provider routing, quantizations, runtime packaging, and deployment conclusions outside series identity.

## Validation

- Phi-4 is not typed as a second model family.
- Concrete Phi-4, Mini, reasoning, multimodal, flash-reasoning, reasoning-plus, and reasoning-vision identities are not collapsed or generalized across siblings.
- No model-selection recommendation is presented as a series fact.
