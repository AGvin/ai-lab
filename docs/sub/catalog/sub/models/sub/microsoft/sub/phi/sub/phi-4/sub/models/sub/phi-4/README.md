# Phi-4

Phi-4 is Microsoft's released **14B dense decoder-only text model**, distinct from later Phi-4 Mini, reasoning, and multimodal checkpoints. Microsoft's official model card records a **16K-token context**, **MIT** license and **December 12, 2024** release. It was enhanced with supervised fine-tuning and direct preference optimization; these model-card facts do not imply deployment suitability or benchmark superiority.
