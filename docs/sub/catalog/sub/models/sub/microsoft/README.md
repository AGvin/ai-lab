# Microsoft Models

This model-domain view groups model families produced by Microsoft. Canonical organization identity remains on the [Microsoft producer page](../../../producers/sub/m/sub/microsoft/).

## Translations

- English

## Model families

- [`phi/`](./sub/phi/) — Microsoft's Phi family of compact language and multimodal models.

- [BitNet](./sub/bitnet/) — native low-bit model family, distinct from bitnet.cpp.

Hosted Azure offerings and third-party inference routes are access concerns rather than replacement model identities.
