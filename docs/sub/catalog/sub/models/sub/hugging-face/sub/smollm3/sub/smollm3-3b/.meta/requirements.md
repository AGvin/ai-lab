# Documentation Requirements

## Requirements

- Identify the exact checkpoint and distinguish generations, sibling checkpoints, mode controls, distribution artifacts and hosted aliases.
- Preserve all source-backed architecture, license, access and integration boundaries from the entity note; do not infer hardware fit.
- Render PROVENANCE/OWNERSHIP REVIEW PENDING immediately below title with a policy link; ownership/control review is incomplete.
- Publisher capability and benchmark claims are source evidence, not AI Lab measured results.
- Link canonical family, first-party card and exact license. No publisher conditions were accepted; no weights, model code or inference executed.

## Validation

- Complete reader output agrees with local entity identity, evidence and boundaries.
- Relative links resolve and required relation inverses are present.
- No independent inference, safety certification or whole-catalog acceptance is implied.
