**AliceAI Foundation** is Yandex's separately published pretrained foundation-model line, represented here by the experimental [AliceAI-Foundation-80B-A3B-Base checkpoint](./sub/models/sub/aliceai-foundation-80b-a3b-base/). Its September 2026 release is **not** a version of the AliceAI-T5 encoder-decoder family or the deployed consumer Alice assistant. [Yandex announcement](https://www.yandex.com/company/news/2026-09-21).

## Identity and operational scope

The released checkpoint is an autoregressive hybrid attention/MoE **base model trained from scratch**. Yandex describes it as experimental groundwork for a future unified reasoning and agent model; this does not make it a released chat-tuned assistant, tool-calling service or drop-in replacement for AliceAI-T5. [Official checkpoint card](https://huggingface.co/yandex/AliceAI-Foundation-80B-A3B-Base).

Technical configuration, the Apache-2.0 weight license, custom model code, context length and resource implications belong to the exact checkpoint. Publisher benchmark comparisons are not independently reproduced AI Lab results.
