# Documentation Requirements

## Requirements

- Identify Aya as Cohere Labs' multilingual research-model family.
- Represent Aya Expanse, Aya Vision, and Tiny Aya as durable series/lines within the family.
- Keep Aya datasets, evaluation suites, papers, hosted API behavior, and community derivatives with their own canonical owners.

## Validation

- Producer provenance resolves to Cohere Labs.
- Concrete parameter-size/regional variants are not generalized to the whole Aya family.
