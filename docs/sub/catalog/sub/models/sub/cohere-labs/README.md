# Cohere Labs models

This producer view organizes the represented research models stewarded by Cohere Labs. Aya is the represented family, with separate Expanse, Vision and Tiny Aya series. [Primary source](https://cohere.com/research)

## Research-model scope

Cohere's current research site identifies Cohere Labs as its ML research lab. The Aya documentation separates the Expanse, Vision and Tiny Aya offerings. This view provides navigation to their represented model records; dataset releases, evaluation collections and publications retain their own identities. [Cohere Labs](https://cohere.com/research) · [Aya documentation](https://docs.cohere.com/docs/aya)

## Choosing a model and access route

Start with the task: multilingual text, image understanding, or compact global/regional text generation. Then check the exact model's current provider route and its separate weight-distribution terms. The current API table marks the two 8B Expanse/Vision routes as retired and lists the two 32B routes plus the four Tiny Aya variants as live. [Current provider table](https://docs.cohere.com/docs/models) · [Retirement notice](https://docs.cohere.com/docs/deprecations)
