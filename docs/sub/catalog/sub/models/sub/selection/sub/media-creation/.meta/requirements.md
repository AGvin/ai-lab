# Documentation Requirements

## Requirements

- Define generative-media selection by exact modality and creative assignment rather than language-model scale.
- Cover the selected media task families without forcing one ranking across images, video, speech, music, sound, editing, identity media, and spatial generation.
- Require exact model/artifact identity plus assignment-relevant generation and delivery conditions.
- Preserve modality-specific quality dimensions and accepted-result metrics from the legacy generative-media guide.
- Require independent QC rather than generator self-approval for material acceptance decisions.
- Preserve rights, consent, privacy, provenance, disclosure, and permitted-use checks when relevant.
- Keep infrastructure lifecycle and broader service/hardware selection outside this model-selection subtree.
- Link canonical model facts from `../../../reference/`.

## Validation

- The page contains no cross-modality universal ranking.
- Rights and provenance are not inferred from technical capability.
- Operational deployment guidance is not presented as intrinsic model selection.
