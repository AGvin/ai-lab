# Documentation Requirements

## Requirements

- Define generative-media selection by exact modality and creative assignment rather than language-model scale.
- Cover the selected media task families without forcing one ranking across images, video, speech, music, sound, editing, identity media, and spatial generation.
- Require exact model/artifact identity plus assignment-relevant generation and delivery conditions.
- Preserve modality-specific quality dimensions and accepted-result metrics from the legacy generative-media guide.
- For speech synthesis/dubbing when applicable, preserve evaluation dimensions for intelligibility/pronunciation, language/accent/terminology, naturalness/prosody/pacing/style, speaker consistency, long-form continuity, audio defects, delivery format, latency/streaming/cancellation as evidence, correction effort, and accepted-result rate.
- Require per-language/accent evaluation for multilingual speech generation rather than transferring results between languages.
- Treat deployment-dependent streaming latency, concurrency, and runtime behavior as evidence context rather than immutable model identity.
- Require independent QC rather than generator self-approval for material acceptance decisions.
- Preserve rights, consent, identity restrictions, privacy, provenance, disclosure, voice/model licensing, and permitted-use checks when relevant.
- State explicitly that technical voice-generation capability does not establish permission to clone, imitate, publish, or commercially use an identity-conditioned output.
- Keep complete real-time voice-agent stacks, hosted speech-service selection, runtime/software selection, hardware planning, provider pricing/retention/regions, and end-to-end operational architecture outside this model-selection subtree.
- Keep infrastructure lifecycle and broader service/hardware selection outside this model-selection subtree.
- Link canonical model facts from `../../../reference/`.

## Validation

- The page contains no cross-modality universal ranking.
- Speech-generation quality is not inferred from a short pleasant sample or provider positioning alone.
- Rights and provenance are not inferred from technical capability.
- Deployment-dependent speech latency is not presented as an intrinsic model fact.
- No complete voice-agent workflow or hosted-service comparison is migrated into this page.
- Operational deployment guidance is not presented as intrinsic model selection.
