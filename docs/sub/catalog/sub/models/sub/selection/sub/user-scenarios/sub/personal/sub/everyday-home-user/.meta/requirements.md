# Documentation Requirements

## Requirements

- Present this scenario for an individual using an ordinary laptop or mobile/desktop devices for personal writing, summaries, planning, questions, files, and other everyday assistance with minimal setup burden.
- Use one managed assistant as the default low-administration starting route when the user's data boundary permits hosted processing; do not imply that switching providers or self-hosting is necessary for ordinary personal use.
- Keep workplace use outside this scenario when employer policy, approved-tool controls, internal/confidential data, or professional review obligations materially apply; route that context to `professionals/general-knowledge-worker/` or the applicable professional/organization scenario.
- Preserve Phi-4 Mini Instruct or Qwen3 8B as compact private/offline text experiments and Gemma 4 E2B/E4B Instruct as bounded private multimodal candidates when local processing is justified.
- Treat roughly 16–32 GB system RAM only as a starting planning context for smaller local experiments; require exact model artifact, runtime, context, modality files, and application memory to be measured.
- State that local setup, update burden, latency, and lower capability can outweigh privacy or provider-independence benefits for an ordinary user; self-hosting is not automatically cheaper or simpler.
- Apply the shared data-boundary rule to personal documents and files and require explicit escalation to an approved work route for employer/client-confidential material.
- Escalate from the simple managed route when privacy/offline needs, repeated file/media tasks, usage limits, quality ceiling, or accepted-result cost materially justify a different route.
- Link model candidates and managed assistants to canonical catalog owners instead of duplicating product/model profiles.

## Validation

- The scenario remains personal/home use and does not retain the old combined `home or office` ambiguity.
- A consumer account is not presented as suitable for confidential work data without explicit approval.
- Local models are presented as optional privacy/offline routes rather than mandatory upgrades.
- Memory ranges are planning context, not guaranteed fit or performance claims.
