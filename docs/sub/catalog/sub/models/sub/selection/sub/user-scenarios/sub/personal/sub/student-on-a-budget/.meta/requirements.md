# Documentation Requirements

## Requirements

- Present this scenario for a student or learner with an ordinary/basic laptop, minimal discretionary budget, and limited desire or ability to administer AI infrastructure.
- Start with free hosted assistants as a rotating evaluation route for study, writing, coding, and file tasks; recheck current free-tier limits and do not present one provider as a permanent winner.
- Present one paid assistant subscription as the first upgrade when one service becomes a recurring daily tool and its measured value exceeds the subscription cost.
- Preserve compact offline text experiments with Phi-4 Mini Instruct or Qwen3 8B as local candidates when privacy/offline use matters, while warning that CPU inference can be slow and compact-model quality may be below stronger hosted routes.
- Preserve Gemma 4 E2B Instruct as a compact multimodal local experiment when image, document, or short-audio input matters; require exact runtime, multimodal support, auxiliary files, context, and memory to be validated rather than inferred from the model label.
- Treat roughly 16–32 GB system RAM only as legacy planning context for compact local experiments, not as a guarantee of fit, speed, useful context, or accepted-result quality.
- Do not recommend uploading private university, employer, or third-party data to a free consumer account merely because the service is available; apply the shared data-boundary rules.
- Compare the accepted-result value of free rotation, one subscription, and local/offline routes including correction time and setup burden rather than optimizing for zero request price alone.
- Escalate away from the minimal route when limits, latency, quality ceiling, privacy/offline needs, or repeated correction cost materially block the student's real workload.
- Link the named model candidates to their canonical Model Reference identities and hosted assistants to their canonical service owners; do not duplicate their complete technical/product profiles here.

## Validation

- Free-tier and subscription details are treated as mutable and rechecked when material.
- Compact local candidates are not presented as equal-quality replacements for stronger hosted models without task evidence.
- RAM figures are not presented as guaranteed model-fit requirements.
- The scenario remains budget/learner-specific rather than becoming generic consumer guidance.
