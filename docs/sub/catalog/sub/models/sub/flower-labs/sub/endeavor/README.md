# Endeavor

Endeavor is Flower Labs' model family for generalist reasoning, coding assistance and long-horizon agent work. Endeavor 1.0 is the represented concrete model. [Primary source](https://flower.ai/docs/model/endeavor.html)

## Family scope

Flower's documentation names Endeavor as the family and 1.0 as the represented model release. It positions the model as a generalist across reasoning, coding and agent workflows. This family provides model navigation; the producer and Flower's wider software/platform products have their own identities. [Official family and model description](https://flower.ai/docs/model/endeavor.html)

## Access and evaluation

The represented member has limited preview access through a Flower-managed service or a supported private deployment. Its concrete record explains what is public and what must be confirmed for an approved deployment. Vendor positioning and benchmark tables inform questions to evaluate; they do not establish a single controlled comparison or a universal operating contract. [Preview and evaluation boundaries](https://flower.ai/docs/model/endeavor.html) · [Product positioning](https://flower.ai/models/endeavor)
