# Documentation Requirements

## Requirements

- Identify Endeavor 1.0 as Flower Labs' released frontier-class generalist model for advanced reasoning, coding assistance, and long-horizon agent work.
- Preserve the exact lifecycle language: `production-ready` describes supported managed/private deployment paths, while `preview` describes limited request-based availability.
- Preserve current access boundaries: Flower-managed service or Flower-supported private deployment; no public open-weight checkpoint is currently listed.
- Treat model identifiers, endpoint/API formats, context limits, tool/streaming support, usage limits, private-deployment artifact formats, benchmark scores, and access availability as freshness-sensitive.
- Keep Flower's benchmark comparisons explicitly attributed and do not normalize cross-vendor scores into controlled head-to-head evidence when harnesses/settings differ.

## Validation

- Endeavor 1.0 remains a concrete model member of the Endeavor family.
- Preview/limited-access lifecycle is explicit.
- Managed and private deployment are not misclassified as separate trained-model identities.
- Vendor evaluation claims remain attributed.
