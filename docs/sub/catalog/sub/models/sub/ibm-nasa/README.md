# IBM-NASA collaborative models

This catalog view groups jointly released IBM-NASA research models without creating a synthetic producer organization. Concrete model records retain their own producer, technical, licensing, and intended-use boundaries. [NASA lunar-model release](https://science.nasa.gov/science-research/artificial-intelligence-lunar-foundation-model/) [IBM lunar-model release](https://newsroom.ibm.com/2026-09-10-ibm-and-nasa-release-open-source-ai-model-to-support-lunar-exploration)

The current materialized member is the NASA-IBM Lunar Foundation Model. Other NASA-IBM AI4Science datasets, demonstrations, downstream task models, and software remain separate artifacts or follow-up identities rather than implicit members of this view. [NASA-IBM AI4Science registry](https://huggingface.co/nasa-ibm-ai4science)
