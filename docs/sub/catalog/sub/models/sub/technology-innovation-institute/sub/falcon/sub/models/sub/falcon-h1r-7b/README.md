# Falcon H1R 7B

Falcon H1R 7B is TII's January 2026 compact reasoning checkpoint built on [Falcon-H1-7B-Base](https://huggingface.co/tiiuae/Falcon-H1-7B-Base). TII's official card describes a **hybrid Transformer/Mamba2** language architecture, reasoning-focused supervised fine-tuning and subsequent reinforcement-learning optimization. It is a separate model identity, not a hosted chat interface.

The exact checkpoint's weights use the **Falcon-LLM License**. Availability of weights is not a blanket open-source license for other Falcon releases; read the applicable terms and verify runtime support. Reported reasoning and efficiency benchmarks are publisher claims, not independent AI Lab reproductions. Inference memory and throughput depend on precision, context and runtime.
