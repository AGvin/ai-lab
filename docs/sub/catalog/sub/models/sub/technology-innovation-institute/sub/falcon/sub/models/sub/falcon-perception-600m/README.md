# Falcon Perception 600M

Falcon Perception 600M is TII's **May 3, 2026** compact vision-language release for language-guided localization, open-vocabulary object segmentation and image/document understanding. The official model registry reports approximately **632M parameters**, with a native early-fusion architecture and an **Apache-2.0** license for the referenced checkpoint.

The input/output and segmentation behavior belong to this concrete visual model, not to Falcon H1R or the wider Falcon family. TII's comparisons with larger segmentation and document models are publisher-reported evaluations, not guarantees for robotics, industrial safety, or a user's own dataset. Confirm supported preprocessing, inference stack, license and performance before deployment.
