# Documentation Requirements

## Requirements

- Identify the exact named model, preserving the local entity's license, lifecycle, modality, uncertainty and execution boundaries.
- Distinguish released weights from a hosted endpoint and exact checkpoints from broader series, sibling models, artifacts or features.
- Show PROVENANCE/OWNERSHIP REVIEW PENDING below title, link the policy, and do not assert unsupported Russian ownership or adoption clearance.
- Do not inherit a sibling's context window, license or API retirement; do not claim independently reproduced benchmarks or performance.
- Link the canonical parent and all local first-party references. No weights, model code, inference or hosted API calls executed.

## Validation

- Reader and canonical note agree, including all material license/lifecycle caveats.
- Model membership has a reciprocal has-member relation; relative links resolve.
