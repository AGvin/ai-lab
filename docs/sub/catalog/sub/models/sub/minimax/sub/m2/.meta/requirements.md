# Documentation Requirements

## Requirements

- Identify MiniMax M2 as MiniMax's agent-oriented text model family and materialize current M2.5 and M2.7 releases separately.
- Keep high-speed API aliases as serving variants rather than new trained model identities unless upstream evidence establishes otherwise.
- Keep MiniMax Agent/Mavis and API pricing/plans separate from model identity.
- Treat benchmarks, provider aliases, API availability, context, pricing, and revisions as freshness-sensitive.

## Validation

- Producer provenance resolves to MiniMax.
