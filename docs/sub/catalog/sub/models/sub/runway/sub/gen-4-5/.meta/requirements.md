# Documentation Requirements

## Requirements

- Identify Runway Gen-4.5 as Runway's released current advanced video-generation model and current Runway Dev API model ID `gen4.5`.
- Preserve current text-to-video and image-to-video generation only while supported by first-party Runway material.
- Keep supported duration, resolution, aspect ratio, frame rate, credit cost, plan availability, API parameters, output formats, and product UI behavior freshness-sensitive.
- Keep Gen-4.5 distinct from Gen-4/Gen-4 Turbo, Aleph editing models, hosted third-party models, Runway Agent, and Runway workflow/product surfaces.
- Attribute quality, motion, prompt-adherence, and visual-fidelity claims to Runway.

## Validation

- The node remains a concrete Runway model rather than the Runway workspace/API as a whole.
- Third-party models available in Runway are not represented as Runway-produced models.
