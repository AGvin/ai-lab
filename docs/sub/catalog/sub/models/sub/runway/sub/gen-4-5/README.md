# Runway Gen-4.5

Runway Gen-4.5 is Runway's video-generation model for text-to-video and image-to-video workflows. The model is documented in Runway's creative workspace and in the developer API, where the current model identifier is `gen4.5`. Gen-4.5 remains distinct from Gen-4 Turbo, editing models and other providers' models hosted on Runway. [Creation guide](https://help.runwayml.com/hc/en-us/articles/46974685288467-Creating-with-Gen-4-5) · [Developer model index](https://docs.dev.runwayml.com/guides/models/).

## Scope and operating boundaries

Choose the web or API route according to the required inputs, duration, aspect ratio, delivery format and account eligibility. Those controls, pricing and plan limits are product-specific and mutable. The API changelog documents additional professional output support, so a web help-table default should not be applied as a universal restriction on API delivery. [API changelog](https://docs.dev.runwayml.com/api-details/api_changelog/) · [Developer model index](https://docs.dev.runwayml.com/guides/models/).

The verified access surface is hosted model use; these sources do not establish a publicly downloadable weights release. Check the current service terms and rights to input media before generating and publishing output. Runway's claims about visual fidelity, motion and prompt adherence describe its own evaluation; assess the selected workflow on representative material. [Creation guide](https://help.runwayml.com/hc/en-us/articles/46974685288467-Creating-with-Gen-4-5).
