# Nemotron Reward Models

This index contains NVIDIA's two separately released Qwen3-Nemotron generative reward checkpoints under the Nemotron family. These trained evaluators are distinct from Nemotron 3's language-model series and from one another.

## Models

- [Qwen3-Nemotron-235B-A22B-GenRM](./sub/qwen3-nemotron-235b-a22b-genrm/) — December 2025 reward evaluator associated with Nano RLHF.
- [Qwen3-Nemotron-235B-A22B-GenRM-2603](./sub/qwen3-nemotron-235b-a22b-genrm-2603/) — separate March 2026 reward checkpoint associated with Super RLHF.

Shared Qwen foundation and reward-evaluation use do not establish unsupported backbone lineage or a direct derivative relation between these checkpoints.
