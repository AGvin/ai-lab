# Documentation Requirements

## Requirements

- Identify Nemotron 3 as the NVIDIA-documented model series within the broader Nemotron family.
- Link Nemotron 3 Nano, Nemotron 3 Super, Nemotron 3 Ultra, Nemotron 3 Nano Omni, Nemotron 3.5 Lightning, Nemotron 3.5 Super VL, its separately released Base checkpoint, and Nemotron 3.5 Bolt as the currently materialized concrete members supported by first-party evidence.
- Keep model-specific parameter counts, workload positioning, artifacts, and benchmark claims with concrete model owners.

- Include separately released Nano Base, Super Base and Ultra Base checkpoints as distinct pretrained members; do not collapse them into post-trained Nano, Super or Ultra.

- Include independently released Lightning Base and Ultra GenRM as distinct members, with source-backed roles and no unsupported checkpoint-parent edges.

## Validation

- Each materialized Nemotron 3 member remains a distinct model identity inside the series.
- Missing or future siblings are not synthesized solely for taxonomy symmetry.
