# Documentation Requirements

## Requirements

- Identify NVIDIA Nemotron 3 Nano as a released core member of the Nemotron 3 Nano/Super/Ultra family lineup.
- Preserve model-specific architecture, parameter, context, and workload facts only when directly supported by current NVIDIA evidence.
- Keep quantized checkpoints, deployment backends, GPU fit, throughput, and hosted-provider availability outside intrinsic model identity unless separately materialized.

- Distinguish this post-trained Nano identity from the separately released Nano Base checkpoint; BF16 and FP8 are deployment forms of the post-trained model.
- Preserve Nano Omni as a distinct multimodal derivative using this Nano checkpoint as its language backbone, as linked by the official Nano Omni model card.

## Validation

- Nemotron 3 Nano remains a concrete member of Nemotron 3 rather than a separate family.
- Provider benchmark and efficiency claims are not presented as independent AI Lab conclusions.
