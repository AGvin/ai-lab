# Nemotron

Nemotron is NVIDIA's **open model family**, including the Nemotron 3 series and separately released Qwen3-Nemotron generative reward evaluators.

## Family and model boundaries

Nemotron 3 is a **model series**, not a second top-level family. Its Nano, Super, Ultra and 3.5 releases contain distinct pretrained, post-trained, multimodal, compressed and reward-model identities. The two Qwen3-Nemotron GenRM checkpoints are separately released reward evaluators fine-tuned from a named Qwen Thinking foundation; use in RLHF does not establish backbone derivation of Nemotron Nano or Super.

NVIDIA publishes different model-specific licenses across the family. NIM packages, quantizations, runtime requirements, GPU sizing, endpoints and throughput are serving or artifact concerns, not common family-wide guarantees.
