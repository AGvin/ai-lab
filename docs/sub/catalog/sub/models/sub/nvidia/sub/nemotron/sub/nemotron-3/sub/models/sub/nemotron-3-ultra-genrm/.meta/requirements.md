# Documentation Requirements

## Requirements

- Identify NVIDIA Nemotron 3 Ultra GenRM as a separately released generative reward model, not an inference-oriented Ultra alias.
- Preserve official NVIDIA registry identity and source-specific parameter counts.
- Maintain reciprocal Nemotron 3 series membership and inherited NVIDIA producer provenance.
- Describe the official early Ultra checkpoint foundation textually until a source identifies an exact released parent checkpoint; do not assert unproven derived-from edges.

## Validation

- Model entity has a first-party registry reference and a member-of relation to Nemotron 3.
- Nemotron 3 has a reciprocal has-member relation.
