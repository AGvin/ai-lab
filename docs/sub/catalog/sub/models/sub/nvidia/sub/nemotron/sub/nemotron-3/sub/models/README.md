## Scope boundaries

Base checkpoints are for further training; post-trained releases target separately documented tasks. Super VL and Bolt have explicit lineage, while Ultra GenRM's early-checkpoint foundation must not be promoted to an unverified released-model relation. Model-specific license terms, active/total parameters and supported serving artifacts belong on the member pages.
