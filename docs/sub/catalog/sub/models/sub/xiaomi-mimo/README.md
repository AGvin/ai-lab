# Xiaomi MiMo models

This is the model-domain view for the Xiaomi MiMo Team's trained model families, not a duplicate team profile, API service or deployment catalog.

## Translations

- English

## Producer and model family

- [Xiaomi MiMo Team](../../../producers/sub/x/sub/xiaomi-mimo-team/) — canonical producing team.
- [MiMo](./sub/mimo/) — represented model family, including the MiMo V2.5 series.

The Xiaomi MiMo API Platform, Studio, hosted routes, model pricing, and runtime/quantized artifacts have separate owners. The official platform deprecated the hosted `mimo-v2.5` and `mimo-v2.5-pro` API IDs on October 21, 2026; this service-lifecycle change does not erase independently published model weights.
