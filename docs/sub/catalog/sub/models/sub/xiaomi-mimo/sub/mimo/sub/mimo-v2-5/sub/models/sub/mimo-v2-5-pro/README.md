# MiMo-V2.5-Pro

**MiMo-V2.5-Pro** is the larger, separately released Xiaomi MiMo Team **sparse Mixture-of-Experts model** with approximately **1.02 trillion total / 42 billion active parameters** and up to **1 million tokens of context**. The official model registry publishes this exact checkpoint under **MIT**.

The publisher positions Pro for demanding agent workflows, complex software engineering, and long-horizon reasoning. These are Xiaomi's claims, not independently reproduced AI Lab benchmarks. Do not transfer the non-Pro model's native image/video/audio-input claims to Pro without exact checkpoint evidence.

## Operational and evidence boundary

The trained open model is distinct from **MiMo-V2.5-Pro-Base**, quantizations, third-party deployments, and hosted API IDs. Xiaomi lists the `mimo-v2.5-pro` **hosted API route** as deprecated on October 21, 2026. This is not evidence that the separately published weights were withdrawn. One-million-token context and trillion-scale total weights do not establish practical GPU fit, inference throughput or benchmark performance for a given setup.
