# Documentation Requirements

## Requirements

- Identify MiMo-V2.5-Pro as the larger concrete open Mixture-of-Experts model in the MiMo V2.5 series.
- Preserve 1.02T total parameters, 42B active parameters, and up to 1M context from the current official model card.
- Attribute demanding agentic, complex software-engineering, and long-horizon positioning to Xiaomi MiMo Team rather than treating it as an independent AI Lab ranking.
- Do not infer every MiMo-V2.5 sibling modality from the non-Pro model; preserve Pro-specific modality claims only when explicitly supported by its own sources.
- Keep provider throughput, benchmark rankings, API pricing, quantization, and Pro-Base checkpoint details outside intrinsic trained-model identity.

## Validation

- Total and active parameter counts remain distinct.
- MiMo-V2.5-Pro is not conflated with MiMo-V2.5 or MiMo-V2.5-Pro-Base.
