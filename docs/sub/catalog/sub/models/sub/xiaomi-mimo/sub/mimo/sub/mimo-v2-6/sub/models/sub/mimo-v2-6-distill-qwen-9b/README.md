# MiMo-V2.6-Distill-Qwen-9B

**MiMo-V2.6-Distill-Qwen-9B** is a separately published Xiaomi MiMo **supervised fine-tuned/distilled** checkpoint. Its official model card reports approximately 9.4B total parameters, with text/image-text and agentic tasks; not verified equivalent audio/video support scope. [Original checkpoint](https://huggingface.co/XiaomiMiMo/MiMo-V2.6-Distill-Qwen-9B).

## Identity and intended use

Published derivative of Qwen3.5-9B supervised fine-tuning using MiMo-generated data, not a quantization of Pro or Flash. No unsupported derived-from edge to an unrepresented upstream node. Avoid treating another MiMo-V2.6 checkpoint, quantization or a faster hosted API route as the same trained model.

## Operational and ownership limitations

The released weights carry an MIT label, but actual runtime support, custom code, data handling, license implications and API billing require separate verification. Xiaomi's [2026 interim report](https://ir.mi.com/static-files/b903a881-8143-44a3-b759-703653bbb043) identifies the controlling shareholder; it is **not complete evidence of all indirect minority ownership**. No Russian equity/control is asserted by the reviewed sources, and further screening is needed under the [AI Lab provenance policy](../../../../../../../../../../../../../project/sub/policies/sub/russia-linked-ai/README.md). No independent AI Lab benchmarks or runtime tests are claimed.
