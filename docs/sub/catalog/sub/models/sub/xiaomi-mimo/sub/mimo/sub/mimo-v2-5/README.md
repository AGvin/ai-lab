# MiMo V2.5

MiMo V2.5 is a model **series**, not a single checkpoint. Xiaomi MiMo Team separately published the open [MiMo-V2.5](sub/models/sub/mimo-v2-5/) and [MiMo-V2.5-Pro](sub/models/sub/mimo-v2-5-pro/) trained models. The models share a stated support ceiling of **up to 1 million tokens**, but have materially different parameter counts and modalities.

## Lifecycle and artifact boundary

The published checkpoints remain distinct from API aliases: the official Xiaomi API documentation lists `mimo-v2.5` and `mimo-v2.5-pro` as **deprecated on October 21, 2026** and recommends migration to newer hosted routes. This does not establish withdrawal of the separately published MIT-licensed model weights. Base training checkpoints, FP8 artifacts and quantizations are not automatically new peers in this series.
