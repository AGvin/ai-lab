# Documentation Requirements

## Requirements

- Identify MiMo as the Xiaomi MiMo model family and preserve provenance to Xiaomi MiMo Team.
- Represent MiMo V2.5 as a series because distinct MiMo-V2.5 and MiMo-V2.5-Pro trained models share that generation identity.
- Keep API access, deployment runtimes, benchmark rankings, quantizations, and base-checkpoint variants outside stable family identity.

## Validation

- MiMo V2.5 remains a series within MiMo rather than a second top-level family.
- Concrete V2.5 model specifications are not generalized across all MiMo models.
