# AlphaFold

Structural-biology model family from Google DeepMind; AlphaFold 3 was co-developed with Isomorphic Labs and is distinct from AlphaFold Server and the structure database.

## Relations

- Produced by: [Google DeepMind](../../../../../producers/sub/g/sub/google-deepmind/)
- Produced by: [Isomorphic Labs](../../../../../producers/sub/i/sub/isomorphic-labs/)
- Has member: [AlphaFold 3](sub/models/sub/alphafold-3/)

## Source-scoped operating boundaries

- AlphaFold 3 has separate commercial Cloud and non-commercial academic access paths; access to one does not grant the other. The family page must defer license, compute, and access details to the concrete release. [AlphaFold 3 access](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/open-models/alphafold-3).
- Structure predictions are research outputs. Google expressly excludes clinical diagnostic use for AlphaFold 3; family membership does not establish diagnostic clearance or therapeutic efficacy. [Research-use boundary](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/open-models/alphafold-3).
