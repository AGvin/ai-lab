# Documentation Requirements

## Requirements

- Identify Gemini 3.8 Live as the stable concrete `gemini-3.8-live` model introduced in September 2026 for low-latency real-time dialogue through the Gemini Live API.
- Preserve its audio-to-audio/live-interaction identity and keep asynchronous function-calling behavior scoped to current first-party Gemini API documentation.
- Treat the 2026-09-24 Live Avatar capability as a current visual-presence feature layered on Gemini 3.8 Live rather than a separate trained-model identity; keep its availability, streaming-video behavior, latency, controls, and product/API access freshness-sensitive.
- Keep token limits, supported modalities, tool behavior, pricing, quotas, and API availability freshness-sensitive.
- Distinguish Gemini 3.8 Live from Gemini 3.8 Live Extended Thinking and from legacy Gemini 3.1 Flash Live preview models.

## Validation

- Gemini 3.8 Live remains a concrete member of Gemini rather than a separate family or a hosted service identity.
- Stable model identity is not conflated with mutable Gemini API behavior.
