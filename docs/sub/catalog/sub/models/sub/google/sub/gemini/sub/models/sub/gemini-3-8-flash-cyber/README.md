# Gemini 3.8 Flash Cyber

Google's cybersecurity post-training variant of Gemini 3.8 Flash, served as gemini-3.8-flash-cyber in GA behind a Fairwind allowlist.

## Relations

- Member of: [Gemini](../../../../)

## Scope and boundaries

- This profile does not infer general-purpose superiority or ordinary public availability from the model's family membership.

## Official resources

- <https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/>
- <https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/3-8-flash-cyber>

## Source-scoped operating boundaries

- GA access remains allowlisted through Google's Fairwind program and subject to the cited Gemini Cyber service terms. It is not an unrestricted public Gemini API model. [Access and terms](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/3-8-flash-cyber).
- The Cloud model supports thinking, structured outputs, and caching. Function calling, code execution, grounding, computer use, Live API, Interactions API, and Batch are unsupported. General Flash features must not be copied onto this specialized endpoint. [Cyber capability matrix](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/3-8-flash-cyber).
