# Gemini 3.6 Flash

Gemini 3.6 Flash is a stable provider-hosted multimodal model in the Gemini family. Google made the stable `gemini-3.6-flash` model generally available on July 21, 2026.

## Model family

- Member of: [Gemini](../../../../)

## Canonical profile

- Model code: `gemini-3.6-flash`
- Access: Gemini API and Google AI Studio
- Input modalities: text, image, video, audio, and PDF
- Output modality: text
- Input token limit: 1,048,576
- Output token limit: 65,536
- Stable release: July 21, 2026

Gemini API and Google AI Studio are hosted access products, not replacement identities for the model. Google currently positions the model for fast code generation, agentic execution, and spatial reasoning; those workload claims are provider positioning rather than independent AI Lab acceptance evidence.

## Mutable provider features

The current model page also lists API capabilities such as caching, code execution, file search, function calling, search/Maps grounding, structured output, thinking, URL context, and preview computer use. Those feature states can change independently of the model's canonical identity and must be rechecked from Google when a workflow depends on them.

## Source-scoped operating boundaries

- The current model supports function calls, code execution, caching, grounding, and structured outputs. Image/audio generation and Live API are unsupported; computer use is separately marked preview. [Model reference](https://ai.google.dev/gemini-api/docs/models/gemini-3.6-flash).
- Model-generated tool requests require application validation and authorization before execution. A stable model release does not make every attached tool or preview capability production-ready. [Function-calling workflow](https://ai.google.dev/gemini-api/docs/function-calling).
