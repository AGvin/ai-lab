# Documentation Requirements

## Requirements

- Identify FLUX.1 as a model series within the FLUX family because multiple distinct FLUX.1 model identities share the series label.
- Link materialized concrete FLUX.1 models.
- Keep model-specific weights, license, distillation method, limitations, and runtime requirements on concrete model pages.

## Validation

- FLUX.1-schnell is a concrete model rather than a version of one universal FLUX.1 model.
- The series page does not contain workload rankings.
