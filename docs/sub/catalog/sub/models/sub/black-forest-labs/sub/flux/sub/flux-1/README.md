# FLUX.1

FLUX.1 is a stable series within the Black Forest Labs FLUX family. Black Forest Labs publishes multiple FLUX.1 model identities, so the shared `FLUX.1` label is modeled separately from a concrete member such as FLUX.1-schnell.
