# FLUX.2 [max]

FLUX.2 [max] is Black Forest Labs' named hosted FLUX.2 image-generation and editing model with web-grounding support. [FLUX.2 overview](https://docs.bfl.ai/flux_2/flux2_overview) [FLUX.2 product page](https://bfl.ai/models/flux-2) [BFL available models](https://help.bfl.ai/articles/7655484417-what-flux-models-are-available).

## Identity and scope

BFL positions max for its highest-quality FLUX.2 workflow and current-world grounding. These are provider claims, not an independently reproduced ranking. [FLUX.2 overview](https://docs.bfl.ai/flux_2/flux2_overview) [FLUX.2 product page](https://bfl.ai/models/flux-2) [BFL available models](https://help.bfl.ai/articles/7655484417-what-flux-models-are-available).

## Use and limitations

Grounding may add external web processing and still requires factual review. Confirm the chosen endpoint's grounding control, reference-image limits, resolution and billing before use. [FLUX.2 overview](https://docs.bfl.ai/flux_2/flux2_overview).

The reviewed public sources establish hosted access, not a public open-weight release or a universal parameter count for this named model. Commercial API access does not grant model-weight redistribution rights. [FLUX.2 overview](https://docs.bfl.ai/flux_2/flux2_overview) [FLUX.2 product page](https://bfl.ai/models/flux-2).
