# FLUX.2 [pro]

FLUX.2 [pro] is Black Forest Labs' named hosted FLUX.2 image-generation and editing model for production workflows. [FLUX.2 overview](https://docs.bfl.ai/flux_2/flux2_overview) [FLUX.2 product page](https://bfl.ai/models/flux-2) [BFL available models](https://help.bfl.ai/articles/7655484417-what-flux-models-are-available).

## Identity and scope

Keep the durable pro identity distinct from max, flex and dev; provider positioning about quality and throughput is not a measured catalog score. [FLUX.2 overview](https://docs.bfl.ai/flux_2/flux2_overview) [FLUX.2 product page](https://bfl.ai/models/flux-2) [BFL available models](https://help.bfl.ai/articles/7655484417-what-flux-models-are-available).

## Use and limitations

The documented fixed pro identifier and mutable preview route have distinct update behavior. Record the endpoint used, request controls and service limits rather than assuming all pro calls use identical weights. [FLUX.2 overview](https://docs.bfl.ai/flux_2/flux2_overview).

The reviewed public sources establish hosted access, not a public open-weight release or a universal parameter count for this named model. Commercial API access does not grant model-weight redistribution rights. [FLUX.2 overview](https://docs.bfl.ai/flux_2/flux2_overview) [FLUX.2 product page](https://bfl.ai/models/flux-2).
