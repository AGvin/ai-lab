# FLUX.2 [flex]

FLUX.2 [flex] is Black Forest Labs' named hosted FLUX.2 image-generation and editing model exposing adjustable sampling steps and guidance. [FLUX.2 overview](https://docs.bfl.ai/flux_2/flux2_overview) [FLUX.2 product page](https://bfl.ai/models/flux-2) [BFL available models](https://help.bfl.ai/articles/7655484417-what-flux-models-are-available).

## Identity and scope

Flex's explicit sampling controls distinguish its intended workflow within FLUX.2. BFL's text-rendering and detail claims remain attributed to the provider. [FLUX.2 overview](https://docs.bfl.ai/flux_2/flux2_overview) [FLUX.2 product page](https://bfl.ai/models/flux-2) [BFL available models](https://help.bfl.ai/articles/7655484417-what-flux-models-are-available).

## Use and limitations

Changing steps or guidance changes sampling behavior; it is an inference setting, not a new trained model. Confirm pricing, reference limits and output limits for the selected API or playground route. [FLUX.2 overview](https://docs.bfl.ai/flux_2/flux2_overview).

The reviewed public sources establish hosted access, not a public open-weight release or a universal parameter count for this named model. Commercial API access does not grant model-weight redistribution rights. [FLUX.2 overview](https://docs.bfl.ai/flux_2/flux2_overview) [FLUX.2 product page](https://bfl.ai/models/flux-2).
