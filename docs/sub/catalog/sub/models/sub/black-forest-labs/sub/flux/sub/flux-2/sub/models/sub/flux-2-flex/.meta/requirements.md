# Documentation Requirements

## Requirements

- Identify FLUX.2 [flex] as a concrete named member of the FLUX.2 model series.
- Control-oriented hosted FLUX.2 variant positioned for typography and precision workflows.
- Preserve shared FLUX.2 generation/editing capabilities only where first-party documentation applies them to this variant.
- Keep variant-specific quality/speed/control positioning explicitly provider-attributed.
- Treat API identifiers, pricing, resolution/reference limits, licenses, open-weight artifacts, quantization, runtime support, fine-tuning, and availability as freshness-sensitive.
- Keep this model distinct from sibling FLUX.2 variants and from Black Forest Labs' API/playground surfaces.

## Validation

- The node remains a concrete FLUX.2 model identity rather than a generic quality tier detached from the named model.
- Serving and artifact details are not generalized to all FLUX.2 members.
