# Documentation Requirements

## Requirements

- Identify FLUX 3 as Black Forest Labs' multimodal FLUX generation spanning released video/audio, image, and action-prediction surfaces from one broader multimodal program.
- Keep the series distinct from FLUX.2 image models and FLUX.1.
- Materialize independently named released FLUX 3 surfaces only when their lifecycle and reader value are established by current first-party sources.
- Preserve lifecycle asymmetry: FLUX 3 Video became generally available before later FLUX 3 Image and Action releases; do not retroactively describe earlier rollout states as simultaneous.
- Treat modality-specific API availability, open weights, resolutions, durations, audio behavior, pricing, partner access, licenses, hardware fit, and benchmark claims as freshness-sensitive.
- Attribute provider comparisons and benchmark claims to Black Forest Labs or the cited evaluator.

## Validation

- FLUX 3 remains a series/program boundary rather than one universal API endpoint.
- Video, Image, and Action remain separately materialized only while their independent named release surfaces are current.
- Preview/future Dev surfaces are not materialized as released peers.
