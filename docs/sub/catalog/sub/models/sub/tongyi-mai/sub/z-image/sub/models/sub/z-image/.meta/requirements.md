# Documentation Requirements

## Requirements

- Identify the exact `Tongyi-MAI/Z-Image` base model as a concrete trained model in the Z-Image family.
- Preserve current source-backed parameter count, S3-DiT architecture, text-to-image modality, undistilled-foundation distinction, Apache-2.0 license, and public checkpoint release date.
- Distinguish the base model from Z-Image-Turbo and other family variants.
- Keep provider quality claims, runtime integrations, hosted access, artifacts, hardware fit, and workload recommendations outside canonical model identity.

## Validation

- Z-Image base model is not conflated with the Z-Image family or Z-Image-Turbo.
- Provider qualitative claims are not presented as independent AI Lab evaluation.
- Legacy hardware/security/recommendation prose is not copied into the canonical model profile without a valid owner and current evidence.
