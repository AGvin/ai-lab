## Specifications and boundaries

The official [IFM model card](https://huggingface.co/IFM/K2-Horizon-7B) describes a dense decoder-only model described as 7B-core with a 512K context window. The card declares Apache-2.0 licensing.

These are publisher-reported specifications, not independent parameter measurements or hardware-fit guarantees. Context capacity does not establish throughput or memory requirements. Benchmark results depend on the publisher's evaluation setup and have not been reproduced here. Quantized packages remain distributions rather than separate trained-model identities. The card's 7B-core wording must not be treated as an independently counted total for every component. Uno derivatives require separate provenance assessment.
