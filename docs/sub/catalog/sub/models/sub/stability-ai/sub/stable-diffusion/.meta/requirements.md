# Documentation Requirements

## Requirements

- Identify Stable Diffusion as Stability AI's image-generation model family.
- Keep concrete series and variants separate from Stability AI hosted/API products, partner distributions, optimized runtime builds, and generated assets.
- Preserve licensing and core-model status only from current Stability AI sources.
- Treat distribution URLs, licenses, commercial terms, runtime optimizations, and hardware-fit claims as freshness-sensitive.

- Render the identity, provenance and operational context recorded in canonical `entity.identity_note`; keep version-sensitive claims and official resources aligned with the cited first-party sources.

- Render the standard `entity-relations` block from validated current-entity relations, ordered by explicit numeric order, target canonical name and target ID; resolve every visible target to its reader.

## Validation

- Producer provenance resolves to Stability AI.
