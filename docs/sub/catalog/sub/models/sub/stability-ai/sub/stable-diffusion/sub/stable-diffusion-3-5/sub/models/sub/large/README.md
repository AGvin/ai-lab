# Stable Diffusion 3.5 Large

Stable Diffusion 3.5 Large is the 8.1-billion-parameter Large variant in Stability AI’s 3.5 series. Its official model card describes a diffusion transformer with separate text encoders. It is a trained image model, distinct from an API endpoint or a runtime-optimized package.

## Deployment choice

Large targets users who can provision the model, text encoders and generation workload together. Downloadable artifacts, scheduler settings and supported inference libraries are documented in the model card. Memory and latency depend on precision, resolution, batch size and runtime; a parameter count alone is not a hardware requirement. Quality and prompt-adherence comparisons in release material are Stability AI’s assessments.

## Access and license

The official distribution requires acceptance of the model’s access conditions and identifies the Stability AI Community license. Check commercial eligibility and any required Enterprise agreement for the intended organization. Hosted service terms, generated-content obligations and optimized artifact provenance must be reviewed separately from model availability.
