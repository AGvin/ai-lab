# Stable Diffusion

Stable Diffusion is Stability AI’s image-generation model family. It contains separately released series and trained variants; the represented series here is Stable Diffusion 3.5. A family name does not identify a single interchangeable checkpoint.

## Choosing a model

Follow the series and concrete model entries for architecture, size and distribution details. Local weights, Stability’s hosted API, partner endpoints and optimized runtime artifacts are different deployment surfaces. A fine-tune or runtime conversion does not automatically become an original Stability AI release.

## Licensing and deployment

Check the exact release’s license. Stable Diffusion 3.5 appears in the current Core Models list and Community/Enterprise program, with revenue-dependent commercial eligibility and other agreement conditions. Do not apply those terms to every historical family member. Hardware fit depends on the selected variant, encoders, precision, runtime and image workload; access to weights alone does not establish performance or suitability.
