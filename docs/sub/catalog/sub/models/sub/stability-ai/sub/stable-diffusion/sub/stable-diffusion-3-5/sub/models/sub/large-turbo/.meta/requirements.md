# Documentation Requirements

## Requirements

- Identify Stable Diffusion 3.5 Large Turbo as the speed-oriented released concrete member of Stable Diffusion 3.5.
- Preserve distillation/step-count, speed, quality, license, artifact, runtime, precision, and hardware claims only with exact current source scope.
- Keep Turbo distinct from Large and Medium; do not describe it as a runtime mode of Large unless upstream does so.
- Keep optimized runtime builds separate from trained-model identity.

- Render the identity, provenance and operational context recorded in canonical `entity.identity_note`; keep version-sensitive claims and official resources aligned with the cited first-party sources.

- Render the standard `entity-relations` block from validated current-entity relations, ordered by explicit numeric order, target canonical name and target ID; resolve every visible target to its reader.

## Validation

- Speed/quality trade-offs remain provider/evaluator attributed and configuration-scoped.
