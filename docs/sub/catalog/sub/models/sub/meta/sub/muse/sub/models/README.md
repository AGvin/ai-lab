# Muse Models

This index lists released concrete models in Meta's Muse family. It excludes preview-only releases and product or API routes. The [Muse Wonder series](../muse-wonder/) has its own separate member index.

## Released models

- [Muse Glimmer 30B](./sub/muse-glimmer-30b/) — open-weight local multimodal agent model.
- [Muse Image](./sub/muse-image/) — image-model identity.
- [Muse Spark 1.1](./sub/muse-spark-1-1/) — released Spark model.
- [Muse Spark 1.2](./sub/muse-spark-1-2/) — coding-focused update.
- [Muse Spark 1.3](./sub/muse-spark-1-3/) — later agentic and coding model.
- [Muse Spark Open](./sub/muse-spark-open/) — open-weight multimodal sparse-MoE model.
- [Muse Voice Transcribe](./sub/muse-voice-transcribe/) — speech-to-text and audio perception.

## Scope and boundaries

Preview-only model proposals do not enter this released-model index. Muse Code, Meta AI, hosted Muse agents and Meta Model API are access or product surfaces rather than trained-model identities. Licensing and local-deployment rights vary by model and must not be generalized.
