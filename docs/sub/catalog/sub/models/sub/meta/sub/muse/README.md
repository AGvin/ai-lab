# Muse

Muse is a family of released Meta Superintelligence Labs models spanning language, coding, image, multimodal local-agent and speech workflows, with a distinct Muse Wonder frontier-model series.

## Model family boundaries

Muse Spark releases are separate trained models, not access aliases for Muse Code, Meta Model API or the hosted Muse personal-agent product. Open-weight releases such as Glimmer and Spark Open have their own published licenses and deployment contracts; those rights do not extend automatically to hosted counterparts. API routes, regions, prices, model aliases and usage limits are mutable service details.

Only releases supported by first-party evidence belong in this catalog. A preview or coming-soon Muse Video announcement does not constitute a released model entry.
