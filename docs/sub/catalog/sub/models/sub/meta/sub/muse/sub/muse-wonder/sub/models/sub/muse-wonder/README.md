# Muse Wonder

Muse Wonder is a **released concrete Meta frontier model** in the Muse Wonder series. Meta positions it for coding, long-running agentic workflows and advanced computer-use tasks.

## Identity and access boundaries

Muse Wonder is distinct from the separately released [Muse Wonder Full](../muse-wonder-full/) model and from Meta's hosted Muse personal-agent product. At launch, Meta described access through Meta Model API and Muse Code; those are product and service surfaces, not separate trained-model identities. Developer eligibility, API routes, regions, pricing, subscriptions, context limits and benchmark comparisons may change.

Treat task-quality claims as producer-reported until evaluated independently; consult the current official documentation for supported behavior.
