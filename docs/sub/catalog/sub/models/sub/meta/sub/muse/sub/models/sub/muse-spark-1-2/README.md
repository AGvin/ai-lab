# Muse Spark 1.2

Muse Spark 1.2 is Meta's released **coding-focused update to Muse Spark 1.1**, intended for code generation, debugging, codebase understanding and agentic developer workflows, including longer-horizon tasks.

## Identity and access boundaries

This is a trained-model identity, **not** the Muse Code product, Meta Model API or the personal Muse service. Meta's announcement positions the update for developer workflows; actual benchmark performance requires current evidence and task-specific testing. Availability, endpoint aliases, prices, supported regions and rate limits are mutable access-layer facts, not intrinsic model properties.

Muse Spark 1.2 is distinct from both Muse Spark 1.1 and 1.3.
