# Muse Wonder

Muse Wonder is Meta's released **frontier-model series** in the broader Muse family. It contains two distinct concrete models—Muse Wonder and Muse Wonder Full—introduced for advanced coding, personal/professional agents and computer-use work.

## Series boundaries

These are separate model identities, not hosting aliases of one checkpoint. Meta's personal-agent product, Muse Code and Meta Model API are separate product or access layers. Member-specific subscription/API routes, pricing, context windows, benchmarks and availability must be verified at the appropriate model or access surface, not generalized across the series.
