# Llama 4 Maverick

Llama 4 Maverick is Meta's released natively multimodal MoE model with 17B active parameters and 128 experts, distinct from Scout. Provider costs, throughput and benchmark rankings are not permanent model properties.

Meta's official card reports 400B total and 17B active parameters, 1M-token context, text/image input and text/code output. The release uses the custom Llama 4 Community License; access and use remain subject to its terms.
