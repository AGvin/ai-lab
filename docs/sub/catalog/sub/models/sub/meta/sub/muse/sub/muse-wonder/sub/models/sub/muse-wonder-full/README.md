# Muse Wonder Full

Muse Wonder Full is a **separately released Meta frontier model** in the Muse Wonder series, not an alias or a new checkpoint version of its [Muse Wonder sibling](../muse-wonder/). Meta's announcement positions the series for coding, long-running agents and advanced computer-use workflows.

## Identity and access boundaries

Meta initially exposed Muse Wonder Full through the Muse Code subscription rather than through the same API access route as Muse Wonder. This describes **launch-time access**, not a permanent property of the model. Verify current Meta Model API, Muse Code, subscription eligibility, regions, pricing, usage limits and product integration independently.

Do not conflate Muse Wonder Full with the hosted Muse personal-agent service. Published benchmarks are producer claims unless independently reproduced.
