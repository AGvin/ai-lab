# Documentation Requirements

## Requirements

- Identify Muse Spark Open as Meta's released open-weight Muse Spark derivative, distinct from hosted Muse Spark checkpoints.
- Preserve source-backed 816B total / 42B active scale, sparse-MoE multimodal identity, one-million-token context and Muse Model License boundary.
- Keep checkpoint formats, runtime/provider routes, concrete hardware sizing, pricing and launch-partner availability outside intrinsic model identity unless separately scoped.
- Do not generalize Muse Spark Open's open-weight license or self-hosting boundary to other Muse models.

## Validation

- Muse Spark Open remains a separate concrete model from Muse Spark 1.2 and 1.3.
- Hosted-provider availability is not treated as the model's only canonical access route.
