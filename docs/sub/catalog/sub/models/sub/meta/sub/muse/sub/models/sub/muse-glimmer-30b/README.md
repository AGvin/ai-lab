# Muse Glimmer 30B

Muse Glimmer 30B is Meta's released **open-weight, 30B-class multimodal agentic model** intended for local autonomous-agent workflows. Meta describes a causal language model paired with a perception encoder, accepting text and image inputs and producing text.

## Model boundaries

This model is distinct from the hosted Muse Spark line and the much larger Muse Spark Open checkpoint. Meta publishes Glimmer weights under **Apache-2.0**. Local deployment is an intended use, not proof of compatibility with every consumer device or inference engine. Validate model variant, runtime, quantization, memory, latency and agent performance before deployment.

Producer-reported benchmark claims are not independently reproduced here.
