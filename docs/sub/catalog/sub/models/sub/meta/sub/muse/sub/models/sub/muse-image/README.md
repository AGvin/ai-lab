# Muse Image

Muse Image is Meta's released image-generation/editing model introduced on 2026-07-07. Meta describes composition from multiple references, tool-assisted generation and iterative refinement. These are model capabilities described by its publisher, not guarantees for arbitrary inputs.

Product integrations, tool access, regional availability and Content Seal verification are separate surfaces. The launch described Muse Video as a coming-soon preview; that evidence does not establish a released peer model.
