# Muse Spark 1.3

Muse Spark 1.3 is a **released Meta Muse model** introduced on **September 2, 2026**. Meta positions it for coding and long-horizon agentic work; current Meta developer material also discusses multimodal interaction, tools and execution environments.

## Model identity and access

Keep the model distinct from Meta AI, the Muse personal-agent product, Muse Code and Meta Model API. A public-preview developer API does not by itself mean the trained model is preview-only when it has been released in Meta products. Conversely, product or hosted-API availability does **not** establish downloadable open weights or self-hosting rights.

Capability details, model routing, benchmarks, context limits, pricing, regions, rate limits and developer access must be checked against current Meta sources.
