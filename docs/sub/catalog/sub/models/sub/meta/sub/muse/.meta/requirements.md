# Documentation Requirements

## Requirements

- Identify Muse as the Meta Superintelligence Labs model line represented by released Muse Spark and Muse Image identities.
- Link Meta as canonical producer and materialize only released model identities.
- Exclude Muse Video while current first-party material describes it as an early preview/coming-soon model.
- Keep Meta AI product routing and public-preview API access separate from model lifecycle when a model is already released in a supported product surface.

## Validation

- Preview-only Muse Video is not materialized as a released peer.
- Product/API availability is not confused with trained-model identity.
