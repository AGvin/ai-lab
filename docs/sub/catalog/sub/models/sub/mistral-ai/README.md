## Scope and status

The catalog includes released general-purpose and specialist models, with historical entries retained where their identity or lifecycle remains useful. Each concrete page owns its supported model facts.

## Operational boundaries

Model weights, API lifecycle and deployment services are separate concerns. Mistral’s API distinguishes GA, public preview, deprecated and retired access; preview can change silently. [Serverless model lifecycle policy](https://docs.mistral.ai/inference/model-lifecycle)

A model offered by a platform is not necessarily produced by that platform. Third-party hosted models retain their own producer identity. [Models overview](https://docs.mistral.ai/models)
