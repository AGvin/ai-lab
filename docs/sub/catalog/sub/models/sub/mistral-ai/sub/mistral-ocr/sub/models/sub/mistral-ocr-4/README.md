# Mistral OCR 4

Mistral OCR 4 is the OCR 4.0 document-extraction release introduced on June 23, 2026.

## Translations

- English

## Relations

- Family: [Mistral OCR](../../../../)

## Model profile

The exact hosted identifier is `mistral-ocr-4-0`; the moving `mistral-ocr-4` alias is not this fixed release. It introduced paragraph boxes and structural block labels. [OCR 4.0 model card and deprecation](https://docs.mistral.ai/models/ocr-4-0)

The hosted `mistral-ocr-4-0` release is retired according to Mistral’s September 30, 2026 retirement schedule. It is retained here as a historical identity; the named replacement is OCR 4.1. [Mistral model changelog](https://docs.mistral.ai/resources/changelogs)

## Operational boundaries

Do not assign OCR 4.1’s block-level confidence extension to this older release. Structured extraction is model output and should be checked against the original document when accuracy matters. [OCR 4.0 model card and deprecation](https://docs.mistral.ai/models/ocr-4-0) [OCR request and confidence-granularity contract](https://docs.mistral.ai/api/endpoint/ocr)
