# Codestral Embed 2505

Codestral Embed 2505 is Mistral AI’s code-embedding model, released on May 28, 2025.

## Translations

- English

## Relations

- Family: [Codestral](../../../../)

## Model profile

The GA Premier release `codestral-embed-2505` accepts an 8K-token context and produces vectors through the embeddings API. [Codestral Embed 2505 model card](https://docs.mistral.ai/models/codestral-embed-25-05)

The `codestral-embed` interface supports vectors up to 3,072 dimensions and provides `output_dimension` and `output_dtype` controls. [Code embedding dimensions and types](https://docs.mistral.ai/studio/knowledge-rag/embeddings/code_embeddings)

## Operational boundaries

Indexing and query vectors must use the same model, dimension and encoding. Dimension changes require a compatible index; code embeddings are not generated source code or a proof of semantic equivalence. [Code embedding dimensions and types](https://docs.mistral.ai/studio/knowledge-rag/embeddings/code_embeddings)
