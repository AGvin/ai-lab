# Voxtral 4B TTS 2603

Voxtral 4B TTS 2603 is Mistral AI’s March 2026 text-to-speech checkpoint for speech generation and reference-voice adaptation.

## Translations

- English

## Relations

- Family: [Voxtral](../../../../)

## Model profile

The BF16 weights and reference-voice package use CC BY-NC 4.0. Mistral documents nine languages, 24 kHz audio and streaming or batch inference. [Voxtral TTS weights and reference-voice license](https://huggingface.co/mistralai/Voxtral-4B-TTS-2603)

The model page lists the March 23, 2026 TTS release as GA. This is speech generation, distinct from Voxtral transcription models. [Voxtral TTS model card](https://docs.mistral.ai/models/voxtral-tts-26-03)

## Scope and boundaries

The released weights are noncommercial; access through a hosted commercial service has its own terms. A voice sample’s availability does not establish permission to imitate its speaker. [Voxtral TTS weights and reference-voice license](https://huggingface.co/mistralai/Voxtral-4B-TTS-2603)

Reference audio is an input used to condition generated speech. Voice similarity is not speaker authentication, and measured time to first audio is configuration-dependent. [Text-to-speech input and voice prompting](https://docs.mistral.ai/studio/audio/text_to_speech)
