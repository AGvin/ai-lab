## Scope and status

Large 3 is a GA release with published Apache 2.0 weights. Large 4 is a released public-preview API model whose launch notice still describes weights as forthcoming. [Mistral Large 3 model card](https://docs.mistral.ai/models/mistral-large-3-25-12) [Mistral Large 4 public-preview model card](https://docs.mistral.ai/models/mistral-large-4-0) [Mistral model changelog](https://docs.mistral.ai/resources/changelogs)

## Operational boundaries

Model generation, parameter counts, context and weight availability remain member-specific. A public-preview listing does not supply GA stability or an immutable weight artifact. [Serverless model lifecycle policy](https://docs.mistral.ai/inference/model-lifecycle)
