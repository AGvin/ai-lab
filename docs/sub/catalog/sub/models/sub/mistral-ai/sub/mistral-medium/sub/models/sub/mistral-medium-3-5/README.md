# Mistral Medium 3.5

Mistral Medium 3.5 is Mistral AI’s multimodal model released on April 28, 2026, combining instruction following, reasoning and coding in one set of weights.

## Translations

- English

## Relations

- Family: [Mistral Medium](../../../../)

## Model profile

It is a dense 128B model with a 256K-token context, text and image inputs, and text output. Reasoning effort supports `none` and `high`. [Mistral Medium 3.5 weights and configuration correction](https://huggingface.co/mistralai/Mistral-Medium-3.5-128B)

The model card lists the API release `mistral-medium-3-5` as GA. [Mistral Medium 3.5 model card](https://docs.mistral.ai/models/mistral-medium-3-5-26-04)

## Operational boundaries

Use the corrected official Transformers configuration. Mistral warns that the original configuration and GGUF conversions made from it degraded long-context performance. [Mistral Medium 3.5 weights and configuration correction](https://huggingface.co/mistralai/Mistral-Medium-3.5-128B)

Its Modified MIT license includes a preceding-month global consolidated revenue threshold of US$20 million for the company or employer; it is not unrestricted MIT. The full license governs weight use. [Mistral Medium 3.5 Modified MIT license](https://huggingface.co/mistralai/Mistral-Medium-3.5-128B/blob/main/LICENSE)

EAGLE is a companion decoding artifact. Tool execution and validation belong to the application, not to the model’s reasoning setting. [Function-calling contract](https://docs.mistral.ai/studio/conversations/function-calling)
