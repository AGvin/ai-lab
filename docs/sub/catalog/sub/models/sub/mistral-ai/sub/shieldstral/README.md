## Scope and status

A supplied natural-language policy defines the question answered about text or images. The released 1.0 checkpoint uses a yes/no score instead of a fixed hosted moderation taxonomy. [Shieldstral release](https://mistral.ai/news/shieldstral/)

## Operational boundaries

The documented release is self-hosted; it is not an alias for Mistral Moderation. Policy wording, thresholds and deployment testing determine how classification is used. [Self-hosted policy moderation with Shieldstral](https://docs.mistral.ai/resources/cookbooks/mistral-moderation-shieldstral_policy_moderation)
