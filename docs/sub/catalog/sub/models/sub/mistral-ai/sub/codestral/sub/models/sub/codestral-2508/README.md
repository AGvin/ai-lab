# Codestral 2508

Codestral 2508 is Mistral AI’s code-generation and fill-in-the-middle completion model released on July 30, 2025.

## Relations

## Model profile

The model card lists a 128K-token context and GA Premier API release `codestral-2508`. [Codestral 2508 model card](https://docs.mistral.ai/models/codestral-25-08)

It supports code completion through `/v1/fim/completions`, alongside chat, function calling and structured outputs. [Codestral 2508 model card](https://docs.mistral.ai/models/codestral-25-08)

## Operational boundaries

A function call is a proposed operation: the application receives its arguments and controls execution. Generated code and arguments still require application validation. [Function-calling contract](https://docs.mistral.ai/studio/conversations/function-calling)

The Premier API listing does not establish a downloadable Apache-licensed checkpoint. Do not inherit licensing from earlier Codestral releases. [Codestral 2508 model card](https://docs.mistral.ai/models/codestral-25-08)
