# Robostral

Robostral is Mistral AI’s embodied-model line, represented by Robostral Navigate.

## Translations

- English

## Relations

- Producer: [Mistral AI](../../../../../producers/sub/m/sub/mistral-ai/)
- Model: [Robostral Navigate 8B](./sub/models/sub/robostral-navigate-8b/)

## Scope and status

Navigate is a released model for instruction-conditioned robot navigation using RGB observations. [Robostral Navigate release](https://mistral.ai/news/robostral-navigate/) [Robostral Navigate lifecycle](https://legal.mistral.ai/ai-governance/models/robostral-navigate/)

## Operational boundaries

Model-generated navigation targets are distinct from robot actuation and physical safeguards. The release does not establish a generally available serverless API, public weight download or universal robot compatibility. [Robostral Navigate release](https://mistral.ai/news/robostral-navigate/)
