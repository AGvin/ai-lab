## Scope and status

The family retains OCR 3 for its documented ongoing GA availability, OCR 4.0 as a retired hosted release, and OCR 4.1 as the current GA successor. [OCR 3 model card and continuing availability](https://docs.mistral.ai/models/ocr-3-25-12) [OCR 4.1 model card](https://docs.mistral.ai/models/ocr-4-1) [Mistral model changelog](https://docs.mistral.ai/resources/changelogs)

## Operational boundaries

OCR release identity, moving API aliases and the wider Document AI service are different concerns. Bounding boxes, labels and confidence granularity must be verified for the exact model version. [OCR request and confidence-granularity contract](https://docs.mistral.ai/api/endpoint/ocr)
