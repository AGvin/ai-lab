## Model profile

The 24B FP8 instruct release accepts text and images, has a 256K-token context, and uses Apache 2.0. [Devstral Small 2 released weights](https://huggingface.co/mistralai/Devstral-Small-2-24B-Instruct-2512)

The hosted `labs-devstral-small-2512` release is deprecated from February 27, 2026; the current model card points new integrations to Mistral Medium 3.5. [Devstral Small 2 lifecycle and API model card](https://docs.mistral.ai/models/devstral-small-2-25-12)

## Scope and boundaries

The released weights and their license persist independently of the hosted Labs endpoint. Published local-hardware examples do not guarantee a full-context serving configuration. [Devstral Small 2 released weights](https://huggingface.co/mistralai/Devstral-Small-2-24B-Instruct-2512)

Tool execution belongs to the agent application. Validate generated edits and restrict the commands and files that the harness exposes. [Function-calling contract](https://docs.mistral.ai/studio/conversations/function-calling)
