## Scope and status

The represented Moderation 2 release scores text against versioned moderation categories, including jailbreak-related content. [Mistral Moderation 2 model card](https://docs.mistral.ai/models/mistral-moderation-26-03) [Moderation scores and guardrail thresholds](https://docs.mistral.ai/studio/conversations/moderation)

## Operational boundaries

Shieldstral is a separate open-weight text-and-image classifier driven by a supplied policy. Category scores and thresholds are fallible inputs to an application’s policy decisions.
