# Mistral OCR 3

Mistral OCR 3 is Mistral AI’s December 18, 2025 document-extraction model, identified by `mistral-ocr-2512`.

## Translations

- English

## Relations

- Family: [Mistral OCR](../../../../)

## Model profile

Mistral still lists OCR 3 as GA for existing integrations and production workloads. It extracts interleaved text and images and supports structured annotations. [OCR 3 model card and continuing availability](https://docs.mistral.ai/models/ocr-3-25-12)

## Operational boundaries

OCR 4.1’s paragraph-block and block-confidence contract must not be assumed for this release. Check extracted text and annotations against source pages; model output is not an authoritative copy. [OCR 3 model card and continuing availability](https://docs.mistral.ai/models/ocr-3-25-12) [OCR output and confidence scores](https://docs.mistral.ai/studio/document-processing/basic_ocr)
