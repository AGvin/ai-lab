# Voxtral Small 24B 2507

Voxtral Small 24B 2507 is Mistral AI’s July 2025 audio-and-text instruction model for transcription, translation, questions and summaries.

## Translations

- English

## Relations

- Family: [Voxtral](../../../../)

## Model profile

The Apache 2.0 weights belong to the Voxtral family; the GA API release is `voxtral-small-2507` with a 32K-token context. [Voxtral Small model card](https://docs.mistral.ai/models/voxtral-small-25-07) [Voxtral Small weights and audio-instruction limitations](https://huggingface.co/mistralai/Voxtral-Small-24B-2507)

The model supports audio understanding and function calling, rather than only verbatim speech transcription. [Voxtral Small weights and audio-instruction limitations](https://huggingface.co/mistralai/Voxtral-Small-24B-2507)

## Operational boundaries

The released model card says system prompts are not supported. Do not assume the instruction-boundary behavior of general chat models. [Voxtral Small weights and audio-instruction limitations](https://huggingface.co/mistralai/Voxtral-Small-24B-2507)

Spoken tool requests require application authorization and argument validation. A voice instruction alone does not authenticate the speaker. [Function-calling contract](https://docs.mistral.ai/studio/conversations/function-calling)
