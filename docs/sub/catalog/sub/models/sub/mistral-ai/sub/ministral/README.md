# Ministral

Ministral is Mistral AI’s compact language-and-vision model family, including the December 2025 Ministral 3 generation.

## Scope and status

The represented 3B, 8B and 14B entries are independently released Instruct checkpoints. The family also has separately trained Base and Reasoning variants. [Ministral 3 3B Instruct weights](https://huggingface.co/mistralai/Ministral-3-3B-Instruct-2512) [Ministral 3 8B Instruct weights](https://huggingface.co/mistralai/Ministral-3-8B-Instruct-2512) [Ministral 3 14B Instruct weights](https://huggingface.co/mistralai/Ministral-3-14B-Instruct-2512)

## Scope and boundaries

Model names are size labels; exact language-model and vision-encoder counts belong to each member. Edge-oriented positioning does not establish a common memory requirement or blanket permission to run tools.
