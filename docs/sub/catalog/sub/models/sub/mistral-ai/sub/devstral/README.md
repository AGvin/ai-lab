The represented December 2025 checkpoints remain distinct historical model identities. Their hosted releases are deprecated, while their released weights have separate license terms. ## Operational boundaries

The 123B Modified MIT checkpoint and Apache 2.0 Small checkpoint do not share one license. Agent software controls tool permissions and command execution; the model is not the agent harness.
