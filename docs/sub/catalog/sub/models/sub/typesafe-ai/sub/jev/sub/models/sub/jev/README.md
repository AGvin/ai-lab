# Jev

Jev is the first public TypeSafe AI System One model, announced in early access on September 15, 2026. It consumes application state and typed questions and returns structured probabilistic decisions rather than free-form text.

The current first-party documentation describes Choice, Score and Noul question types, with output fields and probability or confidence behavior defined for each type. TypeSafe's RLCD, latency, cost, calibration and benchmark statements remain provider evidence. An inability to generate arbitrary strings does not mean the model cannot make incorrect decisions.

API aliases such as jev-latest and returned version strings are mutable access or serving state. They do not independently establish a new trained-model version. The TypeSafe AI organization, hosted APIs, third-party Jev services, pricing, quotas, SDKs, Agent Skills and integration playbooks remain separate subjects.
