# Jev

Jev is TypeSafe AI's first public System One model line, announced in early access on September 15, 2026. The producer describes a machine-oriented decision model that evaluates state and typed questions to return typed probabilistic outputs rather than free-form text.

TypeSafe's RLCD, calibration, speed, cost, benchmark and reliability statements are provider claims. Typed output does not independently establish that a decision is correct. Hosted APIs, provider pricing, quotas, playgrounds, SDKs and third-party Jev services remain outside model-family ownership.

Mutable API aliases and serving revisions do not create new family members without evidence of independently meaningful trained-model identities.
