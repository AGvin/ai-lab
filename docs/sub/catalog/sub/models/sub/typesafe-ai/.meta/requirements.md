# Documentation Requirements

## Requirements

- Provide model-domain navigation for TypeSafe AI model lines represented in the catalog.
- Keep the canonical TypeSafe AI organization identity under `catalog/producers/` rather than duplicating company content here.
- Keep hosted API products, third-party Jev access providers, SDKs, and Agent Skills outside the model-domain ownership view.

## Validation

- TypeSafe AI organization identity remains distinct from Jev model identity and hosted access services.
- Model-domain navigation resolves only to canonical TypeSafe AI model-family/model nodes.
