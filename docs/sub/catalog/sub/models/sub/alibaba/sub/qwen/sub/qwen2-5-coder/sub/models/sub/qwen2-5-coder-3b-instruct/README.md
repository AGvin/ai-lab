# Qwen2.5-Coder 3B Instruct

Qwen2.5-Coder 3B Instruct is a coding-specialized instruction-tuned language model in the Qwen2.5-Coder series.

## Model series

- [Qwen2.5-Coder](../../../..)

## Model profile

- Architecture: dense decoder-only Transformer
- Parameters: 3.09B total; 2.77B excluding embeddings
- Layers: 36
- Configured/default context: 32,768 tokens
The current official card and shipped configuration document 32,768 tokens. Historical YaRN-extension wording is not a current supported-context guarantee.
- Training stage: pretraining and post-training
- License: Qwen Research License
- Inputs and outputs: text input and generated text output
