# Wan 2.7

Wan 2.7 is a hosted creative-media generation spanning distinct image, video-generation, reference-video, and video-editing model IDs.

## Decision and Operational Boundaries

- Keep task-specific 2.7 IDs separate from date snapshots and from the all-in-one Wan 3.0 model contract.
- Do not infer open weights or Apache-2.0 availability from the earlier Wan2.2 repository.
- Use exact image/video API guides for allowed reference combinations, asynchronous task handling, and output persistence.
- Validate reference-media rights and user authorization before upload or synthesis; generated likeness, voice, text, or video is not evidence of an authentic recording.
