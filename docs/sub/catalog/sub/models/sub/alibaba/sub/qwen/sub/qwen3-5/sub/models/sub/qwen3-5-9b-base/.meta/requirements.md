# Documentation Requirements

## Requirements

- Preserve the exact current-node identity, sourced training-stage boundary and canonical owner.
- Render every visible entity relation with resolving canonical links and preserve ordering.
- Separate model identity from precision packages, modes, hosted routes and runtime behavior.
- Treat publisher benchmarks as publisher evidence, not independent AI Lab measurements.

## License and use

The released checkpoint is Apache-2.0. The [published repository](https://huggingface.co/Qwen/Qwen3.5-9B-Base/tree/main) contains independently downloadable model and processor artifacts. Pin the model/processor revision and a compatible multimodal runtime, and validate the intended adaptation or inference behavior; artifact size and a 9B name are not peak-memory estimates.

## Limitations

Do not inherit the post-trained model's benchmark results, reasoning settings or tool-use behavior. Download availability does not guarantee perpetual runtime support or a matching hosted API. This profile establishes no independent runtime, benchmark or beneficial-ownership verification.

## Validation

- Keep source-attributed limitations, licenses and model lineage explicit in the complete reader.
- Do not infer tool-execution permission, hardware fit or source freshness from a model name.
- Do not advance a freshness marker without a complete mutable-fact audit.
