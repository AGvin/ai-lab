# Documentation Requirements

## Requirements

- Identify Wan 2.7 as a released Wan generation spanning current image-generation/editing and video-generation/editing model IDs on Alibaba Cloud Model Studio.
- Preserve the series-level boundary across current `wan2.7-image`, `wan2.7-image-pro`, `wan2.7-t2v`, `wan2.7-i2v`, `wan2.7-r2v`, and `wan2.7-videoedit` serving/model identities without automatically materializing every task-specific route or date snapshot as a peer canonical node.
- Keep Wan 2.7 distinct from Wan 3.0, earlier Wan generations, Qwen-Image, Alibaba Cloud Model Studio, and generated media.
- Treat exact task/model inventory, snapshots, regional availability, input modalities, duration/resolution limits, reference-material support, audio behavior, prices, quotas, editing controls, and provider quality/speed claims as freshness-sensitive.
- Preserve Wan Team producer provenance and the parent Wan family relation.
- Attribute cinematic quality, subject consistency, text rendering, narrative, and speed comparisons to Alibaba/Wan or the cited evaluator.

## Validation

- Wan 2.7 remains a model-series boundary rather than one universal endpoint.
- Date snapshots and task APIs do not become duplicate canonical identities by default.
- Series facts are not generalized to Wan 3.0.
- Producer provenance resolves bidirectionally.
