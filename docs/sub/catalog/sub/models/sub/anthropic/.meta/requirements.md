# Documentation Requirements

## Requirements

- Provide model-domain navigation for model families produced by Anthropic.
- Keep canonical Anthropic producer identity and broader company/product description in the canonical producer page.
- Preserve Claude from the legacy Anthropic model documentation.
- Keep Claude Code, Claude Platform, cloud-platform availability, mutable pricing, plans, and deployment surfaces outside this model-domain view.

## Content Specification

- Use `Anthropic models` as the page title.
- Link the canonical Anthropic producer page under `catalog/producers/`.
- Link the Claude model family.
- Preserve the identity boundary that Claude is the model family while Claude Code, Claude Platform, Anthropic plans, and supported cloud platforms are product or deployment surfaces.
- Include the official Anthropic model documentation and Sonnet 5 references as research sources.

## Excluded Residual Content

The legacy provider page includes time-sensitive access and deployment naming. Preserve those mutable product/service details with their corresponding product, service, deployment/workflow, or concrete-model owners rather than duplicating them here.

## Validation

- The page does not duplicate the canonical Anthropic producer profile.
- Claude links resolve to a canonical model node.
- Product and deployment surfaces are not treated as model-family or concrete-model identities.
