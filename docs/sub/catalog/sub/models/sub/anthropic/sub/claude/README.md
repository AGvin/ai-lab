# Claude

Claude is Anthropic's hosted language-model family for conversation, reasoning, coding, and tool use.

## Producer

- [Anthropic](../../../../../producers/sub/a/sub/anthropic/)

## Model series

- [Fable](./sub/fable/) — demanding reasoning and long-horizon work.
- [Haiku](./sub/haiku/) — high-volume, latency-sensitive work.
- [Mythos](./sub/mythos/) — a restricted-access line with model-specific verification conditions.
- [Opus](./sub/opus/) — complex general and agentic work.
- [Sonnet](./sub/sonnet/) — the durable Sonnet line, with separate model releases.

## Family boundary

The family groups distinct model series and releases. Claude Code, Claude Platform, plans, and cloud integrations are separate product and deployment surfaces. Context limits, thinking behavior, availability, prices, and lifecycle status vary by concrete model; the family name alone does not establish them.
