# Documentation Requirements

## Requirements

- Identify Sonnet as a durable model series within the Claude family.
- Use the series to group distinct Sonnet model releases without collapsing them into versions of one trained model.
- Link the Claude family and materialized concrete Sonnet models.
- Keep cloud IDs, aliases, pricing, and product availability outside series identity.

## Validation

- Claude Sonnet 5 remains a distinct concrete model.
- Sonnet is not represented as one executable model or as a second top-level model family.
