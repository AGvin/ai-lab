# Documentation Requirements

- Identify Claude Haiku 5.5 as Anthropic's concrete Haiku release launched on 2026-10-07 for high-volume and latency-sensitive workloads.
- Preserve the current Claude Platform model ID `claude-haiku-5-5`, text-and-image input, adaptive thinking behavior, and current cross-platform availability only while first-party documentation supports those facts.
- Keep context-window size, maximum output, pricing tiers, cache rates, batch behavior, effort defaults, tokenizer differences, knowledge/training cutoffs, provider IDs, release state, and retirement commitments freshness-sensitive.

- Attribute speed, cost, capability, coding, browser-use, and benchmark comparisons to Anthropic or the cited evaluator rather than converting them into independent AI Lab rankings.
- Keep Haiku 5.5 distinct from Haiku 4.5 and from the Haiku series; a stable model ID does not collapse the series into one mutable latest identity.

## Validation
