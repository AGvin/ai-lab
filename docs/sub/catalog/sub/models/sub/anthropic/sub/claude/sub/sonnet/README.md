# Sonnet

Sonnet is a durable model series within the Claude family. Its concrete releases have separate pinned model identities.

## Model family

- [Claude](../../)

## Models

- [Claude Sonnet 5](./sub/models/sub/sonnet-5/)
- [Claude Sonnet 5.5](./sub/models/sub/sonnet-5-5/)

## Series boundary

Dateless pinned model IDs such as claude-sonnet-5 and claude-sonnet-5-5 identify concrete releases. Convenience aliases, cloud-platform IDs, and subscription or product names are access and versioning surfaces. Current API behavior, prices, and lifecycle status belong to each concrete model.
