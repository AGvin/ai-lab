# Sonnet

Sonnet is a durable model series within the Claude family. Anthropic publishes distinct Sonnet releases such as Claude Sonnet 4.5, Claude Sonnet 4.6, and Claude Sonnet 5, each with its own pinned model identity.

## Identity boundary

Starting with Claude 4.6 and later, Anthropic uses dateless pinned API model IDs such as `claude-sonnet-4-6` and `claude-sonnet-5`. Convenience aliases and cloud-platform IDs are access/versioning surfaces and must not be confused with a broader series identity.
