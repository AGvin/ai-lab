## Use and compatibility

Anthropic's current starting recommendation for most workloads is [Opus 5.5](../opus-5-5/). Opus 5 retains its own model identity and migration context. A recommendation is current provider guidance; suitability still depends on the intended workload.

Prices, knowledge cutoffs, effort behavior, platform availability, and retirement commitments require the current Opus 5 documentation. API and cloud identifiers identify access to this release and do not rename the Opus series.
