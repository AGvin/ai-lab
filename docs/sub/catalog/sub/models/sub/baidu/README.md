# Baidu models

Baidu models is the model-domain navigation view for the represented Baidu-produced model identities. It links the ERNIE family and Baidu's canonical producer profile without duplicating Baidu AI Cloud or Qianfan service identity. [Primary source](https://ernie.baidu.com/)

## Model scope

This view covers the ERNIE family currently represented in the catalog. Baidu's technical articles identify the trained models; the company profile and hosting-service descriptions remain separate. [Baidu model publications](https://ernie.baidu.com/blog/)

## Provider boundary

Qianfan's model catalog includes ERNIE and other producers' models. Its endpoint identifiers, context/output limits and serving variants describe access routes, not ownership or a complete inventory of trained-model identities. Check the selected model and route together before integration. [Current Qianfan model catalog](https://cloud.baidu.com/doc/qianfan/s/rmh4stp0j)
