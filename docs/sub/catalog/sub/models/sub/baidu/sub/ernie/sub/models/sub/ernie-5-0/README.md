# ERNIE 5.0

ERNIE 5.0 is Baidu's native unified multimodal model. Baidu's technical description reports 2.4 trillion total parameters and an autoregressive framework integrating text, images, audio and video with sparse Mixture-of-Experts routing. Baidu records an updated release in January 2026; the technical article is dated 6 February 2026. [Source 1](https://ernie.baidu.com/blog/posts/ernie5.0/) · [Source 2](https://ir.baidu.com/news-releases/news-release-details/baidu-announces-fourth-quarter-and-fiscal-year-2025-results)

## Identity and release evidence

Baidu describes ERNIE 5.0 as a unified autoregressive model for text, image, audio and video, reporting 2.4 trillion total parameters and sparse Mixture-of-Experts routing. Its official results record an updated release in January 2026. The technical article's 6 February 2026 date is not evidence of a first release in February. [Technical description](https://ernie.baidu.com/blog/posts/ernie5.0/) · [January release confirmation](https://ir.baidu.com/news-releases/news-release-details/baidu-announces-fourth-quarter-and-fiscal-year-2025-results)

## Lineage and access

Baidu identifies ERNIE 5.1 as a trained derivative of 5.0's elastic sub-network foundation. Qianfan lists `ernie-5.0` and additional thinking/preview serving names; these names alone do not justify duplicate model identities. Its catalog updated 18 October 2026 lists the `ernie-5.0` route with 128K context, 119K maximum input and up to 65,536 output tokens. These are provider-interface limits. [Derived-model evidence](https://ernie.baidu.com/blog/posts/ernie-5.1-0508-release/) · [Current endpoint table](https://cloud.baidu.com/doc/qianfan/s/rmh4stp0j)

## Evaluation boundary

Check the exact endpoint's supported modalities, retention and access controls before supplying data. The audited technical and provider sources do not establish a public downloadable-weight license or self-hosting workflow for this model. Do not infer an exact active parameter count or universal deployment requirements from rounded architecture claims; evaluate the intended task and serving configuration.
