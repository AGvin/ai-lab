# Documentation Requirements

## Requirements

- Identify North as Cohere's current family of purpose-built generative models.
- Link concrete coding, translation, and compact vision-language members only when they have independent released model identity.
- Keep the Cohere North enterprise platform separate from the North model family.

## Validation

- Concrete models use exact upstream identifiers and remain members of North.
- Platform/workspace features are not treated as model-family capabilities.
