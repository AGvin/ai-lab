# Documentation Requirements

## Requirements

- Identify `embed-v5.0-pro` as Cohere's current Embed 5 variant optimized for maximum retrieval quality and quality-critical/offline indexing workloads.
- Preserve current multimodal text/image/mixed-content input, 100+ language support, 128K context, shared embedding space with Embed 5 Fast, and Matryoshka output dimensions only while first-party documentation supports those facts.
- Treat provider benchmark and quality claims as eligibility evidence rather than independent AI Lab retrieval ranking.
- Keep Embed API pricing, rate limits, supported output encodings/compression, provider availability, batching, and deployment options freshness-sensitive.

## Validation

- Embed 5 Pro remains a concrete Embed-family model, not an API endpoint or vector-search service.
- Shared embedding space does not imply identical quality/latency behavior to Embed 5 Fast.
