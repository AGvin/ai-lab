# Documentation Requirements

## Requirements

- Identify Command as Cohere's model family and preserve producer provenance to Cohere.
- Represent Command A as a series because Cohere's current first-party documentation explicitly groups multiple Command A models under that line.
- Keep hosted API pricing, rate limits, deployment products, and benchmark comparisons outside stable family identity.

## Validation

- Command A remains a series within Command rather than a second top-level family.
- Concrete Command A+ facts are not generalized to every Command model.
