# Documentation Requirements

## Requirements

- Identify Command as Cohere's generation-model family and preserve producer provenance to Cohere.
- Represent Command A and Command R as series because current first-party documentation groups multiple independently identified models under those lines.
- Keep hosted API pricing, rate limits, deployment products, and benchmark comparisons outside stable family identity.

## Validation

- Command A and Command R remain series within Command rather than peer top-level families.
- Concrete model facts are not generalized to every Command model.
