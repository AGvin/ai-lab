# Documentation Requirements

## Requirements

- Identify Command A as Cohere's documented model series and link the live Command A, A Reasoning, A Translate, A Vision, and A+ concrete models.
- Keep concrete parameter counts, context, modalities, language support, and release facts with concrete model owners.
- Keep hosted deployment, pricing, rate limits, and benchmark conclusions outside stable series identity.

## Validation

- Every current concrete Command A member remains a model within the series rather than an alias for the series.
- Deprecated aliases are not materialized as peer model identities.
