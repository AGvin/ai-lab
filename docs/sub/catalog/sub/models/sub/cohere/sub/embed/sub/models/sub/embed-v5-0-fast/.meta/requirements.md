# Documentation Requirements

## Requirements

- Identify `embed-v5.0-fast` as Cohere's current Embed 5 variant optimized for low latency, high throughput, interactive search, agent loops, and high-volume query traffic.
- Preserve current 100+ language support, 128K context, shared embedding space with Embed 5 Pro, and supported Matryoshka output dimensions only while first-party documentation supports those facts.
- Treat provider speed/quality positioning as eligibility evidence rather than independent AI Lab accepted-result economics.
- Keep Embed API pricing, rate limits, supported output encodings/compression, provider availability, batching, and deployment options freshness-sensitive.

## Validation

- Embed 5 Fast remains a concrete Embed-family model, not an API endpoint or retrieval service.
- Shared embedding space does not imply identical modality support, quality, or latency behavior to Embed 5 Pro without current source confirmation.
