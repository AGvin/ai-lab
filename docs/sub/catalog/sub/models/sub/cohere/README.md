# Cohere models

Cohere model catalog: six families covering language generation, embeddings, coding and vision, document parsing, reranking, and speech recognition.

## Identity and provenance

This producer view organizes the Command, Embed, North, Parse, Rerank and Cohere Transcribe families. Organizational identity belongs to the separate Cohere producer profile; this view has no trained parameters or shared model license. [Cohere model lifecycle and API identifiers](https://docs.cohere.com/docs/models) [Cohere models overview](https://cohere.com/models-overview).

Exact public cards co-credit Cohere Labs on some models. That non-exclusive provenance is recorded on those concrete nodes; the Cohere Labs publishing account alone does not transfer a whole family. [Command A model card](https://huggingface.co/CohereLabs/c4ai-command-a-03-2025) [North Micro Vision model card](https://huggingface.co/CohereLabs/North-Micro-Vision-Instruct) [Cohere Labs research](https://cohere.com/research).

## Decision and operating boundaries

- Choose a concrete version before comparing modality, language coverage, context, rights or availability. Cohere API, Model Vault and the North workspace are delivery or application surfaces with their own contracts. [Cohere model lifecycle and API identifiers](https://docs.cohere.com/docs/models) [Cohere models overview](https://cohere.com/models-overview).
- The materialized family membership is the catalog scope, not an assertion that it exhausts every historical or newly announced Cohere model. Current Rerank 5 releases are discovery follow-ups outside this existing-node assessment. [Rerank model comparison](https://docs.cohere.com/v2/docs/rerank) [Rerank 5 release discovery](https://docs.cohere.com/v2/changelog/rerank-v5).
