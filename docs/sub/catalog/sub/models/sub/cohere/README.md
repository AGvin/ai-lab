This node is the Cohere commercial model-domain view and link the canonical Cohere producer plus represented Command, North, Transcribe, Parse, Embed, and Rerank families.

## Scope and boundaries

- Cohere Labs research models such as Aya under the separate `cohere-labs` model-producer namespace.
- API endpoints, Model Vault deployment, pricing, and service limits remains outside model identity.
- Exact model facts with their family, series, and concrete-model owners.
