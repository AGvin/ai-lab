# Seedream 5.0 Lite

ByteDance Seed announced Seedream 5.0 Lite on **2026-02-13** as an image-generation/editing model emphasizing visual/world-knowledge reasoning, reference-guided edits and optional real-time web search. Its self-reported Elo comparison is not an AI Lab benchmark. [ByteDance launch](https://seed.bytedance.com/en/blog/deeper-thinking-more-accurate-generation-introducing-seedream-5-0-lite).

## Identity and scope

Ark lists both `doubao-seedream-5-0-260128` and `doubao-seedream-5-0-lite-260128` for **one** Lite model; BytePlus's `seedream-5-0-lite-260128` is a separate provider route for that named release. None is a second trained model or proof of Pro parentage/downloadable weights. [Ark comparison](https://docs.volcengine.com/docs/ark/image-generation-tutorial?lang=en) [BytePlus list](https://docs.byteplus.com/en/docs/modelark/model-list).

## Hosted lifecycle and limitations

**Not recommended for new integrations via the retiring dated Volcengine Ark Lite route.** It stopped new endpoint purchases on **2026-09-24 10:00 UTC+8** and is scheduled for EOS **2026-11-24 14:00 UTC+8**. Although Pro is the recommended migration target, its batch/search/quality/cost behavior is not equivalent by default. [Ark deprecation notice](https://docs.volcengine.com/docs/ark/model-deprecation-notice?lang=zh).

Additional closures are route-specific: the Volcengine **Agent Plan** Lite service ended on **2026-10-12**, while BytePlus deactivated Lite in **eu-west-1 on 2026-09-10** and directs users to **ap-southeast-1**. The latter dated notice conflicts with BytePlus's generic list still saying Lite supports EU-West; do not presume an EU-West endpoint is usable without a live account-specific check. None of these alone establishes global release/weights retirement. [Agent Plan](https://docs.volcengine.com/docs/ark/agent-plan-personal-model-deprecation-announcement?lang=en) [BytePlus notice](https://docs.byteplus.com/en/docs/modelark/model-deprecation-notice) [BytePlus list](https://docs.byteplus.com/en/docs/modelark/model-list).

Documented provider use includes generation from prompts or references and sequential group images; optional real-time search is announced as a capability, but needs route-specific activation and privacy assessment. Verify resolution, model access, actual current price and per-successful-image batch charging for the selected region/account. [ByteDance launch](https://seed.bytedance.com/en/blog/deeper-thinking-more-accurate-generation-introducing-seedream-5-0-lite) [Ark tutorial](https://docs.volcengine.com/docs/ark/image-generation-tutorial?lang=en) [BytePlus API](https://docs.byteplus.com/en/docs/modelark/image-generation-api) [BytePlus price](https://docs.byteplus.com/en/docs/modelark/model-pricing).

No open weights or exact learned lineage, independent runtime benchmark, exhaustive availability or current Russian beneficial-owner status was verified. Provenance review remains pending, not an asserted Tier 1/2 attribution.
