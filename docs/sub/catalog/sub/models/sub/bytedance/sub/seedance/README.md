# Seedance

**Seedance** is ByteDance Seed's video-generation model family, designed for audiovisual synthesis and controllable editing. It is distinct from the sibling [Seedream image-generation family](../seedream/README.md), downstream consumer applications and hosted inference/API providers.

## Model members

- [Seedance 2.5](./sub/models/sub/seedance-2-5/README.md) — launched 31 July 2026, with audiovisual clip generation, multi-reference composition and editing.

## Relations

- Produced by: [ByteDance Seed](../../../../../producers/sub/b/sub/bytedance-seed/README.md)
- Has member: [Seedance 2.5](./sub/models/sub/seedance-2-5/README.md)

The publisher's description of a shared generation-architecture lineage with Seedance 2.0 is not proof of identical weights, open checkpoints, or all-region serving compatibility.
