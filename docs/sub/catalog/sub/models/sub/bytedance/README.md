# ByteDance Seed Models

Model-domain publishing view for research models from the [ByteDance Seed](../../../producers/sub/b/sub/bytedance-seed/README.md) team. The canonical producer identity is separate from this namespace and from provider-hosted applications or endpoints.

## Model families

- [Seedream](./sub/seedream/README.md) — image creation and editing
- [Seedance](./sub/seedance/README.md) — audiovisual video generation

This is an incremental catalog view, not a claim that these are ByteDance's only model families. Use exact concrete model IDs and provider/region access terms for deployment.
