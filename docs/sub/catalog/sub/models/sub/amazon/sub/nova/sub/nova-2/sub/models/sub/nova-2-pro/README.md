# Amazon Nova 2 Pro

Amazon Nova 2 Pro is the Nova 2 reasoning model announced in Preview on December 2, 2025.

## Scope and boundaries

Nova 2 Pro was announced in Preview on December 2, 2025. AWS announced early access for Nova Forge customers through an AWS account team, with a 1M-token context and three thinking levels. No linked later primary source confirms general availability. Do not infer current self-service access, a model route or retirement from the announcement or from absence in a current model list.
