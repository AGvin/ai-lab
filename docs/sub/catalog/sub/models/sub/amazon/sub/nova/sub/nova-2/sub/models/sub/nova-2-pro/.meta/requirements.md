# Documentation Requirements

## Requirements

- Identify Amazon Nova 2 Pro as the separately named Nova 2 model announced on 2025-12-02 in Preview and preserve that lifecycle boundary while current first-party sources continue to describe it as Preview/early access.
- Preserve up to 1M context and low/medium/high extended-thinking levels only as source-backed current facts.
- Attribute complex multi-step, agentic, multi-document, video-reasoning, and software-migration positioning to AWS rather than treating it as independent AI Lab ranking evidence.
- Keep Forge/Bedrock access details, pricing, quotas, regions, and preview enrollment freshness-sensitive.

## Validation

- Nova 2 Pro is never presented as GA without newer authoritative evidence establishing that transition.
- Preview access state is not generalized to other Nova 2 models.
