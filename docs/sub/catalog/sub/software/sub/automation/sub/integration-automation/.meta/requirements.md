# Documentation Requirements

## Requirements

- Present Integration Automation as the canonical software index for automation products primarily used to connect applications, APIs, events, and business or technical workflows.
- List every materialized direct child exactly once.
- Keep concrete connector catalogs, execution models, deployment options, and mutable hosted state with child software profiles.
- Keep developer-specific automation in the sibling Developer Automation index.

## Validation

- Navigation matches the materialized direct children.
- The index does not duplicate concrete automation-product profiles.
