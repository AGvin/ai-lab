# Activepieces

Activepieces is an extensible automation platform with an MIT-licensed open-source core for building integration flows from triggers, actions, and reusable pieces. Its platform also supports AI-enabled automation while retaining a broader integration-automation identity.

Activepieces supports self-hosting and a vendor-operated cloud service. Enterprise editions add separately licensed features within the same automation platform.

The repository licenses most core code under MIT. Designated enterprise directories have separate licensing, and commercial editions add licensed features; those terms are distinct from the core software license.
