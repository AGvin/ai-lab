# Documentation Requirements

## Requirements

- Identify n8n as a fair-code workflow and integration automation platform that combines visual workflow construction with custom code and native AI capabilities.
- Preserve its primary placement under `automation/integration-automation`; AI-agent/workflow features are capabilities of the broader automation platform rather than a reason to classify n8n primarily as agent software.
- Preserve the distinction between self-hosted n8n software and n8n Cloud or other separately operated service surfaces.
- Do not describe n8n as OSI-open-source when current upstream licensing identifies it as fair-code/source-available.
- Keep integration counts, edition features, supported runtime details, and other mutable claims source-backed when expanded.
- Include current official n8n site and repository references.

## Validation

- The page uses current fair-code/source-available licensing language rather than incorrectly calling n8n open source.
- Self-hosted and cloud operating boundaries are not conflated.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
