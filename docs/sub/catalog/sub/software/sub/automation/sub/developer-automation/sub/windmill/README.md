# Windmill

Windmill is a self-hostable developer platform with an AGPLv3 core for turning code and scripts into jobs, workflows, APIs, internal applications, and related operational automation.

Its workflow engine is part of a broader developer-facing automation surface, which is why Windmill is grouped under developer automation rather than treated only as a generic workflow engine.

## Deployment and licensing

Self-hosted Windmill is customer-operated; Windmill Cloud is a separately operated hosted service. The self-hosted architecture separates the API/UI server, workers that execute jobs, and PostgreSQL for state and the job queue, with documented Docker and Kubernetes deployment options.

The source tree combines AGPLv3 code, Apache 2.0 client/specification files and proprietary enterprise code. Prebuilt Community Edition images and release binaries also include proprietary components with additional use and distribution restrictions. Their terms differ from a build containing only the open-source portions.
