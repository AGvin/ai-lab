# n8n

n8n is a fair-code, source-available workflow and integration automation platform that combines a visual workflow builder with custom code, integrations, and native AI capabilities.

## AI and agentic workflows

n8n can combine deterministic workflow logic with AI components to build AI-agent and agentic workflows. Current upstream capabilities support tool-connected agents, multi-step AI workflows, human-controlled logic, and multi-agent patterns while keeping the resulting automation inside n8n's broader workflow model.

AI-specific builders and assistants evolve more quickly than the core workflow platform, so their exact availability, edition coverage, and release status should be checked against current n8n documentation rather than treated as a permanent baseline capability.

## Self-hosted and cloud boundary

n8n can run on user-controlled infrastructure or through n8n Cloud. Self-hosting can provide tighter control over infrastructure and data paths, while n8n Cloud is a separately operated managed service surface.

n8n's main source distribution uses the Sustainable Use License and is described upstream as **fair-code** and **source-available**, not as OSI-open-source software. Enterprise-licensed components and edition-specific features have separate terms.
