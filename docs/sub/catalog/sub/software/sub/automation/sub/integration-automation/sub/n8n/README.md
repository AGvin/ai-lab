# n8n

n8n is a fair-code, source-available workflow and integration automation platform that combines a visual workflow builder with custom code and native AI capabilities.

n8n can run in a customer-operated self-hosted deployment or through n8n Cloud, the vendor-operated hosted service. These are operating modes of the same automation platform.

AI-agent workflows can call tools and external APIs. The AI Agent Tool node lets a parent agent delegate work to other agents, supporting multi-step and multi-agent patterns within the broader automation platform. Availability of assistant features and edition-specific capabilities depends on the selected release and plan.

The community distribution uses the Sustainable Use License, while commercial Enterprise features have separate licensing. These source-available terms include use restrictions and are not an OSI-approved open-source license.
