# Documentation Requirements

## Requirements

- Present Developer Automation as the canonical software index for automation products primarily used to automate developer-facing jobs, scripts, and operational workflows.
- List every materialized direct child exactly once.
- Keep product-specific execution, integration, deployment, and mutable service facts with child software profiles.
- Keep general integration automation in the sibling Integration Automation index.

## Validation

- Navigation matches the materialized direct children.
- The index does not duplicate concrete automation-product profiles.
