# Documentation Requirements

## Requirements

- Present NVIDIA Isaac Lab as a robot-learning framework/environment centered on reinforcement learning, imitation learning, data generation, and policy development in physically simulated environments.
- Keep generic ML algorithm/library facts with their canonical owners; document them here only as supported robot-learning integrations.
- Treat supported Isaac Sim versions, learning frameworks, robot/task assets, deployment pathways, and API details as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

- Document the standard Isaac Sim-based installation and its matching simulator/Python requirements. Distinguish the source checkout with training/examples from the pip-only external-extension layout, which omits those scripts. Assets may require online retrieval or prior caching. Preserve the separate experimental develop-branch Isaac Lab 3.0 Beta/Newton path and its limited supported task scope.

## Validation

- Isaac Lab remains physical-AI/robotics software rather than generic model-development ownership.
- Producer provenance resolves to NVIDIA.
