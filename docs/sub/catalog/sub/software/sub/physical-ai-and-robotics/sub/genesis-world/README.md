# Genesis World

Genesis World is a physical-AI simulation platform combining multi-physics simulation, photorealistic rendering, compilation, and a Python API for robotics and machine-learning workflows.

## Software boundary

The profile is physical-AI and robotics software rather than generic physics or model-development ownership. Genesis AI support may provide provenance context, but support language does not by itself establish corporate ownership of the project.

Package and version support, physics and rendering backends, accelerator and platform compatibility, APIs, and performance claims are freshness-sensitive.
