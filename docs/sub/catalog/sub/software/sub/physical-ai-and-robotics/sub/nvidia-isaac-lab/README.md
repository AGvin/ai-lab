# NVIDIA Isaac Lab

NVIDIA Isaac Lab is a robot-learning framework and environment centered on reinforcement learning, imitation learning, data generation, and policy development in physically simulated environments.

## Software boundary

Isaac Lab remains physical-AI and robotics software rather than generic model-development ownership. Generic ML algorithms and libraries stay with their canonical owners and appear here only as supported robot-learning integrations.

Supported Isaac Sim versions, learning frameworks, robot and task assets, deployment pathways, and API details are freshness-sensitive.
