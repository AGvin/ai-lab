- Present NVIDIA Isaac ROS as NVIDIA's accelerated ROS software suite for robotics/physical-AI perception and runtime integration on Jetson and discrete GPUs.
- Keep standard ROS middleware semantics outside this profile; focus on NVIDIA's independently maintained accelerated robotics packages and integrations.

- Render the standard `entity-relations` block from validated current-entity relations.
