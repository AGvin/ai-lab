# Documentation Requirements

## Requirements

- Present Hugging Face LeRobot as an open-source robotics/physical-AI toolkit for real-robot data collection, policy training/evaluation, datasets, and deployment workflows.
- Keep concrete robotics datasets and trained models with their dataset/model canonical owners; reference them here only as LeRobot-compatible assets/workflows.
- Treat supported robots, policies, hardware interfaces, datasets, package APIs, and release compatibility as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- LeRobot remains physical-AI/robotics software rather than a generic model-development or dataset owner.
- Producer provenance resolves to Hugging Face, Inc.
