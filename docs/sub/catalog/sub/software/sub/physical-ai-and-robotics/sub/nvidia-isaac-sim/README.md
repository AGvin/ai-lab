# NVIDIA Isaac Sim

NVIDIA Isaac Sim is a robotics and physical-AI simulation and testing platform with physically based simulation and synthetic-data workflows for robot development.

## Software boundary

Isaac Sim remains embodied simulation software rather than generic simulation, data generation, or inference-runtime ownership. Synthetic-data generation, ROS integration, sensors, and robot-learning integrations stay within the embodied simulation lifecycle.

Hardware and software requirements, supported sensors and robots, release compatibility, APIs, and performance claims are freshness-sensitive.
