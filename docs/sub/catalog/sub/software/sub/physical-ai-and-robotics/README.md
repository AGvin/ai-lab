# Physical AI and Robotics

Self-managed software whose primary identity is simulation, training, evaluation, control, or runtime integration for embodied AI systems interacting with physical environments or robots.

Generic robotics middleware, general-purpose game engines, generic physics solvers, robot hardware, robotics datasets or models, and generic inference runtimes remain outside this category unless embodied AI is the durable product center.
