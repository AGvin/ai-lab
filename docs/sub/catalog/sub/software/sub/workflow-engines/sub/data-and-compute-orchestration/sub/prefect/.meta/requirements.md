# Documentation Requirements

## Requirements

- Identify Prefect as an open-source Python workflow-orchestration engine for turning Python functions into observable, schedulable, recoverable production workflows and data pipelines.
- Preserve its primary placement under `workflow-engines/data-and-compute-orchestration`; Python-native flow/task orchestration spans data and application workloads while retaining workflow-engine identity.
- Distinguish self-managed Prefect Server/software from Prefect Cloud and separately operated managed features.
- Keep task/flow APIs, deployment/work-pool architecture, event/automation features, cloud capabilities, and other mutable implementation details source-backed when expanded.
- Include current official Prefect documentation and repository references.

## Validation

- The page preserves Python-native orchestration as the product boundary.
- Self-hosted/server and Prefect Cloud operation are not conflated.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
