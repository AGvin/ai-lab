# Langflow

Langflow is an actively developed open-source Python platform and framework for visually building and deploying AI applications, agents, and workflows from reusable components. Flows can be tested interactively and served through APIs or MCP interfaces.

Langflow remains model- and vector-store-agnostic; connected providers and data systems keep their own canonical identities. Open-source/self-managed Langflow also remains distinct from hosted or enterprise-support surfaces associated with its corporate history.

Langflow joined DataStax in 2024, and later corporate transition material places DataStax within IBM. That history is context only here: no direct current ownership relation is rendered without an authoritative source establishing the exact legal endpoint.
