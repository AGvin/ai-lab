# Dagster

Dagster is an open-source data orchestrator for building, testing, observing, and operating data pipelines and data assets. Its model includes software-defined assets, lineage, testing, and operational observability around data workflows.

Dagster Plus is a separate managed operating surface from the open-source software. Prefect announced an acquisition transition in July 2026, but current first-party close-status wording is not unambiguous enough to render a canonical ownership claim.

## Provenance

- [Elementl, Inc.](../../../../../../../producers/sub/e/sub/elementl-inc/) — company behind the Dagster open-source project, doing business as Dagster Labs.
