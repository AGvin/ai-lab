# Flyte

Flyte OSS is a self-managed open-source platform for orchestrating AI workflows and durable, scalable batch workloads. Current Flyte 2 documentation extends the platform beyond traditional data and ML pipelines to tasks, long-running apps, and agent-oriented workloads written in Python.

The catalog keeps Flyte under data and compute orchestration because durable compute/workflow execution remains its platform foundation. Union.ai's hosted/commercial products are separate operating surfaces.
