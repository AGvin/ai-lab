# Metaflow

Metaflow is an open-source Python framework for developing, executing, deploying, and operating data-intensive applications and workflows, especially across data science, machine learning, and AI workloads.

Originally developed at Netflix, Metaflow provides workflow and data-artifact abstractions that can run across local and cloud compute environments. Netflix origin does not imply that Netflix is the only current deployment or operating environment.

## Origin

- [Netflix, Inc.](../../../../../../../producers/sub/n/sub/netflix-inc/) — origin organization that developed Metaflow internally and open-sourced it in 2019.
