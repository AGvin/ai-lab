# Kubeflow Pipelines

Kubeflow Pipelines (KFP) is the Kubeflow project for authoring, compiling, executing, and tracking portable machine-learning workflows and reusable pipeline components.

KFP is a distinct workflow product within the broader Kubeflow ecosystem rather than a synonym for the complete Kubeflow platform. Current Kubeflow community governance remains distinct from the project's Google origin.

## Origin

- [Google](../../../../../../../producers/sub/g/sub/google/) — origin producer for the Kubeflow/KFP project family.
