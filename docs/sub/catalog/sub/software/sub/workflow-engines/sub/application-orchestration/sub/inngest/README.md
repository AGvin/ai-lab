# Inngest

Inngest is an event-driven durable-execution platform for reliable background jobs, multi-step functions, scheduled work, and application workflows.

Application functions run on user-controlled compute while Inngest coordinates events, steps, retries, timing, and workflow state. Managed Inngest and self-hosted deployment remain separate operating surfaces.

The self-hosted server and CLI use SSPL 1.0 with an Apache 2.0 future-license grant after three years. This license boundary is separate from the managed service and from the user compute on which application functions execute.
