# Documentation Requirements

## Requirements

- Identify Kestra as an open-source orchestration platform for declarative, event-driven and scheduled workflows spanning data, infrastructure, business processes, and automation.
- Preserve its primary placement under `workflow-engines/data-and-compute-orchestration`; broad workflow applicability does not make Kestra a user-facing integration-automation product.
- Preserve declarative workflow definitions and event/schedule triggers as stable concepts while keeping plugin inventories, deployment architecture, editions, and other mutable details source-backed.
- Distinguish self-managed Kestra software from Kestra Cloud and other separately operated commercial surfaces.
- Include current official Kestra documentation and repository references.

## Validation

- The page preserves the orchestration-platform boundary rather than classifying Kestra as a simple no-code integration tool.
- Self-managed and cloud operation are not conflated.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
