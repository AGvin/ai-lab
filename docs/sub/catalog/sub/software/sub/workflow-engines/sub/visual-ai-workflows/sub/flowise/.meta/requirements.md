# Documentation Requirements

## Requirements

- Identify Flowise as an open-source generative-AI development platform for visually building AI agents and LLM workflows through Assistant, Chatflow, and Agentflow builders.
- Preserve its primary placement under `workflow-engines/visual-ai-workflows`; tracing, evaluation, HITL, APIs/SDKs, teams, and deployment features extend the visual workflow platform rather than creating separate products.
- Distinguish locally/self-hosted Flowise software from Flowise Cloud and other managed service surfaces.
- Keep builder capabilities, integrations, supported Node versions, hosted features, and other mutable implementation details source-backed when expanded.
- Include current official Flowise documentation and repository references.

## Validation

- The page reflects current Assistant/Chatflow/Agentflow scope without reducing Flowise to a simple chain editor.
- Self-hosted and cloud operating boundaries are not conflated.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
