# Kestra

Kestra is an open-source orchestration platform for declarative workflows spanning data, infrastructure, business processes, and automation. Workflows can be triggered by schedules and events and are defined through declarative configuration and platform plugins.

Kestra Cloud is a separate managed operating surface from self-managed Kestra software, and the later Kestra Technologies corporate layer remains distinct from the project's origin provenance.

## Origin

- [Ludovic Dehon](../../../../../../../producers/sub/l/sub/ludovic-dehon/) — original creator who started Kestra in 2019 from a Leroy Merlin consulting/data-platform problem.
