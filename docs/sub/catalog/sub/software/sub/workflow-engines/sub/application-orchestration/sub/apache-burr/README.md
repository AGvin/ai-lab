# Apache Burr

Apache Burr is an open-source Python framework for building applications as explicit state machines composed of actions, transitions, and persisted state. It adds persistence and observability around those stateful application flows.

Burr supports conversational and agentic applications as well as non-LLM state machines; those use cases remain applications of the same application-orchestration framework rather than a separate agent-framework identity.

## Origin and governance

- [DAGWorks, Inc.](../../../../../../../producers/sub/d/sub/dagworks-inc/) — origin company behind Burr before transfer into the Apache Software Foundation incubation process. Current Apache governance and stewardship remain distinct from that origin provenance.
