# Apache Burr

Apache Burr is an open-source Python framework for building applications as explicit state machines composed of actions, transitions, and state. It adds persistence and observability around those stateful application flows.

Burr is useful for conversational and agentic applications as well as non-LLM state machines; those use cases remain applications of the same orchestration framework.
