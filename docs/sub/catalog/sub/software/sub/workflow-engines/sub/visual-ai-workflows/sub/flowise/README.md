# Flowise

Flowise is a generative-AI development platform with an Apache-2.0 core and separately licensed commercial components for visually building AI agents and LLM workflows. Its visual surfaces include Assistant, Chatflow, and Agentflow builders together with tracing, evaluation, human-in-the-loop, API, and workspace features.

The first-party sunset notice dates the feature freeze to July 29, 2026, repository archival to August 10, and the end-of-life milestone for official core-team GitHub and Discord presence to August 31. GitHub currently marks the upstream repository archived.

The sunset notice encourages forks of the Apache-2.0 code for internal or community-led maintenance. The root license separately places `packages/server/src/enterprise` and explicitly marked files under a commercial license; third-party components retain their original licenses.

Historical self-hosted Flowise software, Flowise Cloud, FlowiseAI Inc., and future community forks remain distinct operating or identity layers.
