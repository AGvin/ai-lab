# Flowise

Flowise is an open-source generative-AI development platform for visually building AI agents and LLM workflows. Its visual surfaces include Assistant, Chatflow, and Agentflow builders together with tracing, evaluation, human-in-the-loop, API, and workspace features.

The upstream project is now in its announced wind-down lifecycle: active feature development stopped on July 29, 2026, and the GitHub repository was archived on August 10, 2026. Official core-team GitHub and Discord presence is scheduled to conclude at the stated end-of-life milestone on August 31, 2026. The archived Apache-2.0 code can be forked for internal or community-led maintenance.

Historical self-hosted Flowise software, Flowise Cloud, FlowiseAI Inc., and future community forks remain distinct operating or identity layers.
