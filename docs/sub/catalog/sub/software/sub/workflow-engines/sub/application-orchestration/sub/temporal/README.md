# Temporal

Temporal is an open-source durable-execution platform for reliable long-running application workflows. Workflow progress is persisted so application execution can recover from process and infrastructure failures without restarting completed work from scratch.

Temporal Server can be self-hosted; Temporal Cloud is a separate managed operating surface.
