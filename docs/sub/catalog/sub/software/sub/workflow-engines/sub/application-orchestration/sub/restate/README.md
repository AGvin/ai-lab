# Restate

Restate is a source-available durable application runtime for building resilient services, workflows, stateful functions, and AI-agent or application backends. It provides persisted execution together with durable state, timers, and reliable communication.

Its runtime model belongs to application orchestration rather than data-pipeline scheduling. Self-hosted Restate is customer-operated. Restate Cloud and BYOC are vendor-operated offerings; BYOC places the deployment in customer infrastructure.

## Licensing

The runtime uses Business Source License 1.1 with an additional use grant. The grant permits internal production operation and the documented application abstractions while restricting the defined Public Restate Platform Service offered to third parties. Each release changes to Apache 2.0 four years after release. The SDKs use MIT licensing separately.
