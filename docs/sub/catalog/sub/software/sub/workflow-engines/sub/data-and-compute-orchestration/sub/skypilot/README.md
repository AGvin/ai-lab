# SkyPilot

SkyPilot is an open-source AI compute orchestration platform for launching, scheduling, scaling, and managing jobs and services across Kubernetes, Slurm, on-premises infrastructure, and multiple clouds.

## Operation and scope

Tasks and jobs defined as code can use managed jobs, clusters, services and endpoints, batch scheduling, autostop, failover, and placement across clusters or clouds. API-server operation coordinates those resources for users and teams.

SkyPilot can operate inside the user's own cloud accounts and clusters. Those resources remain separate from SkyPilot itself, as do the cloud or cluster providers, inference engines, model servers, registries, and workflow systems that integrate with it.
