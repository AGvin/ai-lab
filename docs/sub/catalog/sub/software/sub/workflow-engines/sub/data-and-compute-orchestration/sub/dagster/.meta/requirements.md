# Documentation Requirements

## Requirements

- Identify Dagster as an open-source data orchestrator for building, testing, observing, and operating data pipelines and data assets.
- Preserve its primary placement under `workflow-engines/data-and-compute-orchestration`; software-defined assets, lineage, and observability are central orchestration concepts rather than separate catalog products.
- Distinguish open-source Dagster software from Dagster Plus and other managed commercial services.
- Keep asset/automation APIs, integrations, deployment architecture, managed-service features, and other mutable implementation details source-backed when expanded.
- Include current official Dagster documentation and repository references.

## Validation

- The page presents Dagster as data orchestration software rather than a generic application durable-execution engine.
- Open-source and managed service boundaries are not conflated.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
