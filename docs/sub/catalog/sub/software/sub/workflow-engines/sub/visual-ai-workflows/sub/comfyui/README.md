# ComfyUI

ComfyUI is Comfy Organization Inc.'s open-source modular node-based generative-AI engine and application. Its graph workflow model supports controllable pipelines for images, video, 3D, audio, and other supported generative media.

## Local and hosted boundary

ComfyUI can run locally or on user-controlled infrastructure, including offline core workflows. Current product surfaces also include optional Comfy Cloud and online/API nodes. Those hosted/API paths have separate network, credential, billing, and data-processing boundaries and should not be described as local merely because they appear inside the same workflow UI.

Saved JSON workflows, built-in templates, local API/backend operation, App Mode, and custom nodes make workflows reusable and embeddable. Custom nodes are executable extensions with their own dependencies and provenance; review them independently. Also review workflow/template sources, model licenses, local API exposure, filesystem/model access, external API credentials, and generated outputs.
