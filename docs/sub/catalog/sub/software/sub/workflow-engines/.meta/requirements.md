# Documentation Requirements

## Requirements

- Present Workflow Engines as the canonical software catalog index for products whose primary role is defining, scheduling, coordinating, and executing multi-step workflows for AI applications, software systems, or data and compute workloads.
- List every materialized direct child exactly once.
- Preserve the distinction between visual AI workflows, application orchestration, and data/compute orchestration while keeping product-specific behavior with child profiles.
- Do not reproduce or depend on legacy `catalog-item`, `catalog-index`, `common/index`, or `catalog/item` selectors.

## Validation

- Navigation matches the materialized direct children.
- The page remains category-level and does not duplicate concrete workflow-engine profiles.
- The page contains no temporary-placeholder wording.
