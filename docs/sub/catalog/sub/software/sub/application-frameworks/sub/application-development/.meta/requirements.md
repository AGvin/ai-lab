# Documentation Requirements

## Requirements

- Present Application Development as the canonical software index for frameworks and SDKs whose primary role is building AI-enabled applications.
- List every materialized direct child exactly once.
- Keep framework-specific APIs, supported runtimes, integrations, and mutable compatibility facts with child software profiles.
- Keep agent orchestration, retrieval-focused frameworks, and hosted application builders with their more specific canonical owners when those are the primary role.

## Validation

- Navigation matches the materialized direct children.
- The index remains category-level and does not duplicate child profiles.
