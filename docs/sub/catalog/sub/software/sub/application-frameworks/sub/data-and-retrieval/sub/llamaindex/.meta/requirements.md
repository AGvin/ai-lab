## Requirements

- Identify LlamaIndex as an open-source framework for building context-augmented LLM applications and agents over user or enterprise data, including ingestion, indexing, retrieval, workflows, and tool/agent abstractions.
- Preserve its primary placement under `application-frameworks/data-and-retrieval`; data/context augmentation is the stable navigation owner even though current LlamaIndex supports broader agent and workflow construction.
- Render the standard `entity-relations` block from the validated current-entity relation projection.
- Distinguish open-source LlamaIndex libraries from LlamaCloud and other hosted/commercial service surfaces.
- Keep package decomposition, provider integrations, workflow/agent APIs, hosted features, and other mutable details source-backed when expanded.
- Include current official LlamaIndex documentation and repository references.

## Validation

- The page does not reduce current LlamaIndex to indexing or RAG-only behavior.
- Open-source framework and LlamaCloud boundaries are not conflated.
- Official resource links match canonical entity metadata.
