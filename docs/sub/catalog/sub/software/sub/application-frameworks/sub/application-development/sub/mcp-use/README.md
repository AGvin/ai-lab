# mcp-use

mcp-use is an actively developed standalone TypeScript framework for MCP application and tool-server development.

## Scope and capabilities

Its v2 developer surface includes typed MCP tools, MCP Apps interactive views, server/client SDK features and Inspector integrations. Scaffolding, Inspector and other bundled features do not automatically become separate products.

## Deployment and safety boundaries

The v2 framework differs from earlier v1 APIs and from the official MCP Inspector, FastMCP Python framework and Arcade MCP. Verify supported hosts, transport, authorization and UI embedding per version. Protect secrets from model-readable schemas and interactive view props.
