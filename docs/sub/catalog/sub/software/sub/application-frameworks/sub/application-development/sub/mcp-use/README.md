# mcp-use

mcp-use is an open-source framework with TypeScript and Python SDKs for building MCP servers, clients, agents and interactive applications.

## Scope and capabilities

The TypeScript v2 surface includes typed MCP tools, MCP Apps interactive views and Inspector integration. The Python SDK provides server, asynchronous client and agent APIs. Language tracks have their own APIs and release histories; host and interactive-view support depend on the selected SDK and client.

## Deployment and safety boundaries

Manufact, Inc., the team behind mcp-use, also operates Manufact Cloud. The installable SDKs remain open source and keep the mcp-use name; cloud hosting, deployment, testing and analytics are separate service capabilities.

The TypeScript v2 framework differs from earlier v1 APIs and from the official MCP Inspector, FastMCP Python framework and Arcade MCP. Verify supported hosts, transport, authorization and UI embedding per version. Protect secrets from model-readable schemas and interactive view props.
