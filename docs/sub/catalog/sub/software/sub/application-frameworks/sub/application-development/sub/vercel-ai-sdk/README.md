# Vercel AI SDK

Vercel AI SDK is Vercel's TypeScript toolkit for building AI-powered applications across server and UI application frameworks. It provides provider-agnostic model access together with streaming, structured outputs, tool calling, multimodal generation, and application/UI integration surfaces without making a specific model provider part of the SDK identity.

AI SDK Core supplies model APIs and AI SDK UI supplies application hooks. Current documentation also describes AI SDK Harnesses adapters for existing agent harnesses; availability follows the installed SDK release. These SDK surfaces remain distinct from the separately operated Vercel AI Gateway and from the harnesses or model services they call.
