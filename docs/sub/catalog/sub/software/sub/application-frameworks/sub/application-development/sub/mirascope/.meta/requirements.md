# Documentation Requirements

## Requirements

- Identify Mirascope as an open-source toolkit with actively developed Python and TypeScript SDK implementations for building LLM-powered applications with provider-agnostic, type-oriented abstractions.
- Preserve model calls, reusable prompts, tools, structured outputs, streaming, async workflows, agents, context/chaining, local-model support, MCP, and observability as high-level capabilities.
- Preserve Mirascope, Inc. as the canonical producer through the `produced-by` relation.
- Keep language-SDK maturity, provider inventories, API/version transitions, tracing backends, compatibility claims, and other mutable product state source-backed when expanded.
- Preserve the broader application-toolkit identity even though Mirascope includes agent-building capabilities.
- Include current official Mirascope documentation, site, and repository references.

## Validation

- The profile is not reduced to a Python-only toolkit or to structured-output utilities alone.
- Agent capabilities do not automatically reclassify the broader Mirascope toolkit as an agent-first framework.
- The producer link resolves to the canonical Mirascope, Inc. profile.
- Official resource links match canonical entity metadata.
