# Documentation Requirements

## Requirements

- Identify Crawl4AI as Unclecode's independently released open-source Python browser-crawling, scraping, Markdown conversion and structured web-data extraction **software library**, appropriate to data-ingestion workflows for AI agents and RAG. This is not a hosted data API, a learned model or an independent retrieval/graph-indexing engine.
- Distinguish the local Python library and separately self-hosted Docker/API execution mode from **Crawl4AI Cloud**, the provider-operated web-data service. The current [hosted service terms](https://crawl4ai.com/legal/) identify CONTEXT4AI PTE LTD as **cloud operator** but do not independently establish that this corporation is the original repository/package author or beneficial owner of the pseudonymous maintainer. Do not materialize a separate cloud service or corporate software-producer edge without further evidence.
- Preserve the original released lifecycle: [v0.9.5](https://github.com/unclecode/crawl4ai/releases/tag/v0.9.5) was published **2026-10-14** as a non-prerelease; the tagged `crawl4ai/__version__.py` confirms **0.9.5** and `pyproject.toml` declares **Python >=3.10**, Apache-2.0 and author **Unclecode**. The current project classifier is **Beta**, while its legacy `setup.py` classifier still says **Alpha**: do not assert production readiness/SLA from the release flag or source classifiers.
- Pin the software, browser engine, Playwright and patchright versions, headless/browser profile configuration, cache locations, extraction schema, concurrency and model/provider choices. Markdown, HTML/JS content, CSS/XPath schema extraction, optional LLM calls, dynamic-page browsing and deep-crawl work as components of the one library, not duplicate model or service identities.
- Record the **tagged legacy setup.py cache-clearing side effect**: the script deletes `~/.crawl4ai/cache` (or the selected `CRAWL4_AI_BASE_DIRECTORY/.crawl4ai/cache`) when it executes, before invoking setuptools. Do not claim every pip installation triggers this path, but check packaging/update workflows, back up valuable local cache and avoid executing source setup scripts against production state without understanding effects.
- Server/API mode can expose URL fetch, screenshots, PDF and arbitrary `execute_js` capabilities and may use persistent authenticated browser profiles, cookies or external LLM providers. Require token authentication, network/URL egress allowlists, SSRF and local-file restrictions, explicit permission for crawling and scraping, domain policies, rate limits, secret isolation, download/corpus provenance and prompt-injection handling.
- Original v0.9.5 release says Docker images were still being built at publication, so do not present their availability as verified from that release announcement alone. Publisher claims about stealth, speed, scalability, cloud limits, accuracy and security are freshness-sensitive, not independently reproduced tests.
- Preserve Apache-2.0 source-license scope separate from third-party website content, images, datasets, provider contracts, robots directives and auth/paywall restrictions; do not frame anti-bot functionality as authority to bypass website controls. The [current hosted-service legal page](https://crawl4ai.com/legal/) independently requires lawful and authorized collection.
- Keep Crawl4AI distinct from [RAGFlow](../../ragflow/) itself: tagged RAGFlow v0.27.3 depends on `crawl4ai>=0.9.2,<0.9.3`, not the independent newer Crawl4AI v0.9.5. Do not substitute new library versions into that deployment without compatibility tests.
- Preserve the exact original `Unclecode` package author as an **individual alias/maintainer**, without inventing a legal name, registered company ownership, location, citizenship, or current Russian/non-Russian effective control.

## Validation

- One direct child exists at `catalog/software/application-frameworks/data-and-retrieval/crawl4ai` with one `produced-by` inverse to the original `Unclecode` author.
- Direct child index contains Crawl4AI once; existing RAGFlow, LlamaIndex, Haystack and Microsoft GraphRAG are retained.
- Cloud operator, model APIs, local library, Docker server, maintainer and their permission/rights boundaries are not conflated.
- Current release/version, license, installer side effect, and original package author are source-backed; full installation/agent/browser execution and corporate beneficial ownership remain unverified.
