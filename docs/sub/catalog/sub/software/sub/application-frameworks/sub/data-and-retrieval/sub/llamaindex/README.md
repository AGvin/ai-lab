# LlamaIndex

LlamaIndex is an open-source framework for building context-augmented LLM applications and agents over user or enterprise data. Its framework covers ingestion, indexing, retrieval, workflows, tools, and agent-oriented application patterns.

The framework connects application data with models through reusable context and retrieval components. The hosted platform now called LlamaParse, formerly LlamaCloud, is a separate operating surface; its rename does not change the open-source framework's identity.
