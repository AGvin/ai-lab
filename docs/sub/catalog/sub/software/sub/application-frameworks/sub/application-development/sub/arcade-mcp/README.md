# Arcade MCP

Arcade MCP is a released MIT-licensed Python framework for building MCP servers and tool integrations.

## Scope and capabilities

It provides tool, resource and prompt declarations, standalone MCP server execution and optional typed authentication declarations. These components are the installable library, not the broader Arcade platform.

## Deployment and safety boundaries

Standalone stdio or HTTP MCP servers differ from Arcade's provider-hosted token brokerage and operations platform. Pin the Python package and MCP revision. Authentication annotations do not replace per-user authorization; protect tokens, tool execution permissions and external API data.
