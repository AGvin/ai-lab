# Documentation Requirements

## Requirements

- Identify Genkit as Google's open-source framework for building full-stack AI-powered and agentic applications.
- Preserve its cross-language application-development surface across JavaScript/TypeScript, Go, Python, and Dart at a high level, together with unified model access, multimodal generation, structured output, tools, workflows, retrieval, and agent capabilities.
- Preserve deploy-anywhere/self-managed framework identity; Firebase and Google Cloud integrations are supported deployment options rather than mandatory runtime ownership.
- Keep language support maturity, plugin inventories, deployment integrations, monitoring products, and other mutable ecosystem facts source-backed when expanded.
- Link the canonical Google producer profile and, as an adjacent role boundary, the canonical Google ADK agent-framework profile without treating them as the same framework.
- Include current official Genkit and Firebase documentation references.

## Validation

- Genkit is not conflated with Firebase, Google ADK, or a hosted Google model service.
- Agent capabilities do not erase Genkit's broader full-stack application-framework identity.
- The Google producer link resolves to the canonical producer node.
