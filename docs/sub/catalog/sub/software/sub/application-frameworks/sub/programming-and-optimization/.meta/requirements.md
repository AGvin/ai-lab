# Documentation Requirements

## Requirements

- Present Programming and Optimization as the canonical software index for frameworks focused on programming, composing, or optimizing AI application behavior and model interactions.
- List every materialized direct child exactly once.
- Keep framework-specific optimization mechanisms, APIs, supported runtimes, and mutable compatibility facts with child software profiles.
- Keep general prompting, evaluation, and optimization concepts with their non-software canonical owners.

## Validation

- Navigation matches the materialized direct children.
- The index does not duplicate child framework profiles or general concept documentation.
