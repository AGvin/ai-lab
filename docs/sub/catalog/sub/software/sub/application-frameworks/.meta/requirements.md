# Documentation Requirements

## Requirements

- Present Application Frameworks as the canonical software catalog index for programming frameworks and libraries used to build AI-enabled applications, retrieval systems, model integrations, and optimized language-model programs.
- List every materialized direct child exactly once.
- Keep framework-specific identity, facts, APIs, setup, and implementation guidance with the child profiles.
- Do not reproduce or depend on legacy `catalog-item`, `catalog-index`, `common/index`, or `catalog/item` selectors.

## Validation

- Navigation matches the materialized direct children.
- The page remains category-level and does not duplicate concrete framework profiles.
- The page contains no temporary-placeholder wording.
