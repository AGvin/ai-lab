# Keras

High-level open-source framework and API for building, training and evaluating neural networks.

## Capabilities and software boundary

Keras 3 supports multiple execution backends, rather than being merely an alias for TensorFlow. TensorFlow, JAX, PyTorch, KerasHub and independently maintained model libraries have separate ownership.

## Compatibility, evidence and operations

Package, backend, export format, Python version, accelerators and distributed/precision features have version-specific compatibility. Do not transfer benchmarks or compatibility claims from one backend to another.
