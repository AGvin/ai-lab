# Kubeflow

Kubeflow is an open-source foundation and modular project ecosystem for building AI platforms on Kubernetes. Its subprojects span multiple stages of the AI lifecycle, including notebooks, training, tuning, pipelines, model artifacts and metadata, serving, and platform interfaces.

Kubeflow Pipelines remains a distinct canonical workflow product within this ecosystem rather than a synonym for the full Kubeflow platform.
