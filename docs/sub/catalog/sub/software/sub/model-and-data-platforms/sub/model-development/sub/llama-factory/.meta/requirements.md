# Documentation Requirements

## Requirements

- Present LLaMA Factory as a unified open-source model-development framework for efficient pre-training, supervised fine-tuning, preference/RLHF workflows, LoRA/QLoRA, reward modeling, and related LLM/VLM adaptation.
- Keep CLI/WebUI delivery and quantization/training integrations as product surfaces rather than separate canonical entities.
- Treat supported models, training stages, quantization methods, backends, package versions, hardware requirements, and benchmark claims as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- LLaMA Factory remains model-development software rather than optimization/compilation or inference-runtime ownership.
- Producer provenance resolves to the project-level LLaMA Factory producer identity.
