# JAX

An open-source Python library for high-performance numerical and machine-learning computation through composable program transformations.

## Capabilities and software boundary

Supports NumPy-like arrays, automatic differentiation, JIT compilation, vectorization and distributed/sharded accelerator computation. Flax, Optax, Orbax and compiler/runtime projects retain separate identities.

## Compatibility, evidence and operations

Upstream describes JAX as a research project, not an official Google commercial product. Check jax/jaxlib versions, supported Python platforms and GPU/TPU plugin requirements. Do not generalize experimental API or hardware behavior.
