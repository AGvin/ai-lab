# Documentation Requirements

## Requirements

- Identify Hugging Face Datasets as an open-source library for accessing, processing, streaming, and sharing AI datasets across text, audio, vision, video, document, tabular, and related data workloads.
- Preserve its primary placement under `model-and-data-platforms/data-libraries`; the library integrates deeply with the Hugging Face Hub but remains a distinct installable software item from the hosted Hub service.
- Preserve Hugging Face, Inc. as the canonical producer through the `produced-by` relation.
- Preserve Apache Arrow-backed processing/streaming and Hub integration as stable concepts while keeping supported formats, framework integrations, and release-specific APIs source-backed when expanded.
- Include current official Datasets documentation and repository references.

## Validation

- The page distinguishes the Datasets library from dataset repositories and hosted Hub dataset services.
- Mutable version or format support is not generalized without current source evidence.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
