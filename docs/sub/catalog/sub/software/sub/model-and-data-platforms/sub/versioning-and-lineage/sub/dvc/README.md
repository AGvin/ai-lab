# DVC

DVC (Data Version Control) is an open-source, Git-oriented command-line tool for versioning data and model artifacts, defining reproducible data or ML pipelines, managing experiments, and synchronizing large artifacts with remote storage.

DVC extends a Git repository with data/model provenance and reproducibility without storing large artifacts directly in Git history. The current open-source DVC project remains distinct from lakeFS and from separately operated historical Iterative commercial surfaces.

## Provenance and stewardship

- [Dmitry Petrov](../../../../../../../producers/sub/d/sub/dmitry-petrov/) — original creator and producer of DVC.
- [Treeverse, Inc.](../../../../../../../producers/sub/t/sub/treeverse-inc/) — current owner and maintainer/steward after lakeFS acquired DVC from Iterative.ai in November 2025.
