# Documentation Requirements

## Requirements

- Identify DVC (Data Version Control) as an open-source, Git-oriented command-line tool for versioning data/model artifacts, defining reproducible data/ML pipelines, managing experiments, and synchronizing large artifacts with remote storage.
- Preserve its primary placement under `model-and-data-platforms/versioning-and-lineage`; DVC extends Git workflows with data/model provenance and pipeline state rather than replacing Git itself or acting as a general experiment-tracking server.

- Preserve local cache plus configurable remote-storage behavior as a stable boundary while keeping supported backends, experiment features, and other mutable details source-backed when expanded.
- Distinguish current DVC CLI/software from lakeFS and from separately operated historical Iterative commercial surfaces; do not present Iterative.ai as DVC's current owner or maintainer.

- Include current official DVC documentation, current Treeverse-hosted repository, creator provenance, and acquisition/stewardship references.
