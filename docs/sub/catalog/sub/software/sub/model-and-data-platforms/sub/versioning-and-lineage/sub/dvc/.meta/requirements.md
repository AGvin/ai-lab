# Documentation Requirements

## Requirements

- Identify DVC (Data Version Control) as an open-source, Git-oriented command-line tool for versioning data/model artifacts, defining reproducible data/ML pipelines, managing experiments, and synchronizing large artifacts with remote storage.
- Preserve its primary placement under `model-and-data-platforms/versioning-and-lineage`; DVC extends Git workflows with data/model provenance and pipeline state rather than replacing Git itself or acting as a general experiment-tracking server.
- Preserve local cache plus configurable remote-storage behavior as a stable boundary while keeping supported backends, experiment features, Studio integrations, and other mutable details source-backed when expanded.
- Distinguish DVC CLI/software from separately operated DVC Studio and Iterative commercial services when those are discussed.
- Include current official DVC documentation and repository references.

## Validation

- The page preserves DVC's Git-oriented data/model versioning and reproducibility role.
- DVC software and DVC Studio/commercial services are not conflated.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
