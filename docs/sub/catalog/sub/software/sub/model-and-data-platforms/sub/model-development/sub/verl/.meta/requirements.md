# Documentation Requirements

## Requirements

- Present verl/HybridFlow as an open-source reinforcement-learning post-training framework for LLMs.
- Keep rollout, training, distributed execution, RL algorithms, inference-engine integration, and scaling mechanisms as parts of the same post-training identity.
- Treat supported algorithms/models, backends, hardware scale, version compatibility, and performance claims as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- verl remains model-development/post-training software rather than inference-runtime ownership.
- Producer provenance resolves to the verl Project; do not infer direct ByteDance production solely from project origin history.
