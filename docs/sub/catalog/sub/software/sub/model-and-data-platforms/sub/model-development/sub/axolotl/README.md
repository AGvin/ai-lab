# Axolotl

Axolotl is an open-source model-development/post-training framework for LLM/VLM fine-tuning and related training workflows.

## Scope and boundaries

- The profile keeps SFT, LoRA/QLoRA, preference optimization, reinforcement-learning methods, reward modeling, and distributed training as capabilities of the same model-development identity.
- The profile treats supported models, trainers, accelerators, optimization libraries, configuration schema, hardware requirements, and package versions as freshness-sensitive.
