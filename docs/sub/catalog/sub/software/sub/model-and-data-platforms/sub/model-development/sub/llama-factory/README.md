# LLaMA Factory

LLaMA Factory is a unified open-source model-development framework for efficient pre-training, supervised fine-tuning, preference/RLHF workflows, LoRA/QLoRA, reward modeling, and related LLM/VLM adaptation.

## Scope and boundaries

- The profile keeps CLI/WebUI delivery and quantization/training integrations as product surfaces rather than separate canonical entities.
- The profile treats supported models, training stages, quantization methods, backends, package versions, hardware requirements, and benchmark claims as freshness-sensitive.
