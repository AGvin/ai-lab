# TensorFlow

Open-source machine-learning framework originally developed at Google Brain and now represented by its own project identity.

## Capabilities and software boundary

Covers tensor computation, differentiation, model training, data pipelines, distributed execution and core deployment APIs. Keras, LiteRT, TensorFlow.js, TensorFlow Serving and TFX have potentially independent product identities.

## Compatibility, evidence and operations

Keep nightly and stable release behavior separate. Verify platform wheels, Python and C++ interfaces, accelerator drivers, supported OS and deprecations for the specific release; do not infer identical compatibility across the ecosystem.
