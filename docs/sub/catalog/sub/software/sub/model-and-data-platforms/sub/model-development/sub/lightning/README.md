# Lightning

The open-source PyTorch Lightning training framework for structuring reproducible neural-network training and evaluation.

## Capabilities and software boundary

Provides LightningModule and Trainer abstractions, callbacks, checkpointing, logging, precision settings and distributed training strategies. PyTorch, DeepSpeed and FSDP remain foundations or integrations.

## Compatibility, evidence and operations

The installable framework is distinct from managed Lightning services. Check PyTorch/Python/accelerator and strategy compatibility for the specific release; scaling and checkpoint behavior depend on runtime configuration.
