# verl

Verl/HybridFlow is an open-source reinforcement-learning post-training framework for LLMs.

## Scope and boundaries

- The profile keeps rollout, training, distributed execution, RL algorithms, inference-engine integration, and scaling mechanisms as parts of the same post-training identity.
- The profile treats supported algorithms/models, backends, hardware scale, version compatibility, and performance claims as freshness-sensitive.
