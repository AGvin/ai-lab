# Documentation Requirements

## Requirements

- Present NVIDIA NeMo RL as a scalable post-training/reinforcement-learning library for language models.
- Keep current RL algorithms, rollout/training backends, distributed-training integrations, checkpoint/model support, and cluster tooling within the model-development identity.
- Treat supported models, algorithms, framework/backends, hardware scale, versions, and performance claims as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- NeMo RL remains model-development/post-training software rather than inference-serving or model-optimization ownership.
- Producer provenance resolves to NVIDIA.
