# OpenRLHF

OpenRLHF is an open-source RLHF/agentic reinforcement-learning post-training framework based on Ray and compatible training/rollout engines.

## Scope and boundaries

- The profile keeps PPO/DAPO/REINFORCE++, asynchronous RL, VLM workflows, SFT, reward-model integration, vLLM/Ray/DeepSpeed-style integrations, and distributed training as parts of the model-development identity.
- The profile treats supported algorithms/models, rollout/inference backends, distributed topology, package versions, hardware requirements, and benchmark/performance claims as freshness-sensitive.
