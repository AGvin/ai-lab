# Hugging Face Datasets

Hugging Face Datasets is an open-source library for accessing, processing, streaming, and sharing AI datasets across text, audio, vision, video, document, tabular, and related workloads. Its processing model is built around Apache Arrow and integrates closely with the Hugging Face Hub.

The library is a local/installable client-side data tool; hosted dataset repositories and viewers on the Hub remain separate service surfaces.
