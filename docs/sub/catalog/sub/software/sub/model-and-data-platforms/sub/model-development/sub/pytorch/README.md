# PyTorch

The open-source tensor and deep-learning framework for model research, development and training.

## Capabilities and software boundary

Includes tensor operations, autograd, neural-network modules, compilation, data utilities and distributed/accelerator primitives. ExecuTorch, inference servers, Lightning and DeepSpeed may be independent software rather than PyTorch core components.

## Compatibility, evidence and operations

Choose release and binaries compatible with Python, OS and supported CUDA, ROCm, XPU, MPS or CPU target. Precision, compiler, distributed and accelerator features are not universal across platforms.
