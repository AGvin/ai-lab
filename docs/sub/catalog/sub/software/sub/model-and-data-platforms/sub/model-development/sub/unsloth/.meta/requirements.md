# Documentation Requirements

## Requirements

- Present Unsloth as an installable local model-development toolkit whose durable product center includes efficient fine-tuning/training, LoRA/QLoRA/full training, reinforcement learning, and related model-development workflows.
- Record current local inference, UI/Studio, API, RAG, and deployment capabilities as secondary product surfaces unless they later establish independently material identities.
- Treat supported models/modalities, fine-tuning methods, inference backends, hardware/platform support, package versions, and performance claims as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Unsloth remains model-development-first despite broader current run/deploy capabilities.
- Producer provenance resolves to Unsloth AI.
