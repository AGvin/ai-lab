# Snorkel Flow

Snorkel Flow is an enterprise platform for developing AI training data through labeling, review, feedback, and dataset curation. Its Kubernetes-native deployment supports customer infrastructure on AWS, Azure, Google Cloud, and Red Hat OpenShift.

The installed data-development platform remains distinct from exported model applications and the infrastructure that serves them. Labeling operators, notebooks, SDK access, and model-development workflows are platform capabilities.
