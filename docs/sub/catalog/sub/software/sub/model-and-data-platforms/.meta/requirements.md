# Documentation Requirements

## Requirements

- Present Model and Data Platforms as the canonical software catalog index for software used to manage, prepare, develop, version, curate, publish, or programmatically use model and data assets.
- List every materialized direct child exactly once.
- Preserve the current category decomposition while keeping library, platform, tooling, and product-specific facts with child profiles.
- Do not reproduce or depend on legacy `catalog-item`, `catalog-index`, `common/index`, or `catalog/item` selectors.

## Validation

- Navigation matches the materialized direct children.
- The page remains category-level and does not duplicate concrete software profiles.
- The page contains no temporary-placeholder wording.
