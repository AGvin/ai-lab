# Data Infrastructure

Self-managed operational data systems whose primary role in AI applications is storing, indexing, retrieving, searching, or maintaining reusable memory and context.

Packaging form is secondary to the product's primary role: a standalone server and a database extension can share a category when they solve the same reader problem.

## Child pages

- [`memory-and-context/`](./sub/memory-and-context/) — persistent or reusable memory and context infrastructure for AI systems and agents.
