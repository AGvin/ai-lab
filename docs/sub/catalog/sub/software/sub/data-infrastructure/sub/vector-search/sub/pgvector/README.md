# pgvector

pgvector is an open-source PostgreSQL extension for vector similarity search. It keeps vectors with PostgreSQL data and supports both exact and approximate nearest-neighbor search through PostgreSQL's extension and indexing model.

Its packaging as a PostgreSQL extension is secondary to its primary catalog role. For navigation, pgvector belongs with vector-search infrastructure such as Qdrant rather than under a packaging-specific database-extension branch.
