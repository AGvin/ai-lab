# RuVector

RuVector is persistent, adaptive memory infrastructure for AI agents. Its upstream design combines local semantic embeddings, persistent vector retrieval, graph relationships, feedback-driven learning, and memory lifecycle controls around the problem of retaining and recalling useful context across sessions.

That memory-first identity determines its catalog placement. Vector and graph mechanisms remain implementation capabilities rather than reasons to place RuVector beside general vector-search backends. The default retrieval path is local; optional hosted services introduce a separate data boundary.
