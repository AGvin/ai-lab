# Chroma

Chroma is open-source vector-search and retrieval infrastructure that developers can run locally, embed in an application, or deploy as a self-managed client/server system.

## Scope and capabilities

Chroma supplies vector storage and retrieval with supported indexing, filtering, persistence and retrieval integrations. Python, TypeScript and other clients are interfaces to the same underlying software, not independently owned databases.

## Deployment, evidence and boundaries

Its released, self-managed software is separate from the provider-operated Chroma Cloud service. Check the current Chroma release documentation for API, persistence, indexing, deployment, security and compatibility requirements. Cloud-only quotas or performance claims must not be applied automatically to local installations.
