# LanceDB OSS

LanceDB OSS is an open-source, self-managed and embedded retrieval/data platform for vector, text and multimodal search.

## Scope and capabilities

LanceDB combines vector and keyword retrieval with columnar storage and the Lance data format ecosystem. Python and other language clients are application interfaces; its indexing, table lifecycle and filtering capabilities depend on the selected release.

## Deployment, evidence and boundaries

The independently released OSS library is distinct from provider-managed or Enterprise offerings, whose deployment architecture, licensing, APIs and support may differ. Keep speed and scaling claims tied to documented index types, data, hardware and reproducible workloads.
