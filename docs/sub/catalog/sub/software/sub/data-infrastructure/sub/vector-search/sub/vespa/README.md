# Vespa

Vespa is an open-source distributed search and AI-serving platform supporting retrieval over vectors, text, tensors and structured data, plus query-time ranking.

## Scope and capabilities

The self-managed Vespa engine can support hybrid retrieval and machine-learned ranking as parts of the same search platform. Search and ranking functionality are not separate product identities merely because they serve different query stages.

## Deployment, evidence and boundaries

The self-managed engine is distinct from Vespa Cloud, where provider-operated infrastructure handles additional application and cluster operations. Verify deployment, supported model/ranking formats, storage and scaling assumptions for the chosen release. Public performance measurements are workload- and hardware-specific.
