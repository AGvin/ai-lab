# Documentation Requirements

## Requirements

- Identify Hindsight as Vectorize's separately released open-source/self-hostable **agent memory infrastructure** focused on the retain, recall and reflect operations, not an end-to-end agent framework or inference-model API.
- Treat memory banks, entity/time extraction, observation consolidation, graph/vector retrieval, PostgreSQL or other supported stores and client integrations as implementation capabilities; compare against actual version and deployment rather than universal guarantees.
- Distinguish source-code **MIT** licensing from the vendor-operated Hindsight Cloud and enterprise/commercial deployment services. Do not assume hosted access rights, backups, security features, prices, data-residency regions or service levels from the OSS code license.
- Scope the observed non-prerelease GitHub **v1.1.0** release to 2026-10-21; packages, storage modes, model-provider lists, SDKs and MCP integration must be revalidated before operational recommendations.
- Surface material long-lived memory risks: PII/confidential data persistence, per-bank tenant authorization, cross-session disclosure, data deletion and backup recovery, remote model provider transfer, stale/hallucinated memories, untrusted prompt injection and auditability. Do not imply that a bank identifier is sufficient authorization.
- Keep performance, benchmark leadership, external collaborator replication, costs and production readiness as publisher/source-attributed, configuration- and date-scoped claims; no independent AI Lab deployment, benchmark or security audit.
- Preserve one canonical `produced-by` relation to `catalog/producers/v/vectorize-ai-inc` with a matching `produces` inverse, no duplicate software/producer entries.
- Render the validated canonical entity-relations block and direct-child navigation when the rendering phase runs; this source-authored package does not claim complete schema/cache/CI/render validation.
