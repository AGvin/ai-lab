# Documentation Requirements

## Requirements

- Present Cognee as an open-source/self-hosted AI memory platform centered on persistent long-term memory and knowledge-graph infrastructure for agents.
- Keep graph/vector storage, ingestion, retrieval, and framework integrations as capabilities of the same memory-first software identity.
- Treat supported stores/providers, package versions, deployment modes, APIs, and benchmark/performance claims as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Cognee remains memory/context software rather than a managed memory service or complete agent framework.
- Producer provenance resolves to the upstream Topoteretes organization.
