# Milvus

Milvus is an open-source vector database for similarity search and retrieval, developed by Zilliz and donated to the LF AI & Data Foundation.

## Scope and capabilities

Self-managed installations include supported lightweight, standalone and distributed configurations; index, filtering, hybrid search and consistency features depend on the software release and deployment mode. Milvus Lite and client SDKs are not automatically independent catalog products.

## Deployment, evidence and boundaries

Milvus software is distinct from Zilliz Cloud and other hosted managed offerings. Verify release-series APIs, storage topology, supported hardware, resource requirements, operational security and SDK compatibility against the deployed version; treat scale and performance figures as configuration-specific.
