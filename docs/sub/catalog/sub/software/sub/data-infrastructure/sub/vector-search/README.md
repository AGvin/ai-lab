# Vector Search

Self-managed software for vector storage, indexing, similarity search, and retrieval.

The category is role-based rather than packaging-based: Qdrant is a standalone vector-search system, while pgvector extends PostgreSQL, but both serve the same primary vector-search need.

## Child pages

- [Chroma](./sub/chroma/) — self-managed vector database and retrieval infrastructure.
- [Faiss](./sub/faiss/) — embeddable vector indexing and similarity-search library.
- [LanceDB OSS](./sub/lancedb/) — embedded vector, text and multimodal retrieval.
- [Milvus](./sub/milvus/) — distributed open-source vector database.
- [pgvector](./sub/pgvector/) — PostgreSQL extension for vector similarity search.
- [Qdrant](./sub/qdrant/) — self-managed vector search database.
- [Vespa](./sub/vespa/) — distributed search, retrieval and ranking platform.
- [Weaviate Database](./sub/weaviate/) — self-managed vector and hybrid-search database.
