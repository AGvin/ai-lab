# Mem0 Open Source

Mem0 Open Source is the self-managed/open-source Mem0 memory engine, distinct from the producer-operated Mem0 Platform service.

## Scope and boundaries

- The profile keeps library and self-hosted-server delivery as deployment forms of the same software identity.
- The profile treats vector stores, graph services, embeddings, rerankers, model/provider support, package versions, and deployment requirements as freshness-sensitive implementation details.
