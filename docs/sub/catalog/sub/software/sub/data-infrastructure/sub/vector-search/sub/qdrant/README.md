# Qdrant

Qdrant is open-source vector-search infrastructure for storing, searching, and managing records represented by vectors together with payload metadata. Its primary catalog role is operational vector search and retrieval, so it is grouped with other vector-search backends rather than with application frameworks or model/data lifecycle tooling.

Qdrant can be operated as self-managed software. Qdrant Cloud is a separate hosted operating surface and should not be treated as the same deployment boundary as the software profile.
