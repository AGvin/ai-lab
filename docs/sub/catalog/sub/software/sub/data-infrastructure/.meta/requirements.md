# Documentation Requirements

## Requirements

- Present Data Infrastructure as the canonical software catalog index for self-managed operational data systems whose primary role is storing, indexing, retrieving, searching, or maintaining reusable memory and context for AI applications.
- List every materialized direct child exactly once.
- Preserve the boundary from application frameworks that orchestrate retrieval, model/data lifecycle tooling, hosted-only managed services, and user-facing knowledge workspaces.
- Keep packaging form such as standalone server, embedded library, or database extension secondary to primary-role placement.

## Validation

- Navigation matches the materialized direct children.
- The page remains category-level and does not duplicate concrete infrastructure profiles.
- The page contains no temporary-placeholder wording.
