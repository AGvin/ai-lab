# AI Management Platforms

This software category owns installable or self-managed control-plane products whose primary identity is organization-wide AI access, governance, policy, cost, identity, provider or model administration, and related operational management across multiple AI capabilities.

A product does not belong here merely because it has an admin UI or gateway. The management/control-plane identity must be broader than a single gateway, observability, workflow, or model-serving role.
