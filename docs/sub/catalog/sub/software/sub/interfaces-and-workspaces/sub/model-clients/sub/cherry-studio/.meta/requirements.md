# Documentation Requirements

## Requirements

- Identify Cherry Studio as an open-source desktop AI client/productivity studio for Windows, macOS, and Linux that connects to multiple hosted and local LLM providers.
- Preserve its primary placement under `interfaces-and-workspaces/model-clients`; assistants, agents, document handling, knowledge features, and MCP/tool integrations extend the desktop client rather than changing its core product boundary.
- Preserve local-provider support such as Ollama and LM Studio without treating those inference runtimes as bundled model ownership.
- Keep model/provider counts, assistant counts, edition/licensing details, supported tools, platform requirements, and release-specific features source-backed when expanded.
- Include the current official Cherry Studio repository reference.

## Validation

- The page presents Cherry Studio as a multi-provider desktop client rather than a model provider or inference runtime.
- Connected local runtimes remain separate canonical products.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
