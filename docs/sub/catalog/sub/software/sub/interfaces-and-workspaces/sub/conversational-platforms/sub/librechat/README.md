# LibreChat

LibreChat is an open-source, self-hosted web conversational platform for working with multiple AI model providers and compatible local or remote endpoints. Its interface also integrates agents, MCP tools, file/RAG workflows, code execution, and related AI-workspace capabilities.

LibreChat is deployed as a web application rather than as a native desktop client; the model providers and auxiliary services it connects to remain separate operating boundaries.
