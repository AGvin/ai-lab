# Documentation Requirements

## Requirements

- Identify AnythingLLM as an open-source, local-first AI workspace that combines model chat, document/knowledge retrieval, agents, tools, vector-storage integration, and multi-user workflows.
- Preserve its primary placement under `interfaces-and-workspaces/integrated-workspaces`; desktop and self-hosted server deployments are operating forms of the same broader workspace product.
- Distinguish local/self-hosted AnythingLLM software from AnythingLLM Cloud and other Mintplex-operated hosted surfaces.
- Preserve the boundary that Desktop is a standalone local instance while Docker/self-hosted deployments can serve centralized multi-user use cases; do not imply those modes automatically share state.
- Keep model/vector-provider integrations, agent features, edition limits, deployment options, and other mutable details source-backed when expanded.
- Include current official AnythingLLM documentation and repository references.

## Validation

- The page presents AnythingLLM as an integrated workspace rather than only a RAG frontend or only an agent product.
- Self-hosted/Desktop and hosted service boundaries are not conflated.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
