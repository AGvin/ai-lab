# Documentation Requirements

## Requirements

- Present Perplexity Comet as Perplexity AI's released AI-native web browser and integrated workspace combining ordinary browsing with context-aware assistant/agent actions across tabs, pages, web applications, research, communication, and other browser-mediated workflows.
- Preserve browser-first primary identity while using the existing Integrated Workspaces category because Comet combines browsing, model interaction, agent actions, connected services, and persistent cross-device work context in one user-facing application.
- Keep Perplexity's hosted answer/research workspace, Perplexity Computer, Portable Computer, API Platform, underlying models, and third-party websites/connectors as separate product or dependency identities.
- Treat supported OS/platforms, sync, default models, Comet Assistant behavior, background assistants, email/voice features, enterprise management, permissions, browser engine/version, plans, regional availability, and connected-app capabilities as freshness-sensitive.
- Preserve browser trust boundaries around logged-in sessions, cookies, browsing history, page content/prompt injection, downloads, connected accounts, form submission, purchase/email/calendar actions, and autonomous/background actions.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Comet remains browser-first integrated software rather than a hosted browser-infrastructure service.
- Comet Assistant/Background Assistant features are not automatically split into peer product identities without independent lifecycle evidence.
- Producer provenance resolves bidirectionally to Perplexity AI.
