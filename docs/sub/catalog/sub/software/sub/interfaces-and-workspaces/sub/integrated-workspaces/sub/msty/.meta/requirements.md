- Identify the current product as Msty Studio, a privacy-first AI platform/workspace for using local and online models from desktop and web surfaces; retain the stable catalog slug `msty` and legacy Msty/Msty App names as aliases rather than creating a duplicate product path.
- Preserve its primary placement under `interfaces-and-workspaces/integrated-workspaces`; local-model management, online providers, knowledge stacks, MCP tools, personas, media, crews, and agent modes are integrated workspace capabilities.

- Render the standard `entity-relations` block from the validated current-entity relation projection.
- Preserve the local-data boundary: Studio Desktop stores data on the device and Studio Web stores data in the browser; current documentation says data does not automatically sync between devices.
- Distinguish current Msty Studio documentation/product surface from legacy Msty App 1.x documentation.
- Keep plan-specific Web access, model/provider inventories, local-engine support, tool/agent capabilities, and other mutable details source-backed when expanded.
