# Perplexity Comet

Perplexity Comet is a browser with an integrated AI assistant for browsing, researching, and taking actions across websites and connected services. Browsing is the primary interface; the assistant and task workflows make it an integrated workspace.

Ordinary browsing data, cookies, and passwords remain on the device by default. When the assistant is asked to act, the context needed for that request is sent to Perplexity. Assistant use of page content and connected accounts is therefore a separate boundary from ordinary local browser storage.

Comet remains distinct from Perplexity's hosted answer workspace, Perplexity Computer, Portable Computer, API Platform, underlying models, and third-party sites or connected services.
