# Documentation Requirements

## Requirements

- Identify Open WebUI as a self-hosted, extensible AI platform centered on a web conversational interface for local and cloud-based models.
- Preserve its primary placement under `interfaces-and-workspaces/conversational-platforms`; knowledge, tools, agents, search, media, and team features extend the conversational platform rather than creating duplicate canonical identities.
- Preserve provider-agnostic operation through Ollama, OpenAI-compatible, Open Responses, and other supported provider surfaces without treating any one backend as required product identity.
- Keep installation methods, provider support, feature inventory, offline behavior, licensing, and other mutable details source-backed when expanded.
- Include current official Open WebUI documentation and repository references.

## Validation

- The page presents Open WebUI as a self-hosted conversational AI platform rather than as an inference engine or model provider.
- Connected model providers remain distinct from the Open WebUI software identity.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
