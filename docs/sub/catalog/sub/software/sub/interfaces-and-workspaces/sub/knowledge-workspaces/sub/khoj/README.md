# Khoj

Khoj is an open-source, self-hostable personal AI and second-brain knowledge workspace centered on a durable personal corpus of notes, documents, and other user knowledge.

## Scope and boundaries

- The profile preserves its primary placement under `interfaces-and-workspaces/knowledge-workspaces`: personal knowledge ingestion, semantic search, source-grounded chat, and working with the user's persistent knowledge corpus are central to the current product identity.
- The profile treats conversational access, agents/automation, public-internet research, and multi-client access as substantial capabilities without letting them override the primary knowledge-workspace boundary.
- The profile preserves Khoj Inc. as the organization behind the product without collapsing organization, software, and the historical hosted-service identity.
- The profile keeps supported document formats, model providers, client integrations, automation/agent features, and other mutable software details source-backed when expanded.
