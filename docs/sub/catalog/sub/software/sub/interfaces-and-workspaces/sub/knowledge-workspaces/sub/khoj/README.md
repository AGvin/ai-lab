# Khoj

Khoj is open-source, self-hostable software for working with a personal collection of notes, documents, and other knowledge. It combines ingestion, semantic search, and source-grounded chat; conversational access, internet research, automation, and agents build on that knowledge workspace.

The hosted Khoj Cloud service shut down on April 15, 2026. The open-source software and self-hosted deployments continue as a separate operating option.
