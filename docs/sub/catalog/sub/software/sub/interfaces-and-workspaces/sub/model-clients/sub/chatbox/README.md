# Chatbox

Chatbox is a cross-platform AI client for working with multiple hosted and local model providers. The desktop application supports configurable provider APIs and local runtimes such as Ollama while keeping conversation and client state on the user's device.

The public `chatboxai/chatbox` repository contains the GPLv3 Community Edition. Chatbox's official distribution also has separately maintained product features, so the community source tree should not be assumed to define the entire commercial/official surface.
