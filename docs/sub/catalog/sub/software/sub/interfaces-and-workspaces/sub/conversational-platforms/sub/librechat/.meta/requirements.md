# Documentation Requirements

## Requirements

- Identify LibreChat as an open-source, self-hosted web conversational platform for interacting with multiple AI model providers and local/provider-compatible endpoints.
- Preserve its primary placement under `interfaces-and-workspaces/conversational-platforms`; agents, MCP tools, RAG/file search, code execution, and other capabilities extend the conversation platform rather than making LibreChat a standalone agent framework.
- Preserve the current boundary that LibreChat is a self-hosted web application rather than a native desktop application.
- Keep provider integrations, agent capabilities, deployment dependencies, storage architecture, and other mutable implementation details source-backed when expanded.
- Include current official LibreChat documentation and repository references.

## Validation

- The page does not describe LibreChat as a native desktop client.
- Self-hosted deployment remains distinct from model/provider services LibreChat connects to.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
