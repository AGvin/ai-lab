# Khoj

Khoj is an open-source personal AI and second-brain workspace for chatting with personal knowledge, searching notes and documents, and incorporating information from the public internet. It is accessible through web and several client integrations and can be self-hosted on consumer hardware.

Khoj Cloud is a separate hosted operating surface; the self-hosted product remains the canonical software boundary here.
