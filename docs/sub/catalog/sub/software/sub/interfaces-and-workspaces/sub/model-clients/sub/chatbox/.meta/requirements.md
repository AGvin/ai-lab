# Documentation Requirements

## Requirements

- Identify Chatbox as a cross-platform AI model client whose desktop product connects to multiple hosted and local model providers, including compatible local runtimes such as Ollama.
- Preserve its primary placement under `interfaces-and-workspaces/model-clients`; provider connectivity, prompt/conversation management, and related client features do not make Chatbox an inference runtime or model provider.
- Preserve the current edition boundary: the public `chatboxai/chatbox` repository is the GPLv3 Community Edition, while the official distribution also includes a separately maintained Official/Pro product surface.
- Keep provider support, platform availability, edition features, mobile/web surfaces, and release details source-backed when expanded.
- Include current official Chatbox site and Community Edition repository references.

## Validation

- The page does not imply that the public Community Edition repository fully represents every Official/Pro feature.
- Chatbox remains a client over external/local model providers rather than an inference engine.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
