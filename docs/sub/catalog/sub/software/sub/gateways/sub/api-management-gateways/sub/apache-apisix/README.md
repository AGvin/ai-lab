# Apache APISIX

Apache APISIX is an open-source, dynamic API gateway for routing, securing, transforming, and governing API traffic.

Its AI and LLM integrations extend a broader API-management role, so APISIX remains under API-management gateways rather than being classified primarily as a model gateway.

APISIX originated at API7.ai and was donated to the Apache Software Foundation in 2019. It is now an Apache top-level project; historical origin is distinct from current Apache governance and API7 commercial products.
