# Higress

Higress is an open-source, cloud-native API gateway based on Istio and Envoy. Its current product surface includes first-class AI-gateway capabilities for model, tool, and agent traffic alongside general API-management functionality.

That broader gateway identity keeps Higress under API-management gateways. Alibaba Cloud also operates commercial gateway services around this technology, which are separate service boundaries.
