# Helicone

Helicone is an open-source AI/model gateway platform whose request path unifies model-provider access, routing/fallback, and observability.

## Scope and boundaries

- The profile covers its gateway, routing, fallback, caching/rate-limit, prompt, analytics/observability, evaluation-feedback, and self-hosting surfaces only from current sources.
- The profile preserves the current lifecycle accurately: Helicone was acquired by Mintlify on 2026-03-03; its services remain live in maintenance mode with security, model, bug, and performance updates, and current signup availability must remain source-backed.
- The profile does not treat maintenance mode as abandonment, but do not present Helicone as an actively expanding peer without current evidence.
- The profile keeps supported providers, model counts, pricing, signup state, and hosted availability freshness-sensitive.
