# Helicone

Helicone is an open-source AI/model gateway platform whose request path unifies model-provider access, routing/fallback, and observability.

## Scope and maintenance

Helicone combines model-provider routing and fallback with request observability and related evaluation workflows. Deployment options, supported models, and hosted availability depend on the selected offering.

In its [March 3, 2026 announcement](https://www.helicone.ai/blog/joining-mintlify), Helicone reported its acquisition by Mintlify and said its services would continue in maintenance mode, with security updates, new-model support, and bug and performance fixes.

The [current official site](https://www.helicone.ai/) now displays an undated notice that Helicone is no longer part of Mintlify and that details will follow. The notice does not specify current legal ownership, transaction structure or new maintenance and support commitments.
