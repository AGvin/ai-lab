# Kong Gateway

Kong Gateway is a cloud-native API gateway and reverse-proxy layer for managing, securing, configuring, and routing API traffic across distributed systems.

Legacy AI-gateway plugins and LLM-oriented use cases in Kong Gateway 3.x extend this general API-management product. The independently versioned Kong AI Gateway 2.x uses a separate product/entity model and has its own [catalog profile](../../../../../../../services/sub/gateways/sub/model-gateways/sub/kong-ai-gateway/). Konnect and other Kong-operated control-plane services remain separate from self-managed Kong Gateway deployments.
