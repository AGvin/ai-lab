# API Management Gateways

Self-managed gateways and ingress/control-plane software for ordinary APIs and agent/MCP endpoints, including routing, authentication, authorization, quotas and observability. Their primary role differs from inference-only model-provider gateways.

## Child pages

- [Apache APISIX](./sub/apache-apisix/) — general-purpose API gateway with AI integration capabilities.
- [Envoy AI Gateway](./sub/envoy-ai-gateway/) — Envoy-based AI gateway control plane.
- [Higress](./sub/higress/) — API and AI ingress gateway.
- [Kong Gateway](./sub/kong-gateway/) — general API ingress and governance gateway.
- [Kuadrant MCP Gateway](./sub/kuadrant-mcp-gateway/) — Kubernetes-native MCP routing and policy gateway.
- [MCP Gateway & Registry](./sub/mcp-gateway-registry/) — asset registry and access-control gateway for MCP resources.
