# Agent Router

Agent Router, formerly Envoy AI Gateway, is an Apache-2.0-licensed, Kubernetes-oriented AI and agent traffic control plane built on Envoy and Envoy Gateway. It adds provider integration, routing, policy, rate limiting, failover and security controls to the Envoy gateway model.

It is gateway infrastructure rather than a model provider or hosted model API. The project became Agent Router and joined the Agentic AI Foundation on September 10, 2026. Tetrate and Bloomberg remain its joint historical originators; AAIF stewardship is a separate relationship.

The canonical `envoy-ai-gateway` path remains stable. Deployed compatibility names such as `aigw`, `AIGatewayRoute`, `AIServiceBackend`, `BackendSecurityPolicy`, `aigateway.envoyproxy.io`, and existing Helm, container and module namespaces retain their historical names.
