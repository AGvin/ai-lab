# Portkey AI Gateway

Portkey AI Gateway is an open-source model gateway for unified access to multiple AI providers together with routing, fallbacks, load balancing, caching, guardrails, and related operational controls.

The open-source gateway can run locally or self-hosted. Portkey also operates hosted gateway and broader platform services, which are separate operating surfaces from the software profile.
