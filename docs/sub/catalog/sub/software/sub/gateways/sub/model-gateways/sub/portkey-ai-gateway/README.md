# Portkey AI Gateway

Portkey AI Gateway is an open-source model gateway for unified access to multiple AI providers together with routing, fallbacks, load balancing, caching, guardrails, and related operational controls.

The open-source gateway can run locally or self-hosted and remains represented here as software produced by Portkey, Inc. Palo Alto Networks completed its acquisition of Portkey in May 2026; the current producer-operated commercial gateway surface is presented as Prisma AIRS AI Gateway, which Palo Alto Networks announced as generally available in July 2026. That managed commercial surface remains distinct from this open-source software profile.
