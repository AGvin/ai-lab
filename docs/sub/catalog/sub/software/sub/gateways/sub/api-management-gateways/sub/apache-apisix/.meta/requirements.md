# Documentation Requirements

## Requirements

- Identify Apache APISIX as an open-source, dynamic API gateway for routing and governing API traffic.
- Preserve its primary placement under `gateways/api-management-gateways`; AI/LLM integrations and plugins are capabilities of the broader API-gateway product rather than its sole identity.
- Keep release versions, plugin inventory, deployment details, performance claims, and other mutable implementation facts source-backed when expanded.
- Include current official Apache APISIX documentation and repository references.

## Validation

- The page presents APISIX as a general API-management gateway rather than an AI-model gateway.
- AI-related capabilities are treated as extensions of the gateway's broader traffic-management role.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
