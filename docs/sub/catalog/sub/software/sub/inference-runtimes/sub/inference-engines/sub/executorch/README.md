# ExecuTorch

ExecuTorch is PyTorch's efficient inference solution/runtime for edge, mobile, desktop, embedded, and microcontroller-class devices.

## Scope and boundaries

- The profile keeps export, quantization, backend lowering, profiling, and LLM deployment tooling as parts of the ExecuTorch deployment workflow while runtime execution remains primary.
- The profile treats supported platforms/backends, PyTorch compatibility, hardware accelerators, package versions, model coverage, and performance claims as freshness-sensitive.
