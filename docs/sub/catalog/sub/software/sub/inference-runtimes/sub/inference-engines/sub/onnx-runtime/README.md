# ONNX Runtime

ONNX Runtime is a cross-platform machine-learning inference runtime/model accelerator for executing models across server, cloud, edge, mobile, and web targets.

## Scope and boundaries

- The profile keeps execution-provider integration, runtime graph optimization, mobile/web variants, and optional training surfaces as capabilities of the same runtime identity.
- The profile treats supported execution providers, ONNX opsets, languages, platforms, accelerator/library versions, packages, and performance claims as freshness-sensitive.
