# LMDeploy

Open-source toolkit for optimized language- and supported multimodal-model inference and serving.

## Runtime capabilities and boundaries

Includes TurboMind and PyTorch inference backends, model compression and quantization, and optional API serving. These are integrated components, not independent managed model services.

## Compatibility and reproducibility

Verify stable release, exact model support, GPU backend, quantization and package dependencies. Benchmark outcomes depend on model, precision, batch, accelerator and runtime revision.
