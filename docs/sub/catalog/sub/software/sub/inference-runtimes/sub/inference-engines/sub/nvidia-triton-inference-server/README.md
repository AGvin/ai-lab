# NVIDIA Triton Inference Server

Open-source server for executing AI models through multiple configurable inference backends.

## Runtime capabilities and boundaries

Provides model repositories, dynamic/sequence batching, ensembles, HTTP/gRPC APIs, metrics and custom backends. TensorRT, TensorRT-LLM, Dynamo and NIM are distinct software or integration boundaries.

## Compatibility and reproducibility

Check compatible Triton and framework backend versions, drivers and CUDA dependencies. Current TensorRT-LLM serving differs from deprecated legacy engine-build workflows; main-branch features may be unreleased.
