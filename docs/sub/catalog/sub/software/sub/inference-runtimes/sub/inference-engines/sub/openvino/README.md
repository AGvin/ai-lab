# OpenVINO

Open-source toolkit for converting, compiling, optimizing and running neural-network inference.

## Runtime capabilities and boundaries

Includes OpenVINO Runtime and supported CPU, GPU and NPU device plugins. NNCF compression and a separate OpenVINO Model Server are distinct products; tokenizers and GenAI libraries can be toolkit components.

## Compatibility and reproducibility

Confirm model formats, toolkit and driver releases, target device, accelerator availability and APIs. Precision, compatibility, latency and throughput depend on a tested device/model configuration.
