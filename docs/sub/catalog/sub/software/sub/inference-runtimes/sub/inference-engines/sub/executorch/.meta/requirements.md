# Documentation Requirements

## Requirements

- Present ExecuTorch as PyTorch's efficient inference solution/runtime for edge, mobile, desktop, embedded, and microcontroller-class devices.
- Keep export, quantization, backend lowering, profiling, and LLM deployment tooling as parts of the ExecuTorch deployment workflow while runtime execution remains primary.
- Treat supported platforms/backends, PyTorch compatibility, hardware accelerators, package versions, model coverage, and performance claims as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- ExecuTorch remains inference-runtime software rather than compiler-first model optimization.
- Producer provenance resolves to the PyTorch Project.
