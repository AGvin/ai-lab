# TensorRT-LLM

TensorRT-LLM is NVIDIA's open-source library and runtime for accelerating and optimizing large-language-model inference on NVIDIA GPUs. It provides APIs and runtime machinery for efficient single- and multi-GPU or multi-node inference setups.

TensorRT-LLM is an inference engine that can integrate with higher-level serving systems such as NVIDIA Dynamo; those systems remain separate canonical products.
