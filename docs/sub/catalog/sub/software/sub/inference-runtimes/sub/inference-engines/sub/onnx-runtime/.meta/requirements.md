# Documentation Requirements

## Requirements

- Present ONNX Runtime as a cross-platform machine-learning inference runtime/model accelerator for executing models across server, cloud, edge, mobile, and web targets.
- Keep execution-provider integration, runtime graph optimization, mobile/web variants, and optional training surfaces as capabilities of the same runtime identity.
- Treat supported execution providers, ONNX opsets, languages, platforms, accelerator/library versions, packages, and performance claims as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- ONNX Runtime remains execution/inference-first rather than model-optimization/compilation ownership.
- Producer provenance resolves to Microsoft.
