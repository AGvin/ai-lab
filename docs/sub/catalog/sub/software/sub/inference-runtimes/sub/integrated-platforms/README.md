# Integrated Inference Platforms

Application- or developer-facing software that combines model acquisition or configuration, runtime management, packaging, local user interfaces, or API exposure into one coherent inference workflow. A desktop GUI is optional: developer packaging and service platforms also qualify. Standalone inference engines, distributed cluster schedulers, and separately operated hosted model services have distinct catalog roles.
