# ONNX Runtime GenAI

Microsoft generative-model inference extension for ONNX Runtime.

## Runtime capabilities and boundaries

Adds generative decoding, sampling, KV-cache management, model-loading helpers and supported multimodal or batching features. It is not the ONNX serialization format, the base ONNX Runtime or a trained model.

## Compatibility and reproducibility

Confirm release-specific architectures, execution providers, API languages, package variants and supported numerical formats. Roadmaps do not establish released support or universal performance improvements.
