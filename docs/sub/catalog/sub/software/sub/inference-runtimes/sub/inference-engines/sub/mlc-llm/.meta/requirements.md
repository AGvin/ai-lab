# Documentation Requirements

## Requirements

- Identify MLC LLM as a machine-learning compiler and high-performance deployment engine for large language models across multiple platforms.
- Preserve its primary placement under `inference-runtimes/inference-engines`; compiler and deployment/runtime surfaces form one project identity.
- Preserve cross-platform native deployment as a stable concept while keeping exact platform/backend support, API surfaces, model coverage, and performance claims source-backed when expanded.
- Include current official MLC LLM documentation and repository references.

## Validation

- The page describes both compilation and inference/deployment roles without splitting them into duplicate products.
- The page does not imply support for a platform or model unless source-backed.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
