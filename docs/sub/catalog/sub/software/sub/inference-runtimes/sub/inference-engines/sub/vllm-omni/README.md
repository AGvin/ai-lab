# vLLM-Omni

Independently released open-source inference runtime for multimodal and non-autoregressive generation.

## Runtime capabilities and boundaries

Targets supported text, images, audio, video and action-based serving, with staged pipelines and selected diffusion and real-time modes. It shares ecosystem concepts with vLLM but has distinct source and release lifecycles.

## Compatibility and reproducibility

Validate released model inventory, backend and device support, stage pipeline, caching and API protocols. Not every modality or accelerator is available in each release; benchmarks need matched workloads.
