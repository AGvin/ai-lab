# LocalAI

LocalAI is an open-source, self-hosted AI engine and integrated platform that exposes compatible APIs over multiple local inference backends. Its current surface spans text generation, embeddings, audio, vision, image and video generation, and agent-oriented capabilities.

LocalAI coordinates and packages multiple underlying engines, so it remains an integrated inference platform rather than being classified as a single low-level inference engine.

Ettore Di Giacinto (`mudler`) is LocalAI's creator, original author, and project lead. The LocalAI Team is its current maintainer group, alongside a wider contributor community. Available modalities depend on the installed backends, models, and hardware.
