# KServe

KServe is a Kubernetes-native model-inference/serving platform for operating predictive and generative model workloads at scale.

## Scope and boundaries

- The profile keeps InferenceService, model-serving runtimes, networking/autoscaling modes, model protocols, and Kubernetes integrations as parts of the distributed-serving platform identity.
- The profile treats KServe/Kubernetes versions, deployment modes, supported runtimes/protocols, generative-serving features, networking requirements, and performance claims as freshness-sensitive.
