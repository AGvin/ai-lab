# Seldon Core 2

Seldon Core 2 is the current v2 Seldon Core model-serving/MLOps framework for deploying, managing, and monitoring production model workloads.

## Scope and boundaries

- The profile keeps runtime/model-server integration, Kubernetes deployment, scheduling, pipelines, observability, and model-management capabilities within the distributed-serving identity.
- Version-2 facts remains distinct from historical Seldon Core v1 behavior when incompatible or structurally different.
- The profile treats release versions, Kubernetes/runtime compatibility, deployment architecture, supported protocols/runtimes, and availability claims as freshness-sensitive.
