# Documentation Requirements

## Requirements

- Identify LocalAI as an open-source, self-hosted AI engine/platform that exposes compatible APIs over multiple local inference backends and supports text, embeddings, audio, vision, image/video generation, and agent-oriented capabilities.
- Preserve its primary placement under `inference-runtimes/integrated-platforms`; LocalAI integrates multiple backend engines and user-facing/runtime capabilities rather than being a single inference kernel.
- Preserve local/self-hosted operation as the canonical software boundary without implying that every backend or modality is available on every hardware configuration.
- Keep backend counts, supported modalities/models, hardware matrices, distributed modes, agent features, and other mutable implementation facts source-backed when expanded.
- Include current official LocalAI site and repository references.

## Validation

- The page reflects LocalAI's current broader integrated-platform identity rather than an obsolete text-only OpenAI-compatible-server description.
- LocalAI is distinguished from individual backend engines such as llama.cpp and vLLM.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
