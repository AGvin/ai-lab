# MLX LM

MLX LM is Apple's MLX-based Python package for generating text and fine-tuning large language models, primarily on Apple silicon. It also supports model conversion, quantization, and a basic OpenAI-like HTTP serving surface.

MLX LM is distinct from the lower-level MLX array framework. Its bundled HTTP server is useful for local workflows but is not presented upstream as a production-hardened serving platform.
