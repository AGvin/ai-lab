# MLC LLM

MLC LLM is a machine-learning compiler and high-performance deployment engine for large language models. It compiles and runs models through a unified inference engine intended for native deployment across multiple platforms and application environments.

Compiler and runtime capabilities belong to one project identity, whose primary catalog role is model deployment and inference.
