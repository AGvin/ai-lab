# CTranslate2

Open-source C++ and Python library optimized for supported Transformer inference.

## Runtime capabilities and boundaries

Supports released model conversion, CPU and GPU execution, reduced-precision weights, batching and text/speech architectures. Converters and language bindings belong to the engine.

## Compatibility and reproducibility

Pin release, CPU instruction sets, CUDA/ROCm builds, supported model converter and numerical precision. Performance claims require matching model, hardware, workload and quantization.
