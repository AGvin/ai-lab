# NVIDIA NIM

Optimized deployable inference microservices for foundation and customized models on NVIDIA infrastructure.

## Runtime capabilities and boundaries

Supports self-hostable NIM containers on compatible systems and optional hosted access. Underlying engines, the model identities and individual model-specific container variants are not automatically new products.

## Compatibility and reproducibility

Verify image tags, supported NVIDIA drivers and devices, model availability, licensing and API compatibility. Hosted access terms and vendor performance claims vary by model and configuration.
