# Documentation Requirements

## Requirements

- Present Seldon Core 2 as the current v2 Seldon Core model-serving/MLOps framework for deploying, managing, and monitoring production model workloads.
- Keep runtime/model-server integration, Kubernetes deployment, scheduling, pipelines, observability, and model-management capabilities within the distributed-serving identity.
- Distinguish version-2 facts from historical Seldon Core v1 behavior when incompatible or structurally different.
- Treat release versions, Kubernetes/runtime compatibility, deployment architecture, supported protocols/runtimes, and availability claims as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Seldon Core 2 remains distributed model-serving software rather than an inference engine.
- Producer provenance resolves to Seldon.
