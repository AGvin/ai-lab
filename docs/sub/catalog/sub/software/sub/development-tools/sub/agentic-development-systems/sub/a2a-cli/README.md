# A2A CLI

A2A CLI is the open-source command-line client for interacting with Agent2Agent-compatible agent servers from terminals, scripts and coding tools.

## Product scope

The official A2A project CLI supports agent discovery and communication, with messaging and compatible streaming interactions. Bundled agent skills/plugins are distribution surfaces, not automatic separate software products. A2A CLI is distinct from the protocol specification, SDKs, A2A Inspector and conformance tests.

## Operational boundaries

The catalog records upstream release v0.3.1. Verify the chosen released package, transport support and command grammar. Remote endpoints, custom request headers, downloaded files, and executable local plugins require authorization, controlled secrets and untrusted-input handling.
