# AMD ROCm.AI

AMD ROCm.AI is an AI-native development experience for building, running, troubleshooting and optimizing AI workloads on supported AMD hardware.

## Product scope

ROCm.AI brings together AMD Skills, ROCm CLI, Hyperloom, SDK tooling and supported coding-assistant workflows. It is not the entire ROCm software/runtime platform, nor is each bundled tool a distinct catalog product.

## Operational boundaries

The catalog associates general availability with ROCm 10. Verify exact hardware, ROCm/runtime revision, installation options and integrations. Treat AMD performance improvements as vendor-reported results specific to the tested workload and environment.
