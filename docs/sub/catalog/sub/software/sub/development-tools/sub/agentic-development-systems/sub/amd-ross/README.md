# AMD Ross

AMD Ross is an agentic development assistant for workflows across AMD Embedded design, optimization, debugging and deployment.

## Product scope

Ross integrates AMD-authored MCP servers, Agent Skills, examples and optional local knowledge bases with supported IDE and CLI assistants. It operates through the selected client and model rather than being a separately trained LLM. Vivado, Vitis and other development environments remain separate tools.

## Operational boundaries

Check current software compatibility, downloads, offline deployment, credentials and MCP tool permissions before use. Restrict generated commands and file modifications in sensitive design projects.
