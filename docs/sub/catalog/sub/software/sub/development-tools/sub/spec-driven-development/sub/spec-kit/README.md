# GitHub Spec Kit

GitHub Spec Kit is GitHub's open-source toolkit and CLI for **Spec-Driven Development** with AI coding agents. It keeps product intent, specifications, technical plans, task breakdowns, validation artifacts, and implementation workflow as durable project artifacts rather than relying on one-shot prompts.

## Workflow boundary

Spec Kit structures work around a selected coding agent; it is not itself the coding agent. A typical flow moves from project principles and feature specification through clarification, planning, executable tasks, consistency checks, implementation, and reconciliation.

The generated specification, plan, task, research, contract, data-model, template, and script artifacts remain reviewable source-controlled inputs. Their detail does not establish correctness: selected coding-agent permissions, generated implementation, extensions, presets, integrations, scripts, and repository writes still require human review, testing, security controls, and ordinary source-control discipline.
