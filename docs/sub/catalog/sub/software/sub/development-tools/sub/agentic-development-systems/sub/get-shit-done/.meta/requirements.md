# Documentation Requirements

## Requirements

- Identify Get Shit Done (GSD) as a meta-prompting, context-engineering, and spec-driven development system that coordinates supported AI coding agents.
- Preserve its primary placement under `development-tools/agentic-development-systems`; GSD supplies planning/execution/verification workflows and persistent project state above host agents rather than replacing them as the coding-agent runtime.
- Preserve the file-based project-state and fresh-context design boundary at a stable conceptual level; keep exact commands, supported agents, configuration keys, and workflow internals source-backed when expanded.
- Include the current official GSD repository reference.

## Validation

- The page distinguishes GSD from a standalone coding agent, general agent framework, and generic workflow engine.
- The page does not imply that GSD itself provides the underlying model or coding-agent runtime.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
