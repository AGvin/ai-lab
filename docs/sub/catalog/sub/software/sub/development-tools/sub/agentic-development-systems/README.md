# Agentic Development Systems

> **Temporary catalog summary:** This overview is a placeholder for the RC structure and will be replaced by a reviewed category description.

Systems installed alongside external coding agents that coordinate a substantial part of the software-development lifecycle through connected workflows, roles or agents, persistent project artifacts, and guided execution.

These systems are broader than an individual agent skill or skill bundle, but they are not standalone coding-agent products or general-purpose workflow engines.
