# Google Cloud Data Agent Kit

Google Cloud Data Agent Kit is an installable toolkit for connecting coding agents to Google Data Cloud workflows.

## Product scope

The kit provides MCP tools, Google-authored skills and plugin/IDE integration around services such as BigQuery, Spanner and other supported data systems. It is distinct from Google ADK, Google Agents CLI, Google Antigravity, and the data services it can access.

## Operational boundaries

Tools execute with the authenticated user's or impersonated service account's IAM permissions, not universal account access. Check client compatibility, service inventory, telemetry policy, project scope and required roles before enabling tasks on real datasets.
