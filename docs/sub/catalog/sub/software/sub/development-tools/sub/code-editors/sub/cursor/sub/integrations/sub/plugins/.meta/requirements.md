# Documentation Requirements

## Requirements

- Document Cursor-specific plugin support as mutable product facts from current official Cursor documentation.
- Explicitly distinguish portable Agent Plugins support from Cursor's product-specific plugin format or extensions when the official documentation distinguishes them.
- Cover current manifest/package structure, supported components, marketplace/discovery, installation/testing, admin controls, permissions, compatibility, and lifecycle only when source-backed.
- Keep exact schema fields, paths, commands, supported components, publication rules, compatibility, and availability current-source-backed because they may change.
- Link the formal Agent Plugins specification for portable standard semantics rather than duplicating it.
- Keep generic plugin concept, lifecycle, trust, adoption, and portability teaching with selected concept/learning owners.

## Validation

- Current Cursor plugin behavior and any Agent Plugins support claim are supported by current official Cursor documentation.
- Cursor-specific fields are not presented as universal Agent Plugins requirements.
- Generic plugin pedagogy is not duplicated.
