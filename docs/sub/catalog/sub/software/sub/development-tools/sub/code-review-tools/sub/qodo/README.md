# Qodo

Qodo is Codium Ltd.'s proprietary AI code-review platform for pull-request workflows. Its review surface combines multiple specialized review agents with repository/codebase context, review rules, and organization-level standards to analyze proposed changes and return structured feedback inside development workflows.

## Review and data boundary

Treat repository and Git-provider permissions, rule and standards sources, CI/ticket context, private code and secrets, generated suggestions, and false-positive/false-negative behavior as explicit adoption boundaries. Qodo review output is decision support, not an authoritative merge or security guarantee; human review remains necessary for consequential changes.

Qodo's current Terms describe Customer Data use for delivering the service and also describe training or improving the platform and Qodo models subject to applicable law, privacy terms, and account/product context. Third-party foundation-model terms can introduce additional data-processing boundaries. Verify current deployment, retention, model-provider, and organization controls before use with sensitive repositories.
