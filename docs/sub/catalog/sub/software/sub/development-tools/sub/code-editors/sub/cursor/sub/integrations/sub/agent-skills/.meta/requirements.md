# Documentation Requirements

## Requirements

- Document Cursor-specific Agent Skills support as mutable product facts while keeping Cursor canonically a code editor/development tool.
- Cover current project and user skill locations or scopes, discovery, invocation or automatic selection behavior, installation or creation flow, and relevant permissions or Agent execution boundaries when source-backed.
- Distinguish Cursor Agent Skills from rules, commands, subagents, hooks, plugins, MCP, and VS Code customization behavior.
- Keep exact paths, supported metadata, commands, precedence, client/version availability, and interaction with Cursor Agent current-source-backed because they may change.
- Link the canonical Agent Skills concept and portability learning owner for reusable semantics and cross-host practices.

## Validation

- Current Cursor-specific behavior is supported by current official Cursor documentation.
- VS Code ancestry is not presented as a 1:1 Agent Skills compatibility guarantee.
- Generic Agent Skills authoring or portability teaching is not duplicated.
