# Documentation Requirements

## Requirements

- Present Visual Studio Code Extensions as the typed navigation node for documentation specific to extensions running in Visual Studio Code.
- Keep VS Code-specific extension installation, configuration, compatibility, limitations, and troubleshooting in this subtree while shared product facts remain on canonical extension profiles.
- Preserve the current Continue example as a link to the canonical cross-client Continue profile rather than creating or duplicating a VS Code-only product profile.
- Render the standard `child-navigation` block from the validated current-node direct-child projection; do not encode direct-child membership or ordering in this requirements file.
- Keep this node structural: do not give it a separate software/product identity or duplicate Visual Studio Code's producer relation.
- Include the current official Visual Studio Marketplace as the supporting extension registry.

## Validation

- The page is an extension-navigation index, not a second Visual Studio Code product profile.
- Direct-child navigation, when present, comes from the validated projection rather than a hand-maintained child list.
- Continue remains linked to its canonical cross-client profile rather than duplicated under this node.
- The page contains no temporary-placeholder wording.
