# A2A Inspector

A2A Inspector is the official web-based developer tool for inspecting, debugging and testing Agent2Agent servers and Agent Cards.

## Product scope

The Inspector explores agent capabilities and exchanges test messages. It is a testing UI, not the Agent2Agent protocol, SDK, A2A CLI or complete compliance certification suite.

## Operational boundaries

The canonical profile records v0.1.0, which predates stable A2A v1.0. Main-branch updates do not prove a released v1.0-compatible build. Pin protocol and Inspector releases; treat remote agent metadata, URLs, messages and credentials as untrusted.
