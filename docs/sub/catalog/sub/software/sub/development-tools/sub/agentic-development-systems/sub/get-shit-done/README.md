# Get Shit Done

> **Temporary catalog summary:** This short description is a placeholder for a future reviewed catalog profile.

Get Shit Done (GSD) is a meta-prompting and context-engineering development system that installs structured planning, execution, verification, and project-state workflows for supported coding agents.

It maintains persistent project artifacts and coordinates a development process above the host agent rather than replacing that agent.
