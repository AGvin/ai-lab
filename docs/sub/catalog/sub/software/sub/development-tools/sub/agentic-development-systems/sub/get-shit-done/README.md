# GSD Core

GSD Core is the active continuation of Get Shit Done (GSD), a context-engineering and spec-driven development system for supported AI coding agents.

## Workflow boundary

The system coordinates planning, execution and verification through fresh-context agent work and persistent project files. The selected coding agent provides the underlying model, tools and execution permissions; GSD Core supplies workflow structure and context management.

Current development and releases live in Open GSD's `gsd-core` repository. The original `gsd-build/get-shit-done` repository is archived and explicitly redirects users to this continuation. Review generated plans, code and repository changes in the host agent's normal review and testing workflow.
