# Get Shit Done

Get Shit Done (GSD) is a meta-prompting, context-engineering, and spec-driven development system that coordinates supported AI coding agents through structured planning, execution, verification, and persistent project state.

GSD sits above the host coding agent: it supplies development-process structure and context management while the selected agent remains the execution environment.
