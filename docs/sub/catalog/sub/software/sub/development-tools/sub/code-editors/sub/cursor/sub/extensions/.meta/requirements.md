# Documentation Requirements

## Requirements

- Present Cursor Extensions as the typed navigation node for documentation specific to extensions used with Cursor.
- Keep Cursor-specific extension configuration, compatibility, limitations, and troubleshooting in this subtree rather than duplicating them in the Cursor product profile.
- Link inherited or shared Visual Studio Code extension guidance to its canonical VS Code context instead of duplicating that guidance here.
- Render the standard `child-navigation` block from the validated current-node direct-child projection; do not encode direct-child membership or ordering in this requirements file.
- Keep this node structural: do not give it a separate software/product identity or duplicate Cursor's producer relation.
- Include current official Cursor documentation as the supporting external resource.

## Validation

- The page is an extension-navigation index, not a second Cursor product profile.
- Direct-child navigation, when present, comes from the validated projection rather than a hand-maintained child list.
- Shared Visual Studio Code extension guidance is linked rather than duplicated.
- The page contains no temporary-placeholder wording.
