# MCPJam Inspector

MCPJam Inspector is a third-party Model Context Protocol testing and debugging product distributed as `@mcpjam/inspector`.

## Product scope

It supports tool/prompt/resource inspection, OAuth troubleshooting, JSON-RPC tracing, client behavior simulation and MCP app/widget debugging. Hosted, local CLI, desktop and source-built distributions are modes of one product, not separately owned inspector runtimes.

## Operational boundaries

The canonical release record is v3.16.0 (2026-10-13), with Node.js >=22 required for its terminal launcher. Open-source project code and separately enterprise-licensed evaluation/server components have different rights and subscription requirements. Guard OAuth tokens and inspect any cloud/evaluation data transfer; testing does not establish security certification.
