# Testing Tools

Tools for application testing, protocol inspection and assessing software or agent-security behavior. Browser E2E testing, A2A/MCP debugging and vulnerability assessment have distinct functions.

## Child pages

- [A2A Inspector](./sub/a2a-inspector/) — inspect Agent2Agent agent servers.
- [MCP Inspector](./sub/mcp-inspector/) — first-party MCP developer debugging.
- [MCPJam Inspector](./sub/mcpjam-inspector/) — third-party MCP inspector.
- [Playwright](./sub/playwright/) — browser end-to-end testing and automation.
- [Snyk Agent Scan](./sub/snyk-agent-scan/) — security scanner for agents, skills and MCP servers.
