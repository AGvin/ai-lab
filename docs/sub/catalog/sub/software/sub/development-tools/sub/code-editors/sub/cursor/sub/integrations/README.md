# Cursor Integrations

This node groups substantial Cursor-specific integration and extension surfaces while preserving Cursor's primary identity as a code editor and development tool.

Concrete installation, discovery, invocation, permissions, configuration, and removal behavior belongs to each integration child. Cursor-owned behavior remains distinct from generic VS Code compatibility and from reusable integration concepts.
