# Documentation Requirements

## Requirements

- Present Development Tools as the canonical software catalog index for tools and systems supporting AI-assisted software development, including editors, review tools, specification workflows, and structured agentic development processes.
- List every materialized direct child exactly once.
- Keep tool-specific identity, setup, integrations, workflows, and operational facts with the child profiles.
- Do not reproduce or depend on legacy `catalog-item`, `catalog-index`, `common/index`, or `catalog/item` selectors.

## Validation

- Navigation matches the materialized direct children.
- The page remains category-level and does not duplicate concrete tool profiles.
- The page contains no temporary-placeholder wording.
