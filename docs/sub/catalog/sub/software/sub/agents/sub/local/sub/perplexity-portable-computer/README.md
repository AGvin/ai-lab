# Perplexity Portable Computer

Perplexity Portable Computer is Perplexity AI's released local agent stack for supported Windows and Linux hardware. Perplexity describes the Computer harness, planner and orchestrator, local models, task queue, tool execution, and sandbox as running on the user's machine.

## Execution and data boundary

The local runtime works with files, connected applications, code, and scheduled or recurring tasks. Supported steps can request approval to use Perplexity Search or remote frontier models, then return results to the local run. Cloud escalation is optional; it is separate from the primary local execution environment.

Local inference and sandboxing do not make every connected application or approved remote request offline. Review connector permissions, provider access, filesystem scope, generated code, and scheduled actions. Perplexity's privacy and isolation descriptions are vendor claims about the documented configuration, not an independent guarantee for every workload.

Check current hardware and memory requirements, operating systems, local model inventory, subscription eligibility, connector support, and cloud options before deployment. The hosted Perplexity Computer workspace, Perplexity Search and APIs, model artifacts, and hardware retain separate product or dependency identities.
