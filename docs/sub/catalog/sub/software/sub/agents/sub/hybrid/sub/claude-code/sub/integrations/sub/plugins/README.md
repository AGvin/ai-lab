# Claude Code Plugins

This profile documents Claude Code-specific plugin support as mutable software/product facts from current official Anthropic documentation.

## Scope and boundaries

- The profile covers current package/manifest structure, installation and discovery, marketplaces, supported plugin components such as commands/hooks/agents/skills/MCP integrations when source-backed, permissions, lifecycle, and compatibility.
- The profile keeps exact paths, manifest fields, commands, marketplace rules, load/update behavior, supported components, and compatibility current-source-backed because they may change.
- Claude Code's product-specific plugin contract remains distinct from the vendor-neutral Agent Plugins standard unless official documentation explicitly states conformance/interoperability.
- The profile keeps generic plugin concept, trust, lifecycle, adoption, removal, and portability teaching with selected concept/learning owners.
