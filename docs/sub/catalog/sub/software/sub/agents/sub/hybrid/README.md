# Hybrid Agents

Hybrid Agents are agent products whose supported product surface materially spans both user-controlled local or self-managed execution and managed or hosted execution. The distinction is about the product's execution and deployment envelope, not merely whether it can call a hosted model API.

## Agents

- [Augment Code](./sub/augment-code/) — Augment's coding suite with local IDE/CLI execution and managed Cloud Agents.
- [Claude Code](./sub/claude-code/) — Anthropic's coding agent across local terminal, editor, desktop, and managed web workflows.
- [Cline](./sub/cline/) — Coding agent with user-controlled clients, operator-selected remote hosts, and Cline-managed Cloud Agents.
- [Devin Desktop](./sub/devin-desktop/) — Cognition's desktop coding workspace with local development and delegation to managed Devin sessions.
- [Factory Droid](./sub/factory-droid/) — Development agent with managed cloud, hybrid enterprise, and self-managed or airgapped deployments.
- [GitHub Copilot](./sub/github-copilot/) — GitHub's development product spanning editor and terminal work together with hosted agent execution.
- [Grok Build](./sub/grok-build/) — Coding agent with local tools and managed web/mobile execution; open-source code and service terms differ.
- [Hermes Agent](./sub/hermes-agent/) — Nous Research's personal agent with local/self-managed deployment and Hermes Cloud instances.
- [Kilo Code](./sub/kilo-code/) — Coding product with local editor/CLI execution and a hosted Cloud Agent runtime.
- [Kiro CLI](./sub/kiro-cli/) — AWS-backed terminal coding agent with local execution and Kiro-managed Cloud Sessions.
- [Mistral Vibe](./sub/mistral-vibe/) — Mistral's professional agent with local coding clients and managed web, mobile, and remote work.
- [OpenAI Codex](./sub/openai-codex/) — OpenAI's coding agent across terminal, editor, desktop, and managed cloud workflows.
- [OpenHands](./sub/openhands/) — Agent Canvas and SDK/Agent Server with local, self-hosted, Cloud, and Enterprise backends.

Products whose primary execution remains user-controlled belong under [Local Agents](../local/). Hosted-first development-agent services belong under [Hosted Development Agents](../../../../../services/sub/development/sub/agents/).
