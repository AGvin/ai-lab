# Kiro CLI

Kiro CLI is Kiro's licensed terminal AI development agent for coding and automation. It supports local user-controlled execution as well as managed Cloud Sessions (`kiro-cli --cloud`), with custom agents, parallel subagents, tool permissions, MCP integrations, steering, hooks, Skills, and non-interactive execution. Cloud sessions run the agent harness in a vendor-managed sandbox rather than on the local computer; remote model calls alone do not explain this hybrid classification.

## Execution and trust boundary

Kiro IDE, CLI, Web, and mobile can connect to the same cloud sessions. Local and cloud tool access, account permissions, synced configuration, connected repositories, automation approvals, and sandbox policies differ by execution environment; do not infer a universal permission or data-isolation guarantee. Check first-party availability and license terms for the intended configuration.
