# Kimi Code

Kimi Code is Moonshot AI's installable coding-agent suite for terminal and IDE work. It examines repositories, edits files, runs development commands, and helps implement and test changes. Its CLI and supported editor integrations are surfaces of the same coding product.

## Execution boundary

The agent works against a user-controlled development environment. Kimi-hosted or other configured model providers can receive task context, so local tool execution does not imply that inference or every data flow stays on the machine.

Repository access, shell commands, generated diffs, provider credentials, MCP servers, hooks, plugins, skills, subagents, and remote control define the operational boundary. Check the active client's permission behavior and review changes before external side effects. Supported integrations, model routing, usage limits, and release versions change independently.

Kimi Code remains distinct from Kimi Work, the hosted Kimi assistant, Kimi Claw, and the Kimi model family. A model, editor, plugin, or external MCP server is a dependency or integration rather than another name for this product.
