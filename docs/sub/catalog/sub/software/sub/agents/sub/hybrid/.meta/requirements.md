# Documentation Requirements

## Requirements

- Present Hybrid Agents as the canonical software index for agent products whose practical execution model spans local/self-managed and hosted components.
- List every materialized direct child exactly once.
- Keep concrete product capabilities, installation, hosted dependencies, and mutable service state with the child profile.
- Keep purely hosted service identities under `catalog/services/` and purely local agents under the sibling Local Agents index.

## Validation

- Navigation matches the materialized direct children.
- Classification does not rely solely on vendor branding or optional cloud access.
