# Documentation Requirements

## Requirements

- Identify OpenAI Codex as OpenAI's coding agent for writing, reviewing, and shipping code across current Codex client and cloud surfaces.
- Preserve the current product boundary across ChatGPT/Codex application workflows, editor or IDE integration, terminal CLI use, and delegated cloud tasks.
- Distinguish local Codex execution surfaces such as CLI and IDE workflows from Codex cloud tasks running in OpenAI-managed environments.
- Keep model selection, plan eligibility, limits, credits, availability, and other mutable product-state claims source-backed when expanded.
- Link the canonical OpenAI producer profile.
- Include current official OpenAI Codex product and usage documentation.

## Validation

- The page does not describe every Codex task as cloud-hosted or every Codex workflow as local.
- The producer link resolves to the canonical OpenAI organization node.
- The profile does not substitute historical Codex model identities for the current Codex coding-agent product.
