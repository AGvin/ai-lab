# Documentation Requirements

## Requirements

- Identify GitHub Copilot as GitHub's AI development product spanning editor, terminal, GitHub, and agentic development workflows.
- Distinguish local or IDE agent experiences from GitHub Copilot cloud agent, which performs delegated repository work in GitHub-managed execution environments.
- Preserve the broader product boundary without reducing GitHub Copilot to only code completion or only the cloud agent.
- Keep model availability, plan eligibility, billing, preview status, repository policy, and other mutable service-state claims source-backed when expanded.
- Include the official GitHub Copilot product page and current official agent documentation.

## Validation

- The page does not conflate IDE agent mode with GitHub Copilot cloud agent.
- Hosted agent execution is described as a GitHub-managed surface rather than as local execution.
- Official resource links match canonical entity metadata.
