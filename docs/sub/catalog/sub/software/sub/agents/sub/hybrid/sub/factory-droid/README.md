# Factory Droid

Factory Droid is Factory's software-development agent and runtime for development workflows across developer machines, CI, remote computers, and enterprise infrastructure. It can participate in planning, implementation, testing, review, and automation while integrating with repositories and other engineering systems.

## Deployment and trust boundary

Factory documents cloud-managed, hybrid enterprise, and fully airgapped deployment patterns. Droid can run on user-managed laptops, CI runners, VPS/VMs, containers, remote development environments, or Factory-managed cloud computers. Factory cloud, cloud session synchronization, remote-access relay services, and Factory-brokered model access are therefore optional surfaces rather than universal runtime requirements.

Treat repository and organization permissions, generated diffs, integrations, credentials and secrets, model/provider routing, session synchronization, remote access, automation scopes, and merge/deploy/release actions as explicit trust and approval boundaries.
