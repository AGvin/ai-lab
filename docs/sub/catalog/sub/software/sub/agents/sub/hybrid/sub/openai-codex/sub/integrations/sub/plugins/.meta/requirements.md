# Documentation Requirements

## Requirements

- Document Codex-specific plugin host and execution behavior as mutable software/product facts while linking the shared ChatGPT/OpenAI plugin catalog owner for behavior common to both products.
- Cover Codex-specific execution environment, sandbox and approval boundaries, capability invocation, client surfaces, installation/use differences, and availability only when current official documentation supports them.
- Keep exact commands, paths, configuration, permission behavior, supported capabilities, CLI/IDE/cloud differences, and availability current-source-backed because they may change.
- Distinguish plugins from Agent Skills, MCP, AGENTS.md instructions, and other Codex extension or instruction surfaces.
- Link the formal Agent Plugins specification for portable package semantics rather than redefining it.
- Keep generic plugin lifecycle, trust, adoption, and portability teaching with the selected concept/learning owners.

## Validation

- Current Codex-specific behavior is supported by current official OpenAI documentation.
- Shared catalog/workspace behavior is not redundantly owned here.
- Portable Agent Plugins normative fields are not duplicated.
