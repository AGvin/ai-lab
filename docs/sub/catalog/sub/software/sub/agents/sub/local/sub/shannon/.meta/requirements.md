# Documentation Requirements

## Requirements

- Identify Shannon as Keygraph's autonomous white-box AI penetration-testing agent for web applications and APIs.
- Preserve the defining workflow boundary: Shannon combines source-code analysis with live exploitation to validate findings and runs the open-source agent locally from the command line.
- State the essential authorization boundary concisely: use only on systems the operator owns or has explicit written authorization to test, and avoid production targets because exploitation can change target state.
- Keep exploit procedures, actionable attack instructions, benchmark/demo vulnerability counts, model-provider details, and operational pentest setup outside this concise catalog identity profile.
- Distinguish Shannon Open Source from the broader hosted/commercial Keygraph platform without duplicating the platform profile.
- Include the current official Shannon repository.

## Validation

- The page does not describe Shannon as a passive vulnerability scanner.
- The page includes the authorized-use and non-production boundary without providing exploit instructions.
- The open-source local agent is not conflated with the Keygraph hosted/commercial platform.
