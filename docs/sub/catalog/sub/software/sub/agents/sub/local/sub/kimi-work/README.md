# Kimi Work

Kimi Work is Moonshot AI's released beta desktop agent for knowledge work on supported Mac and Windows computers. It works with local files, browser sessions, code execution, plugins, skills, and scheduled tasks. It uses the Kimi Code agent kernel while retaining a separate product identity and work-oriented interface.

## Execution and permission boundaries

Actions run against the user's desktop and workspace; model inference and connected services can be remote. Remote control of a desktop does not turn the local agent into a managed hosted workspace.

Default mode handles routine operations automatically while asking about sensitive actions. Manual approval requires confirmation before acting. Fully automatic mode proceeds without those confirmations. Choose the mode for the files, browser sessions, credentials, system changes, and scheduled work involved; permission modes do not guarantee safe or correct results.

Imported browser sessions and cookies can grant access to signed-in services. Review their scope along with plugins, skills, code execution, and external side effects. Beta availability, operating-system support, model defaults, limits, and plan rules remain subject to the current documentation.

Kimi Work is distinct from Kimi Code, Kimi Claw, the hosted assistant, Kimi models, and browser extensions.
