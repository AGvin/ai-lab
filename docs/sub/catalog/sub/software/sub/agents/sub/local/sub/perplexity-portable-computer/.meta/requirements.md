# Documentation Requirements

## Requirements

- Present Perplexity Portable Computer as Perplexity AI's released local-first agent stack that runs the Computer agent harness, orchestrator/planner, local models, task queue, tool execution, and sandbox on supported user-controlled Windows or Linux hardware.
- Preserve its local-agent classification even though approved steps can escalate to Perplexity Search or remote frontier models: the primary agent loop and local workspace execution remain user-controlled, and cloud escalation is an optional external path.
- Preserve current capabilities at a durable level: local files, scheduled/recurring tasks, connected applications, sandboxed code/tool execution, local inference, and explicit approval before supported cloud escalation.
- Keep Perplexity's hosted assistant/Computer workspace, Perplexity Search/API services, local model identities, NVIDIA/AMD hardware, and third-party connectors as separate products/dependencies rather than parts of Portable Computer's producer identity.
- Treat supported operating systems, GPUs/APUs, VRAM requirements, local model inventory, subscription eligibility, connector list, cloud-model list, installation commands, and exact isolation/runtime behavior as freshness-sensitive.
- Attribute local/privacy and benchmark claims to Perplexity/current first-party research rather than converting them into independent AI Lab guarantees.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Portable Computer remains local/self-managed agent software rather than a hosted service simply because cloud escalation is available.
- It remains distinct from Perplexity's hosted Computer experience and from the underlying local models/hardware.
- Producer provenance resolves bidirectionally to Perplexity AI.
