# Devin Desktop

Devin Desktop is Cognition's installable agent workspace and IDE, formerly named Windsurf. It combines an editor with a command center for planning, delegating, and reviewing work across local and cloud coding agents.

## Product continuity and execution

Cognition documents Devin Desktop as the standard Windsurf update: settings, extensions, existing work, and the IDE experience carry forward. Windsurf remains a useful historical name and appears in some official download and documentation routes.

Local agents work in the user's development environment; managed Devin/cloud agents execute elsewhere and return work for review. The desktop interface can coordinate both, including supported agents connected through Agent Client Protocol. This makes the location and permissions of the chosen agent runtime important even when every session is visible in one application.

Use the IDE and diff/review surfaces to inspect proposed changes. Repository access, shell commands, MCP servers, extensions, credentials, and remote-agent authorization remain explicit trust boundaries. Model, platform, plan, and agent compatibility should be checked for the intended configuration.
