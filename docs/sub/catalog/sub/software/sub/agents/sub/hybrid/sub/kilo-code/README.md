# Kilo Code

Kilo Code is an open-source AI coding product spanning editor integrations, a local CLI runtime, model/provider and MCP integrations, and a hosted Cloud Agent surface.

## Local, remote-control, and hosted execution

Local editor and CLI work executes on the developer's machine. **Cloud Agent** is different: it clones and works on repositories in Kilo-hosted execution environments. **Remote Connections** are different again: the Cloud Agents web interface can control an active local CLI session, but the user's machine continues to provide the compute and local permissions.

That distinction matters for trust. Review provider or gateway credentials, repository and filesystem access, custom rules/agents/skills, MCP servers, terminal/browser execution, account security for remote control, hosted-agent environment access, generated diffs, and human approval before commit, push, or merge.
