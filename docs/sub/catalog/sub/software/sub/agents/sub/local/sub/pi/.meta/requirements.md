# Documentation Requirements

## Requirements

- Identify Pi as a minimal local terminal coding harness designed to keep its core small and move workflow-specific behavior into extensions and reusable resources.
- Preserve TypeScript extensions, skills, prompt templates, themes, Pi packages, provider configuration, and programmatic integration as core extensibility surfaces at a high level.
- Preserve the local execution/trust boundary without claiming that model inference itself must be local.
- Keep package versions, provider inventories, ownership-history details, and other mutable implementation state source-backed when expanded.
- Include current official Pi documentation.

## Validation

- The page does not attribute OMP-specific built-in capabilities to Pi.
- The profile does not imply that Pi's local agent runtime requires local models.
