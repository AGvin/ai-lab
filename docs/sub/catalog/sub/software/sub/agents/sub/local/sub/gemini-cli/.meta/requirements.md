# Documentation Requirements

## Requirements

- Identify Gemini CLI as Google's open-source, terminal-first AI agent for code understanding, generation, task automation, and tool-driven workflows with Gemini models.
- Preserve local-project context, file/shell/web tooling, extensibility through MCP, and interactive or non-interactive CLI use at a high level.
- Distinguish local CLI execution from the Google service authentication and model access used by normal current workflows; remote model access does not make the agent runtime hosted.
- Link the canonical Google producer profile.
- Keep quotas, included models, preview features, and other mutable service-state claims source-backed when expanded.
- Include the official Gemini CLI repository.

## Validation

- The page does not claim Gemini CLI is an offline agent merely because it runs locally.
- The Google producer relation resolves to the canonical producer node.
