# Documentation Requirements

## Requirements

- Present Local Agents as the canonical software index for installable or self-managed agent products whose primary execution surface is controlled by the user.
- List every materialized direct child exactly once.
- Keep concrete installation, runtime, model-access, and tool-integration facts with child software profiles.
- Keep primarily hosted agent services under `catalog/services/` and hybrid products under the sibling Hybrid Agents index.

## Validation

- Navigation matches the materialized direct children.
- Hosted access alone does not change the primary ownership classification.
