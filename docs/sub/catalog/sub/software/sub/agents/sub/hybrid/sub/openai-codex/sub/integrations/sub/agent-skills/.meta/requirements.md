# Documentation Requirements

## Requirements

- Document OpenAI Codex-specific Agent Skills support as mutable software/product facts.
- Cover current skill discovery locations and precedence, repository and user scope, installation or placement, explicit invocation, implicit selection behavior, enable or disable controls, and supported skill metadata when source-backed.
- Distinguish Codex Agent Skills from plugins, MCP, AGENTS.md instructions, and other Codex extension or instruction surfaces.
- Keep exact paths, commands, configuration keys, supported metadata, client-surface differences, and availability current-source-backed because they may change.
- Link the canonical Agent Skills concept and portability learning owner for reusable semantics and cross-host practices.

## Validation

- Current Codex-specific behavior is supported by current official OpenAI Codex documentation.
- Generic Agent Skills authoring or portability teaching is not duplicated.
