# Documentation Requirements

## Requirements

- Identify Cline as an open-source coding agent for editor-centered development workflows.
- Preserve its ability to inspect project context, edit files, execute terminal commands, use browser and external-tool capabilities, and apply user approval controls.
- Keep Cline product identity distinct from SDK or underlying component identities.
- Keep model-provider, plan, integration, and preview-state claims source-backed when expanded.
- Include current official Cline documentation and product references.

## Validation

- The page does not imply that Cline is primarily a hosted execution service.
- Approval controls are described as product behavior without promising a universal security guarantee.
