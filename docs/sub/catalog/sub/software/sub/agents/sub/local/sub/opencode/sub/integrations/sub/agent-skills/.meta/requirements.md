# Documentation Requirements

## Requirements

- Document OpenCode-specific Agent Skills support as mutable software/product facts.
- Cover current skill discovery roots and scope, loading or invocation behavior, permissions governing skill access, installation or placement, and supported package metadata when source-backed.
- Distinguish OpenCode Agent Skills from plugins, commands, agents, MCP, and other OpenCode extension or configuration surfaces.
- Keep exact paths, configuration keys, permission syntax, supported metadata, commands, and version-dependent behavior current-source-backed because they may change.
- Link the canonical Agent Skills concept and portability learning owner for reusable semantics and cross-host practices.

## Validation

- Current OpenCode-specific behavior is supported by current official OpenCode documentation.
- Generic Agent Skills authoring or portability teaching is not duplicated.
