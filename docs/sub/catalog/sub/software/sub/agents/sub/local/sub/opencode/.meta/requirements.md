# Documentation Requirements

## Requirements

- Identify OpenCode as an open-source AI coding agent available through terminal, desktop, and IDE-extension surfaces.
- Preserve configurable model-provider support and project-local coding workflows at a high level.
- Do not treat OpenCode Zen or another model-access service as the OpenCode agent identity itself.
- Keep provider counts, usage metrics, model availability, billing, and other mutable product-state claims source-backed when expanded.
- Include current official OpenCode documentation and product references.

## Validation

- The page remains about the OpenCode agent product rather than a specific model-provider service.
- Local/client execution is not mislabeled as a first-party hosted agent runtime without evidence.
