# Documentation Requirements

## Requirements

- Identify OpenHands as the open-source AI-driven software-development platform represented by its current Software Agent SDK, CLI, Local GUI, and hosted OpenHands Cloud surfaces.
- Preserve the product's ability to run agent workflows locally while also supporting hosted cloud execution and enterprise self-hosting.
- Keep the Local GUI, CLI, SDK, Cloud, and Enterprise surfaces distinct enough that the profile does not imply one mandatory runtime or deployment model.
- Preserve provider flexibility at a high level without claiming that every OpenHands mode is offline or local-model-only.
- Keep mutable hosted-service, enterprise-license, integration, model-provider, and deployment details source-backed when expanded.
- Include current official OpenHands documentation and repository references.

## Validation

- The profile does not describe OpenHands Cloud as the only execution surface.
- The profile does not treat the Software Agent SDK as a separate replacement identity for the OpenHands product represented here.
- Official resource links match canonical entity metadata.
