# Documentation Requirements

## Requirements

- Identify Aider as an AI pair-programming tool for terminal workflows that edits code in local Git repositories.
- Preserve its tight Git integration and support for multiple model providers at a high level.
- Keep setup, model-specific behavior, pricing, benchmark results, and mutable provider details out of the concise catalog profile unless source-backed and required.
- Include current official Aider documentation.

## Validation

- The page presents Aider as a user-controlled terminal coding tool rather than a hosted agent service.
- Git integration is not generalized into unsupported repository-hosting behavior.
