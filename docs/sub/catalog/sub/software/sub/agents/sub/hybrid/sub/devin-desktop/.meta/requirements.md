# Documentation Requirements

## Requirements

- Identify Devin Desktop as Cognition's current desktop agent/IDE product and preserve Windsurf as its former product name rather than materializing Windsurf as a second current canonical product.
- Preserve the first-party migration boundary: Devin Desktop arrives as the standard over-the-air Windsurf update and carries forward the IDE, settings, extensions, plans, and existing work while changing product branding and expanding the agent-command-center surface.
- Keep the Hybrid Agent classification explicit: Devin Desktop is an installable desktop/IDE environment for local agent work and also orchestrates vendor-operated Devin/cloud agents and other supported local or cloud agents from one surface.
- Distinguish Devin Desktop from the hosted-first Devin service already owned under `catalog/services/development/agents/devin`; shared branding and integration do not collapse the hosted service and desktop software into one canonical identity.
- Treat Agent Client Protocol support, MCP servers, language servers, extensions, local models/agents, cloud agents, Fast Context, agent-management views, and IDE features as product capabilities or integrations unless a separately useful identity already has its own canonical owner.
- Keep exact plans, model access, agent compatibility, extension support, enterprise/self-hosted options, platform support, usage limits, and product naming freshness-sensitive.
- Preserve legacy Windsurf URLs/doc paths as official continuity evidence where they remain first-party routes for Devin Desktop; do not infer that stale branding in individual docs means Windsurf remains a separate current product.
- Render producer relation and official resources only during the final render phase.

## Validation

- Devin Desktop and Windsurf are not duplicated as separate current products.
- Devin Desktop is not conflated with the hosted Devin service.
- Both local/user-controlled and managed/cloud agent surfaces are represented when explaining Hybrid placement.
- Mutable commercial, compatibility, and feature claims remain source- and time-scoped.
