# Local Agents

Local Agents are installable or self-managed agent products whose primary agent loop and workspace execution run in an environment controlled by the user. A product can still use hosted model APIs or online integrations and remain local when those services do not replace the user-controlled agent runtime.

## Agents

- [Aider](./sub/aider/) — Terminal pair-programming agent for editing Git repositories, with optional editor and experimental browser interfaces.
- [Continue](./sub/continue/) — Coding-agent clients preserved in a read-only upstream repository; review the maintenance boundary before adoption.
- [Gemini CLI](./sub/gemini-cli/) — Google's open-source terminal agent with local tools, configurable policies, and optional sandboxing.
- [Google Antigravity](./sub/google-antigravity/) — Google's standalone agent application and CLI with local and operator-controlled remote execution.
- [goose](./sub/goose/) — General-purpose agent with desktop, CLI, API, and operator-run remote server surfaces.
- [Kimi Code](./sub/kimi-code/) — Moonshot AI's installable coding-agent suite for terminal and editor workflows.
- [Kimi Work](./sub/kimi-work/) — Moonshot AI's beta desktop agent for local files, browser work, and scheduled knowledge tasks.
- [mini-SWE-agent](./sub/mini-swe-agent/) — Minimal, inspectable software-engineering agent for local or configured container execution.
- [NVIDIA NemoClaw](./sub/nemoclaw/) — NVIDIA's alpha, self-managed agent environment with OpenShell isolation and qualified agent integrations.
- [OMP](./sub/omp/) — Pi-derived coding agent with integrated developer tools, subagents, browser capabilities, and extensions.
- [OpenClaw](./sub/openclaw/) — Self-hosted personal assistant with a user-operated gateway, channels, tools, and automation.
- [OpenCode](./sub/opencode/) — Open-source coding agent for terminal, desktop, and editor use with operator-controlled server options.
- [Perplexity Portable Computer](./sub/perplexity-portable-computer/) — Perplexity's local agent stack with optional approved cloud escalation.
- [Pi](./sub/pi/) — Extensible terminal coding-agent harness with a separate experimental Pi Durable framework.
- [Qwen Code](./sub/qwen-code/) — Qwen Team's open-source terminal coding agent with local tools and configurable model providers.
- [Shannon](./sub/shannon/) — Self-managed white-box penetration-testing agent for authorized targets, with a separate commercial platform.

Products with a material first-party hosted agent-execution surface belong under [Hybrid Agents](../hybrid/). Hosted-first development-agent services belong under [Hosted Development Agents](../../../../../services/sub/development/sub/agents/).
