# Documentation Requirements

## Requirements

- Present Agents as the canonical software catalog index for ready-to-use AI agent products that perform development or general computer tasks.
- Group the materialized direct children by execution boundary: locally runnable agents and hybrid agents that materially depend on vendor-operated services.
- List every materialized direct child exactly once and keep product-specific identity, facts, setup, runtime behavior, and service dependencies with the child profiles.
- Do not reproduce or depend on legacy `catalog-item`, `catalog-index`, `common/index`, or `catalog/item` selectors.

## Validation

- Navigation matches the materialized direct children.
- The page remains category-level and does not duplicate concrete agent profiles.
- The page contains no temporary-placeholder wording.
