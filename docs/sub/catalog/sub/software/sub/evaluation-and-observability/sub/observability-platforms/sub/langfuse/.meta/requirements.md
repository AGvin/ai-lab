# Documentation Requirements

## Requirements

- Identify Langfuse as an open-source, self-hostable AI engineering platform combining LLM observability/tracing with prompt management, evaluation, datasets, and experiments.
- Preserve its primary placement under `evaluation-and-observability/observability-platforms`; integrated evaluation and prompt tooling do not create duplicate canonical product pages.
- Distinguish self-hosted Langfuse software from Langfuse Cloud and other separately operated service surfaces.
- Keep SDKs, storage architecture, feature availability, hosting details, and other mutable implementation facts source-backed when expanded.
- Include current official Langfuse documentation and repository references.

## Validation

- The page preserves the broad AI-engineering platform identity while explaining why observability is its catalog owner.
- Self-hosted and cloud operating boundaries are not conflated.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
