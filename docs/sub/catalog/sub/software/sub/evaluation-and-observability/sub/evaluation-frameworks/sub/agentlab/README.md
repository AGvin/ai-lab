# AgentLab

AgentLab is ServiceNow's released research framework for developing and benchmarking browser agents over BrowserGym task environments.

## Evaluation role and boundaries

Agent implementations, parallel experiments, configurable model wrappers, experiment results and reproducibility utilities are integrated features. BrowserGym is the separate task-environment layer; WorkArena and WebArena benchmark datasets are not owned by AgentLab merely because it can run their tasks.

## Reproducibility and operational safeguards

Record AgentLab release, BrowserGym adapter, benchmark revision/split, environment fixtures, random seed, agent scaffold, model/provider configuration and scorer. Parallel experiments may execute browsers and paid model calls: isolate test sessions and bound spend. This is research infrastructure, not a hosted consumer agent.
