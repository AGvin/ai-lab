# Giskard OSS

Giskard OSS is a locally installable Python framework for AI-agent scenario testing, adversarial assessment and RAG/knowledge-base evaluation.

## Evaluation role and boundaries

The umbrella distribution contains independently versioned components such as Giskard Checks and Giskard Scan. These importable packages and extras belong to one framework identity; hosted Giskard Hub remains a separate service. Historical Giskard v2 uses a different maintenance lifecycle.

## Reproducibility and operational safeguards

The canonical record identifies umbrella 3.0.1 (2026-10-02), Python >=3.12 and a Beta package classifier. Check per-package licenses and versions rather than treating all modules as one uniform grant. Test state-changing agents in isolated environments, govern judge/provider traffic and disable unwanted telemetry using supported settings before import.
