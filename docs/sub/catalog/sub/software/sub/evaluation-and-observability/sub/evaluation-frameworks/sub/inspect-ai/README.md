# Inspect AI

Inspect AI is an independently installable MIT-licensed Python framework for evaluating language models and agents, developed by the UK AI Security Institute with Meridian Labs.

## Evaluation role and boundaries

It composes evaluation tasks, prompts, solvers, tools and scorers, including model-graded and multi-turn agent evaluations. The framework and its mutable task catalog are separate from individual benchmark datasets and government evaluation conclusions.

## Reproducibility and operational safeguards

The recorded October 2026 release is 0.3.278. Pin package, task implementation and split, solver and judge versions, model/backend, sampling settings, fixtures and random seeds when reporting scores. Sandboxed tool use, model API costs, credential scopes, trace privacy and retention must be managed explicitly.
