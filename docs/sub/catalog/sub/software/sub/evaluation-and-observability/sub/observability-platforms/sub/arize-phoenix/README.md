# Arize Phoenix

Arize Phoenix is a self-hostable AI observability and evaluation platform released under Elastic License 2.0 (ELv2) for tracing, experimentation, evaluation, troubleshooting, datasets, and prompt workflows around AI applications.

Phoenix can run locally or in self-managed deployments. Arize also offers hosted Phoenix operation, which is a separate service boundary rather than a different software identity.
