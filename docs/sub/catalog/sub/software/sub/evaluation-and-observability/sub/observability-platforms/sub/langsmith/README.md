# LangSmith

LangSmith is LangChain's agent/LLM engineering platform centered on observability and evaluation, with prompt engineering and optional deployment capabilities.

## Scope and boundaries

- The profile covers tracing, monitoring, feedback, datasets/evaluations, and related engineering workflows as the primary observability/evaluation identity.
- LangSmith remains distinct from LangChain, LangGraph, and Deep Agents as separate software identities.
- The profile treats LangSmith Deployment and sandboxes as product surfaces unless upstream establishes a separate canonical product lifecycle.
- The profile keeps plan, deployment, storage dependency, pricing, and feature availability freshness-sensitive.
