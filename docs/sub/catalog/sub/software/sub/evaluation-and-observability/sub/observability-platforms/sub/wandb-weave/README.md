# W&B Weave

W&B Weave is the Weights & Biases product for tracing, observing, and evaluating AI applications and agents.

## Scope and boundaries

- The profile covers traces, datasets, scorers/evaluations, experiments, agent trajectories, and OpenTelemetry/integration surfaces only when current documentation supports them.
- Weave remains distinct from the broader W&B Models/MLOps product family; integrations do not make those products one canonical entity.
- This profile documents hosted and self-managed availability as deployment modes of the same Weave product when current W&B documentation supports that boundary.
- The profile keeps SDK languages, supported integrations, deployment options, and plan constraints freshness-sensitive.

## Lifecycle and tracing data

The documentation reviewed on 2026-10-17 names CoreWeave Agent Lens as Weave's successor; both offer its agent-tracing workflows and already receive that tracing data. This does not establish migration of every SDK or evaluation feature.
