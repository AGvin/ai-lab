# Documentation Requirements

## Requirements

- Identify OpenObserve as OpenObserve Inc.'s installable/self-hostable observability platform for logs, metrics, traces, and related telemetry, with a separate hosted OpenObserve Cloud delivery surface.
- Preserve the v1.0.0 GA boundary from 2026-09-11 and its first-class AI Observability surface for LLM/agent monitoring, evaluation, annotation datasets/queues, experiments, playground execution/scoring, and agent/service graph capabilities only to the depth supported by current upstream release evidence.
- Keep the self-hosted software identity distinct from OpenObserve Cloud as hosted delivery and from generic observability/evaluation concepts.
- Treat edition boundaries, licensing, deployment modes, supported features, retention, pricing, and cloud service behavior as mutable/version-sensitive facts.

## Validation

- OpenObserve is not classified solely as an AI evaluation framework; its broader observability platform identity is preserved.
- Hosted-service terms are not generalized to independently self-hosted open-source components.
- v1.0 AI Observability capabilities are not projected backward onto older releases without evidence.
