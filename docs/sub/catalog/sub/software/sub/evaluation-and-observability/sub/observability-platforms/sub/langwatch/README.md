# LangWatch

LangWatch is an open-core, self-hostable platform for observing, evaluating and managing LLM applications, agent runs and coding-assistant workflows.

## Scope and product boundaries

It offers tracing, evaluations, simulation testing, prompt controls and integrated routing/governance capabilities. Self-hosted LangWatch, managed LangWatch Cloud, optional SDKs and deployment charts are surfaces of the same platform identity unless independently released products are established. The canonical release record identifies server v3.20.1 (2026-10-02); pin exact server, package and chart revisions.

## Deployment and operations

Root repository code is Apache-2.0 licensed; some SDKs use MIT licenses, while separately licensed enterprise capabilities require commercial entitlement for production use. SSO/SCIM, audit-log access and gateway webhooks may have restricted gates. Verify deployment-specific secret scopes, tenant isolation, trace/prompt retention, integrations, model traffic and external telemetry before processing private data.
