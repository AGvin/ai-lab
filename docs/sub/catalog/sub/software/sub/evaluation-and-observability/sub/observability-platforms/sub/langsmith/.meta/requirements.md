# Documentation Requirements

## Requirements

- Identify LangSmith as LangChain's agent/LLM engineering platform centered on observability and evaluation, with prompt engineering and optional deployment capabilities.
- Cover tracing, monitoring, feedback, datasets/evaluations, and related engineering workflows as the primary observability/evaluation identity.
- State the current Cloud, Hybrid, and Self-hosted deployment choices accurately; self-hosting is an Enterprise add-on and must not be implied to be generally available on every plan.
- Distinguish LangSmith from LangChain, LangGraph, and Deep Agents as separate software identities.
- Treat LangSmith Deployment and sandboxes as product surfaces unless upstream establishes a separate canonical product lifecycle.
- Keep plan, deployment, storage dependency, pricing, and feature availability freshness-sensitive.

## Validation

- LangSmith is not reduced to a LangGraph-only service or duplicated as an agent framework.
- Hosted and self-hosted delivery are not represented as duplicate product identities.
