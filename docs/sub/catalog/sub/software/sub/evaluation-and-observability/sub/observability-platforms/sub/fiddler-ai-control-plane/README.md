# Fiddler AI Control Plane

Fiddler AI Control Plane is a platform for AI evaluation, observability, policy enforcement and governance across AI agents and predictive models.

## Scope and product boundaries

The current 2026 Control Plane positioning extends Fiddler's earlier AI Observability and Security Platform branding. Production traces, evaluations, runtime guardrails and governance belong to the evolving platform. Centor evaluator models, acquired technology and third-party telemetry integrations do not automatically become separate platform identities.

## Deployment and operations

Fiddler describes SaaS and customer-controlled deployment options. Confirm the actual deployment, gateway enforcement point, monitoring scope, credentials, retention and data residency. Detecting a violation after an action differs from preventing it on the request/response path. Performance, certification, pricing and evaluator-quality claims require current contractual and first-party evidence.
