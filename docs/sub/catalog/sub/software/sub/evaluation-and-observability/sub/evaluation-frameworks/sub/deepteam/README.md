# DeepTeam

DeepTeam is Confident AI's separately released open-source Python framework for adversarial and red-team evaluation of LLM-based applications and agents.

## Evaluation role and boundaries

The framework generates and scores single- and multi-turn attacks, including jailbreak and prompt-injection scenarios, against configured target applications. It depends on but is distinct from DeepEval. Optional CLI and hosted-reporting integrations do not make the local tool a hosted service.

## Reproducibility and operational safeguards

The canonical review records release v1.0.9 (2025-11-12), Apache-2.0 licensing and Python >=3.9,<3.14; pin supported versions before adoption. Execute attacks only on authorized, isolated test systems with synthetic data, bounded requests/budgets and restricted credentials. A passing red-team run does not certify real-world safety.
