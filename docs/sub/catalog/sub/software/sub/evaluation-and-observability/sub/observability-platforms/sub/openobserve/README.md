# OpenObserve

OpenObserve is OpenObserve Inc.'s installable/self-hostable observability platform for logs, metrics, traces, and related telemetry, with a separate hosted OpenObserve Cloud delivery surface.

## Scope and boundaries

- The profile preserves the v1.0.0 GA boundary from 2026-09-11 and its first-class AI Observability surface for LLM/agent monitoring, evaluation, annotation datasets/queues, experiments, playground execution/scoring, and agent/service graph capabilities only to the depth supported by current upstream release evidence.
- The self-hosted software identity remains distinct from OpenObserve Cloud as hosted delivery and from generic observability/evaluation concepts.
- The profile treats edition boundaries, licensing, deployment modes, supported features, retention, pricing, and cloud service behavior as mutable/version-sensitive facts.
