# Documentation Requirements

## Requirements

- Identify DeepEval as an open-source evaluation framework for testing LLM applications and AI systems, with a pytest-like testing workflow and LLM-specific metrics.
- Preserve its primary placement under `evaluation-and-observability/evaluation-frameworks`; optional tracing, datasets, red teaming, and hosted integrations do not change the framework's primary catalog role.
- Distinguish the local/open-source DeepEval framework from Confident AI's hosted AI quality platform and data synchronization surface.
- Keep exact metrics, provider integrations, Python requirements, hosted behavior, and other mutable implementation details source-backed when expanded.
- Include current official DeepEval documentation and repository references.

## Validation

- The page presents DeepEval as an evaluation framework rather than as the Confident AI hosted platform.
- Hosted synchronization is not implied to be required for local framework use.
- Official resource links match canonical entity metadata.
- The page contains no temporary-placeholder wording.
