# Langfuse

Langfuse is an open-source, self-hostable AI engineering platform combining LLM observability and tracing with prompt management, evaluation, datasets, and experiments.

Its integrated capabilities form one product surface; the canonical catalog placement remains observability-oriented rather than duplicating Langfuse across multiple software categories. Langfuse Cloud is a separate hosted operating surface.

## Editions and data boundaries

The core is MIT-licensed; Enterprise self-hosting includes commercially licensed features. Under the telemetry policy reviewed on 2026-10-17, OSS deployment telemetry can be disabled with `TELEMETRY_ENABLED=false` on all application containers, while Enterprise self-hosted telemetry supports license compliance and cannot be disabled. The documented deployment telemetry is aggregated and excludes raw traces and prompts.
