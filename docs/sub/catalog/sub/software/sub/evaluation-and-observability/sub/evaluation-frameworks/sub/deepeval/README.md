# DeepEval

DeepEval is an open-source evaluation framework for Python and TypeScript that tests LLM applications and AI systems. It provides a pytest-like workflow together with LLM-specific evaluation metrics for applications such as agents, RAG pipelines, and chatbots.

The framework can run independently; Confident AI provides a related hosted quality platform and optional synchronization surface rather than defining the local DeepEval software identity.
