# Pydantic Logfire

Pydantic Logfire is Pydantic's end-to-end AI engineering and observability platform built around OpenTelemetry traces, metrics, and logs.

## Scope and boundaries

- The profile covers AI/LLM instrumentation, agent observability, evaluations, prompt management, infrastructure/application observability, and related engineering workflows only from current documentation.
- The profile treats the current Pydantic AI Gateway as a Logfire platform surface rather than materializing the archived standalone `pydantic-ai-gateway` project as a second current product.
- The profile describes self-hosted deployment and hosted delivery as modes of the same product identity unless upstream establishes an independent service identity.
- Logfire remains distinct from Pydantic AI and Pydantic AI Harness.
