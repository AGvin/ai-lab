# Documentation Requirements

## Requirements

- Identify Pydantic Logfire as Pydantic's end-to-end AI engineering and observability platform built around OpenTelemetry traces, metrics, and logs.
- Cover AI/LLM instrumentation, agent observability, evaluations, prompt management, infrastructure/application observability, and related engineering workflows only from current documentation.
- Treat the current Pydantic AI Gateway as a Logfire platform surface rather than materializing the archived standalone `pydantic-ai-gateway` project as a second current product.
- Describe self-hosted deployment and hosted delivery as modes of the same product identity unless upstream establishes an independent service identity.
- Distinguish Logfire from Pydantic AI and Pydantic AI Harness.
- Keep supported languages, integrations, deployment modes, gateway providers, and plan features freshness-sensitive.

## Validation

- The archived standalone Pydantic AI Gateway repository is not presented as an independent current canonical product.
- General application observability does not erase Logfire's AI-engineering role.
