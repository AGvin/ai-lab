# Galileo

Galileo is a platform for evaluating, monitoring and improving the reliability of LLM applications and AI agents.

## Scope and product boundaries

Its product scope includes offline evaluation, production tracing, monitoring, failure investigation, guardrails and agent-quality workflows. Proprietary evaluator models, named metrics, SDKs and data integrations are capabilities or dependencies of Galileo rather than automatically independent catalog products.

## Deployment and operations

Galileo describes SaaS, customer-controlled VPC and on-premises deployment, including documented air-gapped environments. Check tenant/project access, trace and prompt retention, model egress, evaluator configuration and operational ownership for the selected deployment. Model accuracy, feature availability, quotas, prices and compliance claims require current evidence.
