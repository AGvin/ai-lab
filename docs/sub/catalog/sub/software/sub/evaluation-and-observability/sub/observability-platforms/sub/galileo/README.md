# Galileo

Galileo is the product lineage now presented as Splunk Agent Observability, for evaluating, monitoring and improving the reliability of LLM applications and AI agents. Splunk's acquisition page confirms that Cisco completed the Galileo acquisition. This identity boundary was reviewed on 2026-10-17; the original Galileo Technologies provenance remains recorded below.

## Scope and product boundaries

Its product scope includes offline evaluation, production tracing, monitoring, failure investigation, guardrails and agent-quality workflows. Proprietary evaluator models, named metrics, SDKs and data integrations are capabilities or dependencies of Galileo rather than automatically independent catalog products.

## Deployment and operations

Legacy Galileo documentation describes SaaS, customer-controlled VPC and on-premises deployments, including air-gapped environments. Splunk's 2026-09-18 announcement describes the current Agent Observability offering on premises, in Splunk Observability Cloud and through Cisco Cloud Control. Confirm the selected offering's access, retention, model egress, evaluator configuration and operational ownership; legacy packaging and plan claims do not automatically apply across the transition.
