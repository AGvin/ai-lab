# Documentation Requirements

## Requirements

- Present Agent Frameworks as the canonical software index for frameworks used to build, coordinate, or run agentic systems.
- List every materialized direct framework child exactly once.
- Keep concrete framework identity and implementation facts with child software profiles, and keep hosted agent products under `catalog/services/` when service identity is primary.
- Do not reproduce legacy `catalog-item` or `catalog/item` processing selectors.

## Validation

- Navigation matches the materialized direct children.
- The page does not duplicate concrete framework profiles.
