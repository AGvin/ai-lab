# OpenAI Agents SDK

OpenAI Agents SDK is a lightweight SDK for building agentic applications with agents, tools and handoffs, guardrails, sessions, tracing, and extensible runtime behavior.

## Supported language runtimes

The Python `openai-agents` SDK (Python 3.10+) and JavaScript/TypeScript `@openai/agents` SDK (Node.js 22+, Deno or Bun) are separate upstream distributions of the same Agents SDK family. Do not assume version parity or identical APIs.

The orchestration SDK can run in application-owned infrastructure while using selected model providers. Sandbox agents, tool execution, credentials, sessions, tracing, and realtime audio require application-level isolation, authorization, and privacy controls; SDK guardrails alone do not replace them.
