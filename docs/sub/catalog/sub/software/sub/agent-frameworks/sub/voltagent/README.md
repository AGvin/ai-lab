# VoltAgent

VoltAgent is an open-source TypeScript/JavaScript agent framework whose independently installable core is published as `@voltagent/core`. It is distinct from the VoltOps Console observability and operations product.

## Capabilities and compatibility

The framework covers typed tools and agents, multi-agent coordination, model-provider integrations, workflows, memory adapters, guardrails and MCP connections. Integration, tracing and evaluation packages are not independent core products.

The canonical record last verified **`@voltagent/core@2.11.0` (2026-09-28)** as a non-prerelease release with an **MIT** license. Current monorepo metadata requires **Node.js >=20**. Confirm the pinned core package, compatible `ai`/`zod` peer dependencies and actual runtime separately; a monorepo version is not necessarily the published core version.

## Operations

Tool and workflow plugins can access third-party APIs, stored agent memory, credentials and network resources. Define explicit permissions, scoped secrets, memory retention, model data-handling and usage budgets. Local framework execution does not imply isolation or private provider inference.
