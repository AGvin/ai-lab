# Google Agent Development Kit

Google Agent Development Kit (ADK) is an open-source framework for building tool-using and multi-agent applications, with supporting paths for evaluation and deployment.

Google ADK is available through separately maintained Python, TypeScript, Go, and Java SDKs. They belong to one framework family but have language-specific packages and feature lifecycles. You can run framework code on infrastructure you control; Cloud Run and Vertex AI Agent Engine are optional deployment surfaces. ADK Web is intended for development, not as a production UI without separate controls.
