# Documentation Requirements

## Requirements

- Identify Letta as the open-source framework/server for building stateful agents whose persistent memory and context can evolve across interactions.
- Preserve the software classification because the Letta server can be self-hosted; do not collapse the self-managed framework/server identity into Letta Cloud or another hosted delivery surface.
- Explain the stateful-agent/memory role without treating one memory implementation, model provider, tool interface, agent template, or hosted deployment option as the complete product identity.
- Render the standard `entity-relations` block from validated current-entity relations and preserve Letta as the producer.
- Treat release versions, model/provider compatibility, memory/context APIs, agent templates, sandbox integrations, SDK details, and hosted-service behavior as mutable facts requiring current first-party verification.
- Include current official Letta documentation and repository references.

## Validation

- Letta remains a concrete self-manageable agent framework/server rather than a generic memory concept or hosted-only service.
- The `produces` / `produced-by` relation pair is materially consistent.
- Mutable capabilities are not generalized from one release without current upstream evidence.
