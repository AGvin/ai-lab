# Software

Canonical profiles for installable or self-managed software, grouped by primary role.

Hosted-only or externally operated products belong under [`services/`](../services/). Models, datasets, hardware, and producers retain their separate canonical catalog ownership.

## Software categories

- [Agent Frameworks](./sub/agent-frameworks/) — frameworks and SDKs for building, coordinating, and running agentic systems.
- [Agents](./sub/agents/) — ready-to-use AI agent software for development or general computer work.
- [AI Management Platforms](./sub/ai-management-platforms/) — self-managed control planes for AI access, governance, policy, cost, identity, provider/model administration, and operations.
- [Application Frameworks](./sub/application-frameworks/) — frameworks and libraries for AI-enabled applications, retrieval systems, integrations, and optimized model programs.
- [Automation](./sub/automation/) — software for connecting services, triggering actions, executing scripts, and automating operational or development processes.
- [Data Infrastructure](./sub/data-infrastructure/) — self-managed operational data systems for storage, indexing, retrieval, search, memory, and context.
- [Development Tools](./sub/development-tools/) — tools and systems for AI-assisted software development.
- [Evaluation and Observability](./sub/evaluation-and-observability/) — tracing, testing, measuring, benchmarking, and comparing AI applications, agents, retrieval systems, prompts, and model behavior.
- [Gateways](./sub/gateways/) — control points between AI clients or applications and model backends.
- [Inference Runtimes](./sub/inference-runtimes/) — local, server, and distributed model inference software.
- [Interfaces and Workspaces](./sub/interfaces-and-workspaces/) — user-facing applications for models, conversations, knowledge bases, agents, and integrated AI workspaces.
- [Model and Data Platforms](./sub/model-and-data-platforms/) — software for managing, preparing, developing, versioning, curating, publishing, or programmatically using model and data assets.
- [Physical AI and Robotics](./sub/physical-ai-and-robotics/) — simulation, training, evaluation, control, and runtime integration for embodied AI and robotics.
- [Workflow Engines](./sub/workflow-engines/) — software for defining, scheduling, coordinating, and executing multi-step workflows.

Category placement records primary ownership; it does not imply that a product has only one capability.
