# Holistic AI Governance Platform

Holistic AI Governance Platform is a managed enterprise platform for discovering, assessing, and governing AI systems across models, agents, applications, APIs, pipelines, and vendors.

## Scope

The platform combines AI discovery and inventory, risk and bias assessment, policy and compliance workflows, continuous monitoring, and audit evidence. Security testing and agent oversight are capabilities within its governance control plane.

Integration coverage, regulatory mappings, module names, agent capabilities, and deployment availability depend on the current offering and supported environment.
