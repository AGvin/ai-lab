# Google Agent Registry

Google Agent Registry is Google Cloud's generally available governed registry and discovery service for agents and related reusable agent resources. It provides registration, versioning, lifecycle state, discovery and search, interfaces and bindings, and organizational reuse rather than agent execution.

## Service boundary

Agent Registry has its own product documentation, release notes, API v1 and client libraries, console experience, resource types, and lifecycle. Gemini Enterprise Agent Platform remains the separate managed build, runtime, and orchestration platform even though the products integrate closely.

Supported resource types, regions, lifecycle behavior, search capabilities, interfaces and protocols, quotas, IAM, APIs, and integrations are freshness-sensitive.
