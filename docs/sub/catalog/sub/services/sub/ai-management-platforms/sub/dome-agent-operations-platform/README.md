# Dome Agent Operations Platform

Dome Agent Operations Platform is Dome Systems' generally available cross-runtime, cross-cloud agent operations and governance control plane.

## Service boundary

The platform combines an Agent Registry, MCP Gateway, LLM Broker, policy and authorization controls, guards, quotas, audit, webhooks, and management as components of one control plane. Managed agents, tools, models, pools, gateways, integrations, SDK/CLI/MCP interfaces, and third-party runtimes remain resources or integrations rather than separate Dome product identities by default.

Pricing, plans, limits, integrations, policy and guard capabilities, API/CLI/SDK surfaces, resource models, and availability are freshness-sensitive.
