# Microsoft Agent 365

Microsoft Agent 365 is Microsoft's generally available enterprise control plane for discovering, observing, governing, and securing agents across an organization.

## Service boundary

Its primary identity is AI management and governance even though identity, security, compliance, observability, registry, and lifecycle capabilities are integrated into the product. Microsoft Entra Agent ID, Windows 365 for Agents, Microsoft Copilot Studio, and other independently durable Microsoft products remain separate canonical identities.

Plan eligibility, licensing, integrations, supported agent sources, security features, and administrative workflows are freshness-sensitive.
