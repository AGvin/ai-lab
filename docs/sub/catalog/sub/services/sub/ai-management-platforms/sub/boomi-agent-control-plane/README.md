# Boomi Agent Control Plane

Boomi Agent Control Plane is Boomi's enterprise AI control plane for connecting, governing, observing, securing, and optimizing agentic workloads across native and third-party agents, models, tools, skills, and enterprise systems.

## Service boundary

Its primary identity is organization-wide control and lifecycle management. Connectivity, gateway, context, orchestration, build, and runtime capabilities are components of the same control-plane product rather than automatic peer services. The product can span public cloud, customer VPC, and on-premises runtime placement without changing its managed control-plane identity.

Provider integrations, exact governance and observability features, pricing, certifications, deployment modes, lifecycle status, and component availability are freshness-sensitive.
