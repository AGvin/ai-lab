# Vercel Connect

Vercel Connect is Vercel's managed integration and authentication platform for giving applications and agents scoped runtime access to external tools and data. Vercel's launch material records general availability from 25 August 2026.

## Managed connection boundary

Connect registers connectors, issues scoped runtime credentials, supports delegated authorization and forwards verified triggers. Team configuration and allowed project access determine which connections a runtime may use.

Third-party APIs, OAuth providers, MCP servers and event sources retain their own permissions and service terms. Check the current connector inventory, authentication modes, triggers and plan limits. The AI SDK, AI Gateway and individual connector implementations remain adjacent products or integration surfaces, not duplicate Connect identities.
