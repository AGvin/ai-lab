# Pipedream Connect

Pipedream Connect is Pipedream's producer-operated integration platform for embedding authenticated application and tool access into AI agents and applications.

## Service boundary

The service covers managed authentication, connected accounts, tool and action discovery and execution, and MCP-facing surfaces where supported. The broader Pipedream workflow product and individual third-party app integrations remain separate identities, and connectors, actions, or MCP tools do not become standalone catalog entities merely because Connect exposes them.

Supported application counts, MCP and tool inventories, limits, pricing, and beta or GA state of individual surfaces are freshness-sensitive.
