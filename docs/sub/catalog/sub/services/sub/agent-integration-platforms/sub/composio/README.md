# Composio

Composio is a producer-operated integration platform that gives AI agents and applications managed access to external applications and tools.

## Service boundary

The service covers tool discovery, authentication and connected accounts, tool execution, hosted MCP surfaces, and framework or client integrations where supported. Individual third-party applications and their APIs remain with their own canonical owners; SDKs, CLI surfaces, and plugins remain access mechanisms unless they establish an independently complete product identity.

Integration and tool counts, supported applications, plans, and availability are freshness-sensitive.
