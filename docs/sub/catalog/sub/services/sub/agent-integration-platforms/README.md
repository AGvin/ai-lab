# Agent integration platforms

This category owns producer-operated hosted platforms whose primary identity is managed tool and application access for AI agents and applications.

These services may combine tool discovery, managed authentication or connected accounts, action execution, event triggers, and hosted MCP or equivalent integration surfaces. Ordinary agent frameworks, SDK-only adapters, generic API gateways, and single-application SaaS products remain outside this category.
