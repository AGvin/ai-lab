# Documentation Requirements

## Requirements

- Present `agent-integration-platforms/` as the service catalog owner for producer-operated platforms whose primary identity is managed tool/app access for AI agents and applications.
- Include capabilities such as tool discovery, managed authentication and connected accounts, action execution, event triggers, hosted MCP or equivalent integration surfaces when they are part of the platform's current first-party identity.
- Keep ordinary agent frameworks, SDK-only adapters, generic API gateways, and single-application SaaS products outside this category.
- Render navigation from the validated direct-child projection rather than hard-coding a fixed inventory.

## Validation

- Every child has an independently durable hosted platform identity.
- Authentication/tool execution claims remain scoped to current first-party documentation.
- The category does not become a generic integration or automation catch-all.
