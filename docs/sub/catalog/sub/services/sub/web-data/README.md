# Web Data Services

Producer-operated APIs whose primary identity is supplying AI applications and agents with web search, retrieval, extraction, crawling, mapping, research, or browser-derived web data.

Managed browser/session execution platforms remain under infrastructure when remote browser execution is the primary product. Complete self-managed crawler or search products remain in the software catalog.
