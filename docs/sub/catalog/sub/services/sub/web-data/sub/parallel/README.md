# Parallel

Parallel is the hosted web-data and research API family operated by Parallel Web Systems Inc. Search supplies web results and excerpts for an application to process, while Task combines retrieval, research and synthesis into structured output with supporting sources. These interfaces belong to one vendor-operated service family; client SDKs, processor settings and MCP connectors are integration choices. [Search API](https://docs.parallel.ai/search/search-quickstart) · [Task API](https://docs.parallel.ai/task-api/task-quickstart).

## Scope and operating boundaries

Use Search when the application needs retrieved evidence and Task when it needs an assembled research result. Source citations and confidence indicators help inspection, but they do not make the result independently verified. Evaluate the exact workload and avoid treating the vendor's comparative benchmarks as a universal ranking. [Search documentation](https://docs.parallel.ai/search/search-quickstart) · [Task documentation](https://docs.parallel.ai/task-api/task-quickstart).

The customer terms effective October 17, 2026 restrict output resale, creation of training datasets and some cross-customer reuse. Their data provisions permit input/output use for service improvement and model training and require a separate DPA before processing personal data. Check the governing contract and negotiated controls for the intended use; there is no unconditional no-training or zero-retention conclusion from the API documentation. [Customer terms](https://parallel.ai/customer-terms).
