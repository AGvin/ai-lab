# Linkup

Linkup is a provider-operated web search, retrieval, and multi-source research API for AI applications and agents.

## Provenance

- Produced by: [Linkup](../../../../../producers/sub/l/sub/linkup/)

## Access and interfaces

Clients access the hosted API through authenticated requests. Search, Fetch, Research, and Tasks are workflows of the same service.

| Interface | Primary role |
| --- | --- |
| Search | Retrieve sourced links and snippets, sourced answers, or structured results. |
| Fetch | Retrieve the content of an identified web page. |
| Research | Perform multi-step research and return synthesis with sources. |
| Tasks | Run Search, Fetch, or Research work asynchronously in batches. |

Extract is documented as a closed-beta endpoint. Flash is documented as an alpha Search mode. Neither lifecycle label should be treated as evidence of a stable capability or an independently measured performance advantage.

## Operating and evidence boundaries

Enterprise private-index and Bring Your Own Cloud arrangements have separate deployment and contract boundaries. Confirm data access, residency, licensing, and feature availability for the applicable plan; a private indexing option does not by itself establish a separate installable software product.

Retrieved text and citations remain attributable to the original publishers. Verify material claims at their sources and respect content-access rights. Linkup's own benchmark results describe provider-reported evaluations; they do not establish a universal recommendation, fixed latency, guaranteed accuracy, or permanent coverage.
