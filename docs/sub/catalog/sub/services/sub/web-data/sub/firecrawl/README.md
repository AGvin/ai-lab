# Firecrawl

Firecrawl's hosted offering is a web-data service for scraping, crawling, searching, mapping, and extracting web content for AI applications and agents.

## Service boundary

Browser execution, agent features, and browser-backed extraction remain capabilities of the hosted service while its primary contract is web-content acquisition and transformation. The hosted service remains distinct from independently self-hostable Firecrawl software or source distributions; individual API operations do not become separate service entities.

Endpoint inventory, supported formats, extraction behavior, crawl limits, pricing, and hosted capacity are freshness-sensitive.
