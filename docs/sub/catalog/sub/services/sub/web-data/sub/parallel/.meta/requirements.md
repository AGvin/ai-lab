## Requirements

- Identify Parallel as Parallel Web Systems' producer-operated hosted web-search, extraction and multi-step evidence/research API platform for AI applications and agents, distinct from model APIs and managed browser-session infrastructure.
- Keep the first-party Search API (ranked web URLs/excerpts), Task API (long-horizon structured web research with supporting sources), and other documented Parallel web APIs as one vendor-operated service family unless a genuinely independent product identity and owner is established. Do not create duplicate top-level entities for configurable processor tiers, SDKs, MCP connectors or an agent built with the APIs.

- Track search modes, API schemas, task processors, indexing/crawl policy, freshness, latency, price, rate limits, extraction permissions, uptime and available data protection modes as changing plan/version-dependent claims.

Section 4(b) reserves potential customer-input/output use for service improvement/model training; section 4(d) requires a separate DPA before processing personal data. Recheck current contract, negotiated amendments and account-specific data controls before benchmarks or sensitive use.
- Distinguish Parallel Web Systems Inc. from the unrelated Parallel cobrowsing business at `parallel.tech`; preserve exact producer provenance and reciprocal relation.
