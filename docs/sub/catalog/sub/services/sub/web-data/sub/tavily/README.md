# Tavily

Tavily is a hosted web-data platform and API designed for AI applications and agents, centered on web search and content retrieval or extraction.

## Service boundary

Current Search, Extract, Crawl, Map, and research-oriented API surfaces remain capabilities of the same Tavily service. Tavily is classified as web-data rather than remote-browser infrastructure because its primary contract returns web and search data instead of leasing browser sessions.

API limits, pricing, supported parameters, endpoint inventory, and coverage claims are freshness-sensitive.
