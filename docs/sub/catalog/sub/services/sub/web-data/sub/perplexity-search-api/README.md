# Perplexity Search API

Perplexity Search API returns ranked web retrieval results and extracted content for application processing. It is separate from the generated-answer behavior of Agent API.

## Use and deployment boundaries

Choose domain, language, regional and result-budget controls for the task. Treat returned pages as external source material whose relevance and claims require checking. Review current API data terms and limits before submitting sensitive queries.
