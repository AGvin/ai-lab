# Exa

Exa is a producer-operated web search and retrieval service designed for AI applications and agents.

## Service boundary

Search, retrieval, SDK, MCP, and agent-framework integration surfaces remain part of the same hosted Exa service unless a distinct durable product identity emerges. Exa is classified as web-data rather than a generic model API or remote-browser platform, and external content returned through Exa keeps its own canonical ownership.

Endpoint inventory, limits, pricing, indexing and coverage claims, and ranking behavior are freshness-sensitive.
