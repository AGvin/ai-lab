# Documentation Requirements

## Requirements

- Identify Valyu as a hosted AI-oriented retrieval and cited research service spanning open web and specialized/permissioned finance, research, academic, biomedical and other third-party data sources, rather than a general LLM model inference API.
- Cover the released first-party Search, Contents, Answer and DeepResearch API workflows as one operator/platform family. Distinguish search results, extracted source content, AI-generated answers and longer synthesized reports; do not duplicate API endpoints, MCP or SDK integrations as other providers.
- Clarify that licensed/proprietary source coverage and access, output/citation rights, latency, task limits, indexing freshness, security and data retention may vary by customer, subscription and exact source license.
- Vendor-published benchmark rankings (including DRACO, FreshQA or SimpleQA claims) are not independent comparative certification. Record evaluated version, task set and rubric before relying on performance claims.
- Do not send sensitive or regulated proprietary data or rely on licensed full text without validating actual access rights, DPA and plan-specific processing terms.
- Preserve Valyu as research service operator, not source-data author or owner of cited models/datasets.

## Validation

- Official first-party product/documentation sources demonstrate a released hosted operator service.
- `produced-by` and producer `produces` links are an exact inverse pair.
- Material beta, deployment or third-party content attribution boundaries are preserved.
