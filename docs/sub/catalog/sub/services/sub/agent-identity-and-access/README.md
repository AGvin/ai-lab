# Agent Identity and Access

Producer-operated services whose primary identity is AI-agent authentication, identity lifecycle, delegated authorization, scoped credential issuance, or access control for agents acting autonomously or on behalf of users.

Agent-integration platforms, generic IAM products without a durable agent-specific identity, broad AI-security suites, and SDK-only authentication helpers remain outside this category.
