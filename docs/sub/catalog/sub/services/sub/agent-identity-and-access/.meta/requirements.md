# Documentation Requirements

## Requirements

- Present `agent-identity-and-access/` as the canonical service owner for producer-operated products whose primary identity is AI-agent authentication, identity lifecycle, delegated authorization, scoped credential issuance, or access control for agents acting autonomously or on behalf of users.
- Allow first-class agent identities, autonomous/delegated authorization, short-lived/scoped credentials, OAuth/token exchange, sponsorship/ownership lifecycle controls, and identity-centric access governance.
- Exclude agent-integration platforms where authentication only supports tool execution, generic CIAM/workforce IAM without a durable agent-specific product identity, broad AI-security suites, organization-wide AI-management platforms, SDK-only auth helpers, and draft identity protocols.

## Validation

- Children are independently identifiable agent identity/access services.
- Tool integration, generic IAM, and security-suite capabilities do not cause duplicate placement.
- Navigation matches validated materialized direct children.
