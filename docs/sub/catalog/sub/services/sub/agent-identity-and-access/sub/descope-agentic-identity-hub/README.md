# Descope Agentic Identity Hub

Descope Agentic Identity Hub is Descope's managed control plane for agent identities, protected resources, scoped tokens, credential connections, policy, and agent-access audit trails.

## Service boundary

MCP protection and downstream credential brokering are identity and access capabilities of this product rather than a reason to classify it as an integration platform or gateway.

Supported authorization flows, SDKs, resource and connection behavior, integrations, limits, and availability are freshness-sensitive.
