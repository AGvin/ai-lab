# CrowdStrike Agentic Identity Provider

CrowdStrike Agentic Identity Provider is an identity and access product for establishing trusted AI-agent identities and brokering scoped, contextual access.

## Service boundary

Short-lived and scoped authorization, human or system attribution, and risk-adaptive access are capabilities of the same agent-identity service. CrowdStrike's broader endpoint and security platform, AI-security posture products, and runtime guardrails remain separate identities.

Availability, packaging, licensing, supported identity flows, integrations, and access-policy behavior are freshness-sensitive.
