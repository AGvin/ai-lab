# Microsoft Entra Agent ID

Microsoft Entra Agent ID is Microsoft's agent-specific managed identity and access product for creating, authenticating, authorizing, and governing AI-agent identities.

## Service boundary

Delegated and autonomous access, agent identity lifecycle, token and credential controls, Conditional Access, and identity protection are capabilities of the same identity-first service. General Entra workforce or CIAM identities and broader AI-management or AI-security control planes remain separate.

Availability, licensing, supported identity flows, limits, and integration coverage are freshness-sensitive.
