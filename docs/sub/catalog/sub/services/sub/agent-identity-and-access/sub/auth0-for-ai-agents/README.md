# Auth0 for AI Agents

Auth0 for AI Agents is Auth0's managed identity and access surface for authentication, delegated access, scoped credentials, and authorization in AI-agent applications.

## Service boundary

The profile is agent-identity-first. Generic Auth0 CIAM capabilities belong here only when they directly define the agent-specific surface, while tool execution and integration platforms remain separate even when they consume Auth0-managed credentials.

Product availability, supported flows, token-vault behavior, limits, integrations, and packaging are freshness-sensitive.
