# Okta for AI Agents

Okta for AI Agents is Okta's generally available agent-specific identity product for registering, managing, securing, and governing AI-agent identities with least-privilege access.

## Service boundary

Generic workforce and customer identity features remain outside this profile unless they directly define the AI-agent product surface. Generally available capabilities are kept distinct from separately early-access or roadmap agent-gateway and tool-governance features.

SKU availability, feature lifecycle, supported integrations, token and credential flows, and licensing are freshness-sensitive.
