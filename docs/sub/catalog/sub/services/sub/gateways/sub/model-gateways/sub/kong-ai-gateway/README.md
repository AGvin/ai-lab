# Kong AI Gateway

Kong AI Gateway is Kong Inc.'s generally available AI-native gateway product, independently versioned beginning with the 2.x line.

## Service boundary

Kong AI Gateway 2.x has its own runtime, control plane, Admin API, version number, release cadence, and Konnect experience rather than being only a plugin set inside Kong Gateway 3.x. Legacy AI Gateway plugins that remain supported inside Kong Gateway 3.x stay with the canonical Kong Gateway software identity.

LLM and model routing, MCP and agent traffic, AI policies, provider coverage, analytics, and cost or security controls are service capabilities whose exact support is version-sensitive. Provider and protocol support, policy inventory, Konnect features, migration tooling, pricing, and supported versions are freshness-sensitive.
