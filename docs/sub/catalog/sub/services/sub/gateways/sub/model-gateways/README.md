# Model Gateway Services

Producer-operated gateway offerings designed primarily around unified model access, routing, fallback, model or provider policy, and AI-specific traffic control.

General API-management services remain separate when model traffic is only a secondary capability. The underlying models and model providers reached through these gateways remain with their own canonical owners.
