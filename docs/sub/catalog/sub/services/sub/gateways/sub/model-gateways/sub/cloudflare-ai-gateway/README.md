# Cloudflare AI Gateway

Cloudflare AI Gateway is Cloudflare's producer-operated gateway for observing and controlling AI application traffic across Cloudflare and third-party model providers.

## Service boundary

AI Gateway centralizes gateway capabilities such as logging and analytics, caching, rate limiting, retries and fallback, spend controls, and provider or model access around routed AI traffic. Cloudflare Workers AI, Vectorize, Agents, and other Cloudflare AI products remain distinct products even when they integrate with AI Gateway.

Plans, provider coverage, unified-billing behavior, pricing, limits, API compatibility, and other service state are freshness-sensitive.
