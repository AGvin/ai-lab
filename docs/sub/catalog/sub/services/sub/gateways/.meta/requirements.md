# Documentation Requirements

## Requirements

- Present Gateway Services as the catalog owner for producer-operated gateway offerings whose primary identity is centrally routing, governing, observing, or brokering AI/API requests.
- Keep installable or fully self-managed gateway products under `catalog/software/gateways/` rather than duplicating them here.
- List every materialized direct child exactly once and keep product-specific mutable facts with child profiles.

## Validation

- Navigation matches the materialized direct children.
- Hosted-service and self-managed-software identities are not duplicated solely because both expose gateway APIs.
