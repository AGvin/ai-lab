# Replicate

Replicate is Replicate, LLC's hosted service for running AI models through a web interface or API, including official models, public models, and user deployments.

## Service boundary

Replicate service identity remains separate from the independent authors, publishers, licenses, and versions of the models available through it. Current Replicate documentation describes official models as always-on, actively maintained, predictably priced, and exposed through stable input/output APIs; those characteristics must not be generalized to every community or custom model.

Non-official or versioned models and deployments can have different lifecycle, version, warm- or cold-start, pricing, and availability characteristics. Exact model inventory, pricing, hardware, limits, cold-start behavior, deployment options, and API details are freshness-sensitive.
