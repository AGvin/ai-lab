# Microsoft Foundry Models

## Relations

- Produced by: [Microsoft](../../../../../producers/sub/m/sub/microsoft/)

Microsoft Foundry Models is Microsoft's hosted catalog, deployment and inference-access service for models from Microsoft and other producers.

## Scope and boundaries

The service supports discovery and evaluation, managed-compute or serverless deployment where offered, and supported Foundry inference endpoints. Availability through Microsoft does not reassign partner/community model authorship.

Models sold by Azure and partner/community models can have different terms, support arrangements and deployment responsibilities. Review the particular model card, license, endpoint and deployment mode. Inventory, lifecycle, regions, fine-tuning, filters, capacity, quotas, pricing and SLA coverage change independently. Foundry Agent Service and the wider developer platform remain separate from this model-access identity.
