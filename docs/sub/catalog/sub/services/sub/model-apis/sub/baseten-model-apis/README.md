# Baseten Model APIs

Baseten Model APIs is Baseten's managed hosted API surface for accessing supported public models without managing a custom deployment.

## Service boundary

Model APIs remains distinct from custom Truss deployments, dedicated deployment configuration, and other Baseten infrastructure products. Third-party model identity, licensing, lifecycle, and intrinsic capabilities stay with their model owners rather than Baseten merely because the service hosts them.

Model inventory, API compatibility, pricing, quotas, latency and throughput, regions, and other hosted-service state are freshness-sensitive.
