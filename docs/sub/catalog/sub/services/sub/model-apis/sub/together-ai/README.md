# Together AI

Together AI is Together Computer, Inc.'s hosted model and inference service, including managed API access and deployment options for AI models.

## Service boundary

Together AI service identity remains separate from the independent authors, licenses, and intrinsic properties of models served through the platform. Current Together documentation states that supported third-party models run on Together infrastructure rather than forwarding inference requests to the model author; that service behavior is mutable and should be re-verified before further expansion.

Current documentation also describes inputs and outputs as not stored by default, with account configuration and enterprise controls able to affect behavior. Exact model inventory, deployment modes, pricing, throughput, service levels, regions, retention controls, and other hosted state are freshness-sensitive.
