# Jev AI

Jev AI at `thejevai.com` is an independently operated hosted developer API and playground for structured decision requests, model selection, usage credits and account/workspace management. The website explicitly states that it is **not affiliated with, operated by, or endorsed by TypeSafe**. This is a distinct hosting/operator surface, not the original TypeSafe Jev model or its producer. [Jev AI developer documentation](https://thejevai.com/docs).

## Model and operator boundaries

The documented `POST /v1/systemone` interface accepts state plus typed questions such as `choice`, `score`, and `noul`, with a model identifier and Bearer API key. Results and supplier-provided probabilities or confidence data must not be treated as independently validated accuracy or fairness. Version-pinned model IDs are preferable to moving aliases for reproducible experiments.

The original Jev model is attributed to **TypeSafe AI**, not to this third-party service. The current public evidence does not establish the service operator's legal-entity identity, authority to act as the original producer, redistribution rights or production reliability. No speculative `produced-by` relationship is assigned.

## Operational and trust boundaries

Check pricing/credits, concurrency, documented endpoints, rate limits, available models, terms, data handling, retention, credentials and provider rights before sending business data. Avoid using unvalidated decision outputs as sole authority for high-stakes financial, medical or other material decisions.
