# SpaceXAI API

SpaceXAI API is the direct hosted developer service for Grok inference, produced by SpaceXAI LLC under the SpaceXSI public name.

## Developer access

Current documentation covers responses and chat, image, video and voice generation, files, batches, model discovery and supported server-side tools. OpenAI-compatible REST access describes protocol compatibility and does not imply OpenAI ownership or identical behavior for every endpoint.

The inference API uses an API key at `api.x.ai`; separate management functions use Management API keys. Collections retain their own persistent data-infrastructure identity. Check exact model and tool availability, endpoint and SDK versions, deprecations, rates, billing and data controls. Grok consumer subscriptions and application features do not by themselves establish API entitlements.
