# DeepInfra

DeepInfra is the hosted remote model-inference and API service operated by Deep Infra Inc.

## Service boundary

This identity is scoped to hosted remote model APIs and remains distinct from DeepInfra's dedicated GPU, custom-deployment, and broader infrastructure offerings. Third-party model identity, licensing, lifecycle, and intrinsic capabilities stay with model owners rather than DeepInfra merely because those models are served there.

Model inventory, API compatibility, pricing, rate limits, context and output limits, regions, throughput, and other hosted state are freshness-sensitive.
