# Mistral API

## Relations

- Produced by: [Mistral AI](../../../../../producers/sub/m/sub/mistral-ai/)

Mistral API is Mistral AI's direct hosted API service for model inference and supported API-native capabilities.

## Scope and boundaries

Applications call the service using an API key and an available model identifier. The API reference covers capabilities such as chat, embeddings, classification, OCR, audio, files and batch operations; each endpoint has its own request contract and lifecycle.

The API is distinct from model weights, SDKs, Studio's broader developer-console and asset-management surface, and Vibe's agent experience. Model inventory, authentication, rate limits, prices, regions, API versions and beta/GA status are mutable. Check the applicable endpoint documentation and deployment terms rather than assuming all Mistral-hosted and self-hosted routes behave alike.
