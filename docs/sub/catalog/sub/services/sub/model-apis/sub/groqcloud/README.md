# GroqCloud

GroqCloud is Groq LLC's hosted cloud service for API access to AI models and Groq-provided compound systems.

## Service boundary

Production models and systems remain distinct from preview models; current preview availability is not evidence of production-stable service coverage. Third-party model identity, licensing, lifecycle, and model-specific limitations remain with their proper owners rather than Groq merely because GroqCloud serves them.

Current policy retains usage metadata while inference customer inputs and outputs are not retained by default, subject to feature-specific retention and limited platform-protection handling. Exact model inventory, throughput, pricing, rate limits, context limits, regions, retention controls, and other service state are freshness-sensitive.
