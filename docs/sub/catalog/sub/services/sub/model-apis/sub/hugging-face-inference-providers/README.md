# Hugging Face Inference Providers

Hugging Face Inference Providers is Hugging Face, Inc.'s hosted model-API service for accessing supported inference providers through Hugging Face's inference interface.

## Service boundary

The service provides hosted access and provider integration without taking ownership of the concrete models it exposes. Concrete model identity remains in Model Reference, while provider availability, pricing, routing, limits, and API behavior are mutable service state that must remain source-backed and time-scoped when documented.
