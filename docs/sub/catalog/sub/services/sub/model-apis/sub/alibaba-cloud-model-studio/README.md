# Alibaba Cloud Model Studio

Alibaba Cloud Model Studio is Alibaba Cloud's managed model-service platform for accessing Qwen and supported third-party models through hosted APIs without operating inference infrastructure.

## Service boundary

Model Studio's identity is the managed model API and platform surface, including workspace, regional endpoint, model-management, provisioned-throughput, and related service capabilities. Qwen and third-party model identities, Alibaba Cloud Skills, endpoint aliases, and region-specific model snapshots remain separate from the service itself.

Supported models, endpoints, regions, data-location and deployment scopes, quotas, pricing, retirement schedules, API compatibility, and plan features are freshness-sensitive.
