# Cerebras Inference

Cerebras Inference is Cerebras Systems Inc.'s hosted inference-as-a-service offering for remote model access.

## Service boundary

The hosted service remains distinct from Cerebras hardware systems and self-managed software stacks. Production and preview model availability must remain separate; a callable preview model is not evidence of production stability. Third-party model identity, licensing, lifecycle, and intrinsic model facts remain with canonical model owners.

Model inventory, pricing, rate limits, API behavior, context limits, throughput, availability, and other service state are freshness-sensitive.
