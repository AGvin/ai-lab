# Cisco AI Defense

Cisco AI Defense is Cisco's distinct AI-security product for protecting AI applications and AI infrastructure against AI-specific threats.

## Service boundary

The profile is AI-security-first. Generic Cisco security-suite capabilities belong here only when they are explicitly part of the current AI Defense product surface.

Module names, supported deployment and integration surfaces, availability, licensing, and protection claims are freshness-sensitive.
