# Check Point AI Agent Security

Check Point AI Agent Security is Check Point's AI-security product for discovering AI agents, assessing their risk, and enforcing runtime controls over prompts, tools, data, and actions.

## Service boundary

The profile is security-first. AI Guardrails is treated as a runtime-protection component of the broader AI Agent Security surface rather than as a separate peer service.

Supported platforms, discovery coverage, risk controls, Guardrails packaging, availability, and commercial claims are freshness-sensitive.
