# Prisma AIRS

Prisma AIRS is Palo Alto Networks' AI-security platform for protecting AI applications, models, data, and agents.

## Service boundary

The profile is security-first. Runtime protection, model and supply-chain security, red teaming, posture and discovery, and agent security belong here when supported by current first-party evidence. Protect AI or Portkey provenance may explain current capabilities without restoring absorbed commercial identities as peer services, while AI Gateway-specific facts remain with the appropriate gateway surface when separately materialized.

Packaging, availability, module names, limits, and commercial claims are freshness-sensitive.
