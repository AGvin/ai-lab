# Documentation Requirements

## Requirements

- Present Prisma AIRS as Palo Alto Networks' current AI-security platform identity for protecting AI applications, models, data, and agents.
- Cover runtime protection, model/supply-chain security, red teaming, posture/discovery, and agent security only as current product capabilities supported by first-party evidence.
- Preserve acquisition/provenance context where Protect AI or Portkey technology affects current Prisma AIRS capabilities without reviving absorbed commercial identities as peer services.
- Keep Prisma AIRS AI Gateway-specific gateway facts with the appropriate gateway/service surface when independently materialized.
- Treat packaging, availability, module names, limits, and commercial claims as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Prisma AIRS remains security-first rather than governance-, identity-, or gateway-first.
- Producer provenance resolves to Palo Alto Networks, Inc.
