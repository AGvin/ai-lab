# Documentation Requirements

## Requirements

- Present Check Point AI Agent Security as the broad current agent-security product for discovering agents, assessing risk, and enforcing runtime controls over prompts, tools, data, and actions.
- Treat AI Guardrails as a runtime-protection component/tier of the current broader product surface rather than an automatic peer canonical entity.
- Treat supported platforms, discovery coverage, risk controls, Guardrails packaging, availability, and commercial claims as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- The entity remains security-first rather than identity/governance-first.
- Producer provenance resolves to Check Point.
