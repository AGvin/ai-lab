# AI Security

Producer-operated products whose primary identity is protecting AI models, applications, agents, data flows, or AI supply chains against adversarial, abuse, integrity, and runtime security threats.

Evaluation-first tooling, generic gateways with optional guardrails, governance-first platforms, identity-first products, and generic security suites remain outside this category unless AI security is the durable product center.
