# Zep

Zep is a managed agent-memory and context service centered on storing, deriving, and retrieving reusable context and temporal knowledge.

## Service boundary

The profile is memory and context-first. Graphs, search, and storage mechanisms remain implementation properties when memory is the primary product job; generic vector-database comparisons and framework orchestration remain outside this factual profile.

APIs, limits, hosted architecture, pricing, and current memory and graph capabilities are freshness-sensitive.
