# Vespa Cloud

Vespa Cloud is a managed service for deploying and operating Vespa search and ranking applications. It is separate from the independently available [self-managed Vespa software](../../../../../../../software/sub/data-infrastructure/sub/vector-search/sub/vespa/).

## Managed operations

The service provides a provider-operated environment for tenant applications, application deployment, production zones and lifecycle operations. Features such as scaling, upgrades and endpoint security depend on the active service plan and configuration.

Production applications, staging/development zones, command-line tools and enclave deployment options are surfaces of Vespa Cloud rather than independent managed-service products.

## Security and service limits

Review supported zones and regions, service quotas, cloud-provider availability, authentication, tenancy, network access, data retention, pricing, SLAs, and deployment responsibilities using current first-party material. Managed-service properties must not be attributed to self-managed Vespa by default.
