# Chroma Cloud

Chroma Cloud is Chroma's hosted, production-grade, fully managed distributed Chroma service, distinct from the self-managed and open-source Chroma engine.

## Service boundary

The profile is managed vector and search infrastructure. Dense, sparse and full-text search, collection forking, dashboard, Sync, and managed indexing remain capabilities of the same hosted service rather than separate canonical entities.

Regions, pricing, indexing implementation, limits, operational metrics, and availability are freshness-sensitive.
