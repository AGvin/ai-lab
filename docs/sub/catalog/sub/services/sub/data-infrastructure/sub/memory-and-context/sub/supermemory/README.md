# Supermemory

Supermemory is managed memory and continual-learning infrastructure for AI agents and applications.

## Service boundary

The profile is memory and context-first. API, MCP and plugin access, vector and graph storage, extraction, and learning mechanisms are capabilities of the same service rather than separate vector-search or agent-framework identities.

Model names, APIs, limits, pricing, storage implementation, and availability are freshness-sensitive.
