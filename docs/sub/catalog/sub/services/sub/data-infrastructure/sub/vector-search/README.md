# Vector Search

Producer-operated services whose primary identity is managed vector storage, indexing, similarity or hybrid search, and retrieval infrastructure for AI applications.

Memory-first services, general databases that merely expose vector search, hosted web search/extraction services, and self-managed vector/search software are outside this category.
