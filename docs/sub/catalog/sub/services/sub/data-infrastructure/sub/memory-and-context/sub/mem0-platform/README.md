# Mem0 Platform

Mem0 Platform is Mem0's producer-operated managed memory service for reusable agent and application memory, distinct from the self-managed Mem0 software identity.

## Service boundary

The profile is memory and context-first. Vector stores, graph services, rerankers, embeddings, and search remain implementation or capability details when reusable memory is the primary product job, while self-managed Mem0 stays with the software memory/context owner.

Pricing, managed-backend behavior, enterprise controls, limits, and availability are freshness-sensitive.
