# Pinecone

Pinecone is a producer-operated vector and search data-infrastructure service for production AI applications.

## Service boundary

The profile is managed vector and search infrastructure. Embeddings, reranking, hybrid retrieval, filtering, and related inference helpers remain Pinecone capabilities unless an independently durable product identity is materialized elsewhere; general database comparison and selection guidance stays outside this factual profile.

Pricing, regions, limits, supported hosted models, and performance claims are freshness-sensitive.
