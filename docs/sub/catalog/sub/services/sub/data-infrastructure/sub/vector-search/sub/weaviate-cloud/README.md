# Weaviate Cloud

Weaviate Cloud is Weaviate's fully managed service, distinct from self-managed and open-source Weaviate Database.

## Service boundary

Shared database technology represents product lineage rather than a reason to collapse the managed service into the software identity. Embeddings, hybrid search, generative integrations, and Query Agent features remain secondary while managed vector and search operation is primary.

Plans, regions, SLAs, pricing, operational features, and availability are freshness-sensitive.
