# turbopuffer

turbopuffer is a producer-operated object-storage-native search service for vector, full-text, sparse, hybrid, and filtered retrieval.

## Service boundary

The profile is managed search infrastructure. Native embeddings, namespaces, BYOC and single-tenant options, and branching remain capabilities of the same service while search and retrieval stay primary rather than model-API or generic-database ownership.

Regions, latency and scale benchmarks, pricing, recall claims, embedding models, and deployment options are freshness-sensitive.
