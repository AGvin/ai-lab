# Zilliz Cloud

Zilliz Cloud is Zilliz's fully managed Milvus and vector-search service.

## Service boundary

Serverless, dedicated, BYOC, managed clusters, APIs, and Terraform support remain deployment and operation surfaces of the same service rather than peer entities. The profile stays managed vector and search infrastructure rather than generic cloud infrastructure.

Plans, regions, limits, Milvus compatibility, pricing, availability, and performance claims are freshness-sensitive.
