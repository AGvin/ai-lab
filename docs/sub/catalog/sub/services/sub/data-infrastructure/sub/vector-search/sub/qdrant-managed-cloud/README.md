# Qdrant Managed Cloud

Qdrant Managed Cloud is Qdrant's producer-operated managed vector and search service, distinct from self-managed Qdrant software.

## Service boundary

Cluster operation, scaling, monitoring, upgrades, backups, disaster recovery, and hybrid-cloud support remain service capabilities rather than separate entities. The profile stays vector and search-first rather than generic cloud infrastructure.

Cloud regions, plans, pricing, limits, SLAs, infrastructure providers, and operational features are freshness-sensitive.
