# Documentation Requirements

## Requirements

- Present Supermemory as managed memory and continual-learning infrastructure for AI agents and applications.
- Treat API, MCP/plugin access, vector/graph storage, extraction, and learning mechanisms as capabilities of the same memory-first service.
- Treat model names, APIs, limits, pricing, storage implementation, and availability as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Supermemory remains memory/context-first rather than a generic vector-search or agent-framework product.
- Producer provenance resolves to Supermemory.
