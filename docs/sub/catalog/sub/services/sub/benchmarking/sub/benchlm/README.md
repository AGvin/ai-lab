# BenchLM

BenchLM is a hosted AI benchmarking and benchmark-evidence resource used to compare and evaluate AI models.

## Evidence boundary

Methodology, model coverage, evidence provenance, update cadence, and benchmark limitations should be reviewed before results are used for decisions. Aggregated benchmark evidence remains separate from canonical model facts and AI Lab recommendations.
