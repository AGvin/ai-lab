# Arena

Arena is a hosted public AI benchmarking and leaderboard resource for comparing models across its supported arenas and modalities.

## Evidence boundary

Methodology, model coverage, update cadence, and leaderboard limitations should be reviewed before Arena results are used for decisions. Leaderboard positions are mutable benchmark evidence rather than intrinsic model facts or persistent recommendations.
