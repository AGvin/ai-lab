# Artificial Analysis

Artificial Analysis is a hosted independent AI benchmarking resource covering models, inference providers and endpoints, systems, and adjacent AI-stack performance dimensions.

## Evidence boundary

Methodology, provider and model coverage, benchmark coverage, pricing assumptions, and leaderboard limitations should be reviewed before results are used for decisions. Provider and model measurements remain benchmark evidence rather than canonical provider or model identity facts.
