# LLM Stats

LLM Stats is a hosted AI benchmarking hub that publishes model benchmark, leaderboard, pricing, speed, and related comparison evidence.

## Evidence boundary

Methodology, model inclusion criteria, evidence provenance, update cadence, and benchmark limitations should be reviewed before results are used for decisions. The Open LLM Leaderboard is one LLM Stats leaderboard view rather than a separate canonical service identity, and mutable leaderboard positions remain benchmark evidence rather than intrinsic model facts.
