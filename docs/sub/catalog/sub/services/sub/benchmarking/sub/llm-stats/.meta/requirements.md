# Documentation Requirements

## Requirements

- Identify LLM Stats as the canonical hosted AI benchmarking hub/resource that publishes model benchmark, leaderboard, pricing, speed, and related comparison evidence.
- Preserve the legacy Open LLM Leaderboard source as one LLM Stats leaderboard view, not as a second canonical service entity.
- Require readers to review methodology, model inclusion criteria, evidence provenance, update cadence, and benchmark limitations before using leaderboard results for decisions.
- Keep concrete leaderboard positions and mutable benchmark results out of intrinsic model facts.
- Link the official LLM Stats site, methodology, and Open LLM Leaderboard view as research/identification references.

## Validation

- Facts remain source-backed and service-scoped.
- Mutable benchmark results are not represented as timeless canonical entity facts.
- Recommendations remain with decision support.

## Scoped original-source qualification — 2026-11-06

- LLM Stats maintains a hosted AI model comparison hub spanning benchmark scores, pricing, speed, modality and specialized leaderboards. Its methodology describes combining public reported and independently sampled evidence with uncertainty-aware ratings; the Open LLM Leaderboard is a view of the same service, not an independent producer/registry entity.
- Published rates and rankings are mutable and can use source-dependent inference or estimated data. Distinguish provider-published scores, observed API performance, model versions and composite assumptions; missing or stale values must not be silently treated as failures or recommendations.
- Verified first-party source 1: https://llm-stats.com/methodology
- Verified first-party source 2: https://llm-stats.com/research
- Verified first-party source 3: https://llm-stats.com/leaderboards/open-llm-leaderboard
- Source qualification accepts the present service identity and documented boundaries only; not a complete freshness or legal/security audit, independent benchmark replication, runtime execution, full schema/cache/CI/render, clean pass or final-delivery gate.
