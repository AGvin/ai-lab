# Documentation Requirements

## Requirements

- Present this node as the factual catalog category for identifiable hosted benchmarking and public evaluation resources.
- Explain that the category owns service identities and their source-backed factual characteristics, not benchmark methodology as an abstract concept, benchmark run/result evidence, or recommendations derived from benchmark evidence.
- Distinguish hosted benchmarking resources from installable/self-hosted evaluation and observability software.
- Provide child navigation only to materialized canonical resources.

## Validation

- Every child is an identifiable hosted benchmarking/evaluation resource rather than an abstract benchmark concept or one transient leaderboard view.
- Decision-support conclusions remain outside this factual catalog category.
