# Braintrust

Braintrust is an AI observability and evaluation platform for tracing, datasets, experiments, scorers and evaluations, prompts, and production-quality workflows.

## Deployment boundary

Braintrust supports a hybrid architecture in which customers can host the sensitive data plane while Braintrust operates the control plane, including the web UI, authentication, and lightweight metadata. Customer-hosted data-plane deployment therefore does not make the complete Braintrust product fully self-managed software.

Observability and evaluation features, data-handling behavior, hosting options, plans, and integration support are freshness-sensitive.
