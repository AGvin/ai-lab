# Perplexity Computer

Perplexity Computer is the hosted service for executing multi-step research, coding, creation and connected-application workflows. Its general answer workspace, local Portable Computer stack and underlying model artifacts remain separate.

## Use and deployment boundaries

Use account-specific connector and action scopes, and review consequential external changes. Background work, supported model routes and subscription availability can change. Local or hybrid product descriptions must not be assumed to describe every hosted task's execution and data flow.
