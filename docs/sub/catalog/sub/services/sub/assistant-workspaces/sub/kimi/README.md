# Kimi

## Relations

- Produced by: [Moonshot AI](../../../../../producers/sub/m/sub/moonshot-ai/)

Kimi is Moonshot AI's hosted online assistant/workspace, combining conversation and agent execution through web and mobile clients.

## Scope and boundaries

Its product scope includes search, research, multimodal work and creation of documents, slides, spreadsheets and websites. Agent and Agent Swarm workflows are hosted assistant capabilities rather than separate trained-model identities.

Kimi Work's local desktop execution, Kimi Code's developer tools and Kimi Claw's cloud automation have separate product boundaries. Connected services, memory, scheduled tasks, models, tool inventory, plans/credits, regional availability and data-use controls are mutable. Consult the current product and account terms; a shared Kimi model or membership does not make every product's permissions or execution location identical.
