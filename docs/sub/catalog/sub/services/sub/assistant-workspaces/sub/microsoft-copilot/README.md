# Microsoft Copilot

## Relations

- Produced by: [Microsoft](../../../../../producers/sub/m/sub/microsoft/)

Microsoft Copilot is Microsoft's hosted AI assistant/workspace application across web, desktop and mobile.

## Scope and boundaries

The app supports chat and content work, including file uploads, image/document creation and delegated work such as Cowork where enabled. Voice, search, library and agent capabilities are parts of the product experience rather than separate services merely because they have their own navigation surface.

The account determines the experience: personal Microsoft accounts and Microsoft Entra work/school accounts have different entitlements, grounding, administrative controls and data protection. Microsoft 365 integrations, Copilot Studio, Agent 365 and underlying models remain separate identities. Consult the current account-specific documentation for plans, model choices, data controls, retention/training, features and regional availability.
