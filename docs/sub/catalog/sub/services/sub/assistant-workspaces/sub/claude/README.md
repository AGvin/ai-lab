# Claude

Claude is Anthropic's hosted conversational AI and assistant-workspace service. It is the hosted product surface, distinct from the underlying Claude model identities and from Claude Code as a separate coding-agent product.

Exact plans, available models, features, limits, integrations, workspace controls, regional availability, and data-handling behavior can change and should be verified against current Anthropic documentation when they matter to a decision.
