# Documentation Requirements

## Requirements

- Present Qwen Studio as Qwen Team's hosted end-user AI assistant/workspace across web, desktop and mobile applications, currently branded on qwen.ai as the Qwen assistant/Qwen Studio.
- Preserve the assistant-workspace boundary across reasoning, multimodal chat, long-document work, web/deep research, image/video creation, coding/artifacts and related end-user capabilities.
- Keep Alibaba Cloud Model Studio as the separate developer/model-API platform; do not conflate the similarly named hosted developer service with Qwen Studio's end-user assistant.
- Keep Qwen trained-model families, Qwen Code, Qwen API Platform, image/video models, web-search tools and generated artifacts with their respective canonical owners.
- Treat current model routing, multimodal capability, app/platform availability, agent/deep-research behavior, plans, limits and data controls as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Qwen Studio remains an end-user hosted assistant rather than Alibaba Cloud Model Studio or a Qwen trained model.
- Qwen/Qwen Chat aliases do not create duplicate assistant nodes.
- Producer provenance resolves bidirectionally to Qwen Team.
