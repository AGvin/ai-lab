# Documentation Requirements

## Requirements

- Present Qwen Studio as Qwen Team's hosted end-user AI assistant/workspace across web, desktop and mobile applications, currently branded on qwen.ai as the Qwen assistant/Qwen Studio.
- Preserve the assistant-workspace boundary across reasoning, multimodal chat, long-document work, web/deep research, image/video creation, coding/artifacts and related end-user capabilities.
- Keep Alibaba Cloud Model Studio as the separate developer/model-API platform; do not conflate the similarly named hosted developer service with Qwen Studio's end-user assistant.
- Keep Qwen trained-model families, Qwen Code, Qwen API Platform, image/video models, web-search tools and generated artifacts with their respective canonical owners.
- Treat current model routing, multimodal capability, app/platform availability, agent/deep-research behavior, plans, limits and data controls as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Qwen Studio remains an end-user hosted assistant rather than Alibaba Cloud Model Studio or a Qwen trained model.
- Qwen/Qwen Chat aliases do not create duplicate assistant nodes.
- Producer provenance resolves bidirectionally to Qwen Team.

## Source-backed identity and operating scope

The reader must preserve the following boundaries and their source basis.

Qwen Studio is the Qwen end-user assistant workspace, also represented here by the Qwen and Qwen Chat aliases. The Qwen site presents an assistant for research and content work, and the first-party Qwen Studio app listing names Alibaba Cloud as publisher. It is a hosted assistant experience rather than a downloaded model checkpoint. [Qwen assistant](https://qwen.ai/home) · [Qwen Studio app](https://play.google.com/store/apps/details?hl=en-US&id=ai.qwenlm.chat.android).

The assistant brings together chat, reasoning, search and multimodal or document-oriented tasks, with product capabilities and supported app platforms changing over time. Check the actual account and application for the tools, model route and limits needed by the task. A generated artifact or a model selected inside the assistant does not create another copy of the workspace identity. [Qwen assistant](https://qwen.ai/home) · [App capabilities](https://play.google.com/store/apps/details?hl=en-US&id=ai.qwenlm.chat.android).

Keep the similarly named Alibaba Cloud Model Studio developer platform separate. Its API configuration and retention commitments are not a general policy for the end-user Qwen Studio assistant, and a Qwen model's weights license does not establish assistant-service privacy. Review the chosen assistant's account terms and data controls before uploading sensitive files. [Model Studio retention policy](https://www.alibabacloud.com/help/en/model-studio/data-retention-policy) · [Qwen Studio publisher listing](https://play.google.com/store/apps/details?hl=en-US&id=ai.qwenlm.chat.android).

## Reader projection

- Render every non-hidden current-entity relation in its semantic group, ordered by explicit order, canonical target display name and target ID. Preserve source/contributor, organizational and product distinctions.
- Include the official resources from canonical references as readable links. Navigation to a related catalog entry must resolve to its reader, not to metadata.
- Keep changing version, plan, availability and policy details qualified by the cited source; no general offline, license or privacy guarantee follows from producer attribution.
