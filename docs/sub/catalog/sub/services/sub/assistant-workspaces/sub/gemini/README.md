# Gemini

Gemini is Google's hosted conversational AI and assistant-workspace service, represented here as the Gemini Apps product surface. It is distinct from underlying Gemini model identities and from Gemini CLI as separate installable agent software.

Exact plans, available models, features, Connected Apps, account or workspace controls, regional availability, activity retention, and data-handling behavior can change and should be verified against current Google documentation when they matter to a decision.
