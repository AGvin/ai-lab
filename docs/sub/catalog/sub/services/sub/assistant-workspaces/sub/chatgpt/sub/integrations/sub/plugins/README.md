# ChatGPT Plugins

ChatGPT Plugins documents the current shared ChatGPT/OpenAI plugin catalog and workspace-facing plugin behavior.

## Product boundary

Discovery, installation or enablement, removal and management, supported plugin capabilities, workspace or admin boundaries, UI surfaces, availability, catalog behavior, and terminology are mutable product facts. The shared ChatGPT/Codex plugin-system relationship may be described from current OpenAI documentation, while Codex-specific sandbox, approval, and execution behavior remains with Codex.

When OpenAI exposes portable Agent Plugins behavior, the formal Agent Plugins specification remains the normative owner; this page does not redefine portable manifest fields or generic plugin lifecycle and portability guidance.
