# Cohere North

Cohere North is Cohere's enterprise agentic AI workspace for grounded question answering, document and artifact creation, configurable agents, workflow automation, and connected organizational knowledge. The **October 5, 2026 North 2** release is a major upgrade to this same application identity, not a new standalone service. [North 2 announcement](https://cohere.com/blog/introducing-north-2).

## Product and model boundaries

North provides an integrated workspace with enterprise search, connected data, agent orchestration, libraries, memory, reusable skills, and application or workflow creation. Its connected services and supporting functions are capabilities or dependencies, not automatically separate North products.

The **North model family** is a different canonical model identity; the shared name does not make the application a trained model. Cohere Platform APIs, Model Vault, Compass, Command, Embed, Rerank and external connectors also retain their distinct product and data-processing boundaries. [Cohere product comparison](https://docs.cohere.com/docs/welcome).

## Deployment and operational boundaries

Cohere describes managed, private or on-premises, and air-gapped deployment possibilities. These do not imply identical control-plane, data routing, feature availability or operational responsibilities. Connector access, document-level permission enforcement, credential handling, agent/tool approvals, data retention, audits, models, governance policies, packaging and price must be checked for the actual enterprise deployment. [North product](https://cohere.com/north) · [North 2 release](https://cohere.com/blog/introducing-north-2).
