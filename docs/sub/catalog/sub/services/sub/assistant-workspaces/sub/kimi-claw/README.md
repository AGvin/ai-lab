# Kimi Claw

## Relations

- Produced by: [Moonshot AI](../../../../../producers/sub/m/sub/moonshot-ai/)

Kimi Claw's hosted service lets users deploy an always-online OpenClaw agent in Moonshot AI's cloud without operating a server themselves. Moonshot's Agent overview identifies the February 2026 launch as a public beta.

## Scope and boundaries

The hosted route includes a cloud runtime and workspace and can connect the bot to external chat channels. Community skills and channel platforms retain their own provenance; their availability does not imply Moonshot authorship or safety endorsement.

Kimi also supports linking an existing OpenClaw and documents local desktop deployment. Those routes do not make a user's OpenClaw instance cloud-hosted; this catalog service profile describes the hosted route. The general Kimi assistant, local Kimi Work, Kimi Code and OpenClaw itself have separate identities.

Current lifecycle, models, storage, terminal/workspace features, channels, memory, plans and limits must be checked in the applicable route's documentation. The dated beta launch does not prove unrestricted general availability of every later feature or deployment mode.
