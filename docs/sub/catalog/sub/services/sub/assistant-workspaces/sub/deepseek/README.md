# DeepSeek

DeepSeek is DeepSeek's hosted end-user conversational assistant, accessible through its official web and mobile applications. The assistant supports chat, reasoning, web search and file/document input, subject to current product, account and regional availability. [Official DeepSeek App announcement](https://www.deepseek.com/news/deepseek-app/).

## Assistant and model boundaries

This profile describes the user-facing hosted assistant, **not** a trained DeepSeek model, the separate DeepSeek API Platform, DeepSeek Harness, or self-managed/open-source code. The web or app default model can change without making the hosted assistant a new service.

On **October 17, 2026**, DeepSeek announced a V4.1 Flash model update for its website and app. That is a dated model-routing change rather than a permanent guarantee about the model used in future conversations. Model names, thinking or expert modes, web-search access, uploaded-file capabilities and plan limits should be verified against the current application. [Dated model and app update](https://api-docs.deepseek.com/updates/).

## Account and operating boundaries

Official web and mobile apps have supported account login, synchronized chat history, web search, and file input. Check source permissions, regional availability, account and storage controls, retention and applicable policies before uploading private material. Third-party sites advertising DeepSeek access are not equivalent to the original hosted assistant. [DeepSeek app launch](https://api-docs.deepseek.com/news/news250115/).
