# ChatGPT Agent Skills

ChatGPT Agent Skills documents ChatGPT-specific support for Agent Skills as mutable service behavior rather than redefining the generic Agent Skills contract.

## Product boundary

Current availability, administration, supported package shape, upload or installation flow, invocation behavior, workspace or plan constraints, limits, permissions, and management controls are product facts that can change and must remain tied to current official OpenAI documentation.

User-provided skills, OpenAI-provided skills, and other ChatGPT extension mechanisms remain distinct. Generic Agent Skills authoring, portability, and cross-host semantics belong to the canonical specification, concept, and learning owners rather than this product-integration page.
