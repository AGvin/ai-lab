# Muse

## Relations

- Produced by: [Meta](../../../../../producers/sub/m/sub/meta/)

Muse is Meta's hosted personal AI agent, introduced on September 8, 2026. It is separate from the Muse model family and the Meta AI assistant.

## Scope and boundaries

Muse plans tasks, uses a browser and connected applications, and continues delegated work after the client closes. Meta operates its dedicated Muse Secure VM; apps, web and supported messaging surfaces are clients. Personal context, memory and connected accounts are part of this service.

Meta describes Sentinel as the authority for connector actions and network access, with scoped user approvals, isolated credential handling and an audit trail. These controls depend on the requested action and granted access; they are the vendor's architecture description, not an assurance that every action is error-free.

The launch rollout covered the United States on iOS, Android and web. Confidential VM, AI-glasses access and additional payment/login integrations were announced separately as forthcoming. Consult current documentation for availability, app permissions, data/training controls and plan limits.
