# Documentation Requirements

## Requirements

- Present this service profile as the hosted Kimi Claw route for launching an always-online OpenClaw-based bot in Moonshot AI's cloud without operating a local server or Docker environment; preserve the February 2026 public-beta launch as dated context.
- Preserve the hosted execution boundary for cloud-deployed instances. Linking an existing OpenClaw or using the separately documented local desktop route does not make that instance cloud-hosted; keep those deployment distinctions explicit.
- Keep Kimi's general hosted assistant, Kimi Work local agent, Kimi Code coding agent, OpenClaw itself, ClawHub/community skills, Kimi models, and third-party channel platforms as separate canonical owners.
- Distinguish the dated public-beta launch from the current lifecycle of individual deployment routes and features; do not infer unrestricted GA from the absence of a beta label on another help page.
- Treat storage limits, supported channels, skills-library inventory, Bot/Gateway behavior, models, subscriptions, terminal/workspace features, memory/persona controls, uptime behavior, and plan limits as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

- Reconcile the reader with the source-backed identity, access and interpretation context in canonical `entity.identity_note`.

## Validation

- Kimi Claw remains a hosted always-online agent service, not self-managed OpenClaw software.
- Community skill availability is not presented as Moonshot authorship or safety endorsement.
- Producer provenance resolves bidirectionally to Moonshot AI.
