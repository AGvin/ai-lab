# Documentation Requirements

## Requirements

- Present Kimi Claw as Moonshot AI's released public-beta zero-deployment cloud automation/agent service for launching an always-online OpenClaw-based bot without operating a local server or Docker environment.
- Preserve the hosted execution boundary: the agent instance, workspace/storage and continuous runtime are cloud-hosted even when the bot is connected to external chat channels or uses third-party skills.
- Keep Kimi's general hosted assistant, Kimi Work local agent, Kimi Code coding agent, OpenClaw itself, ClawHub/community skills, Kimi models, and third-party channel platforms as separate canonical owners.
- Preserve public-beta lifecycle explicitly; do not imply unrestricted GA while first-party help material still calls the February 2026 launch public beta.
- Treat storage limits, supported channels, skills-library inventory, Bot/Gateway behavior, models, subscriptions, terminal/workspace features, memory/persona controls, uptime behavior, and plan limits as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Kimi Claw remains a hosted always-online agent service, not self-managed OpenClaw software.
- Community skill availability is not presented as Moonshot authorship or safety endorsement.
- Producer provenance resolves bidirectionally to Moonshot AI.
