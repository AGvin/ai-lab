# Perplexity

Perplexity is Perplexity AI's hosted answer and research workspace. The answer engine, hosted Computer, browser and developer APIs are distinct product surfaces.

## Use and deployment boundaries

Use the workspace for cited answers and research, then check supporting sources before relying on the output. Account eligibility, model routing, connected applications and data controls require current workspace terms; an API agreement does not establish workspace retention.
