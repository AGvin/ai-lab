# Documentation Requirements

## Requirements

- Present Amazon Quick as AWS's hosted agentic-AI assistant/workspace for conversational work, research, deliverable creation, connected-business-data analysis, no-code apps, flows, and autonomous/scheduled agents.
- Preserve the hosted assistant/workspace boundary rather than treating every Quick agent, flow, app, space, skill, connected dataset, or integration as an independent AI Lab product.
- Keep Amazon Quick distinct from Amazon Bedrock AgentCore, AWS Agent Registry, AWS MCP Server, Kiro, Amazon Connect Customer, and AWS Agent Skill collections.
- Preserve current chat-agent and autonomous-agent capabilities, connected knowledge/data sources, deliverable/app creation, activity-feed behavior, enterprise controls, official skill catalog, and desktop/mobile surfaces only at applicable product/release scope.
- Treat plans/pricing, agent-hour allowances, connector/skill inventory, device support, enterprise controls, permissions, scheduling, feed behavior, and product packaging as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Amazon Quick remains a hosted assistant/workspace product, not a general agent-runtime infrastructure service or model.
- Producer provenance resolves bidirectionally to Amazon Web Services.
