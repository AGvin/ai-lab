# Documentation Requirements

## Requirements

- Document ChatGPT-specific Agent Skills support as mutable service facts, not as the generic Agent Skills concept.
- Cover current availability and administration, supported skill package shape, upload or installation flow, invocation behavior, and relevant workspace or plan constraints when source-backed.
- Distinguish user-provided skills from OpenAI-provided skills and from other ChatGPT extension mechanisms.
- Keep exact limits, supported surfaces, plan availability, permissions, and administration controls current-source-backed and time-scoped where they can change.
- Link the canonical Agent Skills concept and portability learning owner for reusable semantics and cross-host practices instead of reproducing them here.

## Validation

- Current ChatGPT-specific facts are supported by current official OpenAI documentation.
- No cross-platform support matrix is maintained here.
- Generic Agent Skills authoring or portability teaching is not duplicated.
