# Meta AI

## Relations

- Produced by: [Meta](../../../../../producers/sub/m/sub/meta/)

Meta AI is Meta's hosted general-purpose assistant across its app, web experience and supported Meta applications and devices.

## Scope and boundaries

The assistant supports conversation and personal context, with source-described voice and live-perception features, image work, web and social-content grounding, shopping/discovery and parallel reasoning. These are capabilities of the assistant; underlying Llama or Muse models, social applications and glasses hardware have separate identities.

Meta AI is distinct from the Muse personal-agent service that runs delegated background tasks. Model routing, memory, connected app/device support, countries, languages, teen controls and data-use settings can differ by account, surface and rollout. Consult the current product documentation before assuming a feature or data control is available everywhere.
