# Grok Bot

Grok Bot is the hosted AI-teammate service produced by SpaceXAI LLC under the SpaceXSI public name. It performs persistent, multi-step work across connected applications using a vendor-managed cloud computer.

## Computer, accounts and approvals

The product FAQ reviewed on 21 October 2026 states that all Bots belonging to one user share one persistent cloud computer, including files, the browser and signed-in accounts. The documented isolation boundary is between users, not between that user's Bots. Parallel Bots therefore must not be treated as independent credential or file compartments.

Bots can continue while the local device is offline. Connected accounts, files, scheduling and external actions require the selected product's access scopes, approval controls and data-handling configuration; a persistent cloud computer is not the user's local terminal.

## Product scope

Team Bots and the Bot Marketplace remain collaboration and discovery surfaces of the service. Grok's general assistant, Grok Build, model identities and third-party applications retain separate boundaries. Verify current plans, eligibility, app compatibility, isolation, controls, retention and limits when using the service.
