# Gretel Platform

## Relations

- Produced by: [NVIDIA](../../../../../producers/sub/n/sub/nvidia/)

## Platform identity and provenance

Gretel Platform identifies the synthetic-data service originally developed by Gretel. NVIDIA's account of the acquisition confirms that Gretel joined NVIDIA in **2025** and describes its work on synthetic data for model training and differential privacy. This supports the acquired lineage while preserving Gretel's original authorship. [NVIDIA acquisition provenance](https://developer.nvidia.com/blog/author/alexwatson/).

## Current access boundary

On **October 20, 2026**, the former Gretel service-description pages were unavailable, and the Gretel homepage redirected to NVIDIA's [synthetic-data use-case page](https://www.nvidia.com/en-us/use-cases/synthetic-data-generation-for-agentic-ai/). That page describes current NVIDIA offerings; the redirect does not establish that the former Gretel hosted platform is still available or that it has been formally shut down.

Current access therefore needs confirmation from the operator. Establish the available service, contracting entity, support terms, API endpoints, control plane, and data-processing locations before relying on earlier deployment descriptions. If a deployment runs a data plane in a customer environment, its control-plane and metadata dependencies still require separate review.

## Product and privacy boundaries

Historical Cloud, Hybrid, module, connector, SDK, and model names are not a current feature inventory. Shared terminology with NVIDIA NeMo does not establish identical products, migration support, or API compatibility. Synthetic-data generation also does not by itself establish a privacy guarantee for a particular input dataset, model, configuration, or downstream use.
