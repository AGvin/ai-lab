# Labelbox

Labelbox is a producer-operated AI data-development and curation platform for expert labeling and related data-production workflows.

## Service boundary

The profile covers RLHF, preference-data, evaluation-data, review, and quality-control workflows when they remain parts of the same data-production lifecycle rather than independent product identities. Persisted working datasets and annotations remain distinct from live application retrieval or context state.

Current product packaging, expert-network offerings, pricing, supported modalities, and workflow limits are freshness-sensitive.
