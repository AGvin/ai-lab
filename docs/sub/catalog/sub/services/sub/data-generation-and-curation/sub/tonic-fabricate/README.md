# Tonic Fabricate

Tonic Fabricate is Tonic.ai's managed synthetic-data generation product for creating relational databases, files and datasets, mock APIs, and repeatable generation workflows for development, testing, and AI workloads.

## Service boundary

Fabricate remains a distinct data-generation and curation product rather than a generic ETL or data-infrastructure service. Tonic Structural, Tonic Textual, and other Tonic products remain outside this profile unless they are independently materialized.

Supported connectors and formats, generation agents, workflow, MCP and API features, pricing, limits, and package tiers are freshness-sensitive.
