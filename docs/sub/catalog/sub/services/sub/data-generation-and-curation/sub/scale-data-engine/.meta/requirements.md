# Documentation Requirements

## Requirements

- Present Scale Data Engine as a producer-operated AI data-development service for expert data generation, curation, RLHF, preference data, evaluation, safety, and alignment workflows.
- Keep evaluation and red-teaming capabilities in this profile when they primarily generate signals/data for model improvement rather than form an independent security/observability product identity.
- Treat workforce/expert-network packaging, modalities, product modules, pricing, and current service capabilities as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Scale Data Engine remains data-generation/curation-first.
- Producer provenance resolves to Scale AI.
