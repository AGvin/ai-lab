# Scale Data Engine

Scale Data Engine is Scale AI's AI data-development service for expert data generation, curation, RLHF, preference data, evaluation, safety, and alignment workflows.

## Service boundary

The profile is data-generation and curation-first. Evaluation and red-teaming capabilities belong here when they primarily produce signals or data for model improvement rather than form an independent security or observability product identity.

Workforce and expert-network packaging, modalities, product modules, pricing, and current service capabilities are freshness-sensitive.
