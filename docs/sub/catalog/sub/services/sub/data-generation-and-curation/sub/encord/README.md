# Encord

Encord is a managed applied-AI data platform spanning data ingestion, curation, annotation, review, export, and iterative evaluation and active-learning workflows.

## Service boundary

The profile is data-generation and curation-first. Model evaluation belongs here when it closes the data-improvement loop rather than becoming the primary product identity, and working datasets and annotations remain distinct from live application retrieval or context state.

Supported modalities, storage integrations, annotation and evaluation capabilities, pricing, and package details are freshness-sensitive.
