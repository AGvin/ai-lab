# Civitai Asset Sharing Platform

**Civitai** is a hosted community platform for discovering, publishing and discussing generative-image models and related assets. The underlying service is distinct from its open repository, the externally contributed model files and the people publishing those files.

## Asset-sharing boundary

The [pinned first-party README](https://github.com/civitai/civitai/blob/e33d090034326331d5a250e38357bed0c3dec004/README.md) documents upload and discovery workflows, model collaboration, user feedback and a self-hostable application codebase. The hosted community at [civitai.com](https://civitai.com/) is managed separately; a local application checkout is not a copy of all remotely hosted assets, user accounts or content moderation processes.

## Ownership and operations

The repository's [Apache-2.0 LICENSE](https://github.com/civitai/civitai/blob/e33d090034326331d5a250e38357bed0c3dec004/LICENSE) governs covered application source. It **does not** automatically grant copying, commercial use, retraining, republishing or redistribution rights for community models, LoRAs, images, source datasets, prompts or other uploads. Verify each asset's explicit terms and the platform's current policies.

Operators and users should consider provenance, potentially unsafe model files, impersonation, image consent, sensitive content, malware risk and account protection. Community ranking, hosting availability, service prices and terms can change.

This is a source-backed catalog entry, not a claim of examining hosted models, running the app, auditing community content or completing a whole-catalog clean pass.
