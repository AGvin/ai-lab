# Hugging Face Hub

Hugging Face Hub is Hugging Face, Inc.'s hosted repository and collaboration service for versioned models, datasets, and machine-learning applications.

## Service boundary

The Hub owns hosted discovery, repositories, versioning, sharing, access control, and collaboration. Downloading an artifact for local use does not make its execution part of the Hub service, and Hugging Face open-source libraries, Spaces, Inference Providers, and Inference Endpoints remain separate canonical entities.

Treat repository visibility, access tokens, gated/private assets, model and dataset licenses, provenance, remote/custom code, and third-party artifacts as independent trust and review boundaries.
