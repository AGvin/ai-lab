# Claude Code Templates

Claude Code Templates (`aitmpl.com`, also presented as AI Templates) is a hosted interactive catalog for discovering and installing ready-to-use Claude Code components such as skills, agents, commands, settings, hooks, MCP integrations, and plugins where currently supported.

## Service boundary

The canonical service identity is the hosted catalog and discovery surface. Installable CLI tooling, analytics, conversation monitoring, health checks, and other local project tooling remain separate software capabilities rather than the service identity.

Its relation to Agent Skills means Claude Code Templates is a material skill-discovery resource. It is not the authority for the Agent Skills specification, an AI Lab endorsement, or a claim of complete skill coverage. Aggregated components may originate from multiple upstream and community sources; producer provenance for the catalog does not imply authorship of every listed component.

Counts, integrations, sponsorships, supported component totals, and similar service facts are mutable.
