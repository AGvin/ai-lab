# Mistral Studio

Mistral Studio is Mistral AI's hosted developer console and platform for reusable prompt and skill assets, API keys, playground and testing workflows, agent setup, model access, evaluations, usage monitoring, and related AI-application workflows.

## Service boundary

Studio's primary catalog identity is hosted AI assets because it provides durable, versioned, shareable prompt and skill resources with workspace visibility and rollback semantics. Concrete Mistral model families, Vibe products, administration surfaces, libraries, connectors, and standalone model-access concerns remain separate when independently materialized; Agentic Search remains a Studio, Search Toolkit, or Libraries capability unless Mistral establishes a separate durable product identity.

Plan availability, asset and version limits, API resources, supported models and features, workspace permissions, integrations, and beta or GA state are freshness-sensitive.
