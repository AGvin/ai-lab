# Bolt

Bolt is StackBlitz's hosted AI application and website building service. Users create and iterate on software through a browser-based agent workflow, with generated code and project state integrated into a managed workspace rather than a standalone local coding-agent installation.

## Service and integration boundary

Bolt can connect development work to services such as GitHub, Figma, Supabase, Bolt-managed database and hosting capabilities, and MCP-compatible connectors. Those integrations can expose repositories, designs, application data, credentials, external tools, or deployment state, so review connector scopes, secrets, workspace permissions, generated dependencies, and deployment changes before production use.

Generated application code can be exported or integrated with ordinary development workflows, but Bolt's account, hosted workspace, model/token limits, plan features, and individual integrations remain mutable service concerns.
