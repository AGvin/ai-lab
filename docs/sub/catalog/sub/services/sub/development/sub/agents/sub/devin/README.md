# Devin

Devin is Cognition AI, Inc.'s hosted software-development agent for planning and executing engineering tasks in managed development sessions. It can work from tickets or direct tasks, access connected repositories, modify code, run development tools and tests, and contribute through pull-request and review workflows.

## Service, integration, and automation boundary

Devin is a managed service rather than a standalone local coding-agent installation. Current official integrations span source control, issue tracking, team communication, API/CI workflows, MCP-connected tools, and organization-managed secrets. Scheduled sessions and managed parallel Devin sessions can extend work into unattended or concurrent automation.

Treat repository and organization permissions, workspace isolation, service users, secrets and credentials, terminal/browser/MCP/API access, scheduled execution, deployment capabilities, generated changes, and merge or release actions as explicit trust and approval boundaries. Integration availability and product limits are mutable service concerns.
