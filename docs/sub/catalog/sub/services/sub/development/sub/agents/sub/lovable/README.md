# Lovable

Lovable is Lovable Labs Incorporated's hosted full-stack application-building service. It turns natural-language instructions into editable web-application code and supports frontend, backend, database, authentication, integrations, deployment, and continued iteration through a managed workspace.

## Service, code, and deployment boundary

Lovable can synchronize project code bidirectionally with GitHub while Lovable Cloud and connected services retain their own managed state. It can also connect APIs, app integrations, MCP/chat connectors, databases, authentication systems, and external deployment targets.

Current Lovable terms distinguish customer data and generated AI output from the Lovable platform itself. Treat generated dependencies and code review, GitHub access, production data, secrets, workspace roles, database/authentication permissions, MCP/API connector scopes, deployment changes, and portability/self-hosting work as explicit trust and operational boundaries.
