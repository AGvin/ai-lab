# Replit Agent

Replit Agent is Replit, Inc.'s hosted AI builder and development agent. It operates inside Replit's managed project environment, where it can plan work, create or modify code, run and debug projects, test behavior, and help move an app from an idea through preview and publishing.

## Hosted development boundary

Replit Apps and projects are cloud-hosted, and Agent works through Replit's Project Editor and managed runtime. Importing repositories, exporting code, or connecting external developer workflows does not make Agent a primarily local coding-agent product.

Treat project/workspace permissions, generated dependencies, Secrets, databases and storage, connected services, GitHub imports or sync, publishing/deployment configuration, public visibility, and production data as explicit trust boundaries. Replit's own guidance emphasizes reviewing and testing Agent output and using checkpoints; a successful generation or preview is not a production-readiness guarantee.
