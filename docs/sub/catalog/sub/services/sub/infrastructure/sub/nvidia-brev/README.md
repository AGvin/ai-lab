# NVIDIA Brev

NVIDIA Brev is NVIDIA's producer-operated GPU development platform that provisions preconfigured GPU virtual machines across multiple cloud providers.

## Service boundary

Brev manages discovery, provisioning, configured AI and ML environments, access, and lifecycle while underlying capacity may come from different providers. GPU Instances, Environments, Launchables, CLI and web-console access, and Brev Connect remain product surfaces of the same service; Brev Connect can manage connectivity to user-owned hardware without making NVIDIA the owner of that hardware or every underlying cloud provider.

Provider inventory, GPU types, prices, regions, capacity, and preinstalled version details are freshness-sensitive.
