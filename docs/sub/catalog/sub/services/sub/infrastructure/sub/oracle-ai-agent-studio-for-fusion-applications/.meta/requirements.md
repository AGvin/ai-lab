# Documentation Requirements

## Requirements

- Identify Oracle AI Agent Studio for Fusion Applications as Oracle's managed builder/runtime platform embedded in Fusion Cloud Applications for creating, connecting, validating, deploying, and operating agents, agent teams, automation, and Fusion Agentic Applications.
- Preserve the Fusion-native boundary: security, business objects, workflows, approvals, auditability, and runtime integration are part of its managed service context rather than evidence that every Fusion application or packaged agent is the same product identity.
- Keep Oracle Fusion Cloud application suites, Fusion Agentic Applications, individual Oracle/partner agents, AI Agent Marketplace assets, and external agents as separate identities or catalog content where independently materialized.
- Treat builder capabilities, supported protocols/agents, marketplace inventory, pricing/entitlement, exact no-code/low-code/pro-code surfaces, feature lifecycle, and Fusion release compatibility as freshness-sensitive.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- The entity remains a managed agent-development/runtime platform rather than a generic Oracle Fusion application or a single packaged agent.
- Producer provenance resolves to Oracle.
