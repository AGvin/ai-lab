# TensorDock

TensorDock is a producer-operated GPU cloud marketplace and service that connects customers to GPU-backed virtual machines supplied across an independent hosting network.

## Service boundary

The marketplace model distinguishes TensorDock from a direct single-provider GPU cloud. Root-access virtual machines, GPU selection, API access, and pay-as-you-go operation remain service capabilities, while individual host or operator identities are not attributed to TensorDock as producer-owned infrastructure by default.

GPU inventory, host locations, prices, availability, and instance-product lifecycle labels are freshness-sensitive.
