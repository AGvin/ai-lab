# Microsoft Foundry Agent Service

## Relations

- Produced by: [Microsoft](../../../../../producers/sub/m/sub/microsoft/)

Microsoft Foundry Agent Service is Microsoft's generally available managed platform for building, deploying, running and scaling AI agents.

## Scope and boundaries

The service manages agent runtime, conversations, tool calls, identity, monitoring, versioning and publishing. Prompt agents use service-managed configuration; hosted agents bring application code into a managed runtime. These are service capabilities, separate from the installable Microsoft Agent Framework, Copilot Studio, Entra identity products and the underlying model catalog.

Service availability does not make every feature generally available. Tools, protocols, networking, storage, regions, quotas, publishing destinations and runtime options have their own support and preview boundaries. Connected-resource permissions and deployed application behavior still depend on the chosen identity, model, tools and configuration.
