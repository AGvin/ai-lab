# Vast.ai

Vast.ai is a hosted GPU infrastructure marketplace and service for renting compute capacity and running containerized AI, ML, and other GPU workloads.

## Service boundary

Users search provider offers, select capacity, and create instances from available marketplace supply, so pricing and hardware availability are market-driven rather than fixed catalog constants. Vast Serverless remains a service mode unless its lifecycle or ownership becomes independently substantial.

The `vastai` CLI, Python SDK, REST API, templates, volumes, SSH or Jupyter access, and related tooling are management interfaces rather than separate canonical products. Instances may run arbitrary model servers, notebooks, applications, and containers without making Vast.ai the owner of those runtimes or models.

GPU inventory, provider verification state, geographic supply, prices, storage or bandwidth charges, contract terms, Serverless behavior, limits, and availability are mutable. Independent marketplace hosts may differ in physical security, compliance, networking, and reliability, so provider-host variability should not be collapsed into a universal guarantee.
