# Daytona

Daytona is producer-operated secure sandbox and composable-computer infrastructure for running AI-generated code and agent workloads in isolated environments.

## Service boundary

Programmatic sandbox lifecycle, code execution, filesystem and process access, networking, snapshots or persistent state, and agent-framework integrations remain capabilities of the managed runtime. The profile is sandbox and execution infrastructure rather than generic IDE or workspace tooling, and security claims are limited to documented isolation and control properties.

Runtime limits, regions, supported resources, persistence behavior, pricing, and quotas are freshness-sensitive.
