# Cerebrium

Cerebrium is producer-operated serverless AI and GPU infrastructure for deploying and scaling AI applications and inference workloads.

## Service boundary

GPU-backed deployments, autoscaling and serverless execution, real-time or streaming workloads, and configurable compute remain capabilities of the hosted infrastructure service. Underlying model identities and third-party frameworks remain separate, and ordinary deployment primitives or SDK surfaces do not become standalone catalog identities by default.

GPU inventory, regions, cold-start characteristics, prices, quotas, concurrency, runtime limits, and performance claims are freshness-sensitive.
