# Gemini Enterprise Agent Platform

Gemini Enterprise Agent Platform is Google's managed enterprise platform for developing, orchestrating, deploying, and operating agents at organizational scale.

## Service boundary

The platform remains distinct from the Gemini model family, the Gemini end-user assistant, Google ADK software, and individual managed agents. Google Agent Registry is a separate generally available governed registry and discovery service; Gemini Enterprise Agent Platform integrates with it but does not own its canonical identity. Agent Gateway, sandboxes, runtime, orchestration, and related platform features remain inside this identity unless Google establishes an independently durable service boundary.

Supported models, connectors, governance controls, deployment and runtime capabilities, billing, quotas, integrations, availability, and preview or GA state are freshness-sensitive.
