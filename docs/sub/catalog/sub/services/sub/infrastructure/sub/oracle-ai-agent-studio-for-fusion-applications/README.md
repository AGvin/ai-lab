# Oracle AI Agent Studio for Fusion Applications

Oracle AI Agent Studio for Fusion Applications is Oracle's managed builder and runtime platform embedded in Fusion Cloud Applications for creating, connecting, validating, deploying, and operating agents, agent teams, automation, and Fusion Agentic Applications.

## Service boundary

Fusion-native security, business objects, workflows, approvals, auditability, and runtime integration define the managed context without collapsing every Fusion application or packaged agent into the same identity. Oracle Fusion Cloud application suites, Fusion Agentic Applications, individual Oracle or partner agents, AI Agent Marketplace assets, and external agents remain separate where independently materialized.

Builder capabilities, supported protocols and agents, marketplace inventory, pricing and entitlement, no-code or pro-code surfaces, feature lifecycle, and Fusion release compatibility are freshness-sensitive.
