# Microsoft Copilot Studio

Microsoft Copilot Studio is Microsoft's producer-operated SaaS platform for building, testing, publishing, operating, and managing AI agents and agentic workflows.

## Service boundary

Copilot Studio is the maker and runtime surface rather than Microsoft Agent 365, which is the organization-wide agent control plane. Microsoft 365 Copilot, GitHub Copilot, Microsoft Foundry, Power Automate, external A2A agents, and individual published agents remain separate identities or integrations where independently materialized.

Harness availability, preview and GA status, channels, connectors, models, workflow formats, licensing and Copilot Credits, governance controls, and integrations are freshness-sensitive.
