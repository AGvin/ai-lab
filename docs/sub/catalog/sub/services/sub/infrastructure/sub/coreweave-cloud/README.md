# CoreWeave Cloud

CoreWeave Cloud is CoreWeave's producer-operated AI cloud and infrastructure service for GPU-backed AI workloads.

## Service boundary

The service covers GPU compute and AI-workload infrastructure, including its Kubernetes-oriented operating model where applicable. Software projects such as `llm-d` remain separate identities even when CoreWeave produces or contributes to both.

Accelerator inventory, capacity modes, regions, prices, availability, and related cloud inventory are freshness-sensitive.
