# Modal

Modal is a producer-operated serverless compute platform for running compute-intensive applications and AI workloads, including GPU-backed functions and endpoints.

## Service boundary

Workload execution, autoscaling and serverless operation, GPU access, scheduled or batch jobs, and sandbox capabilities remain infrastructure surfaces of the same service. Models runnable on Modal remain with their canonical model owners, and individual execution primitives do not become separate service identities by default.

GPU inventory, prices, quotas, cold-start behavior, regions, and limits are freshness-sensitive.
