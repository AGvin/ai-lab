# Lambda Cloud

Lambda Cloud is Lambda's externally operated accelerated-compute service for provisioning GPU infrastructure for AI workloads.

## Service boundary

Users provision compute and remain responsible for the workloads and model-serving stack they run on it; Lambda Cloud is not a managed model-inference API or an installable inference runtime. Lambda-branded physical systems and workstations remain outside this service identity.

Accelerator inventory, regions, instance shapes, capacity, prices, and availability are freshness-sensitive.
