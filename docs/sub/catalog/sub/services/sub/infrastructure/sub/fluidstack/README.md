# Fluidstack

Fluidstack is a producer-operated AI cloud focused on large-scale GPU infrastructure for AI training and inference.

## Service boundary

Managed bare-metal Kubernetes and managed Slurm are orchestration surfaces of the same hosted infrastructure identity rather than separate services. The profile reflects large-scale managed cluster infrastructure rather than a generic self-service GPU marketplace.

Accelerator inventory, cluster scale, locations, networking specifications, commercial availability, prices, and operational limits are freshness-sensitive.
