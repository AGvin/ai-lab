# Sana Agents

Sana Agents is Sana Labs AB's hosted enterprise AI-agent and knowledge workspace grounded in an organization's connected knowledge and data sources.

## Product boundary

Enterprise integrations, synchronized company data, permission-aware access, enterprise search, and assistants or agents grounded in selected organizational knowledge form the source-first workspace boundary. Current multi-step analysis, action, and content-generation capabilities broaden the product without removing that knowledge grounding. Sana Agents remains distinct from Sana Learn and from its producer organization.

Pricing, connector counts, model availability, security certifications, and other mutable operational details are freshness-sensitive.
