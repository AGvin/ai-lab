# Tettra

Tettra is a hosted AI-powered internal knowledge-base and knowledge-management service.

## Product boundary

The durable internal knowledge base is the primary work object, including creating or importing documentation, AI-assisted search and answers, reusable Q&A, content verification, curation, and keeping organizational knowledge current. The Kai assistant remains a capability within Tettra rather than a separate product identity.

Pricing, integration coverage, AI feature limits, and other mutable details are freshness-sensitive.
