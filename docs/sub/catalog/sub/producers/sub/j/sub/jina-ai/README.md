# Jina AI

Jina AI, founded in 2020, develops search foundation models and technology for embeddings, reranking, document understanding and AI-powered retrieval. **Elastic acquired Jina AI on October 9, 2025**, according to both organizations' first-party announcements. Jina remains an identifiable product, model and research brand; it should not be described as an unaffiliated company.

## Search foundation platform

The separately documented **Jina Search Foundation API** offers managed model endpoints for embeddings and reranking, with related Reader/Search/document functions described across Jina's API surfaces. It is not the same thing as an individual open model, a full local search engine, or Elastic's separate Elastic Inference Service.

Jina's [post-acquisition legal notice](https://jina.ai/legal/) directs users to applicable Elastic data-processing documents. Validate data privacy, model weights and output rights, API account terms, quotas and supported modalities for a particular integration.
