# Documentation Requirements

## Requirements

- Identify Jina AI as a search-model brand and former independent company founded in 2020. Explicitly acknowledge Elastic's **October 9, 2025 acquisition** and avoid presenting Jina as an unaffiliated current corporate parent.
- Distinguish Jina AI's model/brand lineage from the standalone Jina Search Foundation hosted API, Elastic's other search infrastructure, and separately published open-weight models.
- Support historical and ownership claims with [Jina's official About page](https://jina.ai/about-us/), [Elastic's acquisition release](https://ir.elastic.co/News--Events/news/news-details/2025/Elastic-Completes-Acquisition-of-Jina-AI-a-Leader-in-Frontier-Models-for-Multimodal-and-Multilingual-Search/default.aspx), and [Jina's legal notice](https://jina.ai/legal/).
- Preserve one reciprocal `produces` / `produced-by` link to the frozen `jina-ai-search-foundation` service. Do not imply that Elastic Inference Service, Jina Reader, embeddings/reranking model weights and a Jina-hosted API are interchangeable identities or that one account automatically grants access to all.
- The Jina legal notice states post-acquisition data processing is subject to applicable Elastic terms; review current contractual privacy and data-processing conditions before sending private data.
- Do not assume uniform licenses across model weights, hosted API calls, data inputs or third-party web content. Version, cost, quotas, regions and embedding modalities vary.
- No authenticated API use, actual model ranking/embedding output, complete security/privacy/rights assessment, full repository CI or catalog clean pass is claimed.

## Validation

- Producer J navigation lists one Jina AI node and its API relation is reciprocal.
- Both original origin and current group ownership remain clear.
