# JetBrains

JetBrains curates and distributes the JetBrains Skills collection. The repository describes a filtered and verified snapshot of upstream agent skills and preserves each skill's source link.

Curation does not make JetBrains the original author of every skill. Preserve upstream attribution and source metadata; separately represented collections retain their own owners. A curated snapshot is not a guarantee that arbitrary agent instructions are safe or current for every environment.
