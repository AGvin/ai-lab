# Comfy Organization Inc.

Comfy Organization Inc. is the company behind ComfyUI and related Comfy products. Its [company page](https://comfy.org/about/) describes that role; the [terms](https://comfy.org/terms-of-service) use the legal name Comfy Organization, Inc.

ComfyUI retains its own software identity and creator/contributor provenance. The commercial terms exclude open-source software from their defined Products, so the company profile does not apply one commercial agreement to every ComfyUI deployment or extension.
