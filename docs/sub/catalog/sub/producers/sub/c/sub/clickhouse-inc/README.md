# ClickHouse, Inc.

ClickHouse, Inc. is the current corporate ownership layer for the acquired Langfuse and LibreChat surfaces while those projects and organizations retain distinct canonical identities and provenance.

## Ownership

- [Langfuse GmbH](../../../l/sub/langfuse-gmbh/) — organization owned by ClickHouse, Inc.
- [LibreChat](../../../../../software/sub/interfaces-and-workspaces/sub/conversational-platforms/sub/librechat/) — software acquired by ClickHouse, Inc.; Danny Avila's founder provenance remains distinct.
