# Documentation Requirements

## Requirements

- Identify CrowdStrike as the producer identity for CrowdStrike Agentic Identity Provider.
- Keep the agent-identity product relationship distinct from CrowdStrike's broader endpoint, threat-intelligence, and identity-security portfolio.
- Render the standard `entity-relations` block from validated current-entity relations.
