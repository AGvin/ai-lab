# Documentation Requirements

## Requirements

- Identify Cline Bot Inc. as the organization behind the Cline open-source coding-agent product.
- Keep the producer organization distinct from the Cline software entity and from individual client/runtime surfaces such as the IDE extension, CLI, or SDK.
- Link the canonical Cline Local Agent profile from the physically materialized `produces` relation when the reciprocal Cline `produced-by` relation resolves successfully.
- Include current official Cline site, privacy-policy, and repository references sufficient to establish provenance.
- Keep broader corporate, staffing, funding, pricing, and other mutable company details outside this concise producer profile unless they become relevant to represented catalog entities.

## Validation

- The page does not collapse Cline Bot Inc. and Cline into one entity.
- The Cline Bot Inc./Cline `produces` / `produced-by` relation pair is physically present at both endpoints and semantically consistent.
- The Cline link resolves to the canonical Local Agent profile.
- Official resource links match canonical entity metadata.
