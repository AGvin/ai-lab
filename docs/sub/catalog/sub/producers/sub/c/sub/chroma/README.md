# Chroma

Chroma is the organization identified as Chroma Inc. in its [terms](https://www.trychroma.com/terms). It produces the Chroma database software and the managed Chroma Cloud service.

The [open-source deployment documentation](https://docs.trychroma.com/docs/overview/oss) and [Cloud documentation](https://docs.trychroma.com/cloud/getting-started) describe separate delivery surfaces. Their catalog entries preserve the difference between operating the software and using the managed service.
