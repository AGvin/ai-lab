# Cohere

Cohere develops enterprise AI models and provides deployment and application products. Its [model catalog](https://docs.cohere.com/docs/models) identifies model families, while the [documentation introduction](https://docs.cohere.com/docs/welcome) describes Cohere Platform, Model Vault and the North workspace.

Model families, managed deployment services and the North workspace retain separate catalog identities. The North model family and North workspace are distinct entries. Cohere Labs remains a research organization within Cohere, with its own model-family provenance.
