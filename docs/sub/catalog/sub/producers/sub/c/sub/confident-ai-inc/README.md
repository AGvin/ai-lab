# Confident AI, Inc.

Confident AI, Inc. is the organization that created and maintains the represented DeepEval evaluation framework. The company remains distinct from the open-source DeepEval framework and from Confident AI's hosted quality platform.

## Produces

- [DeepEval](../../../../../software/sub/evaluation-and-observability/sub/evaluation-frameworks/sub/deepeval/) — open-source LLM evaluation framework.
