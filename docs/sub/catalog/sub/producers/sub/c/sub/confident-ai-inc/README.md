# Confident AI, Inc.

Confident AI, Inc. produces the DeepEval evaluation framework and the DeepTeam red-teaming framework. Its [terms](https://www.confident-ai.com/terms) identify the company; the [DeepEval page](https://www.confident-ai.com/frameworks/deepeval) and [DeepTeam project](https://www.trydeepteam.com/) establish the framework provenance.

The frameworks retain separate software identities. Their connection to the hosted Confident AI platform does not merge the software and service boundaries, as described in the [DeepEval FAQ](https://deepeval.com/docs/faq).
