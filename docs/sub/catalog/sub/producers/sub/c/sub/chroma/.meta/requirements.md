# Documentation Requirements

## Requirements

- Identify Chroma as the producer identity for Chroma Cloud and related Chroma products represented in the catalog.
- Keep managed Chroma Cloud distinct from self-managed/open-source Chroma when both are represented.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- `produces` is the inverse of Chroma Cloud `produced-by`.
