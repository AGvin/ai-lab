# Composio

Composio is the trading name of Sampark Inc, as identified in its [terms](https://composio.dev/terms). It operates the Composio [developer platform](https://composio.dev/developers) for agent tool integration, execution and authentication.

The producer, integration service and maintained Agent Skills collection retain separate catalog identities. Connected applications, user accounts and model providers retain their own ownership and authorization boundaries; the [authentication documentation](https://docs.composio.dev/docs/authentication) describes how Composio connects those accounts.

## Catalog relations

- [Composio](../../../../../services/sub/agent-integration-platforms/sub/composio/) — produced catalog entity.
- [Composio Awesome Claude Skills](../../../../../agent-skills/sub/collections/sub/composio-awesome-claude-skills/) — maintained curated and contributed Agent Skills collection; individual skills and plugins have separate rights and operational boundaries.
