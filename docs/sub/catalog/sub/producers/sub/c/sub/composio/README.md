# Composio

Composio is the trading name of Sampark Inc, as identified in its [terms](https://composio.dev/terms). It operates the Composio [developer platform](https://composio.dev/developers) for agent tool integration, execution and authentication.

The producer and integration service retain separate catalog identities. Connected applications, user accounts and model providers retain their own ownership and authorization boundaries; the [authentication documentation](https://docs.composio.dev/docs/authentication) describes how Composio connects those accounts.
