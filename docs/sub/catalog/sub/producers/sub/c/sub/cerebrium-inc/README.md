# Cerebrium Inc.

Cerebrium Inc. operates the Cerebrium platform. Its [terms](https://cerebrium.ai/terms-of-service) identify the company, and its [documentation](https://cerebrium.ai/docs/getting-started/introduction) describes serverless infrastructure for deploying AI applications.

The company and the infrastructure service retain separate catalog identities. Models and application code deployed on the platform retain their own producer attribution.
