# Documentation Requirements

## Requirements

- Identify Cloudflare as the producer identity for the selected Cloudflare AI/developer-platform services, its separately trained Clef decision-model family, and the official Cloudflare Skills collection.
- Keep the organization profile distinct from Workers AI, AI Gateway, Vectorize, Agents, individual models, and skill contents.
- Render the standard `entity-relations` block from validated current-entity relations.

- Keep Cloudflare's own Clef model-family attribution distinct from the third-party models served through Workers AI.
- Use Browser Run as the current display name for the existing Browser Rendering service identity; preserve the former name as an alias and do not add a second service node.
- Render all current producer relations from entity metadata, including the represented model family, skills collection and separately operated services.

## Validation

- Every `produces` relation represented here has a matching `produced-by` relation on the selected canonical entity.
