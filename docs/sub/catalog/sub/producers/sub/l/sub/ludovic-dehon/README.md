# Ludovic Dehon

Ludovic Dehon is Kestra's original creator and producer. He started the project in 2019 from a Leroy Merlin consulting and data-platform problem before a later company was formed to support its development.

The creator relation remains distinct from the later Kestra Technologies company and from Kestra Cloud or Enterprise commercial surfaces.
