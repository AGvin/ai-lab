# LLaMA Factory Project

LLaMA Factory Project is the open-source project/community publishing LlamaFactory, a platform for training and fine-tuning pretrained language and multimodal models.

This is a project identity rather than an inferred legal company. The training toolkit remains distinct from Meta's Llama models and other supported models or datasets, which retain their own provenance and applicable licenses.
