# LMSYS Org

LMSYS Org / Large Model Systems (LMSYS Corp.) is the nonprofit research organization that incubates SGLang. The organization remains distinct from the SGLang project team and from other LMSYS projects such as FastChat and Vicuna and from Chatbot Arena, which the current LMSYS site marks as graduated.

## Produces

- [SGLang](../../../../../software/sub/inference-runtimes/sub/inference-engines/sub/sglang/) — high-performance serving and programming framework incubated by LMSYS.
