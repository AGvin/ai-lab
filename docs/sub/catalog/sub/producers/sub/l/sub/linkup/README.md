# Linkup

Linkup is the first-party organization and operator behind the Linkup hosted web-data service for AI applications and agents.

The producer, service, and its API or SDK interfaces are distinct from the external publishers whose content is retrieved or cited. Service output provides source material for evaluation; it does not establish independent verification or ownership of those sources.
