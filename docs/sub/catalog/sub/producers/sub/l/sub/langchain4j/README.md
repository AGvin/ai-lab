# LangChain4j

LangChain4j is the independent open-source project/community identity publishing the LangChain4j Java library. Naming similarity does not establish organizational identity with LangChain Inc.; the producer identity remains separate from both LangChain Inc. and the LangChain4j software entity.

## Produces

- [LangChain4j](../../../../../software/sub/application-frameworks/sub/application-development/sub/langchain4j/) — Java application-development framework for LLM applications.
