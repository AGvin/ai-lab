# LlamaIndex, Inc.

LlamaIndex, Inc. is the organization behind the represented open-source LlamaIndex framework and related first-party product ecosystem. The company remains distinct from the LlamaIndex software framework and from hosted or commercial LlamaCloud surfaces.

## Produces

- [LlamaIndex](../../../../../software/sub/application-frameworks/sub/data-and-retrieval/sub/llamaindex/) — open-source data and retrieval application framework.
