# Documentation Requirements

## Requirements

- Identify Lambda, Inc. as the canonical producer for represented Lambda cloud services.
- Keep Lambda hardware products distinct from Lambda Cloud service identities.
- Preserve current first-party legal identity and source-backed product provenance.
- Render the standard `entity-relations` block from validated current-entity relations.
- Distinguish the Cloud Terms, which name Lambda, Inc. or its Affiliate, from Website Terms and the customer's applicable signed agreement; do not assert one contracting entity for every customer.

## Validation

- Lambda, Inc. is not conflated with the Lambda Cloud service itself.
- `produces` / `produced-by` relation pairs resolve consistently.
