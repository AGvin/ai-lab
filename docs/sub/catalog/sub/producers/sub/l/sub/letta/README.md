# Letta

Letta is the first-party organization and publishing identity behind the Letta stateful-agent software and App Server.

The software, hosted agent-memory service, and local or self-hosted tool execution have distinct operating boundaries. Tools execute where the agent harness runs; using a local client does not by itself establish that every part of the workflow is locally hosted.
