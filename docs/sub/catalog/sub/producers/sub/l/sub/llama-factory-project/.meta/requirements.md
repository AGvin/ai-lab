# Documentation Requirements

## Requirements

- Identify LLaMA Factory Project as the open-source project/community publishing the LlamaFactory model-training and fine-tuning software; a repository account alone does not establish a legal company.
- Render the standard `entity-relations` block from validated current-entity relations.
- Distinguish the training-tool project from Meta's Llama models and all other supported pretrained models and datasets, which retain their own provenance and applicable licenses.

## Validation

- `produces` is the inverse of LLaMA Factory `produced-by`.
