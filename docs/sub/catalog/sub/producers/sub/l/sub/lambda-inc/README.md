# Lambda, Inc.

Lambda, Inc. is the producer organization behind the represented Lambda Cloud services. The company, its hardware products, and the cloud service are separate identities.

The Cloud Terms name Lambda, Inc. or its Affiliate, while the Website Terms and any applicable signed agreement have their own scope. The producer profile therefore does not establish the contracting party for every customer.
