# Documentation Requirements

## Requirements

- Identify Lightning AI as the organization producing and maintaining the Lightning/PyTorch Lightning framework represented in the catalog.
- Keep the open-source framework identity distinct from Lightning AI hosted/cloud products, studios, templates, and managed compute services.
- Preserve current organization/product naming from first-party sources.

## Validation

- Hosted Lightning products are not conflated with the framework.
- Producer relation resolves to the canonical Lightning framework.
