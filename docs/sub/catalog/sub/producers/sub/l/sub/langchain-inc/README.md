# LangChain Inc.

LangChain Inc. develops the LangChain, LangGraph, and Deep Agents open-source projects and operates related LangSmith platform services.

Framework licenses and LangSmith platform rights are separate. Self-hosted LangSmith is an Enterprise offering with its own licensing and deployment contract; an open-source framework does not confer those platform rights.

## Related catalog entities

- [Deep Agents](../../../../../software/sub/agent-frameworks/sub/deep-agents/) — agent harness built on the LangChain stack.
- [LangChain](../../../../../software/sub/agent-frameworks/sub/langchain/) — higher-level agent framework.
- [LangGraph](../../../../../software/sub/agent-frameworks/sub/langgraph/) — low-level stateful orchestration runtime.
- [LangSmith](../../../../../software/sub/evaluation-and-observability/sub/observability-platforms/sub/langsmith/) — agent observability and evaluation platform.
