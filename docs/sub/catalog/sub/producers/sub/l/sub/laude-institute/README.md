# Laude Institute

Laude Institute is a research organization and upstream steward associated with Terminal-Bench. Laude describes the benchmark as a collaboration with Stanford researchers; its producer relation records provenance and stewardship without claiming exclusive authorship of every task.

The represented Terminal-Bench 2.0 dataset is distinct from the Harbor evaluation harness, later benchmark revisions, leaderboard submissions, and the models being evaluated. A benchmark score depends on the evaluated agent and execution protocol.
