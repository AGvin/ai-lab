# LanceDB

LanceDB is the producer and maintainer of [LanceDB OSS](../../../../../software/sub/data-infrastructure/sub/vector-search/sub/lancedb/), an open-source retrieval and data platform. The underlying Lance file format is a related project rather than a synonym for the whole LanceDB product.

## Scope

The released, self-managed OSS project and separately offered enterprise or hosted deployments have distinct operational and licensing terms. Provider-managed features, release compatibility and service-tier claims must be checked against current official documentation.
