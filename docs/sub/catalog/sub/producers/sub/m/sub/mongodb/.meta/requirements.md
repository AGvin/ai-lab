# Documentation Requirements

## Requirements

- Identify MongoDB as the first-party publisher of the official MongoDB Agent Skills collection.
- Preserve product ownership separately for MongoDB Atlas, Community/Enterprise Advanced, Search/Vector Search, MCP server implementation and hosted identity.
- Do not treat every plugin-distributed skill or integrated MCP feature as a separate product or independently authored skill.

- Include the identity and producer-boundary context from canonical `entity.identity_note`; keep detailed product behavior with the related canonical owners.

## Validation

- The producer relation reciprocates the MongoDB Agent Skills `produced-by` relation.
- Provider, library, database deployment and skill collection roles remain distinct.
