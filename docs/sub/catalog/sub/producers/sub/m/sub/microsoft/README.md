# Microsoft

Microsoft is the technology company that publishes Phi models, developer and model-runtime software, agent frameworks and skills, and operates Microsoft Copilot and Azure/Microsoft Foundry services. It also develops Maia accelerators and owns GitHub.

## Producer boundary

Corporate ownership and product authorship are different relationships: GitHub remains a separately identified producer, and hosting partner models in Foundry does not make Microsoft their author. Microsoft-origin DeepSpeed was contributed to foundation governance; the producer relation preserves its origin without asserting exclusive current control. Installable frameworks, runtimes, testing tools, and skills retain their own repositories, licenses, security reporting and maintenance policies; Code - OSS's MIT license differs from the Microsoft Visual Studio Code distribution license. Copilot's personal and work/school experiences have different account and data controls. Foundry model support, terms and deployment responsibilities depend on the model and hosting route. Agent Framework, Foundry Agent Service, Copilot Studio, Entra Agent ID, Agent 365, and Windows 365 for Agents remain separate products; their names do not confer a shared release status, entitlement or permission to use connected resources.
