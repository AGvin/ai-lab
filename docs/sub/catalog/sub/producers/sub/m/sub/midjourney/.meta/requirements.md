# Documentation Requirements

## Requirements

- Identify Midjourney as the producer/operator of the represented Midjourney model family.
- Keep model versions, Niji collaboration/versioning, web/Discord product behavior, plans, GPU accounting, and editing tools in their applicable owners.
- Treat current default-version state and product controls as freshness-sensitive.

## Validation

- Midjourney model provenance resolves bidirectionally.
- Product UI/tool behavior is not generalized into permanent model architecture.
