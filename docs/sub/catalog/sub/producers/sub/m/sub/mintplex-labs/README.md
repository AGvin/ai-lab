# Mintplex Labs

Mintplex Labs is the organization producing AnythingLLM. The organization remains distinct from the AnythingLLM software identity and from its hosted or self-hosted operating surfaces.

## Producer boundary

The official company site and AnythingLLM documentation identify this producer. Local installation, managed hosting, external model providers, and agent integrations have separate data flows and support responsibilities; a local-first product description does not mean every configuration is offline or that Mintplex owns the connected models.
