# ManiSkill Project

ManiSkill Project is the open-source project behind the ManiSkill robotics simulation and manipulation framework.

## Producer boundary

This project identity does not establish a separate corporate vendor or a single university owner. Software, simulation assets, third-party dependencies, and real-robot deployment have their own licensing and operational requirements; project provenance does not guarantee hardware compatibility or deployment safety.
