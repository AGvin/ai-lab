# Documentation Requirements

## Requirements

- Identify Mem0 as the producer identity for Mem0 products.
- Keep Mem0 Platform service identity distinct from current self-managed/open-source Mem0 software when both are materialized.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- `produces` is the inverse of Mem0 Platform `produced-by`.
- Producer references are current first-party sources.
