# MLCommons

MLCommons is an open AI engineering consortium that develops and operates AI benchmarks with industry, academia and other contributors. Its represented work includes MLPerf system-performance suites and the AILuminate safety benchmark family.

## Producer boundary

Consortium provenance is distinct from the authorship of each reference model or dataset and from the vendors submitting systems or hosting tested endpoints. Results apply to a specified benchmark revision, workload, quality target and system configuration. AILuminate grades describe the fixed system under test and tested hazards; they are not universal safety certification for an underlying model. Public code, practice data, protected official tests, result publication and trademark use can have different access or licensing conditions. MLPerf Endpoints v0.7 remains an identifiable release even as later rules develop; newer metrics and submission rules must not be backported into that snapshot.
