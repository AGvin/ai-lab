# Documentation Requirements

## Requirements

- Identify Moonshot AI as the canonical producer organization for the documented Kimi model family.
- Preserve the Moonshot AI model-domain view as navigation without duplicating model-owned facts.
- Render the standard `entity-relations` block from the validated current-entity relation projection when rendering is separately requested.
- Keep Kimi model architecture, benchmarks, hosted-product access, pricing, quotas, and deployment guidance in their corresponding owners.
- Include the official Moonshot AI site, GitHub organization, and official Hugging Face organization as research references.

## Validation

- The producer page does not duplicate Kimi model profiles.
- The `produces` relation resolves to the canonical Kimi family endpoint.
- Mutable Kimi service/access state is not generalized into producer identity.
- Official resource links match canonical entity metadata.
