# Documentation Requirements

## Requirements

- Identify Mastra as the first-party organization/publishing identity behind the Mastra TypeScript framework.
- Keep producer identity distinct from the Mastra software framework and from separate hosted or commercial platform surfaces.
- Link the canonical Mastra agent-framework profile from the physically materialized `produces` relation when the reciprocal Mastra `produced-by` relation resolves successfully.
- Include the official Mastra site and first-party repository as identity and research references.
- Do not invent a legal-company suffix that is not established by the cited authoritative sources.

## Validation

- The page does not collapse the producer identity and Mastra software into one entity.
- The Mastra/Mastra framework `produces` / `produced-by` relation pair is physically present at both endpoints and semantically consistent.
- The Mastra framework link resolves to the canonical software node.
- Official resource links match canonical entity metadata.
