# Moonshot AI

Moonshot AI is the organization behind Kimi models and the Kimi product family. Kimi's published terms name Beijing Moonshot Technology Co., Ltd. and its affiliates as service providers, with product-specific agreements applying where stated.

## Producer boundary

Kimi web/mobile is a hosted assistant, Kimi Work is a local desktop agent, Kimi Code is a developer coding suite, and Kimi Claw includes a hosted OpenClaw deployment route. Their shared branding and model access do not make their execution location, permissions, data handling or subscription limits identical. Connecting an existing or locally deployed OpenClaw through Kimi does not turn that instance into Moonshot-operated cloud infrastructure. OpenClaw, third-party channels, community skills and external model hosts retain their own provenance and responsibilities. Model artifact licensing is separate from Kimi service terms; current account controls, connected-resource access and product-specific terms govern use of each route.
