# Maxime Beauchemin

Maxime Beauchemin is the original creator and producer who started Apache Airflow at Airbnb in October 2014. Airbnb's organizational context and current Apache Software Foundation governance remain distinct from that creator provenance.

## Producer boundary

Apache's project history establishes this origin and the later Apache incubation and top-level-project transition. Creator credit is not a claim of sole current maintenance, commercial support, or ownership of every Airflow deployment; those responsibilities follow the project, distributor, and operator involved.
