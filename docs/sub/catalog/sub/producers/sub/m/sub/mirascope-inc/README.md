# Mirascope, Inc.

Mirascope, Inc. is the organization publishing and developing the represented Mirascope open-source SDK and toolkit.

## Producer boundary

The official website terms identify Mirascope, Inc.; the current Cloud notice says Mirascope Cloud was discontinued while Python and TypeScript SDK development continues. Website terms, SDK licenses, third-party model APIs and external observability backends have different scopes; SDK provenance does not imply a currently available hosted Mirascope service.
