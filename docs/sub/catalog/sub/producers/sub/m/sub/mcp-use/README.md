# Manufact, Inc.

Manufact, Inc. is the company/team behind the open-source mcp-use framework and its TypeScript and Python SDKs. The company uses the former mcp-use publisher brand in its history; the SDK retains the mcp-use name.

## Producer boundary

The same team builds the open-source framework and operates Manufact Cloud. Hosted deployment, analytics, service terms, and commercial support are separate from the SDKs; external MCP servers, model providers, client applications, and the MCP specification retain their own ownership and operational responsibilities.
