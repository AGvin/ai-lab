# Manufact, Inc.

Manufact, Inc. is the company/team behind the open-source [mcp-use framework](../../../../../software/sub/application-frameworks/sub/application-development/sub/mcp-use/) and its TypeScript and Python SDKs. The company uses the former mcp-use publisher brand in its history; the SDK retains the mcp-use name.

## Scope

The same team also operates Manufact Cloud for MCP deployment, testing and analytics. Cloud service capabilities are separate from the installable open-source SDKs. External MCP servers, model providers and client applications remain independently owned products.
