# mcp-use

mcp-use is the publisher/team behind the open-source [mcp-use TypeScript application framework](../../../../../software/sub/application-frameworks/sub/application-development/sub/mcp-use/).

## Scope

The SDK, MCP Apps features, tooling and Inspector integration are part of this framework ecosystem. External MCP servers, models and deployment providers remain independently owned products.
