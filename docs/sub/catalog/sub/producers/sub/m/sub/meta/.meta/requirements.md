# Documentation Requirements

## Requirements

- Identify Meta as the canonical producer organization for the represented Llama model family.
- Keep Meta AI assistant/product surfaces distinct from Llama model identities.
- Include current first-party Meta sources sufficient to establish organization and Llama provenance.
- Render the standard `entity-relations` block from validated relation state.

## Validation

- The Llama `produced-by` relation has the matching `produces` inverse here.
- Product or model specifications are not duplicated into the producer profile.
