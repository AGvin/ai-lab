# Mem0

Mem0 is the producer identity behind the managed Mem0 Platform and the self-managed Mem0 Open Source memory software.

## Producer boundary

The official documentation separates Mem0-operated storage and infrastructure from software run on the customer's own infrastructure. Shared memory-engine provenance does not make data handling, hosted service terms, support, or model and vector-store dependencies identical across the two operating models.
