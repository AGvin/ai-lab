# Documentation Requirements

## Requirements

- Identify MCPJam Inc as the first-party publisher of the MCPJam Inspector testing/debugging software, not as the governing body of the MCP specification or official MCP Inspector.
- Attribute the open-source local Inspector, CLI and SDK to the published MCPJam project while preserving the separate hosted-service and Enterprise Edition subscription/licensing boundaries.
- Expose the validated `produces` relation to the single canonical Inspector product; do not split launchers, hosted modes or proprietary evaluation components into duplicate producers.

## Validation

- Official project README, repository license and product site identify MCPJam and its Inspector package.
- The `produces` endpoint has the exact software `produced-by` inverse.
