# MongoDB

MongoDB is the database and data-platform company, formerly 10gen, that publishes the official MongoDB Agent Skills collection. The company is distinct from MongoDB database software and the managed Atlas service.

## Producer boundary

The collection's first-party instructions are distributed through plugins and standalone skill installation. The Atlas plugin connects to MongoDB-hosted MCP using OAuth, while the self-managed plugin runs an MCP server for a user's own database deployment. Installing instruction files alone does not configure a live connection or grant database credentials. The collection's Apache 2.0 license does not establish the license, service terms, access permissions or support entitlement for every database, Atlas feature, connected coding agent or third-party tool it can use.
