# Mastra

Mastra is the first-party organization and publishing identity behind the Mastra TypeScript framework. The producer identity remains distinct from the Mastra software framework and from separate hosted or commercial platform surfaces.

## Producer boundary

The team's official account establishes the framework's provenance. Open-source framework access does not automatically include hosted infrastructure, commercial support, or third-party model access; each deployment and service contract must be assessed at its own scope.
