# Scale AI

Scale AI is the organization behind Scale Data Engine and the first-party SWE-bench Pro benchmark release. Scale’s product pages cover expert-supported data generation, curation and evaluation; its scaleapi repository and ScaleAI dataset distribution establish the benchmark publisher.

## Producer boundary

Data Engine is a commercial data service, while SWE-bench Pro has separately versioned public code, tasks and evaluation infrastructure. Scale’s statement following Meta’s 2025 investment describes continued independent operations and customer-data separation; the investment does not make Meta the producer of these catalog entries. Define permitted data access, expert processing, delivery and evaluation terms for service work, and pin the benchmark release and protocol when comparing results.
