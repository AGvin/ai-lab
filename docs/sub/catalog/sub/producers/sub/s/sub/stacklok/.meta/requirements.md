# Documentation Requirements

## Requirements

- Identify Stacklok as the first-party maintainer/publisher of its independently released software, without implying ownership of client agents, hosted model providers or third-party MCP servers published through it.
- Retain the official publisher website and maintained code repository as primary sources; external deployment integrations are not automatically another canonical vendor.
- Preserve exact reciprocal producer relations and distinguish product licenses and applicable managed enterprise editions.

- Render the identity, provenance and operational context recorded in canonical `entity.identity_note`; keep version-sensitive claims and official resources aligned with the cited first-party sources.

- Render the standard `entity-relations` block from validated current-entity relations, ordered by explicit numeric order, target canonical name and target ID; resolve every visible target to its reader.

## Validation

- All `produces` targets resolve and each software record points back with an exact `produced-by` relation.
- Vendor identity remains separate from the maintained software's primary operational purpose.
