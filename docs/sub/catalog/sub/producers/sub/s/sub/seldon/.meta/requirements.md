# Documentation Requirements

## Requirements

- Identify Seldon as the producer identity for the current Seldon Core 2 catalog entity.
- Keep commercial Seldon products distinct unless separately materialized as independent identities.
- Render the standard `entity-relations` block from validated current-entity relations.

- Render the identity, provenance and operational context recorded in canonical `entity.identity_note`; keep version-sensitive claims and official resources aligned with the cited first-party sources.

## Validation

- `produces` is the inverse of Seldon Core 2 `produced-by`.
