# Stripe

Stripe is the first-party publisher of the Stripe Agent Skills collection distributed through stripe/ai and its official agent tooling. The collection provides instructions for building with Stripe and is distinct from payment APIs, AI SDKs, remote MCP services and installed plugin bundles.

## Producer boundary

The repository’s MIT license governs its source; authenticated Stripe access and financial operations remain subject to account permissions and service terms. Installing skills does not itself authorize payments, refunds or production API access. Review the selected plugin or manual installation path and its update behavior, use appropriately scoped credentials, and separate test-mode work from live operations.
