# Seldon

Seldon is the original producer identity for Seldon Core 2. Its current website directs customers to TrueFoundry; TrueFoundry’s announcement states that it acquired Seldon’s business and customers. This business transition does not erase the Seldon provenance of the existing Core 2 software.

## Producer boundary

The inspected Core v2 license names Seldon Technologies Limited and uses Business Source License 1.1, with limited additional production permission and a per-version change to Apache 2.0 after four years. Do not infer unrestricted production rights from an “open source” marketing label. Confirm the exact version’s license and the current commercial support or migration agreement with TrueFoundry; its combined platform is a separate offering from the Core 2 code.
