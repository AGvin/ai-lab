# Shopify

Shopify is the first-party publisher of Shopify Agent Skills, a generated collection supporting development against its commerce ecosystem. The Shopify-owned repository says the skills are generated upstream and checked against the corresponding APIs; it does not accept direct contributions to the generated repository.

## Producer boundary

The collection contains agent instructions, documentation-search and validation scripts, and reference material. It remains separate from the hosted commerce platform, merchant stores, GraphQL APIs, Hydrogen, themes and third-party extensions. Review the selected skill and scripts before installation, match the target API version, and grant store credentials separately. Repository visibility and successful installation do not establish merchant access or a blanket redistribution license.
