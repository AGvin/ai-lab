# SkyPilot Team

SkyPilot Team is the producer and maintainer identity behind the SkyPilot open-source AI compute orchestration platform.

SkyPilot integrates with cloud providers, Kubernetes and Slurm projects, cluster operators, and model providers. Those integrations remain distinct from the SkyPilot Team identity.
