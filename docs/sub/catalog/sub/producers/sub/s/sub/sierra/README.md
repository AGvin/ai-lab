# Sierra

Sierra is the first-party publisher of the τ-bench benchmark family through sierra-research/tau2-bench and the official τ-bench site. Current upstream 2.0 extends the historical τ, τ² and τ³ work with multilingual evaluation and changed grading. Cited researchers and historical academic affiliations remain part of that provenance.

## Producer boundary

The benchmark evaluates customer-service agents, user interaction, tools and policy adherence; it is separate from Sierra’s commercial agent platform. Its simulated retail, airline, telecom and banking domains do not establish ownership of real services. Pin the task corpus, modality, user simulator, model configuration and grading protocol. The repository’s MIT code license does not cover separately billed model or voice-provider access, and results across corrected releases are not automatically comparable.
