# Supabase, Inc.

Supabase, Inc. is the represented Supabase producer organization for the official Supabase Agent Skills collection. Current Supabase terms explicitly identify Supabase, Inc. for AWS Marketplace purchases by default and Supabase Pte. Ltd. for other purchases, unless an order says otherwise; the brand is not a universal statement of contracting entity.

## Producer boundary

The MIT-licensed skill collection is separate from hosted Supabase services, individual skills and database credentials. Its instructions and scripts do not grant project access or make generated migrations safe automatically. Confirm the applicable order and data-processing terms, scope database and MCP permissions, and review schema changes before applying them. The current online legal sources replace the unavailable older DPA PDF as evidence of contracting arrangements.
