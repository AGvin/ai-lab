# Snyk

Snyk is the current publisher of Agent Scan through snyk/agent-scan. Its June 2025 announcement records the acquisition of Invariant Labs, preserving the earlier MCP security research origin while establishing the present first-party publishing organization.

## Producer boundary

Agent Scan’s Apache 2.0 CLI source is separate from the remote analysis service and enterprise security products. The maintained README describes scanning local agent configuration, MCP tools and skills and documents what discovery data is sent for analysis. Review the installed version, service terms, outbound data and server-contact approvals before scanning confidential environments. A security finding or successful scan is not a guarantee that every agent action is safe.
