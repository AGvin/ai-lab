# Snyk

Snyk publishes [Snyk Agent Scan](../../../../../software/sub/development-tools/sub/testing/sub/snyk-agent-scan/), a local scanning tool for agent configurations, MCP servers and skills.

## Provenance

Agent Scan continues tooling originated at Invariant Labs under the former MCP-Scan identity. Snyk's ownership of this product does not make it the producer of the external agents or MCP servers being tested.
