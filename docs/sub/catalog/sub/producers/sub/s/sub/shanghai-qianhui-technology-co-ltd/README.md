# Shanghai Qianhui Technology Co., Ltd.

Shanghai Qianhui Technology Co., Ltd. is the legal organization associated with Cherry Studio. The website currently uses the Cherry Intelligence brand; that brand and the GitHub namespace are not independent proof of a different legal company.

## Producer boundary

Keep the legal organization, CherryHQ publishing namespace and Cherry Studio software separate. The desktop Community Edition uses AGPL-3.0, with a separate commercial-license route; mobile, enterprise and hosted model offerings have their own conditions. Local conversation storage does not prevent data from reaching configured model or tool providers.
