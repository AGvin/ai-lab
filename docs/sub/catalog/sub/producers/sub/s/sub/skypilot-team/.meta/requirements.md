# Documentation Requirements

## Requirements

- Identify SkyPilot Team as the producer/maintainer identity for the SkyPilot open-source AI compute platform.
- Preserve only validated current producer relations; keep cloud providers, Kubernetes/Slurm projects, cluster operators, and model providers as integrations rather than SkyPilot-owned producers.
- Keep company/team history, commercial offerings, hosted deployment options, and partnership details freshness-sensitive.

## Validation

- SkyPilot Team remains distinct from infrastructure providers it orchestrates.
- Produced-product relations resolve to canonical SkyPilot software nodes.
