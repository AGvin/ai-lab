# SylphAI, Inc.

SylphAI, Inc. publishes and develops AdalFlow, the represented Python library for building and optimizing AI applications. Its maintained SylphAI-Inc repository, official documentation and MIT copyright identify the organization; AdalFlow remains a separate software identity.

## Producer boundary

AdalFlow’s MIT source license does not include model-provider services, credentials or rights to training and evaluation data. The framework’s agents, optimization and tracing features operate within the application’s chosen providers and tool permissions. Review data exposure in prompts and traces, API costs, output validation and tool execution for the actual application. Other SylphAI products are outside this software’s producer relation.
