# StackBlitz, Inc.

StackBlitz, Inc. operates the StackBlitz development environment and the Bolt application, as explicitly stated in its current privacy policy. Bolt is the represented hosted application-building service; the company, its development tools and customers’ generated applications remain separate identities.

## Producer boundary

The current policy covers prompts, code and attached files and explains processing by service providers for AI features. Customer applications can introduce additional data-processing responsibilities. Confirm the applicable Bolt plan, project visibility, publication destination, connected repositories and third-party integrations before deployment. A browser-based editor or WebContainer runtime does not mean every prompt or project remains on the local device.
