# Documentation Requirements

## Requirements

- Identify Stripe as the canonical producer organization for the represented Stripe Agent Skills collection.
- Keep payment APIs, Stripe AI SDKs, MCP service, plugins, and commerce protocols separate from the skill-collection identity unless independently materialized.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- The `produces` relation is the inverse of Stripe Agent Skills `produced-by`.
