# Documentation Requirements

## Requirements

- Identify Stanford NLP Group as the Stanford research group that develops DSPy and publishes the represented DSPy project through the `stanfordnlp` upstream.
- Keep the research-group identity distinct from the DSPy software entity and from Stanford University as a broader institution.
- Link the canonical DSPy software profile through the `produces` relation.
- Include the official Stanford NLP Group site and DSPy repository as provenance references.

## Validation

- The page does not collapse Stanford NLP Group, Stanford University, and DSPy into one entity.
- The DSPy link resolves to the canonical application-framework node.
- Official resource links match canonical entity metadata.
