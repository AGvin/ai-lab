# Stanford NLP Group

Stanford NLP Group is the Stanford research group that develops DSPy and publishes the represented project through the `stanfordnlp` upstream. It remains distinct from both DSPy software and Stanford University as the broader institution.

## Produces

- [DSPy](../../../../../software/sub/application-frameworks/sub/programming-and-optimization/sub/dspy/) — programming and optimization framework for language-model applications.
