# Supermemory

Supermemory is the producer and operator identity for the represented managed memory and context service. Its current site describes memory for agents through an API, plugins and MCP; its service terms describe cloud infrastructure for storage, retrieval and management.

## Producer boundary

The managed service stores and processes uploaded content and data from explicitly connected services. Confirm retention and deletion, tenant separation, geographic processing, credentials and contractual requirements before sending private context. SDKs, plugins and client integrations are distinct from the hosted backend and from model providers. The public terms use the Supermemory name without establishing a more specific corporate form, so this profile does not invent one.
