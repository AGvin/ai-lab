# SideGuide Technologies, Inc.

SideGuide Technologies, Inc. is the Delaware corporation doing business as Firecrawl, explicitly named in Firecrawl’s October 7, 2026 service agreement. It is the operating organization for the represented Firecrawl web-data service.

## Producer boundary

Firecrawl’s hosted API converts web content into data for applications. The service agreement, account credentials, permitted-use rules and third-party content rights govern hosted use. An API capability does not grant permission to collect every source website’s content, and hosted subscriptions are separate from any source-code distribution or self-hosted deployment. Determine which URLs and data may be processed and who controls retention before connecting production workflows.
