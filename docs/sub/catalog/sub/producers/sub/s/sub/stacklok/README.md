# Stacklok

Stacklok is the organization behind the [ToolHive](../../../../../software/sub/ai-management-platforms/sub/toolhive/) open-source runtime and MCP server management platform.

## Publisher boundary

Stacklok produces the released ToolHive core and offers separately licensed enterprise capabilities. Third-party MCP servers, integrations and skills installed through ToolHive are not owned by Stacklok merely because ToolHive manages their runtime.
