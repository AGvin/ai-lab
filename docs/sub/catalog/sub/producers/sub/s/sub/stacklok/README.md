# Stacklok

Stacklok is the first-party publisher and maintainer of ToolHive through the stacklok upstream. ToolHive is a separately released MCP platform; the organization is distinct from client agents, model providers and the third-party MCP servers it runs.

## Producer boundary

ToolHive’s Apache 2.0 source can be deployed on operator-controlled infrastructure. Container isolation and configurable identity policies depend on the selected deployment and configuration; they do not make every server or exposed tool trustworthy. Review server provenance, image permissions, authentication, network access and secrets. Managed or enterprise offerings and each connected service may have additional agreements beyond the ToolHive source license.
