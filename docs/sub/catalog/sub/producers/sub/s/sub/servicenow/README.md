# ServiceNow

ServiceNow publishes the represented AI Control Tower product and the WebArena-Verified and WorkArena benchmark releases. It also publishes BrowserGym as a browser-environment framework and AgentLab as experiment and analysis software. These are distinct product, benchmark, environment and evaluation roles within the ServiceNow research ecosystem.

## Producer boundary

The current product page markets the control-tower offering as Super Intelligence Control Tower; the catalog retains its established AI Control Tower identity. Enterprise product entitlements do not follow from access to research repositories. WebArena-Verified refines the original WebArena benchmark rather than claiming its original authorship, and WorkArena instance access has a separate approval process. Pin tasks, evaluators, environments and agent versions, and use isolated test accounts for browser agents.
