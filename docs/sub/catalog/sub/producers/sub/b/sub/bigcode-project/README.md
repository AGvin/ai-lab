# BigCode Project

[BigCode](https://www.bigcode-project.org/) is an open scientific collaboration focused on responsible development and use of large language models for code. It was announced in September 2022 and is **jointly led by Hugging Face and ServiceNow**, with open research working groups and a shared steering committee. The collaboration should not be mistaken for a separately incorporated company or one of its corporate sponsors.

## Research and governance

BigCode's mission includes code-focused language models, benchmark design, data preparation, efficient training/inference and responsible sourcing of code. The collaboration has published work associated with StarCoder, The Stack, code-evaluation datasets and developer rights, but individual trained models, training corpora, benchmarks and software repositories retain their own identities, licenses and version history.

The [governance description](https://www.bigcode-project.org/docs/about/organization/) places technical decisions in research groups and a jointly led steering committee. Participation and sponsorship do not imply sole authorship of all downstream work.

## Source and rights boundaries

Open collaboration does not imply that every input source or model weight is unrestricted. BigCode's [IP guidance](https://www.bigcode-project.org/docs/about/ip/) distinguishes code contributions, model artifacts and data with differing legal/ethical requirements. Review dataset licenses, training-data provenance, PII handling and generated-code attribution before reuse or distribution. Evaluation results require a pinned model, test dataset and execution configuration.

No model, dataset, training job, legal assessment or benchmark was executed or certified for this profile.
