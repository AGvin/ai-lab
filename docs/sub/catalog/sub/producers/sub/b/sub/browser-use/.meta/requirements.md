# Documentation Requirements

## Requirements

- Identify Browser Use as the first-party organization/brand behind Browser Use Cloud and the maintained `browser-use/browser-use` source project.
- Distinguish the Browser Use Cloud managed browser-agent session/task service from the open-source Browser Use browser-automation agent framework, third-party MCP clients and externally hosted browser backends; these may be related but do not share a single delivery identity.
- Maintain official first-party site, source repository and product API documentation, with changing pricing and hosted task/model versions assigned to the owned service identity rather than static producer facts.
- Avoid inventing a specific incorporated legal entity or identifying all browser-agent models and related libraries as Browser Use products without evidence.

## Validation

- `produces` reciprocates the `catalog/services/infrastructure/browser-use-cloud` `produced-by` relation.
- Organizational provenance remains distinct from products/services integrated by Browser Use.
