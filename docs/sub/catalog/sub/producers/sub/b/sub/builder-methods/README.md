# Builder Methods

Builder Methods publishes Agent OS, the project for giving coding agents a shared set of development standards and product context.

The publisher, the Agent OS software, and the coding agents or model providers that use its files are distinct. Agent OS publishing does not imply ownership of every downstream agent or application.
