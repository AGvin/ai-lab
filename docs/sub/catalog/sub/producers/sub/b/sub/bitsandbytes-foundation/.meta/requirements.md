# Documentation Requirements

## Requirements

- Identify bitsandbytes Foundation as the current upstream maintenance organization for the independently released bitsandbytes library.
- Preserve the original creator/authorship of the LLM.int8, QLoRA and k-bit-optimizer research separately from present project stewardship; do not misattribute every original paper to the current GitHub organization.
- Separate project software maintenance from cloud API providers, generated model checkpoints, and vendor-specific hardware support.

## Validation

- `produces` inverts the canonical bitsandbytes `produced-by` relation.
- The project organization is not misrepresented as a managed model-hosting service.
