# Documentation Requirements

## Requirements

- Identify Bright Data as the producer of the first-party Bright Data hosted web-data product, distinct from its API consumers, data sources, open-source libraries and unrelated products in the same market.
- Preserve the vendor official product and maintained documentation URLs as sources for changing delivery capabilities.
- Render the canonical producer relation and avoid additional product/service identity merely due to multiple interface modes.

## Validation

- The producer `produces` endpoint exactly reciprocates the corresponding service `produced-by` link.
- First-party product operator identity is verifiable at the documented official site.
