# Bright Data

Bright Data is the organization behind its hosted web-data platform and documented data-access interfaces.

The producer and service remain distinct from customer workflows, source websites, external models, and browser libraries. Multiple API and browser interfaces do not create separate producer identities or transfer ownership of the returned source material.
