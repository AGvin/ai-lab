# Benn Huang

Benn Huang, represented in the upstream metadata as bennhuang and by the Bin-Huang profile, is the original creator associated with Chatbox.

Original authorship is separate from the current Chatbox AI service operation by Mediocre, LLC and from community contributions. The Chatbox client and the optional paid model-access service are also separate delivery concerns.
