# Browser Use

Browser Use is the first-party organization/brand behind the [Browser Use Python framework](../../../../../software/sub/agent-frameworks/sub/browser-use/) and separately operated [Browser Use Cloud](../../../../../services/sub/infrastructure/sub/browser-use-cloud/) service.

## Ownership boundaries

The open-source agent/browser library and provider-run Cloud API have different deployment and billing identities. Provider integrations, third-party MCP clients, external browser backends and model services are not all Browser Use-owned products. The available sources do not establish an independent incorporated legal-entity name.
