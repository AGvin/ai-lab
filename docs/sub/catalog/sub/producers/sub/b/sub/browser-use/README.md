# Browser Use

Browser Use is the publishing organization behind the Browser Use open-source framework and the operator of Browser Use Cloud.

The installable framework and managed cloud service retain separate catalog identities. External browser backends, model providers, third-party MCP clients, and the websites operated by an agent remain separate parties.
