# Browserless

Browserless is the platform publishing and operating identity behind the Browserless browser infrastructure service.

Managed browser-as-a-service and documented self-managed Docker or enterprise deployments are different delivery modes of the product family. Browserless remains distinct from Browserbase, Browser Use, cloud platforms, and browser automation libraries; its brand alone does not establish an incorporated legal name.
