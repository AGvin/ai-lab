# Browserbase, Inc.

Browserbase, Inc. is the organization named in Browserbase’s terms and the operator of the Browserbase browser infrastructure service and producer of the separately published Stagehand browser-agent SDK.

The organization, managed browser infrastructure, customer agents, and upstream browser or model projects remain distinct. Browserbase is also separate from Browser Use and Browserless, which have their own producer and product identities.

## Relations

- Produces: [Browserbase](../../../../../services/sub/infrastructure/sub/browserbase/) — managed browser infrastructure.
- Produces: [Stagehand](../../../../../software/sub/agent-frameworks/sub/stagehand/) — open-source browser-agent SDK, not an extra managed service.
