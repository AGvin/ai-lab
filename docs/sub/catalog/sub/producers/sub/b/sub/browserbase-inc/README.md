# Browserbase, Inc.

Browserbase, Inc. is the organization named in Browserbase’s terms and the operator of the Browserbase browser infrastructure service.

The organization, managed browser infrastructure, customer agents, and upstream browser or model projects remain distinct. Browserbase is also separate from Browser Use and Browserless, which have their own producer and product identities.
