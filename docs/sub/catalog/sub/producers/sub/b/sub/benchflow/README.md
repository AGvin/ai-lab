# BenchFlow

**BenchFlow** is the original open-source publishing project behind [SkillsBench](../../../../../datasets/sub/skillsbench/), an agent-skill benchmark distributed from its [GitHub organization](https://github.com/benchflow-ai) and [Hugging Face publisher account](https://huggingface.co/benchflow). Its separate [BenchFlow SDK/CLI](../../../../../software/sub/evaluation-and-observability/sub/evaluation-frameworks/sub/benchflow/) executes and scores task environments; it is **not** the SkillsBench dataset itself.

The publisher identity here is an open-source organization/account, **not an independently verified incorporated company**. Public repository attribution does not establish complete beneficial ownership or third-party IP rights in contributed benchmark material.

## Dataset and operational scope

The published SkillsBench v1.1 snapshot pins 87 active native `task.md` tasks; its reported skills-assisted improvements depend on exact skill-mode, agent/harness, trial and verifier configuration. The February 2026 paper used a different 86-task snapshot, and later mainline 1.2 documentation does not establish the availability of a correspondingly tagged new public benchmark release.

Both the [original repository](https://github.com/benchflow-ai/skillsbench/blob/main/LICENSE) and [publisher's dataset metadata](https://huggingface.co/datasets/benchflow/skillsbench) declare Apache-2.0, but third-party artifacts require independent rights checks. Treat task oracle/verifier scripts and arbitrary content as untrusted; isolate sandbox execution and protect credentials. No physical/runtime benchmark execution, complete rights/ownership review or global catalog build was performed.
