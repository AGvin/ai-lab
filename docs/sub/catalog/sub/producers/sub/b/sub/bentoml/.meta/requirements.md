# Documentation Requirements

## Requirements

- Identify BentoML as the first-party organization/publishing identity behind the BentoML software platform.
- Keep producer identity distinct from BentoML software and from separately operated hosted delivery such as BentoCloud.
- Render the standard `entity-relations` block from validated current-entity relations.
- Include the official BentoML site and first-party repository as identity/research references.
- Do not invent a legal-company suffix not established by cited authoritative sources.

## Validation

- The page does not collapse producer, self-managed software, and hosted-service identities.
- The `entity-relations` block matches validated current-entity relations and the produced software destination resolves.
- Official resource links match canonical entity metadata.
