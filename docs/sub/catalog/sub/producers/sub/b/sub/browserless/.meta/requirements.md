# Documentation Requirements

## Requirements

- Identify Browserless as the first-party platform team/brand operating `browserless.io` cloud browser infrastructure and distributing documented self-hosted implementations; do not infer a separate corporate registration name solely from its brand.
- Keep hosted Browserless infrastructure and the self-managed Docker/enterprise deployment options as modes of one primary product family; do not conflate it with Browserbase, Browser Use, Cloudflare or browser libraries.
- Retain the official service website and documentation as source-of-truth references for current plan, deployment and browser-agent lifecycle.
- Render the standard validated relation block and the exact `produces` target.

## Validation

- First-party documentation confirms managed BaaS and alternate deployments.
- The service `produced-by` inverse points to this same canonical producer.
