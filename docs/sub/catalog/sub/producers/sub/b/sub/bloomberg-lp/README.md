# Bloomberg L.P.

Bloomberg L.P. is one of the organizations that initiated the open collaboration that became Envoy AI Gateway. Its origin role remains joint with Tetrate and does not imply sole ownership or sole current maintenance of the multi-organization project.

## Produces

- [Envoy AI Gateway](../../../../../software/sub/gateways/sub/api-management-gateways/sub/envoy-ai-gateway/) — open-source AI gateway project with joint Bloomberg and Tetrate origin.
