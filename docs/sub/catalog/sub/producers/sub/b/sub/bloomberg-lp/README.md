# Bloomberg L.P.

Bloomberg L.P. and Tetrate initiated the collaboration that became Envoy AI Gateway, now named Agent Router.

The project adopted the Agent Router name and joined the Agentic AI Foundation on September 10, 2026. Bloomberg’s producer relation preserves joint historical origin; it does not claim sole ownership or current maintenance of the foundation-hosted project.
