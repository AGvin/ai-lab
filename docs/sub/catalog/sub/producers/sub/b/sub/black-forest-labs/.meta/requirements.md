# Documentation Requirements

## Requirements

- Identify Black Forest Labs as the canonical producer organization for the documented FLUX model family.
- Link the canonical FLUX family from the physically materialized `produces` relation and preserve the broader Black Forest Labs model-domain view as navigation.
- Keep model facts, API offerings, runtime integrations, and deployment guidance in their corresponding owners.
- Include the official site and official Hugging Face organization as research references.

## Validation

- The Black Forest Labs/FLUX `produces` / `produced-by` relation pair is physically present at both endpoints and semantically consistent.
- The producer page does not duplicate FLUX model profiles.
- Third-party access paths are not generalized into producer identity.
- Official resource links match canonical entity metadata.
