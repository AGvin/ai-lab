# Documentation Requirements

## Requirements

- Identify BigCode Project as an **open scientific collaboration**, led by Hugging Face and ServiceNow with technical governance shared among community working groups. Do not invent a legal incorporation, solely assign ownership to one corporate sponsor, or equate community-supported work with a commercial API provider.
- Ground its original scope in [BigCode mission](https://www.bigcode-project.org/docs/about/mission/) and [organizational governance](https://www.bigcode-project.org/docs/about/organization/). The governance materials date the project's public announcement to September 2022; StarCoder, The Stack and other downstream releases have their own versions and rights.
- Explain research areas: code large language models, evaluation suites, training and inference methods, data transparency, developer attribution, source provenance and responsible governance. A project collaboration is not the same identity as every model, benchmark or contributor.
- Follow the [official IP guidance](https://www.bigcode-project.org/docs/about/ip/): BigCode seeks permissive/open releases when rights allow, but licenses vary by models, datasets, upstream source code and contribution type. Do not make an all-project Apache-2.0 or unrestricted dataset rights assertion.
- Do not claim that permissively available public source code permits unrestricted inclusion in training datasets; inspect dataset/source licenses, provenance, opt-out/attribution terms, PII and potentially generated code before reuse.
- Keep Hugging Face and ServiceNow as factual co-leads, not automatically mirrored or newly counted producer identities. Add no model/dataset reciprocal relations without confirming specific existing canonical targets and original authorship.
- Cite official collaboration sources rather than stale secondary rankings, unsupported corporate/funding claims or software benchmarks. Avoid claiming live model execution or complete technical/legal audit.

## Validation

- The Producers B directory indexes one BigCode Project reader, and first-party mission/organization/IP sources support scoped metadata.
- No large-model training, benchmark execution, comprehensive code/data rights audit, full repository CI or whole-catalog clean pass is claimed.
