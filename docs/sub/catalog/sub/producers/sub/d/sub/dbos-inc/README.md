# DBOS, Inc.

DBOS, Inc. is the company behind the DBOS open-source durable-execution software family. The company identity remains distinct from the self-managed DBOS libraries and from DBOS Cloud or other hosted service surfaces.

## Produces

- [DBOS](../../../../../software/sub/workflow-engines/sub/application-orchestration/sub/dbos/) — open-source durable-execution library family.
