# Documentation Requirements

## Requirements

- Identify Dome Systems as the producer identity for Dome Agent Operations Platform.
- Keep the organization profile distinct from the platform's Registry, Gateway, Broker, controls, resource types, and integrations.
- Render the standard `entity-relations` block from validated current-entity relations.
- Explain that Dome supplies agent operations controls while customers retain their own agents, tools, models, and data; do not attribute those assets to the platform producer.
- Include the official operating-model source alongside the company identity reference.

## Validation

- `produces` is the inverse of Dome Agent Operations Platform `produced-by`.
