# Dapr Project

**Dapr Project** is the open-source contributor community behind the [Dapr Agents framework](https://github.com/dapr/dapr-agents). The first-party [Dapr Community](https://github.com/dapr/community) repository documents project stewardship, and the [original tagged package metadata](https://github.com/dapr/dapr-agents/blob/v1.1.0/pyproject.toml) credits **Dapr Authors**.

## Publisher and legal boundary

A project community is not synonymous with an historical sponsor, the CNCF foundation, a commercial Dapr service provider, or a documented exclusive legal owner. The sources do not independently establish all beneficial owners, sanctions clearance, data-processing arrangements or production security certification. The separate [Dapr runtime](https://github.com/dapr/dapr) underlies Agents but is not a second framework identity accepted by this package.
