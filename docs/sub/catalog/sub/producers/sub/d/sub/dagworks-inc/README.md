# DAGWorks, Inc.

DAGWorks, Inc. is the origin company behind Burr before the project entered the Apache Software Foundation incubation process. That origin provenance remains distinct from current Apache governance, branding, and source stewardship.

## Produces

- [Apache Burr](../../../../../software/sub/workflow-engines/sub/application-orchestration/sub/apache-burr/) — state-machine application-orchestration framework originally developed under DAGWorks.
