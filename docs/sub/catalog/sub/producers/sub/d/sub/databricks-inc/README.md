# Databricks, Inc.

Databricks, Inc. created MLflow and operates Databricks Model Serving. That origin provenance remains distinct from MLflow's current Linux Foundation open governance and from Databricks-managed MLflow offerings.

## Produces

- [Databricks Model Serving](../../../../../services/sub/infrastructure/sub/databricks-model-serving/) — managed model-serving service.
- [MLflow](../../../../../software/sub/model-and-data-platforms/sub/lifecycle-platforms/sub/mlflow/) — open-source AI engineering and lifecycle platform created by Databricks.
