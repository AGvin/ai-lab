# Documentation Requirements

## Requirements

- Identify DigitalOcean as the cloud and AI platform provider, with DigitalOcean, LLC as the only direct party to the vendor's July 20, 2026 published general Terms of Service. The terms encompass parents and affiliates in the defined name without making them additional TOS parties; do not invent an ownership chain, infer a parent-company guarantee, or create another producer identity.
- Preserve two independently documented hosted offerings: DigitalOcean Inference for model API, serverless/dedicated serving, model-catalog and router workflows; DigitalOcean Evaluations for dataset-based and simulated assessment of models, routers and supported agents. Do not mistake either service for a separately trained model, customer self-managed runtime, or blanket transfer of third-party model rights.
- Use exactly two reciprocal `produces` / `produced-by` relations to the canonical service entities. Do not create separate producer identities for one service's feature variants.
- Distinguish mutable service state: available models/providers, usage prices, API features, geographic availability, quota, data residency, log and prompt retention, and provider-specific terms must be checked at the point of use. Vendor API access does not by itself establish original training-model authorship or downstream processing terms.
- Ground claims in official DigitalOcean company, current TOS, Inference and Evaluations documentation. Do not imply that use of model APIs grants permission to copy weights, private evaluation datasets, provider responses, or protected prompts.

## Validation

- Reciprocal producer-to-service relations resolve both ways and the Producers D directory index lists this identity exactly once.
- The general TOS contracting party is cited accurately, while separately negotiated contracts and additional service-specific terms are not overridden by this summary.
- No authenticated cloud account checks, API calls, model inference, legal audit, provider rights audit, full repository CI, or whole-catalog clean pass are claimed.
