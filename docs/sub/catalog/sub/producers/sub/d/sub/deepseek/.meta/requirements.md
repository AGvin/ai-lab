# Documentation Requirements

## Requirements

- Identify DeepSeek as the canonical producer organization for the documented DeepSeek models.
- Preserve the DeepSeek model-domain view as navigation without duplicating model-owned facts.
- Render the standard `entity-relations` block from the validated current-entity relation projection.
- Keep model facts, API offerings, pricing, rate limits, and deployment guidance in their corresponding owners.
- Include official site, API documentation, and official Hugging Face organization as research references.

## Validation

- The producer page does not duplicate DeepSeek-V4 or concrete model profiles.
- The `entity-relations` block matches the validated current-entity relation projection and every rendered destination resolves to a canonical node.
- Model-domain navigation resolves to its canonical catalog node.
- Mutable API state is not generalized into producer identity.
- Official resource links match canonical entity metadata.
