# Documentation Requirements

## Requirements

- Identify Databricks, Inc. as the organization that created MLflow.
- Keep Databricks origin provenance distinct from current Linux Foundation open governance and from Databricks-managed MLflow offerings.
- Render the standard `entity-relations` block from the validated current-entity relation projection.
- Include current first-party Databricks and MLflow provenance references.

## Validation

- Databricks is represented as MLflow's origin producer rather than as the sole current open-source maintainer or governance body.
- Managed MLflow services are not conflated with the open-source MLflow software entity.
- The `entity-relations` block matches the validated current-entity relation projection and every rendered destination resolves to a canonical node.
