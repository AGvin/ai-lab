# Docker

Docker publishes Docker Skills, a collection of agent guidance for Docker workflows.

## Producer boundary

The collection supplies instructions and knowledge. Docker Engine, hosted services, independently authored dependencies, and the agent executing those instructions have separate product and operating boundaries.
