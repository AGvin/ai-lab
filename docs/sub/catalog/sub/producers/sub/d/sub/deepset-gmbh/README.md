# deepset GmbH

deepset GmbH is the organization behind the development of the Haystack open-source framework. The company remains distinct from open-source Haystack and from deepset-operated commercial or enterprise product surfaces.

## Produces

- [Haystack](../../../../../software/sub/application-frameworks/sub/data-and-retrieval/sub/haystack/) — open-source AI application and retrieval framework.
