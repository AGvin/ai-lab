# DigitalOcean

DigitalOcean is a cloud infrastructure provider whose product portfolio includes hosted model inference and managed evaluation workflows. Its [published Terms of Service](https://www.digitalocean.com/legal/terms-of-service-agreement), last updated July 20, 2026, define DigitalOcean, LLC as the only direct party to that general agreement; other agreements and service-specific provisions can still apply.

## AI service boundaries

**DigitalOcean Inference** provides a provider-operated model catalog and API serving layer. It includes serverless inference, dedicated inference deployments and model-routing workflows, including original models from outside DigitalOcean. Accessing a third-party model through DigitalOcean does not make DigitalOcean the model's original developer or license holder.

**DigitalOcean Evaluations** separately provides managed dataset assessments and simulations for models, Inference Router configurations and supported agents. It helps compare tested configurations but does not replace reviewing results, deploying an independently hosted evaluator, or running inference as a model API.

API costs, supported upstream providers, inference limits, locations, evaluation metrics, data processing and retention may change. Verify the current model/provider and plan-specific terms and keep credentials and private prompts or evaluation results out of public repositories and logs. This entry does not establish a complete corporate ownership chain or a legal or model-rights certification.
