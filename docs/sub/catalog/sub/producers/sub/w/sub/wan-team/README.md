# Wan Team

Wan Team is Alibaba Cloud's team for the Wan generative-model family. Its official organization publishes model materials and the Wan Agent Skills collection; the team remains a distinct organizational part of Alibaba Cloud.

## Producer and operating boundary

Model checkpoints, hosted Model Studio access and agent skills have different release, licensing and data-transfer boundaries. Some skills call remote APIs and upload local inputs. Model or service availability must be checked for the exact version and region rather than generalized across every Wan generation.
