# WorkOS

WorkOS is the organization operating WorkOS Agent Auth within AuthKit. Its September 2026 release announcement identifies Agent Auth as early access, with first-class agent identities and reusable blueprints; the current guides do not establish a later general-availability transition.

## Producer and operating boundary

Agent identities, delegated sessions and short-lived scoped credentials are access-control mechanisms. Actual authority depends on the configured blueprint, grant and target service. Generic user authentication, machine-to-machine applications, Fine-Grained Authorization and WorkOS Connect remain separate product or capability boundaries.
