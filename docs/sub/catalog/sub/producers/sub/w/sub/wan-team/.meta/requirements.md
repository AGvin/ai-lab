# Documentation Requirements

## Requirements

- Identify Wan Team as the Alibaba Cloud model team behind the Wan large-scale generative-model family.
- Preserve the validated organizational relation to Alibaba Cloud without inventing a stronger ownership/legal relation than first-party sources establish.
- Keep concrete model versions, hosted Model Studio serving, creative tools, pricing, and deployment details with their model/service owners rather than duplicating them in the producer profile.
- Preserve the team's official Wan site and GitHub organization as identity/provenance evidence.
- Render the standard entity-relations block from validated current relations.

## Validation

- Wan Team remains distinct from Alibaba Cloud as the broader organization and from Alibaba Cloud Model Studio as a service.
- Every produced-model relation resolves to a canonical model node.
- Model capability details are not duplicated into the producer profile.
