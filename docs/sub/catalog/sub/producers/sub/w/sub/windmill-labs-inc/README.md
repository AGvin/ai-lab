# Windmill Labs, Inc.

Windmill Labs, Inc. is the company behind the Windmill developer automation platform and its hosted service. The current service terms separately address hosted access; self-managed software and distributed releases have their own licensing conditions.

## Producer and operating boundary

The source tree and prebuilt Community Edition binaries are not interchangeable licensing units: distributed binaries include proprietary components in addition to open-source portions. Deployment also gives workers access to scripts, secrets and connected systems, so operating permissions and selected distribution terms matter independently of company identity.
