# Weaviate

Weaviate is the producer organization behind Weaviate Database and Weaviate Cloud. First-party deployment documentation separates self-managed database installations from the managed cloud service.

## Producer and operating boundary

Database releases and selected components determine software capabilities and licensing, while cloud plans determine managed operations. Vectorizer and generative-model integrations can add external processing and credentials. Review the complete deployment and data path instead of assigning every cloud or model-provider property to the database itself.
