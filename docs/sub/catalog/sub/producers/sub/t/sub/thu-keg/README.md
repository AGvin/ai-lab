# THU-KEG

**THU-KEG** is the Knowledge Engineering Group's research publishing identity at Tsinghua University. Its current public [GitHub](https://github.com/THU-KEG) and [Hugging Face](https://huggingface.co/THU-KEG) organization profiles are the publisher sources for the original AgentIF benchmark and dataset.

This entry represents an academic research **group**, not a separately verified legal company. It is not the entire Tsinghua University and should not be silently identified with the distinct THUDM account. Publication and repository hosting do not establish complete downstream intellectual-property, commercial licensing, beneficial-ownership, or sanctions status.

## Scope and operational boundaries

AgentIF is a human-annotated agentic instruction-following dataset distinct from its model judge, evaluation code and any leaderboard scores. The GitHub dataset-specific license (CC BY 4.0) conflicts with the Hugging Face mirror metadata (CC BY-NC 4.0), so users must confirm rights for the exact distribution and intended reuse. Different 2025/2026 scoring regimes must not be compared without normalization; running code-based checkers requires isolation and credential safeguards.
