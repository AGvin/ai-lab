# Tenstorrent

Tenstorrent produces the represented Galaxy Blackhole system and Wormhole n150/n300 accelerator-card family. The company also publishes hardware documentation and software for its platforms; individual cards, systems and software releases remain distinct products.

## Operating boundary

Select the exact hardware variant and matching software stack. Wormhole installation requirements distinguish chassis clearance, airflow, power and board variants, so one card's installation or performance claims cannot be generalized to Galaxy systems or Blackhole-generation hardware. Verify current ordering availability and supported workloads with Tenstorrent; a product documentation page is not a stock or shipment guarantee.
