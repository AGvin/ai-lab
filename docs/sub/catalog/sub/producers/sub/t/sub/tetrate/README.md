# Tetrate

Tetrate and Bloomberg jointly initiated the collaboration that became Envoy AI Gateway, now named Agent Router. The project's September 2026 transition to the Agentic AI Foundation preserves that historical origin without making either company its sole owner, maintainer or operator.

## Operating boundary

Use the current Agent Router project and documentation to assess releases and deployment support. The rename preserves existing API groups, CRDs, CLI and deployment namespaces, so a current product name does not authorize renaming installed interfaces. Tetrate's commercial offerings and contractual support remain separate from the shared open-source project's origin and foundation stewardship.
