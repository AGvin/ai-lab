# THUDM

THUDM is the Tsinghua University research publishing identity represented here for AgentBench. Its first-party organization and benchmark sources distinguish academic contributors and project stewardship from the models and tools evaluated by the benchmark.

## Operating boundary

Pin the benchmark and harness revision when reproducing results. The original AgentBench and later AgentBench FC use different task packaging; the current FC repository depends on AgentRL and containerized environments. Isolate those execution environments and treat evaluated models, Docker, Redis and other dependencies as separate identities. A benchmark score is evidence for its versioned protocol, not a universal model-quality guarantee.
