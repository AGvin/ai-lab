# Tongyi-MAI

Tongyi-MAI is the official publishing identity for the represented Z-Image project and model repositories on GitHub and Hugging Face. The catalog keeps that publishing identity separate from the model-domain navigation view and does not infer an unsupported corporate-parent relation from the name.

## Operating boundary

Use the exact checkpoint card for license and training-state decisions. Z-Image base and Z-Image-Turbo are separately released models; hosted demos, inference providers and optimized runtime conversions are separate access or implementation surfaces. Shared branding does not establish identical licensing or readiness for every announced family variant, and publisher performance claims require workload-specific evaluation.
