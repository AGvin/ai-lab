# Documentation Requirements

## Requirements

- Identify TensorFlow Project as the current open-source project identity responsible for the TensorFlow framework.
- Preserve the historical fact that TensorFlow originated inside Google Brain separately from current project identity; do not infer a stronger current legal ownership relation than first-party governance material supports.
- Keep TensorFlow ecosystem libraries, Keras, TensorFlow Lite/LiteRT, TensorFlow.js, TF Serving, and downstream products separate when they have independently useful identities.

## Validation

- TensorFlow Project remains distinct from Google as an organization and from the TensorFlow software framework.
- Producer relation resolves to the canonical TensorFlow software node.
