# Documentation Requirements

## Requirements

- Identify Tongyi-MAI as the official publishing identity for the represented Z-Image repositories.
- Preserve the Tongyi-MAI model-domain view as navigation without duplicating model-owned facts.
- Preserve only relationships supported by current authoritative sources; do not infer an Alibaba or other corporate parent relation from legacy placement or naming.
- Render the standard `entity-relations` block from the validated current-entity relation projection.
- Include the official GitHub and Hugging Face organizations as identification and research references.

## Validation

- The producer page does not duplicate Z-Image model facts.
- The `entity-relations` block matches the validated current-entity relation projection and every rendered destination resolves to a canonical node.
- Model-domain navigation resolves to its canonical catalog node.
- Unverified corporate ownership is not encoded as a canonical relation.
