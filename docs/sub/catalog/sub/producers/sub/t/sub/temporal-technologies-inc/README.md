# Temporal Technologies Inc.

Temporal Technologies Inc. is the company behind the Temporal open-source durable-execution platform. Its founders' work on Cadence is historical provenance; Temporal, Cadence and the Temporal Cloud hosted service retain separate identities.

## Operating boundary

Choose explicitly between operating the open-source Temporal Service and purchasing Temporal Cloud. Self-hosting requires deployment and long-term operational ownership; the Cloud terms define access, fees and support through the applicable service agreement and order. A local development server or evaluation account does not establish production readiness or the same support commitments.
