# TensorFlow Project

TensorFlow Project is the open-source project identity responsible for the represented TensorFlow framework. The upstream README records its origin with researchers and engineers at Google Brain; that history does not turn the project profile into Google's corporate identity.

## Operating boundary

Evaluate the selected TensorFlow release and installation path, including supported language APIs, operating system and accelerator dependencies. Stable releases and nightly packages have different stability expectations. Keras, LiteRT, TensorFlow.js, TensorFlow Serving, TFX and hosted products retain their own release and support boundaries; core framework provenance does not guarantee compatibility across that ecosystem.
