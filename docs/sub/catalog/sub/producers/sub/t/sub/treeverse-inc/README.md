# Treeverse, Inc.

Treeverse, Inc. is the legal company behind lakeFS and the current owner and maintainer/steward of DVC following lakeFS's November 2025 acquisition of the open-source DVC project from Iterative.ai.

DVC remains a separate open-source project and brand rather than the same product as lakeFS. Current Treeverse stewardship is also distinct from Dmitry Petrov's creator provenance.
