# Topoteretes

Topoteretes is the upstream GitHub organization publishing the represented Cognee repository. This is a source-backed publishing identity; the repository handle alone does not establish a differently named legal company or ownership of every Cognee integration and dependency.

## Operating boundary

Distinguish the open-source installation from Cognee Cloud and the configured model providers. The current upstream README supports local extraction and embedding without an LLM key, but enabling a hosted model provider introduces provider calls. For shared deployments, review authentication, persistent storage and file-ingestion permissions; a local demonstration configuration does not establish a safe multi-user operating posture.
