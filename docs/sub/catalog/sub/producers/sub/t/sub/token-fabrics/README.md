# Token Fabrics

Token Fabrics is the organization represented as operating the hosted Big-AGI product surface. The upstream project credits Enrico Ros and Token Fabrics, while the catalog preserves Enrico Ros's original producer role separately from Token Fabrics' operating role.

## Operating boundary

Distinguish self-hosted Big-AGI Open from the hosted Free and Pro tiers. The upstream project requires users' model-provider API keys and explains that model usage is separate from the workspace subscription. Assess the chosen hosting, synchronization and provider settings before using private content; local-first workspace design does not by itself make remote model requests local. No unsupported legal suffix or ownership claim is inferred from branding.
