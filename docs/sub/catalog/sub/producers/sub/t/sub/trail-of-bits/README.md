# Trail of Bits

[Trail of Bits](https://trailofbits.com/) is an independent security research and engineering firm founded in 2012. Its work includes software assurance, security audits, application and AI/ML security, cryptography, reverse engineering, smart-contract security, and open-source tooling.

## Agent Skills publisher

Trail of Bits publishes **Trail of Bits Skills**, a repository-backed collection of AI-assisted security analysis, testing and development workflows. The collection includes skill/plugin packages for code review, static analysis, supply-chain inspection, smart-contract review and related engineering tasks. Skills are published by the firm, but third-party systems, repositories and model artifacts reviewed using them retain their own authorship and rights.

The published collection is separate from Trail of Bits' paid consulting services and other unrelated public tools. An automated analysis workflow does not grant permission to assess, probe or modify someone else's systems. Authorization, tool permissions and human verification remain necessary.
