# TensorDock.com, Inc.

TensorDock.com, Inc. operates the TensorDock platform for obtaining GPU compute. Its first-party terms distinguish the platform company from the independent hosts supplying infrastructure and from the agreement governing an accepted compute-services order.

## Operating boundary

Check the selected host, location, hardware and compute-services agreement before placing an order. The platform terms expressly distinguish browsing and offers from accepted Compute Services, while hosts use a separate supplier agreement. Marketplace provenance alone does not establish that TensorDock owns every server or that availability, facilities and service commitments are identical across hosts.
