# Tonic.ai

Tonic.ai is the producer identity for Tonic Fabricate. Its official documentation separates Fabricate's generation of relational data, unstructured datasets and mock APIs from the distinct Tonic Structural and Tonic Textual products.

## Operating boundary

Choose the product that matches the data workflow: generating new synthetic data, transforming existing structured data and redacting unstructured material have different inputs and controls. Do not transfer a privacy or capability claim between Tonic products solely because they share a producer. Review the selected product's data inputs, connected systems, output validation and subscription terms before using generated data in a development or AI workflow.
