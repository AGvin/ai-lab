# All Hands AI, Inc.

All Hands AI, Inc. is the for-profit organization that supports and develops the OpenHands ecosystem.

The broader OpenHands community remains distinct from the company. OpenHands software and the separately distributed OpenHands SDK keep their own product identities, while commercial hosting and enterprise terms belong to their delivery surfaces.
