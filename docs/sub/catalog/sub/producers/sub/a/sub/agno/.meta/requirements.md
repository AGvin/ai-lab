# Documentation Requirements

## Requirements

- Identify Agno as the first-party organization/publishing identity behind the Agno open-source agent framework.
- Keep producer identity distinct from the Agno software framework and from separate hosted or production-platform surfaces such as AgentOS.
- Link the canonical Agno agent-framework profile through the `produces` relation.
