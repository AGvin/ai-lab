# Documentation Requirements

## Requirements

- Identify Agno as the first-party organization/publishing identity behind the Agno open-source agent framework.
- Keep producer identity distinct from the Agno software framework and from separate hosted or production-platform surfaces such as AgentOS.
- Link the canonical Agno agent-framework profile from the physically materialized `produces` relation when the reciprocal Agno `produced-by` relation resolves successfully.
- Include the official Agno site and first-party repository as identity and research references.
- Do not invent a legal-company suffix that is not established by the cited authoritative sources.

## Validation

- The page does not collapse the producer identity and Agno software into one entity.
- The Agno/Agno framework `produces` / `produced-by` relation pair is physically present at both endpoints and semantically consistent.
- The Agno framework link resolves to the canonical software node.
- Official resource links match canonical entity metadata.
