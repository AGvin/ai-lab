# Arcade AI, Inc.

Arcade AI, Inc. develops the installable [Arcade MCP](../../../../../software/sub/application-frameworks/sub/application-development/sub/arcade-mcp/) framework and operates the separately represented Arcade automation platform.

## Ownership boundaries

Arcade MCP is a self-managed Python MCP integration framework. Provider-hosted orchestration, OAuth brokerage and policy services are separate platform capabilities. Third-party models and connected tools are not Arcade-owned products solely because they integrate with the platform.

## Relations

- Produces: [Arcade MCP](../../../../../software/sub/application-frameworks/sub/application-development/sub/arcade-mcp/)
- Also produces the separate Arcade automation platform, whose canonical relation is retained in metadata.
