# Arcade AI, Inc.

Arcade AI, Inc. is the organization behind the Arcade integration platform and the separately distributed arcade-mcp Python framework.

The integration platform, the MIT-licensed Python framework, and managed delivery remain distinct. Connecting an external application or tool through Arcade does not make that tool or its data an Arcade product.
