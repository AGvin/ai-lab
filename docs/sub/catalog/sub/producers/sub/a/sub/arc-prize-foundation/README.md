# ARC Prize Foundation

The ARC Prize Foundation is the nonprofit organization behind the represented ARC-AGI benchmarks and ARC Prize activities.

The foundation is distinct from participating model developers. ARC-AGI-2’s static reasoning tasks and ARC-AGI-3’s interactive environments retain their separate benchmark identities, evaluation rules, and results.
