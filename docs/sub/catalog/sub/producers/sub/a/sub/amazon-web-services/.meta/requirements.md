# Documentation Requirements

## Requirements

- Identify Amazon Web Services (AWS) as the producer organization for represented Amazon Nova models, Strands Agents SDK, and Kiro CLI entities.
- Base model and software provenance on first-party AWS material while keeping product-specific evidence with the corresponding canonical entity.
- Keep AWS organization identity distinct from Amazon Nova models, Strands Agents, Kiro CLI, Amazon Bedrock access, and individual AWS hosting/integration services.
- Render the standard `entity-relations` block from the validated current-entity relation projection.
- Include the official AWS site as organization identity context and keep product-specific resources with their owners.

## Validation

- The `entity-relations` block matches the validated current-entity relation projection and every rendered destination resolves to a canonical node.
- The page does not collapse AWS, models, agent software, and AWS hosting/services into one entity.
- Official resource links match canonical entity metadata.
