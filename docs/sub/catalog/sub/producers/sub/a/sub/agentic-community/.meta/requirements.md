# Documentation Requirements

## Requirements

- Identify Agentic Community as the GitHub community publisher/maintainer of MCP Gateway & Registry, without inventing a corporate ownership or making it steward of the official MCP specification or public MCP Registry.
- Keep the separately deployed gateway/registry product distinct from the many third-party MCP servers, IdPs, tools, agents and cloud deployment platforms that it catalogs, routes or integrates.
