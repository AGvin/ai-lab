# Auth0

Auth0 is the identity-platform brand behind Auth0 for AI Agents.

The producer profile is distinct from the Auth0 for AI Agents offering, the broader Auth0 platform, and the applications or third-party tools it authorizes. Okta’s completed acquisition provides corporate context; it does not collapse the Auth0 product identity into every Okta offering.
