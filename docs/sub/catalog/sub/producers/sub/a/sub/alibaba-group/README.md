# Alibaba Group

Alibaba Group is the parent organization represented by the Alibaba Cloud hierarchy and by the historical Alibaba provenance of Higress and AgentScope.

Higress originated within Alibaba Group. AgentScope’s upstream package metadata credits the SysML team of Alibaba Tongyi Lab. Those project origins do not imply that Alibaba owns every model, service, or community contribution integrated by the projects.
