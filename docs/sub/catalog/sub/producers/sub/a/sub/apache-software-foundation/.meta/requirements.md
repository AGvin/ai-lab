# Documentation Requirements

## Requirements

- Identify the Apache Software Foundation as the producer/governance organization for Apache TVM in this catalog.
- Render the standard `entity-relations` block from validated current-entity relations.
- Interpret the Apache TVM producer relation as its Apache publishing/governance identity, preserving original research authorship and downstream operators as distinct roles.

## Validation

- `produces` is the inverse of Apache TVM `produced-by`.
- The foundation is not presented as the sole original inventor of TVM or as an operator of every service built with it.
