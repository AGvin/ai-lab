# Documentation Requirements

## Requirements

- Identify the ARC Prize Foundation as the official organization behind the ARC Prize benchmark series and competitions.
- Keep ARC-AGI-2 static abstract-reasoning tasks distinct from ARC-AGI-3 interactive game-style agent environments, as they assess different capabilities and use different evaluation procedures.
- Do not treat challenge prize amounts, evaluation leaderboards, competition tracks, auxiliary harnesses, training code, or per-model scores as separate producer identities.
- Use the foundation's official site and repository organization for provenance and life-cycle details.

## Validation

- The producer remains distinct from independent model developers participating in the benchmarks.
- Each `produces` link reciprocates the corresponding dataset `produced-by` relation.
- Reported rankings or model scores are not inferred solely from foundation ownership.
