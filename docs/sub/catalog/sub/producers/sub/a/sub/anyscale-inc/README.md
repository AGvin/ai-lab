# Anyscale, Inc.

Anyscale, Inc. is the organization that introduced and developed the early Ray Serve serving library within the Ray project. That producer provenance remains distinct from current Ray Foundation / PyTorch Foundation neutral governance and from Anyscale's separately operated commercial services.

## Produces

- [Ray Serve](../../../../../software/sub/inference-runtimes/sub/distributed-serving/sub/ray-serve/) — distributed model and application serving library in the Ray project.
