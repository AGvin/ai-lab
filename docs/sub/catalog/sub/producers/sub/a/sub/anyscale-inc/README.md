# Anyscale, Inc.

Anyscale, Inc. is the organization that introduced and developed the early Ray Serve serving library within the Ray project.

That origin is separate from the Ray project’s neutral home under the PyTorch Foundation and from Anyscale’s commercial platform. Serving a model with Ray Serve does not make Anyscale its producer.
