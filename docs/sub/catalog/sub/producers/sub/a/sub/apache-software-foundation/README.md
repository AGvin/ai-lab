# Apache Software Foundation

The Apache Software Foundation is the foundation publishing and governing Apache TVM as an Apache project.

The catalog’s producer relation identifies the Apache project’s publishing home. It does not attribute all original TVM research to the foundation or turn TVM into a commercial Apache-hosted inference service; researchers, contributors, and downstream service operators retain their separate roles.
