# Arize AI, Inc.

Arize AI, Inc. is the organization behind Arize Phoenix and the Arize AX platform.

Phoenix is developed with an open-source community; Arize AX is a managed enterprise platform. The company, the separate products, OpenTelemetry/OpenInference integrations, and the models they observe retain their own identities.
