# API7.ai

API7.ai is the organization that originally created and donated Apache APISIX. That origin provenance remains distinct from the vendor-neutral Apache APISIX top-level project and Apache Software Foundation governance.

## Produces

- [Apache APISIX](../../../../../software/sub/gateways/sub/api-management-gateways/sub/apache-apisix/) — open-source API gateway originally created by API7.ai and donated to Apache.
