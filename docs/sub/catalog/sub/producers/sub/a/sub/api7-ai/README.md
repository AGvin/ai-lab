# API7.ai

API7.ai is the organization that originally created Apache APISIX and contributed it to the Apache Software Foundation.

Historical project origin is separate from the vendor-neutral Apache APISIX project and its Apache governance. API7.ai’s commercial offerings and deployments do not define ownership of the Apache project.
