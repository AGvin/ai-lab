# Aider AI LLC

Aider AI LLC, also represented by the concise name Aider AI, is the organization named in Aider’s official privacy policy and associated with the Aider coding assistant.

The organization is distinct from the Aider software and its contributor community. Third-party model providers and the APIs configured in Aider remain separate providers.
