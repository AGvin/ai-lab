# Advanced Micro Devices, Inc.

Advanced Micro Devices, Inc. (AMD) is the organization behind the cataloged AMD processors, accelerators, developer hardware, and AMD software projects.

Individual Instinct, Radeon, and Ryzen products remain separate hardware entities. ROCm and related developer software remain separate software entities; systems and cloud services supplied by other organizations retain their own provenance.
