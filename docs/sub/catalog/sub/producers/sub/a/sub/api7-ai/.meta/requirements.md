# Documentation Requirements

## Requirements

- Identify API7.ai as the organization that originally created and donated Apache APISIX.
- Keep API7.ai's product/company identity distinct from the vendor-neutral Apache APISIX top-level project and Apache Software Foundation governance.
- Render the standard `entity-relations` block from the validated current-entity relation projection.
- Include current first-party API7.ai identity material and official Apache APISIX provenance evidence.

## Validation

- API7.ai is represented as the APISIX originator rather than as the current owner of the Apache top-level project.
- Apache governance is not collapsed into API7.ai product ownership or maintenance.
- The `entity-relations` block matches the validated current-entity relation projection and every rendered destination resolves to a canonical node.
