# Agentic AI Foundation

The Agentic AI Foundation (AAIF) is a Linux Foundation initiative that provides a neutral home for the open agentic-AI projects linked below.

Foundation stewardship is separate from original authorship, company membership, sponsorship, and the authority of each project’s maintainers. MCP, for example, retains governance by individual maintainers; its foundation home does not make every member company a protocol producer.
