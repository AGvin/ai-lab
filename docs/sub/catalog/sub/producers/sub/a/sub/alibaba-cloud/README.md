# Alibaba Cloud

Alibaba Cloud is the cloud and AI organization within Alibaba Group. The catalog separately represents its Qwen and Wan producer teams, Alibaba Cloud Skills, and Model Studio service.

The hierarchy expresses the first-party organizational attribution of those teams, not a claim that they are separately incorporated companies. Model Studio supplies access to Alibaba models and third-party models; hosted access does not transfer model provenance to Alibaba Cloud.
