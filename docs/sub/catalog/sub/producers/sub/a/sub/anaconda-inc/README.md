# Anaconda, Inc.

Anaconda, Inc. is the organization identified in Anaconda's official terms. It provides software and services for data and AI development.

Anaconda announced the acquisition of Kilo Code in July 2026. Kilo's published terms subsequently identified Anaconda, Inc. acting for itself and affiliates including Kilo Code Inc. This ownership relationship preserves Kilo Code Inc.'s original product provenance.
