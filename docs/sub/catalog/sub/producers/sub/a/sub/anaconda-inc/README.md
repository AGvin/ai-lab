# Anaconda, Inc.

Anaconda, Inc. is the organization named in Anaconda’s first-party terms. Its July 2026 acquisition of Kilo Code is represented as an ownership relation to Kilo Code Inc.

Kilo Code Inc. remains a distinct producer identity for the Kilo Code product. The acquisition does not merge that software into Anaconda’s other distributions, package services, or model offerings, and it does not make Anaconda the producer of every routed model.
