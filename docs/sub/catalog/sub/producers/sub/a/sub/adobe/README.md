# Adobe

Adobe publishes the Adobe Firefly model family represented in the model catalog.

The Firefly app, Creative Cloud integrations, Firefly Services, and partner-model access are separate product and delivery surfaces. Models from other providers retain their original producer attribution when accessed through Adobe products.
