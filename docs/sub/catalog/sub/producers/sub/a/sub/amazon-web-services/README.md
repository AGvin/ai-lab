# Amazon Web Services

Amazon Web Services (AWS) is the producer and service operator represented by the Amazon models, developer projects, hosted services, hardware, and Agent Skill resources linked below.

AWS organization identity remains separate from each model, software package, specification, hardware product, and hosted service. Models accessed through Amazon Bedrock or other AWS infrastructure retain their original producer, and open-source contributors remain distinct from AWS as the publishing organization.
