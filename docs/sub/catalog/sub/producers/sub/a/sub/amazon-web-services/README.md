# Amazon Web Services

Amazon Web Services (AWS) is the producer organization for the represented Strands Agents SDK and Kiro CLI entities. The organization remains distinct from those software products and from the AWS hosting or service surfaces they can use.

## Produces

- [Kiro CLI](../../../../../software/sub/agents/sub/hybrid/sub/kiro-cli/) — Kiro terminal agent spanning local development and AWS-operated cloud sessions.
- [Strands Agents](../../../../../software/sub/agent-frameworks/sub/strands-agents/) — open-source AI agents SDK introduced by AWS.
