# ARISE Initiative

ARISE Initiative means **Advancing Robot Intelligence through Simulated Environments**. Its [official project organization](https://github.com/ARISE-Initiative) publishes robosuite and related robot-learning projects.

The [robosuite project description](https://robosuite.ai/docs/overview.html) places the framework within ARISE. It records its Stanford Vision and Learning Lab origin and maintenance across Stanford SVL, the UT Robot Perception and Learning Lab, and NVIDIA GEAR. This project identity preserves that shared provenance without assigning the framework exclusively to one participating lab or sponsor.
