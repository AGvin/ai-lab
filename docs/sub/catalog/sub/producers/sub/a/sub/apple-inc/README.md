# Apple Inc.

Apple Inc. is the original publisher of [GSM-Symbolic](../../../../../datasets/sub/gsm-symbolic/), a 2024 symbolic-template mathematical reasoning evaluation dataset derived from GSM8K question templates, and the organization behind MLX LM, the language-model package built on the MLX framework.

Apple's producer identity is distinct from both dataset artifacts and software. GSM-Symbolic's main, P1 and P2 configurations are one released dataset family; the original GSM8K dataset is published by OpenAI, **not** Apple. MLX LM is distinct from the lower-level MLX framework and from models distributed or executed using those tools. Compatibility does not establish Apple model authorship.
