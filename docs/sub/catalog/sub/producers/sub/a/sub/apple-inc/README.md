# Apple Inc.

Apple Inc. is the organization behind MLX LM, the language-model package built on the MLX framework.

Apple’s producer identity is distinct from the MLX LM package, the lower-level MLX framework, and models distributed or executed using those tools. A model’s compatibility with MLX LM does not make it an Apple-produced model.
