# Documentation Requirements

## Requirements

- Identify the KServe Project as the open-source community/project publishing KServe's Kubernetes-based generative and predictive inference platform.
- Keep foundation/governance relationships outside the direct producer edge unless they are separately required and source-backed.
- Render the standard `entity-relations` block from validated current-entity relations.
- Keep project stewardship separate from the organizations operating Kubernetes clusters, model servers, or hosted inference services; project identity alone does not establish a commercial service provider.

## Validation

- `produces` is the inverse of KServe `produced-by`.
