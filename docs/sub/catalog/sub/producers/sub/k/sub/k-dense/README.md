# K-Dense

[K-Dense](https://www.k-dense.ai/) develops AI agents for scientific research, engineering, healthcare-related analysis and complex professional workflows. Its product family includes **K-Dense Web**, organization-focused **K-Dense Enterprise** deployments and separately published open-source tools.

## Provider and product boundaries

K-Dense Web provides a hosted research-agent workflow for collecting and analyzing information and producing research outputs. Enterprise deployments have different infrastructure and governance arrangements. K-Dense BYOK is a separate desktop research assistant using a user's configured model access, while Claude Scientific Writer and Scientific Agent Skills support writing and specialized research tasks.

These offerings have separate deployment, source, price, data-flow and maintenance boundaries. Publishing skills does not make K-Dense a developer of each third-party model, research dataset or tool that a workflow uses. No additional frozen product identity is accepted solely because it is mentioned here.

## Operating considerations

Scientific results require method review, reproducibility checks and appropriate domain expertise. Before uploading confidential research or personal data, verify the chosen product's model providers, data location, retention, access permissions and contract. Open-source installation and research-agent execution can involve scripts and third-party dependencies; inspect them and use least privilege.
