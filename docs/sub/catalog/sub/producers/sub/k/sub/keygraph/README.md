# Keygraph

Keygraph is the organization behind Shannon and the separate commercial Keygraph application-security platform.

Shannon's self-run software and Keygraph's commercial editions have separate licensing and operating boundaries. Shannon performs active exploitation; its official documentation limits testing to authorized, non-production targets.
