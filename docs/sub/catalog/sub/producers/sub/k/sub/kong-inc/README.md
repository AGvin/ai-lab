# Kong Inc.

Kong Inc. is the organization behind Kong Gateway and Kong AI Gateway. The company remains distinct from its software, Konnect, and other separately operated product or service surfaces.

AI Gateway uses a Konnect-managed control plane and self-managed data plane nodes that connect to upstream AI providers. Producer identity does not determine who operates every gateway deployment.

## Produces

- [Kong AI Gateway](../../../../../services/sub/gateways/sub/model-gateways/sub/kong-ai-gateway/) — separately represented AI gateway service.
- [Kong Gateway](../../../../../software/sub/gateways/sub/api-management-gateways/sub/kong-gateway/) — API gateway software.
