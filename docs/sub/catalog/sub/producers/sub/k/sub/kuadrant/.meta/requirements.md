# Documentation Requirements

## Requirements

- Identify Kuadrant as the first-party project/publisher of the separately released Kuadrant MCP Gateway, not as a generic synonym for Envoy, Istio, Kubernetes Gateway API, or every Kuadrant ecosystem component.
- Reuse the official project site and MCP gateway repository for current provenance. Identity providers, policy engines, deployment dependencies and cloud infrastructure remain distinct vendors/components rather than implicit Kuadrant-owned subproducts.
- Preserve the exact `produces` relation to the single canonical MCP Gateway software profile and its reciprocal `produced-by` link.

## Validation

- Official first-party project/repository documentation supports software attribution.
- Producer and software relation targets match exactly.
