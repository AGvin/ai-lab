# Khoj Inc.

Khoj Inc. is the organization producing the open-source, self-hostable Khoj knowledge workspace. Khoj Cloud was a separate operating surface and shut down on April 15, 2026, according to the first-party sunset notice. The producer and software continue to be distinct from that retired hosted service.

Older terms and documentation can still describe cloud access; the explicit sunset notice governs the hosted-service lifecycle.
