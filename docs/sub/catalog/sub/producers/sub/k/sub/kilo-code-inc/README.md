# Kilo Code Inc.

Kilo Code Inc. is the original producer organization behind Kilo Code. Anaconda announced its acquisition of Kilo in July 2026.

The Kilo terms published on September 30, 2026 identify Anaconda, Inc. acting for itself and affiliates including Kilo Code Inc. Those terms contain transition provisions for existing users and recognize applicable enterprise agreements. Corporate ownership and the product's original producer remain separate catalog relations.
