# Documentation Requirements

## Requirements

- Identify K-Dense as the first-party publisher of research-oriented AI agents, not a generic foundation-model provider, a single open-source package, or a separate producer for each K-Dense product.
- Keep [K-Dense Web](https://www.k-dense.ai/) hosted research, [K-Dense Enterprise](https://www.k-dense.ai/faq) customer-specific deployment, K-Dense BYOK, Claude Scientific Writer and Scientific Agent Skills as distinct product or collection surfaces; do not count any of them as additional accepted frozen identities in this batch.
- The official [About](https://www.k-dense.ai/about) and [FAQ](https://www.k-dense.ai/faq) describe the team, mission and delivery model. Vendor-marketed productivity, database coverage and adoption statistics are mutable claims, not independent performance evidence.
- Avoid promising that a hosted platform processes data entirely locally, that a BYOK client provides managed hosted services, or that every agent skill is maintained or licensed identically.
- Scientific and clinical workflows may handle confidential datasets, personal health information or untrusted computational scripts; require data rights, access controls, source inspection, reproducibility checks and human validation before decision-making.
- Product pricing, research limits, supported data sources, enterprise controls, availability, software licensing and external model providers must be checked per selected product and actual version.
- Add the Producers K index entry once; create no speculative model/service/skills entity relation without an accepted canonical target.

## Validation

- The producer reader and metadata cite K-Dense's first-party website.
- No installed agent, executed scientific analysis, benchmark reproduction, full license/privacy audit, repository-wide CI or whole-catalog clean pass is claimed.
