# Google

Google is the broader producer organization for the represented Google models, services, hardware and developer tools. Its [AI developer site](https://ai.google.dev/) describes model and API surfaces, while the [organizational announcement](https://blog.google/innovation-and-ai/technology/ai/april-ai-update/) establishes Google DeepMind as a distinct research unit within Google.

Model families, hosted products and software retain separate catalog identities. Google's [Kubeflow history](https://opensource.googleblog.com/2022/10/kubeflow-applies-to-become-a-cncf-incubating-project.html) records originating contributions; [CNCF's project record](https://www.cncf.io/projects/kubeflow/) establishes current community governance. That provenance does not imply exclusive current ownership.
