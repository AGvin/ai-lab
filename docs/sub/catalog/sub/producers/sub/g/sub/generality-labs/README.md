# Generality Labs

Generality Labs is a London-based AI safety research and engineering organization founded in 2026 as a spin-off from Arcadia Impact. Its work focuses on reliable AI evaluation methods, software and practical audits.

## Evaluation tooling and stewardship

Generality Labs currently maintains the open-source **Inspect Evals** implementation collection and its distributed Inspect Evals Register. This is a maintenance and development relationship, not an assertion that the organization originally created the separately released Inspect AI framework or independently authored every third-party evaluation linked from the register.

Inspect Evals was introduced by the UK AI Security Institute and collaborators in 2024; its current repository continues to use the historical UKGovernmentBEIS GitHub namespace. Keep the project's original provenance separate from today's maintainer. Research services and evaluations are not themselves licenses to redistribute third-party benchmark datasets, prompts or model responses.
