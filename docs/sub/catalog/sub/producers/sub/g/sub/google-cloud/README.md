# Google Cloud

Google Cloud is the provider organization for the represented managed model API and agent-runtime services. The [platform overview](https://docs.cloud.google.com/gemini-enterprise-agent-platform/overview) describes its cloud delivery surfaces. It is also a founding contributor to [llm-d](https://github.com/llm-d/llm-d), a project with shared governance.

Google Cloud's [name-change documentation](https://docs.cloud.google.com/gemini-enterprise-agent-platform/vertex-ai-name-changes) identifies Agent Runtime on Gemini Enterprise Agent Platform as the current name of Vertex AI Agent Engine. That managed runtime remains distinct from model APIs, installable frameworks and the broader platform.
