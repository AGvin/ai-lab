# GitHub, Inc.

GitHub, Inc. produces GitHub Copilot and Spec Kit and maintains the community-contributed Awesome GitHub Copilot repository. The [GitHub terms](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service) identify the company, and Microsoft's [completed-acquisition announcement](https://blogs.microsoft.com/blog/2018/10/26/microsoft-completes-github-acquisition/) supports its parent-company relationship.

[Spec Kit](https://github.com/github/spec-kit) is an agent-independent toolkit with its own product identity. Microsoft ownership remains distinct from GitHub product authorship, and repository hosting does not make GitHub the producer of every hosted project. [Customer agreements](https://github.com/customer-terms) also distinguish direct GitHub purchases from purchases through Microsoft.
