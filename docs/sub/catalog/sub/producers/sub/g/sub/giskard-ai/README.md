# Giskard AI

Giskard AI is the public producer identity identified as GISKARD AI SAS on its [legal page](https://www.giskard.ai/legal). It publishes the Giskard open-source evaluation framework and offers the separate enterprise Hub.

The [comparison documentation](https://docs.giskard.ai/start/comparison) distinguishes the library from the Hub. Software modules, hosted services and external benchmarks retain their own license and operating boundaries.
