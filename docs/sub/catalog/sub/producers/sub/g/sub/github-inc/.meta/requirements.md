# Documentation Requirements

## Requirements

- Identify GitHub, Inc. as the organization operating GitHub and producing the GitHub Copilot and GitHub Spec Kit products represented in the catalog.
- Preserve Microsoft as GitHub, Inc.'s canonical owner and link it through the `owned-by` relation.
- Keep ownership distinct from production: Microsoft ownership does not replace GitHub as the producer of GitHub-authored products represented here.
- Keep producer identity distinct from the GitHub platform and from the individual GitHub Copilot and Spec Kit software/product identities.
- Link GitHub Copilot and GitHub Spec Kit through the canonical `produces` relations.
- Include current official GitHub and Terms of Service references sufficient to establish organization identity and the current Microsoft affiliate relationship.

## Validation

- Ownership is not treated as a producer relation for GitHub-authored products.
- Related organization and software links resolve to their canonical profiles.
- Official resource links match canonical entity metadata.
