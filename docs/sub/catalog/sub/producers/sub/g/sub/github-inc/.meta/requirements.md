# Documentation Requirements

## Requirements

- Identify GitHub, Inc. as the organization operating GitHub and producing the GitHub Copilot product represented in the catalog.
- Keep producer identity distinct from the GitHub platform and GitHub Copilot software/product identities.
- Link the canonical GitHub Copilot Hybrid Agent profile.
- Include current official GitHub and Terms of Service references sufficient to establish provenance.
- Keep broader corporate, ownership, staffing, pricing, and mutable platform details outside this concise producer profile unless they become relevant to represented catalog entities.

## Validation

- The page does not collapse GitHub, Inc., the GitHub platform, and GitHub Copilot into one entity.
- The GitHub Copilot link resolves to the canonical Hybrid Agent profile.
- Official resource links match canonical entity metadata.
