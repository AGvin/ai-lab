# Documentation Requirements

## Requirements

- Identify GitHub, Inc. as the organization operating GitHub and producing the GitHub Copilot and GitHub Spec Kit products represented in the catalog.
- Keep producer identity distinct from the GitHub platform and from the individual GitHub Copilot and Spec Kit software/product identities.
- Link the canonical GitHub Copilot Hybrid Agent and GitHub Spec Kit spec-driven-development profiles from the physically materialized `produces` relations when their reciprocal `produced-by` relations resolve successfully.
- Include current official GitHub and Terms of Service references sufficient to establish provenance.
- Keep broader corporate, ownership, staffing, pricing, and mutable platform details outside this concise producer profile unless they become relevant to represented catalog entities.

## Validation

- The page does not collapse GitHub, Inc., the GitHub platform, GitHub Copilot, and Spec Kit into one entity.
- The GitHub/Copilot and GitHub/Spec Kit `produces` / `produced-by` relation pairs are physically present at both endpoints and semantically consistent.
- Both related software links resolve to their canonical profiles.
- Official resource links match canonical entity metadata.
