# Documentation Requirements

## Requirements

- Identify GitHub, Inc. as the organization operating GitHub and producing represented GitHub-authored products in the catalog.
- Preserve Microsoft as GitHub, Inc.'s canonical owner without conflating ownership with production.
- Keep ownership distinct from production: Microsoft ownership does not replace GitHub as the producer of GitHub-authored products represented here.
- Keep producer identity distinct from the GitHub platform and from individual GitHub software/product identities.
- Render the standard `entity-relations` block from the validated current-entity relation projection.
- Include current official GitHub and Terms of Service references sufficient to establish organization identity and the current Microsoft affiliate relationship.

## Validation

- Ownership is not treated as a producer relation for GitHub-authored products.
- The `entity-relations` block matches the validated current-entity relation projection and every rendered destination resolves to a canonical node.
- Official resource links match canonical entity metadata.
