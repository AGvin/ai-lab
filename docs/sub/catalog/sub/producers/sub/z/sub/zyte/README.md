# Zyte

Zyte is the operator of Zyte API's hosted web-data extraction and browser services. The API's access modes are distinct from the Scrapy framework and the separately operated Scrapy Cloud spider-job platform.

## Producer and operating boundary

HTTP extraction, browser requests, proxy transport and live CDP connections have different state and feature boundaries. Browser-request sessions are not a persistent shared CDP browser. Review the selected mode, account eligibility, source-content permissions and retention; service access does not grant rights to every destination's data.
