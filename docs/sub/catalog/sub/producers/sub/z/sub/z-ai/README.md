# Z.AI

Z.AI is the producer identity used by the current GLM documentation and official zai-org model registry. The long-lived GLM family and its individually reviewed models remain separate from the organization and from hosted access plans.

## Producer and operating boundary

Model-weight licenses, API availability and commercial subscriptions need assessment for the exact model and access route. Provider benchmark claims are not independent catalog evaluations. Historical Zhipu AI wording alone does not establish an additional parent or ownership relation in the canonical graph.
