# Zep

Zep is the organization behind the managed Zep context service and the open-source Graphiti temporal-graph framework. First-party material connects the projects while keeping the operated service and installable framework distinct.

## Producer and operating boundary

Self-hosting Graphiti does not inherit the managed service's operating controls, and graph storage can still use external model and embedding providers. Review credentials, source-data access, persistence and retention across the chosen graph, model and service configuration.
