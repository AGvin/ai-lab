# Isomorphic Labs

Isomorphic Labs co-developed AlphaFold 3 with Google DeepMind. The AlphaFold family relation below records this specific collaboration, not authorship of all earlier AlphaFold versions.

The company's drug-discovery work is distinct from the AlphaFold model, AlphaFold Server and structure database. Applicable use rights belong to the exact model release or serving surface; collaboration alone does not establish additional legal ownership relations.
