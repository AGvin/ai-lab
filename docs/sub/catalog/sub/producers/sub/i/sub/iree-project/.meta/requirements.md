# Documentation Requirements

## Requirements

- Identify the IREE Project as the project-level producer identity for IREE.
- Explain that IREE is a sandbox-stage LF AI & Data Foundation project with technical governance exercised by its Technical Steering Committee under the project charter.
- Do not infer corporate ownership from contributor affiliations, hosting, foundation participation or use of IREE in a vendor product.
- Keep software release, license and backend support details with the IREE software profile.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- `produces` is the inverse of IREE `produced-by`.
- Project governance remains distinct from corporate ownership and product support commitments.
