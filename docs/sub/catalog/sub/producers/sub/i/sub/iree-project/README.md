# IREE Project

The IREE Project is the project-level producer identity for IREE. It is a sandbox-stage project of the LF AI & Data Foundation; its Technical Steering Committee exercises technical governance under the project charter.

Contributor affiliations, hosting and foundation participation do not establish exclusive corporate ownership or product support commitments. Software releases, licensing and backend support belong to the IREE software profile.
