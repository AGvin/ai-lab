# Documentation Requirements

## Requirements

- Identify Intel as the producer represented by its distinct accelerator and professional graphics products in this catalog.
- Keep product-specific specifications, benchmark conditions, software compatibility and support with each hardware profile; shared producer identity does not establish interchangeability.
- Distinguish Intel hardware provenance from partner OEM systems and cloud services using that hardware.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Every rendered `produces` relation has an exact reciprocal `produced-by` relation on its canonical target.
- The profile does not reduce Intel's represented portfolio to one product or imply universal software compatibility.
