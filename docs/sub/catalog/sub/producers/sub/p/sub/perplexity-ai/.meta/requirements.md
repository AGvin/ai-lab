# Documentation Requirements

## Requirements

- Identify Perplexity AI as the canonical producer organization for represented Perplexity hosted and local agent/workspace products.
- Keep product, model, API, connector, and plan details with their respective canonical owners rather than duplicating them into the producer profile.
- Render the standard `entity-relations` block from the validated current-entity relation projection.
- Include Perplexity's official product/company site as identity evidence.

## Validation

- Producer provenance resolves bidirectionally for every represented Perplexity product.
- The producer identity is not collapsed into Perplexity's end-user assistant/workspace service or Portable Computer software.

## Source-backed identity and operating scope

The reader must preserve the following boundaries and their source basis.

Perplexity AI develops the represented Perplexity workspace, Computer products, Comet browser, developer APIs, retrieval models and skill distributions. Its official product and API documentation separates hosted workspaces from installed software and trained artifacts. API access to another provider's model does not make Perplexity that model's original producer. [Computer](https://www.perplexity.ai/products/computer) · [Comet](https://www.perplexity.ai/comet) · [Agent API](https://docs.perplexity.ai/docs/agent-api/quickstart).

Select the product boundary first. Portable Computer describes local execution with approved cloud escalation, while Comet can send needed browsing context to its assistant service. A local installation therefore requires checking connector access and the data flow of the selected action. [Portable Computer](https://www.perplexity.ai/en-GB/hub/products/portable-computer) · [Comet data use](https://www.perplexity.ai/help-center/comet/en/articles/12867415-comet-assistant-privacy-data-use).

For API use, zero data retention is not the default: eligible accounts require configuration and a written agreement, and provider-specific conditions apply. For artifacts, check the exact card and access instructions; Decider V1.1 has Apache-2.0 metadata but describes authenticated repository access. Q2D-Web is a private benchmark with a public leaderboard. Public documentation does not establish downloadable benchmark data or anonymous access to every model artifact. [API privacy](https://docs.perplexity.ai/docs/resources/privacy-security) · [Decider V1.1](https://huggingface.co/perplexity-ai/pplx-decider-v1.1-27b) · [Q2D-Web](https://www.perplexity.ai/uk/hub/blog/q2d-web).

## Reader projection

- Render every non-hidden current-entity relation in its semantic group, ordered by explicit order, canonical target display name and target ID. Preserve source/contributor, organizational and product distinctions.
- Include the official resources from canonical references as readable links. Navigation to a related catalog entry must resolve to its reader, not to metadata.
- Keep changing version, plan, availability and policy details qualified by the cited source; no general offline, license or privacy guarantee follows from producer attribution.
