# Prime Radiant

Prime Radiant is the applied-AI organization associated with the Superpowers development workflow collection. Its site links to Superpowers, and the upstream repository credits Jesse Vincent and the rest of the Prime Radiant team. That is first-party project provenance, without implying that the organization wrote every community contribution. [Prime Radiant](https://primeradiant.com/) · [Superpowers](https://github.com/obra/superpowers).

## Scope and operating boundaries

Superpowers is an MIT-licensed collection of agent instructions and workflow resources. Choose the installation appropriate to the coding client and review the capabilities enabled by the selected revision. Instructions are executed through the host agent's tools and permissions; the collection is not a separately hosted model or an independent execution service. [Superpowers repository](https://github.com/obra/superpowers).
