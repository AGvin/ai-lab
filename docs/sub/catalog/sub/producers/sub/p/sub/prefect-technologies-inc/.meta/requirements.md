## Source-backed identity and operating scope

The reader must preserve the following boundaries and their source basis.

Prefect Technologies, Inc. is the company identified in Prefect's legal terms and the producer behind the represented Prefect and FastMCP projects. Prefect's history places the orchestration project's origin with Jeremiah Lowin and the founding team. FastMCP is now published in the PrefectHQ organization as a standalone Python framework for MCP applications. [Company terms](https://www.prefect.io/legal/terms) · [Prefect history](https://docs.prefect.io/v3/get-started/index) · [FastMCP](https://github.com/PrefectHQ/fastmcp).

Both represented repositories declare Apache-2.0 licensing, while Prefect Cloud and Horizon have hosted-service and subscription boundaries. For a deployment, determine where workflow or MCP code runs, which credentials it can use and whether state or logs are sent to a hosted control plane. Repository licensing does not supply that service or authorize the tools exposed by an MCP application. [Prefect repository](https://github.com/PrefectHQ/prefect) · [FastMCP repository](https://github.com/PrefectHQ/fastmcp) · [Service terms](https://www.prefect.io/legal/terms).
