# Palo Alto Networks, Inc.

Palo Alto Networks, Inc. is the current corporate owner of Portkey, Inc. following completion of the Portkey acquisition on May 29, 2026.

The corporate owner identity remains distinct from Portkey, Inc., the open-source Portkey AI Gateway software, and Palo Alto Networks' producer-operated Prisma AIRS / Prisma AIRS AI Gateway service surfaces.
