## Source-backed identity and operating scope

The reader must preserve the following boundaries and their source basis.

Pydantic is the first-party organization and publishing identity behind the represented Pydantic AI, AI Harness, Evals and Logfire products. AI is a Python agent SDK; Harness adds reusable agent capabilities; Evals is a separate evaluation package; Logfire supplies observability. The official documentation links these components without making them one interchangeable product. [AI](https://pydantic.dev/docs/ai/overview/) · [Harness](https://pydantic.dev/docs/ai/harness/) · [Evals](https://pydantic.dev/docs/ai/evals/evals/) · [Logfire](https://pydantic.dev/docs/logfire/get-started/).

The Pydantic AI repository declares MIT licensing. Model requests, executable tools and observability exports still require separate configuration: a typed interface does not limit a shell tool's filesystem access or determine what a telemetry backend receives. Choose the required capabilities and trace content deliberately, and check the terms of any hosted backend. [Repository](https://github.com/pydantic/pydantic-ai) · [Harness](https://pydantic.dev/docs/ai/harness/) · [Logfire](https://pydantic.dev/docs/logfire/get-started/).
