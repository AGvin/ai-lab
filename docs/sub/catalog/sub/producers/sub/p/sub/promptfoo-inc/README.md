# Promptfoo Inc.

Promptfoo Inc. is the organization behind the represented Promptfoo framework and is currently documented by first-party sources as part of OpenAI. The organization remains distinct from Promptfoo software and from OpenAI as the broader parent organization.

## Produces

- [Promptfoo](../../../../../software/sub/evaluation-and-observability/sub/evaluation-frameworks/sub/promptfoo/) — open-source AI evaluation framework.

## Organization structure

- [OpenAI](../../../o/sub/openai/) — broader organization that Promptfoo Inc. is currently part of; this is not strengthened into a different corporate relation without separate evidence.
