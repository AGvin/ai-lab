# Promptfoo Inc.

Promptfoo Inc. is the retained producer identity behind the Promptfoo evaluation and red-teaming project. The published website terms name Promptfoo Inc. and are dated January 24, 2025; the current company page and repository state that Promptfoo is now part of OpenAI. This preserves project provenance and the documented organizational relationship without turning it into a stronger ownership assertion. [Website terms](https://www.promptfoo.dev/terms-of-service/) · [Company update](https://www.promptfoo.dev/about/) · [Repository](https://github.com/promptfoo/promptfoo).

## Scope and operating boundaries

The project remains MIT-licensed, but deployment privacy depends on the evaluation configuration. Tests can call the selected model provider, and red-team generation or grading may use local or remote services. Review those routes and any trace or report export before submitting sensitive prompts; running the CLI locally does not establish that all processing stays on the machine. [Repository](https://github.com/promptfoo/promptfoo) · [Red-team data handling](https://www.promptfoo.dev/docs/red-team/troubleshooting/data-handling/).
