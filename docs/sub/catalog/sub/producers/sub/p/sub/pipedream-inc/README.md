# Pipedream, Inc.

This catalog retains the established Pipedream, Inc. producer identity and its Pipedream alias for the operator behind Pipedream Connect. The live terms updated September 30, 2026 name Pipedream, LLC in the legal body while the site footer still displays Pipedream, Inc. Use the applicable agreement to establish the contracting party; these pages alone do not establish a legal succession history. [Pipedream terms](https://pipedream.com/terms).

## Scope and operating boundaries

Connect supplies managed authentication and application integrations. OAuth connections, API credentials and proxy/tool operations act within the permissions granted to the connected accounts; the integration operator is separate from each downstream application's producer. Review connection scopes and the actions exposed to an agent before deployment. [Connect documentation](https://pipedream.com/docs/connect).

The current terms direct Sana Enterprise customers to a separate main subscription agreement. Contract applicability therefore depends on the purchased offering, and should not be inferred solely from the preserved catalog label. [Pipedream terms](https://pipedream.com/terms).
