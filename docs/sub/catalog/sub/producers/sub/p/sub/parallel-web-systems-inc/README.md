# Parallel Web Systems Inc.

Parallel Web Systems Inc. is the company named in the Parallel Customer Terms and the operator of the Parallel web-search and research API family. This producer record concerns parallel.ai; it is separate from the unrelated Parallel cobrowsing business at parallel.tech. [Customer terms](https://parallel.ai/customer-terms) · [Search API](https://docs.parallel.ai/search/search-quickstart).

## Scope and operating boundaries

Search returns retrieved pages and excerpts; Task combines web research with synthesis and structured results. Choose the interface according to whether an application needs source material or an assembled research result, and check the underlying evidence before relying on generated output. [Search API](https://docs.parallel.ai/search/search-quickstart) · [Task API](https://docs.parallel.ai/task-api/task-quickstart).

The customer terms effective October 17, 2026 restrict output resale, training-dataset construction and some cross-customer reuse. They also reserve input/output use for service improvement and model training and require a separate DPA before personal-data processing. Evaluate the applicable contract and negotiated data controls before sending sensitive inputs. [Customer terms](https://parallel.ai/customer-terms).
