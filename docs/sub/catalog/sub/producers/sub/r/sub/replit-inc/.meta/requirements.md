# Documentation Requirements

## Requirements

- Identify Replit, Inc. as the organization providing the Replit hosted development platform and Replit Agent.
- Keep the producer organization distinct from Replit Agent, Replit Apps/projects, deployments, databases, and other individual platform services.
- Link the canonical Replit Agent hosted development-service profile through the `produces` relation.
