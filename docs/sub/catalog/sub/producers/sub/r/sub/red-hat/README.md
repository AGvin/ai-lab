# Red Hat

Red Hat is an enterprise open-source software company and one of the founding organizations credited by llm-d. The llm-d repository describes a multi-organization project and current CNCF Sandbox status. The represented production relationship records Red Hat's founding contribution; it does not assign sole authorship, ownership or governance of llm-d to Red Hat. [Red Hat](https://www.redhat.com/en/about) · [llm-d project](https://github.com/llm-d/llm-d).
