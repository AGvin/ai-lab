# Documentation Requirements

## Requirements

- Identify Runway as the canonical producer/operator behind the represented Runway generative-media models.
- Keep model/version, hosted workspace, API, pricing, credits, plans, and third-party partner-model inventory with their applicable model or service owners.
- Preserve first-party provenance without treating Runway-hosted third-party models as produced by Runway.
- Render only validated current relations.

## Validation

- Gen-4.5 provenance resolves to Runway.
- Third-party models exposed through Runway remain attributed to their upstream producers.

## Source-backed identity and operating scope

The reader must preserve the following boundaries and their source basis.

Runway is the first-party producer of the represented Gen-4.5 video-generation model. Its help center documents the model's creative workflow, and the developer model index attributes Gen-4.5 to Runway while identifying separate providers for third-party models available through the same platform. [Gen-4.5 guide](https://help.runwayml.com/hc/en-us/articles/46974685288467-Creating-with-Gen-4-5) · [Developer model index](https://docs.dev.runwayml.com/guides/models/).

Select the web workspace or developer API according to the required workflow, account eligibility and output format. The API index exposes Gen-4.5 as `gen4.5`; product access does not establish downloadable weights or a general open-source model license. Check rights to supplied media and the chosen service's current terms before publishing generated work. Web help-table limits should not be assumed to describe every developer API format. [Developer models](https://docs.dev.runwayml.com/guides/models/) · [API changes](https://docs.dev.runwayml.com/api-details/api_changelog/).

## Reader projection

- Render every non-hidden current-entity relation in its semantic group, ordered by explicit order, canonical target display name and target ID. Preserve source/contributor, organizational and product distinctions.
- Include the official resources from canonical references as readable links. Navigation to a related catalog entry must resolve to its reader, not to metadata.
- Keep changing version, plan, availability and policy details qualified by the cited source; no general offline, license or privacy guarantee follows from producer attribution.
