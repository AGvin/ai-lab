# Raspberry Pi Ltd

Raspberry Pi Ltd. is the producer profile behind the represented Raspberry Pi AI HAT+ and AI HAT+ 2 boards. Official product pages distinguish the Raspberry Pi add-on boards from their Hailo accelerator components and identify Raspberry Pi 5 as the host platform. This company/product provenance is separate from the educational foundation and the accelerator supplier. [AI HAT+](https://www.raspberrypi.com/products/ai-hat/) · [AI HAT+ 2](https://www.raspberrypi.com/products/ai-hat-plus-2/).

## Scope and operating boundaries

Select a board against the required host, accelerator runtime and supported workload. AI HAT+ and AI HAT+ 2 have different accelerator and memory configurations, so model compatibility or performance should not be carried from one to the other by name. Local hardware also leaves model licensing and any application-level network calls to the chosen software stack. [AI HAT+](https://www.raspberrypi.com/products/ai-hat/) · [AI HAT+ 2](https://www.raspberrypi.com/products/ai-hat-plus-2/).
