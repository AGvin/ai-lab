## Identity and boundaries

The [current terms](https://fal.ai/legal/terms-of-service) identify fal – Features & Labels, Inc. as the platform provider. The [original launch](https://fal.ai/blog/introducing-flux-3-max-by-fal) attributes FLUX 3 Max post-training to fal Research in collaboration with Black Forest Labs. This does not establish a separately incorporated fal Research company, exclusive BFL authorship or current beneficial ownership. Indirect stakes and control rights remain unverified; do not infer affiliation from founders' names.

fal Research also [announced H3 Max](https://blog.fal.ai/introducing-h3-max-by-fal/) as separately post-trained from MiniMax H3; the API endpoint namespace preserves original H3 lineage without assigning all model authorship to MiniMax. No separate fal Research legal company is inferred.

The separately documented [fal Model APIs](../../../../../services/sub/model-apis/sub/fal-model-apis/README.md) is an API service of this existing legal provider; the frozen `v1:fal-ai` label is a duplicate identity case, **not a second producer**. Hosted API and model-weight rights are different. Keep model architecture, endpoint limits, pricing, processing/privacy settings and recommendations with their exact model/service owners. Original production attribution is not a security certification.
