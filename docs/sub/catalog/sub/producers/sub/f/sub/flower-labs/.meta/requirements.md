# Documentation Requirements

## Requirements

- Identify Flower Labs as the canonical producer organization for the represented Endeavor model family.
- Keep model capabilities, preview lifecycle, deployment modes, evaluation claims, and access details with the model entities rather than duplicating them in the producer profile.
- Render the standard `entity-relations` block from validated current-entity relations.

- Include the source-backed Lizzy family relation separately from existing families and product/runtime identities.
