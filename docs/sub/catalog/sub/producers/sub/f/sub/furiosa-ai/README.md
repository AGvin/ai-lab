# FuriosaAI

FuriosaAI develops AI accelerator hardware and supporting software, including the RNGD platform.

## Producer boundary

Platform provenance is distinct from the models, applications, and deployments built by customers and integrators. Hardware specifications and runtime support belong to the linked RNGD product.
