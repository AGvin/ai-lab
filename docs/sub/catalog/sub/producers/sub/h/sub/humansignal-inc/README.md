# HumanSignal, Inc.

HumanSignal, Inc., formerly Heartex, is the company that created Label Studio and continues to advance and support the open-source project. The company identity remains distinct from Label Studio software and from Enterprise or hosted operating surfaces.

## Produces and maintains

- [Label Studio](../../../../../software/sub/model-and-data-platforms/sub/dataset-curation/sub/label-studio/) — open-source data-labeling platform produced and maintained by HumanSignal.
