# H3 Labs Inc.

H3 Labs Inc. is the company behind Maxim AI and the represented Bifrost AI gateway. `Maxim AI` remains the product/company brand while the source-backed organization identity is H3 Labs Inc.

The organization remains distinct from Bifrost software and from separately operated Maxim platform or service surfaces.
