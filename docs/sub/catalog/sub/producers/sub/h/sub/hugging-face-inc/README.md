# Hugging Face, Inc.

Hugging Face, Inc. operates the Hugging Face services and publishes the open-source projects represented here. Its [terms](https://huggingface.co/terms-of-service) and [documentation](https://huggingface.co/docs) distinguish hosted content, managed services and software projects; hosting a model does not make Hugging Face its original producer.

[ggml.ai](https://ggml.ai/) and [Argilla](https://huggingface.co/posts/dvilasuero/203008804842390) retain distinct project and producer provenance following their acquisitions by Hugging Face. The ggml team's continuing technical role is separately represented.

On September 3, 2026, [NVIDIA announced an agreement to acquire Hugging Face](https://blogs.nvidia.com/blog/nvidia-to-acquire-hugging-face/) for $12.9303 billion. The source states intentions to preserve an open platform and multi-cloud, multi-accelerator choices. Those are acquirer-stated future commitments; a completed NVIDIA ownership relation requires authoritative closing evidence.
