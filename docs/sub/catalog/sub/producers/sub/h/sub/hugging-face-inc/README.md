# Hugging Face, Inc.

Hugging Face, Inc. operates Hugging Face hosted services and publishes related open-source AI tooling represented by separate canonical catalog entities. The organization remains distinct from those services, libraries, frameworks, runtimes, and other product identities.

## Produces

- [Accelerate](../../../../../software/sub/model-and-data-platforms/sub/model-development/sub/accelerate/) — model-development library.
- [Datasets](../../../../../software/sub/model-and-data-platforms/sub/data-libraries/sub/datasets/) — data library.
- [Diffusers](../../../../../software/sub/model-and-data-platforms/sub/model-libraries/sub/diffusers/) — diffusion-model library.
- [Hugging Face Hub](../../../../../services/sub/ai-assets/sub/hugging-face-hub/) — hosted asset repository and collaboration service.
- [Hugging Face Inference Endpoints](../../../../../services/sub/infrastructure/sub/hugging-face-inference-endpoints/) — managed inference infrastructure service.
- [Hugging Face Inference Providers](../../../../../services/sub/model-apis/sub/hugging-face-inference-providers/) — model API service.
- [Hugging Face Spaces](../../../../../services/sub/infrastructure/sub/hugging-face-spaces/) — hosted application/Space service.
- [huggingface_hub](../../../../../software/sub/model-and-data-platforms/sub/hub-clients/sub/huggingface-hub/) — Hub client library.
- [PEFT](../../../../../software/sub/model-and-data-platforms/sub/model-development/sub/peft/) — parameter-efficient fine-tuning library.
- [Smolagents](../../../../../software/sub/agent-frameworks/sub/smolagents/) — agent framework.
- [Text Embeddings Inference](../../../../../software/sub/inference-runtimes/sub/inference-engines/sub/text-embeddings-inference/) — embeddings inference runtime.
- [Transformers](../../../../../software/sub/model-and-data-platforms/sub/model-libraries/sub/transformers/) — model library.
- [TRL](../../../../../software/sub/model-and-data-platforms/sub/model-development/sub/trl/) — reinforcement/fine-tuning library.

## Owns

- [Argilla](../../../../../software/sub/model-and-data-platforms/sub/dataset-curation/sub/argilla/) — data-curation platform acquired by Hugging Face in 2024; ownership does not imply current active maintenance.
- [ggml.ai](../../../g/sub/ggml-ai/) — organization represented as owned by Hugging Face while retaining a separate canonical identity.
