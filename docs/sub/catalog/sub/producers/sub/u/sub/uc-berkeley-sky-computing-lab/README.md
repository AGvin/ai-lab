# UC Berkeley Sky Computing Lab

UC Berkeley Sky Computing Lab is the research lab where vLLM originated. Its project page records the original research and contributors; later PyTorch Foundation hosting and the current community are separate from that origin.

## Producer and operating boundary

The producer relation records provenance, without implying sole current maintenance or a lab-operated inference service. Deployment, model and accelerator support, and workload-specific performance belong to the vLLM software record.
