# UC Berkeley Sky Computing Lab

UC Berkeley Sky Computing Lab is the research lab where vLLM was originally developed. That origin role is distinct from current community-driven development and current PyTorch Foundation / Linux Foundation hosting.

## Produces

- [vLLM](../../../../../software/sub/inference-runtimes/sub/inference-engines/sub/vllm/) — LLM inference engine.
