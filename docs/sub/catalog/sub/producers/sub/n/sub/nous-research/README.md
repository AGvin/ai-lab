# Nous Research

Nous Research develops the represented Hermes Agent project. Its official site and project repository establish the organization-to-project provenance. [Nous Research](https://nousresearch.com/); [Hermes Agent repository](https://github.com/NousResearch/hermes-agent).

## Scope and operating boundaries

Hermes Agent supports self-hosted use and can connect to configured model providers. The agent software license does not grant rights to every model or external service, and local software use does not by itself keep requests local when a remote provider is selected. [Hermes Agent documentation](https://hermes-agent.nousresearch.com/).
