# Neon

Neon publishes the Neon Agent Skills collection under the neondatabase organization. The project describes Neon as part of Databricks. [Collection repository](https://github.com/neondatabase/agent-skills).

## Scope and operating boundaries

The Neon platform schedule identifies Databricks, Inc. as the contracting parent of Neon, LLC. The publisher name, affiliate name, billing entity, and applicable platform agreement are therefore distinct roles. [Platform terms](https://neon.com/platform-terms).

Agent instructions and plugin packaging do not themselves supply a database service, API authorization, or a running MCP server. Repository licensing and the configured database or service permissions must be assessed at their own scopes. [Collection repository](https://github.com/neondatabase/agent-skills).
