# Netflix, Inc.

Netflix, Inc. originally developed Metaflow internally and open-sourced it in 2019. Netflix corporate governance documents establish the company identity, and the Metaflow project documents its origin. [Netflix governance](https://ir.netflix.net/governance/governance-docs/default.aspx); [Metaflow](https://metaflow.org/).

## Scope and operating boundaries

The current upstream identifies support by Outerbounds. Netflix origin provenance does not make Netflix the exclusive current maintainer or the operator of every Metaflow deployment and commercial service. Software licenses, deployment access, and support agreements remain separate. [Upstream repository](https://github.com/Netflix/metaflow).
