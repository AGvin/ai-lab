# Netflix, Inc.

Netflix, Inc. is Metaflow's origin organization. Metaflow was developed internally at Netflix before Netflix open-sourced it in 2019.

That origin provenance remains distinct from later community use and from third-party or commercial hosted Metaflow products.

## Produces

- [Metaflow](../../../../../software/sub/workflow-engines/sub/data-and-compute-orchestration/sub/metaflow/) — open-source Python data and AI workflow framework.
