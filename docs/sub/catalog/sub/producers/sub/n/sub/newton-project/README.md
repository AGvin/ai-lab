# Newton Project

Newton Project is the community project that produces Newton. Disney Research, Google DeepMind, and NVIDIA initiated the project, which is hosted by the Linux Foundation. [Project governance](https://github.com/newton-physics/newton-governance).

## Scope and operating boundaries

The Technical Steering Committee sets technical direction, while maintainers coordinate repository health and releases. Foundation hosting and contributor employer affiliations do not establish exclusive corporate ownership. Code contributions, documentation, and contribution agreements have separate conditions. [Contributor roles](https://github.com/newton-physics/newton-governance/blob/main/CONTRIBUTING.md).
