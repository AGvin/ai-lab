# Newton Project

Newton Project is the community project that produces the Newton robotics simulation engine. Its [governance repository](https://github.com/newton-physics/newton-governance) identifies it as a Linux Foundation project initiated by Disney Research, Google DeepMind, and NVIDIA.

The [project roles](https://github.com/newton-physics/newton-governance/blob/f64e05785206fac64896411ac05906039502cbab/CONTRIBUTING.md) assign technical direction to the Technical Steering Committee and release coordination to maintainers. Hosting, initiation, and technical governance are distinct parts of that provenance.
