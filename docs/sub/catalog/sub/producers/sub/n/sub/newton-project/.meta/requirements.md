# Documentation Requirements

## Requirements

- Identify Newton Project as the community project that produces Newton, grounded in the official project governance repository and contributor-role documentation.
- Distinguish Linux Foundation hosting from technical direction by the Newton Technical Steering Committee and release work by project maintainers.
- Preserve Disney Research, Google DeepMind, and NVIDIA as project initiators without converting that history into exclusive present ownership by one company or three unqualified direct-producer edges.
- Keep governance and project provenance here; keep software behavior, compatibility, installation, and security details with the Newton profile.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- The producer is the documented project/community identity, not an inferred legal entity or a duplicate company profile.
- The Newton `produces` relation is the exact inverse of its `produced-by` edge.
