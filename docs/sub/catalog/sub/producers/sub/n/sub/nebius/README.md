# Nebius

Nebius operates AI cloud infrastructure and managed model-serving platforms. On [November 5, 2025](https://nebius.com/newsroom/nebius-launches-nebius-token-factory-to-deliver-production-ai-inference-at-scale), the company introduced **Nebius Token Factory** as the evolution of **Nebius AI Studio**. These names describe the same hosted service lineage rather than separate current products.

## AI service boundary

Token Factory exposes managed, OpenAI-compatible model inference and supported post-training and dedicated deployment workflows. The platform is separate from Nebius' general GPU cloud infrastructure. Hosted third-party models retain their original publishers' licenses and restrictions.

Models, prices, quotas, account permissions, region options and retention/data-processing settings can change. Review the actual deployment mode and terms before sending confidential prompts or fine-tuning data. Keep API keys in a protected secret store.
