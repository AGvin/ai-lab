# NAVER Cloud

NAVER Cloud is the producer identity represented for HyperCLOVA X SEED. The official model license names NAVER Corporation and NAVER Cloud Corporation, with the former identified as the model IP holder and the latter as the HyperCLOVA X business operator. [SEED model license](https://huggingface.co/naver-hyperclovax/HyperCLOVAX-SEED-Vision-Instruct-3B/blob/main/LICENSE).

## Scope and operating boundaries

This producer attribution preserves those separate corporate roles. Exact model releases, downloadable weights, hosted CLOVA services, and cloud infrastructure retain their own access and license conditions; one release license is not a license for the entire portfolio. [HyperCLOVA X](https://navercorp.com/en/tech/hyperclovax).
