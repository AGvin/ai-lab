# Documentation Requirements

## Requirements

- Identify Neon as the current first-party publisher of its Agent Skills collection.
- Keep the skill collection distinct from the provider's database, application services, SDKs, hosted APIs, MCP servers and client-specific plugin packaging.
- Preserve dated upstream sources for mutable product names, supported development tooling, installed skill inventory, releases and compatibility.
- Retain original third-party attribution and version boundaries where the official collection links to an independent project.

## Validation

- The `produces` relation reciprocates the collection's `produced-by` relation.
- The producer identity is not conflated with upstream skill authors or platform integrators.

## Producer decision boundaries

- Preserve Neon as the existing publisher identity while distinguishing Databricks, Inc., Neon, LLC, and the contracting party named by the applicable platform schedule.
- Do not transfer platform service permissions or commitments to the Agent Skills collection or to independently operated integrations.
- Render the official-resources block from canonical references supporting the producer identity and stated boundaries.

These boundaries are grounded in the first-party references recorded in the current entity. Detailed product behavior remains with each related artifact.
