# Vectorize AI, Inc.

Vectorize AI, Inc. is the company behind the Hindsight open-source agent memory project and the Hindsight Cloud/enterprise offerings. The [first-party trust center](https://trust.vectorize.io/) identifies the company as Vectorize AI Inc., while the [Hindsight software license](https://github.com/vectorize-io/hindsight/blob/main/LICENSE) names Vectorize AI, Inc. as copyright holder.

## Producer and operating boundary

Open-source software stewardship, operated cloud infrastructure, and corporate legal/beneficial ownership are different claims. The vendor [describes its corporate history and investors](https://vectorize.io/about), but those materials are not a comprehensive ownership/control or sanctions audit. Do not infer any undisclosed ownership, jurisdictional risk clearance, or corporate-group relationship from project hosting.

Hindsight users may store sensitive memories across sessions and supply content to external LLMs. Cloud and self-hosted configurations have different identity, network, data-processing, payment, legal and backup responsibilities; an open-source license does not cover hosted processing.
