# Documentation Requirements

## Requirements

- Identify the verl Project/community as the current project producer identity for verl and the separately released verl-vla.
- Ground the shared identity in the verl-project repositories and official project site. Preserve verl-vla's ByteDance package-author attribution without inferring that project-origin history alone replaces the current project release identity.
- Keep core verl's LLM post-training role distinct from verl-vla's embodied vision-language-action post-training role and preserve their respective canonical software owners.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- Each `produces` edge is the exact inverse of the corresponding verl or verl-vla `produced-by` edge.
