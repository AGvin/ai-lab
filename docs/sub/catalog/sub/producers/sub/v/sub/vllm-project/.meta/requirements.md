# Documentation Requirements

## Requirements

- Identify the vLLM Project upstream community as the current project-level source for the separately released vLLM-Omni runtime.
- Preserve original UC Berkeley Sky Computing Lab authorship for upstream vLLM, its later PyTorch Foundation governance, and present community maintenance as distinct provenance concepts; do not silently rewrite historical vLLM ownership.
- Distinguish independently released software products from project-level submodules, example deployments, documentation recipes, and linked third-party models.

## Validation

- The vLLM-Omni `produced-by` relation is inversed by `produces`.
- No unsupported claim is made that vLLM-Omni represents a provider-operated hosted model API.
