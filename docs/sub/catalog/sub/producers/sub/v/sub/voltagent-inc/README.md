# VoltAgent Inc.

VoltAgent Inc. is the first-party software publisher behind the open-source [VoltAgent framework](../../../../../software/sub/agent-frameworks/sub/voltagent/), as identified by its upstream licensing and repository materials.

## Scope

The company produces the independently released `@voltagent/core` framework. Related VoltOps features do not make third-party model providers, external tools, hosts or telemetry integrations company-owned products.
