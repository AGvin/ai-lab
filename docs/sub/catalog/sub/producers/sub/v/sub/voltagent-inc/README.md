# VoltAgent Inc.

VoltAgent Inc. is the company named in the VoltAgent repository's MIT license. It publishes the TypeScript agent framework; VoltOps Console and related operational services have distinct product and deployment boundaries.

## Producer and operating boundary

The framework license does not set the terms of connected model providers or hosted telemetry. Tools and workflows can use network services, credentials and memory stores, so review their permissions and data destinations for the chosen deployment rather than inferring isolation from local installation.
