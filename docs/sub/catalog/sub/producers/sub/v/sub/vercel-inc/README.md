# Vercel Inc.

Vercel Inc. is the company behind the AI SDK, AI Gateway, Vercel Connect and Vercel Agent Skills represented here. Its current terms distinguish the operated service agreement from software supplied exclusively under an open-source license.

## Producer and operating boundary

The installable SDK and skill collection have different operating boundaries from managed routing and connector services. Routed models and connected applications retain their own providers, terms and access scopes. Review connector credentials and skill actions that can transmit project content or deploy changes.
