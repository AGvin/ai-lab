# vLLM Project

A community upstream steward of vLLM-Omni and LLM Compressor, which are independent software packages.

## Ownership boundary

The project's current stewardship is separate from historical vLLM authorship at UC Berkeley and PyTorch Foundation governance. It is not by itself a provider-operated inference API.
