# vLLM Project

The vLLM Project is the current upstream project identity for vLLM-Omni and LLM Compressor in this catalog. Their separate repositories and release lifecycles coexist with original vLLM's Berkeley origin and neutral foundation hosting.

## Producer and operating boundary

LLM Compressor retains Neural Magic and Red Hat engineering provenance while its current producer relation points to the vLLM Project. Runtime modality, model, precision and accelerator support are release-specific; upstream publication does not transfer third-party model licenses or guarantee benchmark performance on another configuration.
