# vLLM Project

A community upstream steward of vLLM-Omni and LLM Compressor, which are independent software packages.

## Ownership boundary

The project's current stewardship is separate from historical vLLM authorship at UC Berkeley and PyTorch Foundation governance. It is not by itself a provider-operated inference API.

## Relations

- Produces: [vLLM-Omni](../../../../../software/sub/inference-runtimes/sub/inference-engines/sub/vllm-omni/)
- Produces: [LLM Compressor](../../../../../software/sub/model-and-data-platforms/sub/model-optimization-and-compilation/sub/llm-compressor/) — model compression and quantization library.
