# OpenAPI Initiative

The OpenAPI Initiative (OAI) is the standards project behind the OpenAPI, Arazzo, and Overlay specifications. The published specification registry and project repositories establish their separate normative identities. [Specification registry](https://spec.openapis.org/); [OpenAPI Initiative](https://www.openapis.org/).

## Scope and operating boundaries

The Initiative is a Linux Foundation collaborative project. Foundation hosting, standards governance, and individual authors/editors are distinct roles; tool vendors and hosted API operators do not become the standards owner by implementing a specification. [Arazzo repository](https://github.com/OAI/Arazzo-Specification); [Overlay repository](https://github.com/OAI/Overlay-Specification).

A specification describes a contract or format. It does not by itself certify an implementation, grant API access, or establish the security of a deployed service. OpenAI the model producer is a separate organization.
