# Open GSD

Open GSD maintains GSD Core, the active continuation of Get Shit Done (GSD). Its origin account credits Lex Christopherson, known as Taches, with creating the original project. [Origin](https://www.opengsd.net/origin); [Current repository](https://github.com/open-gsd/gsd-core).

## Scope and operating boundaries

The maintenance relationship preserves original authorship. The current project license, agent runtime, configured model provider, and any separately operated cloud surface have their own responsibilities; the maintainer identity does not grant an agent authority over a user’s code or accounts. [GSD Core](https://www.opengsd.net/products/gsd-core); [License](https://github.com/open-gsd/gsd-core/blob/main/LICENSE).
