# Documentation Requirements

## Requirements

- Identify the OpenAPI Initiative (OAI) as the standards-governing organization for the separately published OpenAPI Specification (OAS), Arazzo Specification, and Overlay Specification, not OpenAI the model provider or any cloud platform that consumes API descriptions.
- Preserve provenance and versioned normative ownership in the published specification at `spec.openapis.org`. OpenAPI tooling implementations, code generators, clients and vendors do not replace the standards owner.
- Keep authors/editors, release version and governance distinct from provider-specific extensions and ecosystem implementation support.

## Validation

- Each of the three independent published specification identities (OAS, Arazzo, Overlay) has an exact reciprocal `produces` / `produced-by` relation.
- The organization is not confused with OpenAI or any similarly abbreviated AI provider.
