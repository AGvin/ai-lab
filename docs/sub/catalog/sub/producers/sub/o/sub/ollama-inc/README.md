# Ollama Inc.

Ollama Inc. is the company identified in the official terms for Ollama. It publishes the Ollama runtime and offers optional cloud services. [Terms](https://ollama.com/terms); [Documentation](https://docs.ollama.com/index).

## Scope and operating boundaries

Local runtime operation and cloud inference have different data paths. The privacy policy distinguishes these modes; a local installation does not establish that every selected model executes locally. [Privacy policy](https://ollama.com/privacy).

The runtime repository uses the MIT license. Downloaded model weights, hosted model access, and cloud-service terms remain separate from that software license. [Runtime license](https://github.com/ollama/ollama/blob/main/LICENSE).
