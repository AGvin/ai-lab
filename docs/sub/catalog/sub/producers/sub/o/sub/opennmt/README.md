# OpenNMT

OpenNMT is an open-source project ecosystem originally established by Harvard NLP and SYSTRAN. Its official site identifies current maintenance by SYSTRAN and Ubiqus. [OpenNMT](https://opennmt.net/index.html).

## Scope and operating boundaries

The OpenNMT project namespace is the represented upstream producer for CTranslate2, rather than a separately inferred corporation. The runtime license preserves SYSTRAN and OpenNMT Authors attribution. Converted or executed model weights and provider-operated services retain their own rights and responsibilities. [CTranslate2 repository](https://github.com/OpenNMT/CTranslate2); [License](https://github.com/OpenNMT/CTranslate2/blob/master/LICENSE).
