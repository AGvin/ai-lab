# Open WebUI Inc.

Open WebUI Inc. is the corporate copyright layer identified by the current Open WebUI distribution license. The same source credits Timothy Jaeryang Baek as creator. [Upstream license](https://github.com/open-webui/open-webui/blob/main/LICENSE).

## Scope and operating boundaries

The ownership relationship is bounded by that copyright attribution; it does not erase contributor authorship or establish exclusive rights over every historical or third-party component. The current license includes branding conditions, while earlier material retains its applicable license history. [License notice](https://github.com/open-webui/open-webui/blob/main/LICENSE_NOTICE); [License guidance](https://docs.openwebui.com/license/).

The company, deployed interface, model weights, and configured model/API providers remain separate. The interface license does not grant model rights or make every connected service company-operated.
