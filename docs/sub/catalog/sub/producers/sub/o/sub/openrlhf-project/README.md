# OpenRLHF Project

OpenRLHF Project is the upstream project identity publishing the OpenRLHF training framework through its official organization and repository. [Project repository](https://github.com/OpenRLHF/OpenRLHF); [Documentation](https://openrlhf.readthedocs.io/).

## Scope and operating boundaries

Contributor affiliations, acknowledgements, and infrastructure sponsorship do not establish exclusive corporate ownership. The framework’s Apache 2.0 license is a code license; training datasets, base models, resulting weights, and the chosen compute environment require their own provenance and operating assessment. [Framework license](https://github.com/OpenRLHF/OpenRLHF/blob/main/LICENSE).
