# Oracle

Oracle provides the represented AI Agent Studio for Fusion Applications. Official product documentation places it within the Fusion Applications environment. [Product announcement](https://www.oracle.com/applications/dawn-of-ai-enterprise-agent-workforce/).

## Scope and operating boundaries

The producer name does not establish one contract or operating policy for Fusion applications, OCI infrastructure, marketplace content, and independently configured model services. Application administrators control relevant roles and approvals, and the applicable service agreement identifies the contracting entity. [Fusion documentation](https://docs.oracle.com/en/cloud/saas/readiness/common/25c/common25c/25C-common-wn-f38824.htm); [Oracle product explanation](https://blogs.oracle.com/fusioninsider/new-oracle-ai-agent-studio-for-fusion-apps).
