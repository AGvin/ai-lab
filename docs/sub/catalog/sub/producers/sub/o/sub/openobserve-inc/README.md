# OpenObserve Inc.

OpenObserve Inc. is the company behind OpenObserve. Its service terms and enterprise license establish the corporate contracting identity. [Service terms](https://openobserve.ai/legal/terms-of-service/); [Enterprise license](https://openobserve.ai/legal/enterprise-license/).

## Scope and operating boundaries

The open-source repository license, enterprise software agreement, and hosted-service contract apply to different distribution and access scopes. A self-managed deployment also leaves telemetry collection, credentials, and storage operations with its operator. [Repository](https://github.com/openobserve/openobserve); [Repository license](https://github.com/openobserve/openobserve/blob/main/LICENSE).
