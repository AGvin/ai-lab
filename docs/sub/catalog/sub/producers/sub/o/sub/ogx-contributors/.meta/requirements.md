- Identify OGX Contributors as the currently identified project publisher/maintainer of OGX, using the first-party `ogx-ai/ogx` repository, project manifest author and MIT license; do not misstate it as the current official Meta-owned Llama Stack project.
- Record the April 2026 Llama Stack to OGX rename as the same evolving project lineage, not as concurrent independently owned product branches. Distinguish publisher, model providers, legacy SDK distributions and self-hosted server deployments.
- Keep the exact `produces` relation to `catalog/software/gateways/model-gateways/ogx` and the software's reciprocal `produced-by`. Do not invent OGX corporate ownership or external vendor product identities based on integrations.

- Producer and software relation endpoints match exactly.
