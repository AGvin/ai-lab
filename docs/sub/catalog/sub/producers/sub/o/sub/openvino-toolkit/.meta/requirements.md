# Documentation Requirements

## Requirements

- Identify the OpenVINO Toolkit project/organization as the producer identity for NNCF for catalog provenance purposes.
- Do not infer additional corporate ownership relations without separate authoritative evidence and a need for that relation.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- `produces` is the inverse of NNCF `produced-by`.
