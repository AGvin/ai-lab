# Okta

Okta provides the represented Okta for AI Agents product within its identity platform. Official product and administration documentation establish that provenance. [Product overview](https://www.okta.com/products/govern-ai-agent-identity/); [Administration documentation](https://help.okta.com/oie/en-us/content/topics/ai-agents/ai-agents-home.htm).

## Scope and operating boundaries

Okta identity controls do not make Okta the author or operator of every connected agent and application. Tenant policy, delegated user identity, granted scopes, and the target service determine what an agent can access; a producer relationship is not an authorization grant. [Delegated access guide](https://developer.okta.com/docs/guides/ai-agent-secure-third-party/main/).
