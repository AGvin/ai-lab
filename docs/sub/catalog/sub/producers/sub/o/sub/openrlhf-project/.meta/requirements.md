# Documentation Requirements

## Requirements

- Use the OpenRLHF Project/GitHub Organization as the direct producer identity for OpenRLHF.
- Do not infer a separate corporate producer from acknowledgements, infrastructure sponsorship, or historical organization names without authoritative evidence.
- Render the standard `entity-relations` block from validated current-entity relations.

## Validation

- `produces` is the inverse of OpenRLHF `produced-by`.
