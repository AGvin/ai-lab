- Identify Ollama Inc. as the organization behind Ollama software and its optional hosted/cloud services.
- Keep the producer identity distinct from the Ollama local runtime, model library entries, and cloud-model/API service surfaces.
- Render the standard `entity-relations` block from the validated current-entity relation projection.
