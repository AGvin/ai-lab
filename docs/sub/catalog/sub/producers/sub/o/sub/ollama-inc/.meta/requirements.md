## Requirements

- Identify Ollama Inc. as the organization behind Ollama software and its optional hosted/cloud services.
- Keep the producer identity distinct from the Ollama local runtime, model library entries, and cloud-model/API service surfaces.
- Link the canonical Ollama integrated inference-platform profile from the physically materialized `produces` relation when the reciprocal Ollama `produced-by` relation resolves successfully.
- Include current official Ollama site and Terms references establishing provenance.
- Keep unrelated corporate, staffing, funding, pricing, and other mutable organization details outside this concise producer profile.

## Validation

- The page does not collapse Ollama Inc., Ollama local software, and Ollama Cloud into one entity.
- The Ollama Inc./Ollama `produces` / `produced-by` relation pair is physically present at both endpoints and semantically consistent.
- The Ollama link resolves to the canonical inference-runtime profile.
- Official resource links match canonical entity metadata.
