# OGX Contributors

OGX Contributors is the project publishing and maintenance identity named in OGX metadata and its MIT license. The upstream documents OGX as the continuation of the renamed Llama Stack project. [Repository](https://github.com/ogx-ai/ogx); [Rename announcement](https://ogx-ai.github.io/blog/from-llama-stack-to-ogx).

## Scope and operating boundaries

A contributor collective, historical project name, model-provider integration, and deployed gateway are separate identities. The project attribution does not establish a new corporation or current Meta ownership. The gateway operator and configured providers determine their respective access, credentials, and service responsibilities. [Project manifest](https://github.com/ogx-ai/ogx/blob/main/pyproject.toml); [License](https://github.com/ogx-ai/ogx/blob/main/LICENSE).
