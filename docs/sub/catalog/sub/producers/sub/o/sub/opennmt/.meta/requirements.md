# Documentation Requirements

## Requirements

- Identify OpenNMT as the upstream project organization maintaining the released CTranslate2 transformer inference runtime.
- Preserve the distinction between OpenNMT as an open-source project steward, independently maintained software packages, model artifacts, and provider-operated services.
- Cite current official project repositories for project identity, release provenance, and compatibility.
