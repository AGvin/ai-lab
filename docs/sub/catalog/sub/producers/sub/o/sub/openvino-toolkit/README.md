# OpenVINO Toolkit

OpenVINO Toolkit is the upstream project identity shared by OpenVINO Runtime and the Neural Network Compression Framework (NNCF). Intel’s documentation identifies the toolkit, while the separate repositories establish the two software artifacts. [Intel toolkit documentation](https://docs.openedgeplatform.intel.com/2026.2/edge-ai-libraries/OpenVINO.html).

## Scope and operating boundaries

This project identity does not create a separate corporation or an additional ownership relation. Runtime execution and model compression remain different software responsibilities. Their code licenses do not establish rights to every input model, and hardware or driver support must be checked for the selected release. [OpenVINO repository](https://github.com/openvinotoolkit/openvino); [NNCF repository](https://github.com/openvinotoolkit/nncf).
