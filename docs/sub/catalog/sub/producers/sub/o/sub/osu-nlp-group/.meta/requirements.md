# Documentation Requirements

## Requirements

- Identify Ohio State NLP Group as first-party research publisher/steward for original Mind2Web (NeurIPS 2023), Online-Mind2Web (COLM 2025) and Mind2Web 2 (NeurIPS 2025 Datasets & Benchmarks). Do not conflate the maintained research group with all of Ohio State University or with a commercial LLM service.
- Keep the three independently released evaluation contracts separate: original offline web-action trajectories, updated real-site live browser tasks and long-horizon citation-backed search answers, with versioned metrics and access semantics owned by each dataset requirements record.
- Preserve UC Berkeley coauthors on Online-Mind2Web and other collaborating researchers on related Mind2Web works while distinguishing author affiliation from first-party GitHub project maintenance.
- Render the standard validated producer-relations block and keep exact reciprocal links for all three dataset entities.

## Validation

- Official first-party repositories under `OSU-NLP-Group` document original Mind2Web, Online-Mind2Web and Mind2Web 2 as independently published protocols.
- All three `produces` relation targets have a matching dataset `produced-by` link and current source-backed requirements.
