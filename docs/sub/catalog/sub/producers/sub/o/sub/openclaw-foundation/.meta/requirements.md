# Documentation Requirements

## Requirements

- Identify OpenClaw Foundation as the non-profit organization currently developing and stewarding OpenClaw in the open.
- Keep the foundation organization distinct from the OpenClaw software product, the Gateway component, individual contributors, and third-party channel/model providers.
- Render the standard `entity-relations` block from the validated current-entity relation projection.
- Include current official OpenClaw site and documentation references establishing foundation stewardship.
- Keep mutable governance, partner, staffing, sponsorship, and funding details outside this concise producer profile unless they become relevant to represented catalog entities.

## Validation

- The page does not collapse OpenClaw Foundation and OpenClaw into one entity.
- The `entity-relations` block matches the validated current-entity relation projection and every rendered destination resolves to a canonical node.
- Official resource links match canonical entity metadata.
