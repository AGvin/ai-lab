# ElevenLabs

ElevenLabs develops AI voice and audio technology and provides products for speech synthesis, transcription, voice agents and related audio workflows. The [official product overview](https://elevenlabs.io/docs/overview/intro) distinguishes creator-facing products, agent workflows and the programmatic **ElevenAPI**.

## Hosted API boundary

**ElevenLabs API** is the hosted developer interface to supported speech and audio capabilities. It uses API credentials and product-specific model/endpoint configurations. The API identity is separate from ElevenLabs as the producer, any specific underlying voice model, the hosted ElevenAgents application and third-party SDK/client libraries.

Supported models, voice permissions, languages, usage limits, prices and regional/data-processing options can differ by account, endpoint and release. Check the current documentation and applicable terms for the intended workload rather than treating one example as a universal contract.

Voice cloning, audio and transcripts may include personal or biometric data and protected performances. Use lawful source material with appropriate permissions and consent, limit credential access and review retention and contractual data-processing settings before production use.
