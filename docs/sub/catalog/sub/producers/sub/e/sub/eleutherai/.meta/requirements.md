# Documentation Requirements

## Requirements

- Identify EleutherAI as the research collective maintaining the released Language Model Evaluation Harness; distinguish harness software and included third-party benchmark implementations from the original benchmark creators, model providers and leaderboard operators.
- Keep this producer identity independent of datasets authored by outside benchmark contributors, evaluated third-party models and infrastructure used in running evaluations.
- Render the standard `entity-relations` block from validated current-entity relations and include the official publishing repository alongside the organization site.

## Validation

- The publisher's official site/repository substantiates stewardship of the maintained software.
- The `produces` relation reciprocates the software entity's exact `produced-by` target.
