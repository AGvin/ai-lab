# Epoch AI

Epoch AI is the research organization that creates and publishes FrontierMath benchmarks with contributing mathematicians.

## Producer boundary

Benchmark creation and evaluation are distinct from sponsorship and problem ownership. Epoch's disclosure describes an OpenAI-commissioned problem set and its access restrictions; that arrangement should not be generalized to every FrontierMath program.
