# Qdrant Solutions GmbH

Qdrant Solutions GmbH is the legal-name producer profile associated with the Qdrant vector-search engine. Qdrant's official imprint identifies that company, and the engine is published in the qdrant GitHub organization. The catalog also retains the Qdrant brand profile for its managed cloud offering; the two labels do not establish two unrelated businesses. [Company imprint](https://qdrant.tech/legal/impressum/) · [Engine repository](https://github.com/qdrant/qdrant).

## Scope and operating boundaries

The engine repository declares Apache-2.0 licensing. Self-managed operators choose the deployment, access policy, storage and upgrades; Qdrant Cloud supplies a separate managed-service arrangement. An open-source engine license does not grant hosted capacity or define the cloud service's customer-data commitments. [Engine repository](https://github.com/qdrant/qdrant) · [Cloud documentation](https://qdrant.tech/documentation/cloud/).
