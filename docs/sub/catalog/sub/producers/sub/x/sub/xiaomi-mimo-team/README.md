# Xiaomi MiMo Team

Xiaomi MiMo Team is the producing team identified by the MiMo site and official XiaomiMiMo model registry. The MiMo family is separate from Xiaomi corporate identities, consumer devices and hosted MiMo product surfaces.

## Producer and operating boundary

Checkpoint licenses, architecture code, inference requirements and publication revisions must be checked per model. Registry examples that load custom model code require review of that code and its pinned revision. Publishing a new checkpoint does not automatically complete catalog intake or expand the team's canonical family membership.
