# SpaceXAI LLC

SpaceXAI LLC is the legal producer organization identified in the current terms, which use SpaceXSI as its public name. The existing xAI and SpaceXAI names preserve continuity. SpaceX's February 2026 acquisition is corporate provenance, separate from the legal contracting entity and public brand.

## Producer and operating boundary

The Grok model family, assistant, Bot, Build, API and Collections retain distinct identities and operating boundaries. Consumer subscriptions do not establish developer API entitlements. Persistent Bot computers, connected accounts, API credentials and uploaded collections require product-specific permission and data-handling review.
