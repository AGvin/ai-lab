# Specifications

The specifications catalog owns identifiable formal or normative artifacts whose primary identity is a specification rather than a software product, service, model, hardware item, dataset, producer, Agent Skill, concept, or learning topic.

Versioned normative claims remain tied to authoritative upstream specifications and their applicable revisions. Implementations, SDKs, runtimes, products, support matrices, tutorials, and explanatory concepts remain with their own owners.
