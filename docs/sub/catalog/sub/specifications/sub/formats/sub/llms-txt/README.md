# llms.txt

`llms.txt` is the current llmstxt.org v2 proposal and emerging convention for publishing a concise agent-readable website or documentation index. It is not a ratified IETF, W3C, or universally required web standard.

## Proposal boundary

A file may be published at `/llms.txt` or beneath another path and describes pages under its path; when multiple files apply, the most specific applicable file takes precedence. Under the current v2 proposal, the H1 project or site name is the only required content section. Optional summary/detail content and H2-delimited resource sections support progressive disclosure, with list items linking to detailed resources.

The proposal is distinct from `robots.txt`, sitemaps, crawler permissions, authentication, search indexing, RAG infrastructure, and runtime interoperability protocols. The current v2 proposal does not define `llms-full.txt`; ecosystem-specific variants must not be treated as normative here.
