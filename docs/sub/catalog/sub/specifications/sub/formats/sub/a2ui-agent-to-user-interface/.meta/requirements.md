# Documentation Requirements

## Requirements

- Present A2UI as a declarative JSON format and accompanying evolving protocol for agent-generated UI, not as executable UI source or standalone transport.
- Keep first-party early public-preview status and the reviewed v0.9.1 stable protocol family versus v1.0 release candidate distinction date-scoped.
- Describe host-controlled component allowlists/renderers and the separation between UI intent, transport (A2A, AG-UI) and renderer implementation.
- Explain that a declarative format does not remove untrusted input, component-injection, unsafe action, permission or third-party asset risks.

## Validation

- Canonical identity and first-party references match the current frozen cohort source lead.
- Version and source maturity are explicit and no implementation, availability or conformance is invented.
