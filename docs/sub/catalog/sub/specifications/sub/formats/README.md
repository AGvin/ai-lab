# Formats

The formats specification group owns identifiable formal file, serialization, graph-exchange, model-artifact, agent-readable-document, and related data-format contracts.

Placement here identifies a specification-class artifact; it does not imply that every child is a ratified standard. Version, proposal maturity, normative fields, encoding rules, and compatibility semantics remain scoped to the applicable upstream specification. Runtime support, conversion guidance, performance findings, and deployment recommendations belong to their software, learning, evidence, or decision owners.
