# Standards

The standards specification group owns identifiable published or active normative artifacts whose upstream identity is a standard, guide, recommended practice, Technical Report, or Technical Specification with durable AI relevance.

Artifact class and maturity are preserved exactly. A Technical Report, Technical Specification, guide, or recommended practice is not silently upgraded into a mandatory certification requirement. Version, edition, amendment, corrigendum, lifecycle, conformance, and status remain scoped to authoritative upstream records.
