# IEEE 3378-2025

IEEE 3378-2025 is the active IEEE Framework and Process for Large-Scale Deep Learning Model Evaluation.

## Standard boundary

The standard defines supported task classes, evaluation metrics, and evaluation requirements for large-scale deep-learning models. It is not a concrete benchmark dataset, leaderboard, model card, product certification program, AI-server performance benchmark, or agent-evaluation standard.

The standard number remains IEEE 3378-2025 even though the active standard was published in January 2026.
