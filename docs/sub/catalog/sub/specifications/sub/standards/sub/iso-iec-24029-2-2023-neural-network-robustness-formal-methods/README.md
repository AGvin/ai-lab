# ISO/IEC 24029-2:2023

ISO/IEC 24029-2:2023 is the published Part 2 standard for using formal methods to assess robustness properties of neural networks.

## Standard boundary

Part 2 is methodology-specific and remains distinct from Part 1's overview and from still-unpublished statistical-methodology work. Formal-method examples do not imply support for a particular verifier, neural-network architecture, or benchmark.

The page preserves the released Part 2 identity and revision state without reproducing normative text.
