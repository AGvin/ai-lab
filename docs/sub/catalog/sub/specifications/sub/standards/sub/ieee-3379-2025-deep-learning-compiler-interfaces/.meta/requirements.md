# Documentation Requirements

## Requirements

- Identify IEEE 3379-2025 as the active IEEE standard specifying technical architecture, flow, functions, and input/output parameters for deep-learning compiler interfaces.
- Preserve its compiler-interface/interoperability scope rather than treating it as a particular compiler implementation, model-optimization product, accelerator ISA, or inference runtime.
- Keep the standard distinct from IEEE 3549 inference-optimization systems and from concrete compilers such as TVM, IREE, Olive, Optimum, or NNCF.
- Preserve active-standard lifecycle and avoid reproducing normative text.

## Validation

- The entity is represented as the published active standard rather than its project/draft state.

## Scoped original-source qualification — 2026-11-08

- **IEEE 3379-2025** is an **active IEEE Standard**, approved **2025-12-10** and published **2026-06-19**. Its edition remains **2025** despite publication occurring in 2026; the public original-source abstract covers deep-learning compiler interface architecture, interface flows, functions and input/output parameters.
- This compiler-interface interoperability specification is distinct from actual compiler code, an accelerator instruction set, the inference-system optimizations addressed by IEEE 3549 or proof of cross-vendor implementation compatibility.
- Verified original publisher source: https://standards.ieee.org/ieee/3379/11305/
- The scoped gate verifies the existing standard identity, current published lifecycle and official synopsis only. Complete licensed text, compiler execution, hardware tests, independent security/legal/conformance review, repository-wide validation, clean and final gates remain unperformed.
