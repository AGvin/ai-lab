# ISO/IEC 23053:2022

ISO/IEC 23053:2022 is the published International Standard defining a framework for describing AI systems that use machine learning.

## Standard boundary

The released standard remains distinct from reusable ML-system concepts and from under-development amendments such as Generative AI amendments. Draft or developing amendments do not become part of the released 2022 identity until publication.

Edition, amendment, corrigendum, revision, and conformance state are version-sensitive.
