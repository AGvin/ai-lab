# WebGPU Shading Language

WebGPU Shading Language (WGSL) specifies the shader source language associated with WebGPU, including type rules, parsing, validation and execution semantics. It is distinct from the WebGPU JavaScript API and from native GPU hardware/software backends.
## Standards maturity
The [26 October 2026 W3C WGSL publication](https://www.w3.org/TR/2026/CRD-WGSL-20261026/) is a **Candidate Recommendation Draft**, not a final Recommendation. Its [working Editor's Draft](https://gpuweb.github.io/gpuweb/wgsl/) may differ. Version-specific validation, optional language features and implementation limits must be checked before relying on them.
A common shader language does not imply identical hardware capabilities, security boundaries or runtime speed across browsers and graphics drivers.
