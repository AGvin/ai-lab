# ISO/IEC 25059:2023

ISO/IEC 25059:2023 is the currently published Edition 1 SQuaRE quality-model standard for AI systems.

## Standard boundary

The formal quality model remains distinct from local evaluation guidance and benchmark results. Edition 1 is published but expected to be replaced by a future Edition 2; an under-development FDIS is not treated as the released replacement until publication.
