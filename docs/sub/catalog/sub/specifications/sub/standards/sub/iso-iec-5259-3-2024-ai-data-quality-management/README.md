# ISO/IEC 5259-3:2024

ISO/IEC 5259-3:2024 is the published Part 3 standard for data-quality management requirements and guidelines for analytics and machine learning.

## Standard boundary

Part 3 owns management requirements and guidance. It remains distinct from Part 4's operational process framework and Part 5's governance framework.
