# Documentation Requirements

## Requirements

- Identify ISO/IEC 23053:2022 as the published international standard defining a framework for describing AI systems that use machine learning.
- Keep the formal standard artifact distinct from reusable ML-system concepts and from under-development amendments such as the Generative AI amendment until those amendments are published.
- Preserve the exact edition/year and treat amendments, corrigenda, revision state, and conformance interpretations as freshness-sensitive.
- Do not promote under-development amendments into the current released standard identity.

## Validation

- Placement follows the artifact's upstream International Standard identity even though `framework` appears in its title.
- AI Lab summaries do not substitute for the normative standard text.

## Scoped original-source qualification — 2026-11-07

- ISO/IEC 23053:2022 is the published **Edition 1 (June 2022) International Standard** defining a conceptual framework and common components/functions for describing AI systems built using machine learning. It supplies a system description vocabulary, not an executable ML training framework or a performance certification.
- ISO records a Generative AI Final Draft Amendment 1 and an additional amendment under development as of November 2026. These drafts do not modify the currently released 2022 base edition until formally published. Runtime support, model architecture and compliance interpretations are separate matters.
- Verified first-party source 1: https://www.iso.org/standard/74438.html
- Verified first-party source 2 (unpublished amendment context only): https://www.iso.org/standard/88149.html
- Existing standard identity/source scope accepted only from official public metadata. Full copyrighted normative framework, amendments, conformance and model testing were not accessed or independently validated; no full repository schema/cache/CI/render, clean pass or final gate.
