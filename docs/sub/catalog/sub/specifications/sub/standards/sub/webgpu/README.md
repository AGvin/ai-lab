# WebGPU

WebGPU defines a web-platform API for GPU-backed graphics and compute operations, including adapters, devices, resources, commands, supported features and limits. Its associated shading language WGSL is a **separate** specification.
## Revision and implementation boundary
The [15 September 2026 W3C publication](https://www.w3.org/TR/2026/CRD-webgpu-20260915/) is a **Candidate Recommendation Draft**. The [GPU for the Web Editor's Draft](https://gpuweb.github.io/gpuweb/) was dated **30 October 2026** when reviewed and may contain newer or unsettled proposals. Neither status is a final W3C Recommendation.
Real browser and GPU support, feature flags, shader limits, driver behavior, numerical results and performance require their own testing. Using the API is not proof of secure or accelerated model execution.
