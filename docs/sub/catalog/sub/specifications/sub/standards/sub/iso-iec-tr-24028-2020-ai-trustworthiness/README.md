# ISO/IEC TR 24028:2020

ISO/IEC TR 24028:2020 is the published Technical Report providing an overview of trustworthiness in artificial intelligence.

## Report boundary

It surveys trustworthiness topics, threats, pitfalls, mitigations, and assessment approaches across attributes such as reliability, resilience, safety, security, privacy, transparency, explainability, and controllability. The report is not a quantitative trust score, certification scheme, or product-security standard.

Dedicated risk, bias, robustness, security, transparency, and explainability standards remain separate artifacts.
