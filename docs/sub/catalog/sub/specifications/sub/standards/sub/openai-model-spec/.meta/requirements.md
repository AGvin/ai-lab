# Documentation Requirements

## Requirements

- Present the 29 October 2026 OpenAI Model Spec as versioned guidance for intended GPT model behavior and instruction hierarchy, not an API schema or formal W3C/ISO standard.
- Explain the publisher's explicit statement that production models do not yet fully reflect the published Model Spec.
- Keep instruction precedence, safety, honesty, human agency and behavioral principles tied to the chosen edition; avoid claims of deployed-model guarantees.
- Distinguish this policy/behavioral specification from OpenAI API documentation, product usage policy, independent evaluation and legal compliance.

## Validation

- Canonical identity and first-party references match the current frozen cohort source lead.
- Version and source maturity are explicit and no implementation, availability or conformance is invented.
