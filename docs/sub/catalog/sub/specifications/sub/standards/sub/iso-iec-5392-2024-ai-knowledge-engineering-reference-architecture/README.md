# ISO/IEC 5392:2024

ISO/IEC 5392:2024 is the published International Standard defining a reference architecture for knowledge engineering in AI.

## Standard boundary

The standard covers knowledge-engineering roles, activities, layers, components, relationships, and vocabulary. It remains distinct from concrete knowledge-graph products, RAG architectures, ontologies, vector databases, and AI Lab explanatory concepts.
