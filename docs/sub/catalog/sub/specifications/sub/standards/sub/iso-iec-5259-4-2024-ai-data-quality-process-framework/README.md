# ISO/IEC 5259-4:2024

ISO/IEC 5259-4:2024 is the published Part 4 data-quality process framework for analytics and machine learning.

## Standard boundary

Part 4 addresses operational process structure and remains distinct from Part 3 management requirements and Part 5 governance responsibilities.
