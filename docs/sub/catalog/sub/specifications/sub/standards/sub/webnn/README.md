# Web Neural Network API

The Web Neural Network API (WebNN) specifies an interface for accelerating neural-network **inference** through supported devices and graph operations. It does not provide model checkpoints, neural-network training tooling or a full application framework.
## Publication and support boundary
The [26 June 2026 W3C publication](https://www.w3.org/TR/2026/CRD-webnn-20260626/) is a **Candidate Recommendation Draft**; the separate [Editor's Draft](https://webmachinelearning.github.io/webnn/) is mutable. The specification is not a final W3C Recommendation.
Browser support, backend coverage, operations and data-type limits are implementation-specific. Test deployment and correctness, and apply platform privacy and execution-security controls rather than assuming the API is available or uniformly accelerated.
