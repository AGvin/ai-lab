# Documentation Requirements

## Requirements

- Identify WebNN as a browser-side low-level inference graph API, not a pretrained model or a general framework.
- Pin normative graph operations, tensors, contexts, execution controls and capability limits to the 21 October 2026 Candidate Recommendation Draft.
- Keep updated Editor's Draft and subsequent implementation status independent of the dated published report.
- Do not promise browser/hardware availability, universal speedups, identical numerical results or privacy security from standards status.

## Validation

- Canonical identity and first-party references match the current frozen cohort source lead.
- Version and source maturity are explicit and no implementation, availability or conformance is invented.

## Scoped original-source qualification — 2026-11-07

- WebNN defines a browser-side graph API for neural-network inference, not a pretrained model, checkpoint, training framework or AI provider. Operations, tensor types, graph compilation and execution controls belong to the W3C Web Machine Learning specification, while browser, accelerator and backend support remain implementation-specific.
- W3C publication history confirms the latest published **Candidate Recommendation Draft dated 21 October 2026**, superseding the 26 June 2026 draft previously quoted in canonical metadata and the reader. It is not a final Recommendation; working Editor's Draft and feature maturity are distinct.
- Verified first-party source 1: https://www.w3.org/standards/history/webnn/
- Verified first-party source 2: https://www.w3.org/TR/webnn/
- Existing source/identity and revised publication boundary accepted only; no browser support, accelerator, benchmark, model correctness, user privacy, protocol conformance or repository-wide schema/cache/CI/render, clean/final gate or merge credit.
