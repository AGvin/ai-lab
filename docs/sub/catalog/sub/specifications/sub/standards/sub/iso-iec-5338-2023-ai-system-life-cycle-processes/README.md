# ISO/IEC 5338:2023

ISO/IEC 5338:2023 is the published International Standard defining AI-system life-cycle processes and associated concepts.

## Standard boundary

The formal process standard is distinct from AI Lab explanatory lifecycle concepts, project-management practices, and software-development frameworks. It informs lifecycle and process decision support without replacing those implementation-oriented owners.
