# ITU-T F.748.74 — Requirements and Framework for Evaluation of Multimodal Foundation Models

**ITU-T F.748.74 (06/2026)** is an **in-force ITU-T Recommendation** covering requirements and an evaluation framework for multimodal foundation models. The official record gives **June 13, 2026** as its approval date and lists an English publication artifact posted on **September 8, 2026**. [ITU-T edition record](https://www.itu.int/rec/T-REC-F.748.74-202606-I/en).

## Standard and measurement boundary

The Recommendation is a framework for assessing multimodal models, not itself a benchmark dataset, public model leaderboard, evaluator implementation or validation of a specific model's score. Detailed evaluation dimensions, measurement methods and conformance interpretation require the correct edition and normative text.

## Applicability and verification

Publication does not show that an independently operated model has been evaluated under this framework, that its scores are reproduced, or that it is safe or suitable for every workload. Amendments, corrigenda and successors must be checked against current ITU-T records.
