# IEEE 2937-2022

IEEE 2937-2022 is the active IEEE Standard for Performance Benchmarking for Artificial Intelligence Server Systems.

## Standard boundary

It defines formal methods, metrics, measures, and tool requirements for benchmarking AI server, cluster, and HPC systems. The standard is distinct from a concrete accelerator benchmark suite, model benchmark, procurement requirement, MLPerf result, or vendor performance claim.
