# ISO/IEC TR 24029-1:2021

ISO/IEC TR 24029-1:2021 is the published Part 1 overview of methods for assessing neural-network robustness.

## Report boundary

Part 1 provides the overview layer. Methodology-specific formal and statistical assessment parts remain separate artifacts. The report is not a general AI-trustworthiness standard, model-safety policy, adversarial-security tool, or concrete robustness benchmark.
