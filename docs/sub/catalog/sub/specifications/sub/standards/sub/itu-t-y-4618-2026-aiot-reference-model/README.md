# ITU-T Y.4618 — Artificial Intelligence of Things Reference Model and Requirements

**ITU-T Y.4618 (06/2026)** is an **in-force ITU-T Recommendation** establishing an Artificial Intelligence of Things (AIoT) reference model and system requirements. It was approved on **June 29, 2026**; the official final-edition page lists the English PDF as posted on **September 3, 2026**. Earlier prepublication records must not be mistaken for the current final-edition availability. [ITU-T final-edition record](https://www.itu.int/rec/T-REC-Y.4618-202606-I/en).

## Architecture boundary

The public reference model addresses distributed AI, data and IoT capabilities across device, edge and cloud, and interoperability and operational requirements at those layers. This formal specification is distinct from concrete IoT or robotics hardware, cloud platforms, edge frameworks, inference runtimes and application protocols.

## Evidence and deployment boundary

The Recommendation's existence does not itself validate a product's latency, privacy, security, governance, resilience or conformity. Use the applicable edition and separately verify system design, implementation, regulatory context and any future amendments. This catalog profile does not claim an AIoT deployment or independent conformance test.
