# Agent Control Standard

Agent Control Standard (ACS) is an open runtime-control standard and wire-format specification for an observed AI agent to submit lifecycle, tool, and context activity to a separate Guardian.

## Standard boundary

The Guardian may permit, deny, modify, ask about, or defer actions under an auditable control contract. The published versioned specification and conformance definitions are normative authority; the published v0.1-series contract, repository maintenance versions, and staged proposals remain distinct lifecycle states.

ACS can control or wrap interactions involving protocols such as MCP and A2A, but it is not a replacement for those interoperability protocols. Guardian implementations, SDKs, instrumentation adapters, example policies, and deployment guidance remain separate from the standard identity.
