# ISO/IEC 8183:2023

ISO/IEC 8183:2023 is the published International Standard defining an AI data-life-cycle framework.

## Standard boundary

The framework covers stages and associated data-processing actions from acquisition or creation through development, deployment, maintenance, and decommissioning. It is distinct from concrete data platforms, dataset-curation products, governance tooling, and the ISO/IEC 5259 data-quality series.
