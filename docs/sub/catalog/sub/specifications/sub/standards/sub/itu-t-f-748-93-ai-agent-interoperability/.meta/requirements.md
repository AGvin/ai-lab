# Documentation Requirements

## Requirements

- Present ITU-T F.748.93 as the approved ITU-T Recommendation `Framework and Requirements for AI Agent Interoperability`, formerly developed as `F.AAI`.
- Distinguish the approved Recommendation from draft/proposal-stage agent interoperability documents and from implementation protocols such as A2A or MCP.
- Keep scope, approval date/status, normative requirements, referenced architecture elements, and revision identifiers traceable to current ITU-T work-programme/publication records.
- Treat later amendments, corrigenda, successor Recommendations, and numbering/title changes as freshness-sensitive.

## Validation

- The standard remains under `specifications/standards` rather than `protocols`.
- Current approval/status claims resolve to ITU-T first-party records.

## Scoped original-source qualification — 2026-11-08

- **ITU-T F.748.93 (08/2026)** is an **in-force (prepublished) Recommendation** for **Framework and Requirements for AI Agent Interoperability**, approved on **2026-08-29**; the original ITU-T work programme identifies its former working title **F.AAI**. Public recommendation record still states **To be published**, so approval must not be confused with downloadable final edition.
- Standards-level agent interoperability framework and requirements remain separate from concrete Agent2Agent/MCP protocol releases, SDK implementations, trusted agent identity, transport conformance or tested cross-vendor interoperability.
- Verified original publisher sources: https://www.itu.int/rec/T-REC-F.748.93-202608-I/en and https://www.itu.int/ITU-T/workprog/wp_item.aspx?isn=23620
- Existing Recommendation identity, formal approval/edition and first-party scope are accepted only, without unavailable final normative publication, authenticated agent interaction, independent governance/legal/security audit, repository-wide validation, clean or final credit.
