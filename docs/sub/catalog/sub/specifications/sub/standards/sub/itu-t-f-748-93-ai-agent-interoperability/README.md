# ITU-T F.748.93

ITU-T F.748.93 is the approved ITU-T Recommendation **Framework and Requirements for AI Agent Interoperability**, formerly developed as F.AAI.

## Standard boundary

The approved Recommendation is distinct from draft or proposal-stage interoperability documents and from implementation protocols such as A2A or MCP. Scope, approval status, normative requirements, referenced architecture elements, and revision identifiers remain tied to current ITU-T publication and work-programme records.

Later amendments, corrigenda, successor Recommendations, and numbering or title changes are freshness-sensitive.
