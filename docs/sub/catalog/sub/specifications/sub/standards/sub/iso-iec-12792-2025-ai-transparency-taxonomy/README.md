# ISO/IEC 12792:2025

ISO/IEC 12792:2025 is the published International Standard providing a transparency taxonomy for AI systems.

## Standard boundary

The artifact owns a formal transparency taxonomy and terminology boundary. It is distinct from legal transparency obligations, explainability techniques, model cards, organization-specific disclosure policy, and IEEE 2894 architectural guidance.

Edition and revision state remain version-sensitive; this page identifies the standard without reproducing its normative text.
