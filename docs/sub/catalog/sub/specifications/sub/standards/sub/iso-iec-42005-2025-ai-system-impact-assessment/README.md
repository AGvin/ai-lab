# ISO/IEC 42005:2025

ISO/IEC 42005:2025 is the published International Standard for AI-system impact-assessment guidance.

## Standard boundary

The artifact remains distinct from general AI risk management, AI management-system requirements, regulatory impact-assessment mandates, and organization-specific templates. Its lifecycle impact-assessment purpose is described only at the scope supported by current ISO metadata; mandatory procedural detail must not be invented from secondary summaries.

Revisions, mappings, implementation guidance, and regulatory references remain freshness-sensitive.
