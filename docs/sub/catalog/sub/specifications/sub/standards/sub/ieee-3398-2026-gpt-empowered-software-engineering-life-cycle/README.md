# IEEE 3398-2026 — Generative Pre-trained Transformer Empowered Software Engineering Life Cycle

**IEEE 3398-2026** is an IEEE recommended practice for applying GPT-based capabilities across the software engineering life cycle. IEEE SA marks it **Active Standard**, with Standards Board approval on **September 25, 2026**, and describes it as an **Approved Draft Recommended Practice**. A distinct final-publication date is not established by that approval alone. [IEEE publisher record](https://standards.ieee.org/ieee/3398/11380/).

## Scope and application boundary

The publisher's public description concerns intelligence levels, competencies and evaluation approaches across requirements, design, coding, testing, delivery and operations. It is neither a software-development agent nor a benchmark result, endorsement of a model provider or certification that a particular coding tool achieves a claimed capability level.

Actual level definitions, assessment procedures and normative obligations must be checked against the licensed edition and any revisions. Applying a practice to a development process does not automatically validate the quality, security or correctness of resulting software.
