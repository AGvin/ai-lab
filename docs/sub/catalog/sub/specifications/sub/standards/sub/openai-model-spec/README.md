# OpenAI Model Spec

The OpenAI Model Spec is a public document describing intended behavior for OpenAI GPT models. It covers instruction precedence, safe use, honesty, human agency and response behavior. This is a publisher-authored behavioral specification, **not** an API wire format, an ISO standard or a certification.
## Edition and limits
This record uses the [29 October 2026 edition](https://model-spec.openai.com/2026-10-29.html). OpenAI states that its **production models do not yet fully reflect the Model Spec**, and it continues refining both the guidelines and model behavior. Publication is not proof that any deployed model behaves in exactly the same way or fulfills legal obligations.
Treat this edition as a dated source and check the [current Model Spec](https://model-spec.openai.com/) before claiming present behavior.
