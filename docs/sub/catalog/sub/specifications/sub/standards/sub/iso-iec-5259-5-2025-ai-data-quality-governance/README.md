# ISO/IEC 5259-5:2025

ISO/IEC 5259-5:2025 is the published Part 5 governance framework for organizational oversight of data quality in analytics and machine learning.

## Standard boundary

Part 5 owns governance-level responsibilities. It remains distinct from Part 3 management requirements and Part 4 operational process guidance.
