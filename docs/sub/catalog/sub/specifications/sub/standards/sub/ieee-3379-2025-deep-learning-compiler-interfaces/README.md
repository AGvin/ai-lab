# IEEE 3379-2025

IEEE 3379-2025 is the active IEEE Standard for Interfaces of Deep Learning Compiler on Artificial Intelligence.

## Standard boundary

It specifies technical architecture, flow, functions, and input/output parameters for deep-learning compiler interfaces. The standard is distinct from concrete compiler implementations, model-optimization products, accelerator ISAs, inference runtimes, and IEEE 3549's inference-optimization-system scope.
