# Documentation Requirements

## Requirements

- Identify IEEE 3378-2025 as the active IEEE standard defining supported task classes, evaluation metrics, and evaluation requirements for large-scale deep-learning models.
- Preserve its cross-cutting model-evaluation framework identity rather than treating it as a concrete benchmark dataset, leaderboard, model card, or product certification program.
- Keep model-specific benchmark results, agent evaluation, AI-server performance benchmarking, and domain-specific evaluation standards separate.
- Preserve the standard number/year while noting that publication occurred in January 2026.

## Validation

- The entity is represented as the published active standard rather than its earlier project/draft state.
