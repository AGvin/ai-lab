# IEEE 2894-2024

IEEE 2894-2024 is the active IEEE Guide for an Architectural Framework for Explainable Artificial Intelligence.

## Standard boundary

The guide covers XAI concepts, method classes, application scenarios, architecture, and evaluation. It is not a particular explainability library, a legal transparency mandate, or the same artifact as ISO/IEC 12792's transparency taxonomy.

This page identifies the published 2024 guide rather than its earlier draft project.
