# Documentation Requirements

## Requirements

- Present ITU-T Y.4615 (06/26) as the in-force Recommendation for an AIoT on-device framework and requirements for robot services.
- Preserve its standards-level framework/requirements identity rather than treating it as a concrete robot runtime, agent framework, hardware platform, or implementation protocol.
- Keep implementation products such as Strands Robots, LeRobot, Isaac ROS/Sim/Lab, concrete robots, and model runtimes with their canonical software/hardware/model owners.
- Treat later amendments, corrigenda, successor Recommendations, detailed framework elements, and conformance requirements as freshness-sensitive to current ITU-T publication records.

## Validation

- Approval date and in-force status remain traceable to ITU-T first-party records.
- The Recommendation remains under standards rather than software or protocols.

## Scoped original-source qualification — 2026-11-08

- **ITU-T Y.4615 (06/2026)** is an **in-force Recommendation**, approved **2026-06-29**, covering **Artificial Intelligence of Things — on-device framework and requirements for robot services**. The original publisher lists an English final-edition PDF posted **2026-09-01**, distinct from its earlier prepublication lifecycle.
- The public summary addresses on-device robotic AI/IoT integration, local processing, real-time response and diverse hardware environments. This reference framework is not a deployed robot, verified runtime, ML model, robotics safety assessment or conformance test for any Isaac/LeRobot or third-party stack.
- Verified original publisher sources: https://www.itu.int/rec/T-REC-Y.4615-202606-I and https://www.itu.int/dms_pubrec/itu-t/rec/y/T-REC-Y.4615-202606-I%21%21SUM-HTM-E.htm
- Source gate covers canonical identity, edition/approval, in-force status and publicly provided summary only. No physical robot, system/security/legal/safety audit, full repository schema/cache/CI/render, clean or final credit.
