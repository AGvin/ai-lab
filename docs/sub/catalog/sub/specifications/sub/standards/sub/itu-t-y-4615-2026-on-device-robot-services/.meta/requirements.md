# Documentation Requirements

## Requirements

- Present ITU-T Y.4615 (06/26) as the in-force Recommendation for an AIoT on-device framework and requirements for robot services.
- Preserve its standards-level framework/requirements identity rather than treating it as a concrete robot runtime, agent framework, hardware platform, or implementation protocol.
- Keep implementation products such as Strands Robots, LeRobot, Isaac ROS/Sim/Lab, concrete robots, and model runtimes with their canonical software/hardware/model owners.
- Treat later amendments, corrigenda, successor Recommendations, detailed framework elements, and conformance requirements as freshness-sensitive to current ITU-T publication records.

## Validation

- Approval date and in-force status remain traceable to ITU-T first-party records.
- The Recommendation remains under standards rather than software or protocols.
