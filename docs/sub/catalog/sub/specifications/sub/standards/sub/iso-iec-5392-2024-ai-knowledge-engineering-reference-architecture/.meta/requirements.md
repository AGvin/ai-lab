# Documentation Requirements

## Requirements

- Identify ISO/IEC 5392:2024 as the published international standard defining a reference architecture, roles, activities, layers, components, relationships, and vocabulary for knowledge engineering in AI.
- Keep the standard distinct from concrete knowledge-graph products, RAG architectures, ontologies, vector databases, and AI Lab explanatory concepts.
- Preserve edition/revision state and avoid reproducing normative text.

## Validation

- The entity remains a formal knowledge-engineering architecture standard rather than a software implementation.

## Scoped original-source qualification — 2026-11-07

- ISO/IEC 5392:2024 is the published **Edition 1 (March 2024)** International Standard defining an AI knowledge-engineering reference architecture. Its ISO public abstract covers roles, activities, structural layers, components and relationships, plus common terminology from user and functional perspectives.
- The reference architecture is not an implemented ontology, database, knowledge graph, RAG system or certified interoperability stack. Whether a concrete product maps to these roles or benefits from them requires independent implementation evidence and access to the authoritative text.
- Verified original publisher source: https://www.iso.org/standard/81228.html
- Public ISO identity, published edition/status and abstract only are source-qualified; no copyrighted normative clause reproduction, deployment or testing, quality/security certification, whole-repo schema/cache/CI/render, clean pass or final gate.
