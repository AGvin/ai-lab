# ISO/IEC TR 24368:2022

ISO/IEC TR 24368:2022 is the published Technical Report providing a high-level overview of ethical and societal concerns in artificial intelligence.

## Report boundary

It surveys concern sources, principles, processes, and relevant standards without prescribing one ethical value system, certifying products, or replacing organization-specific governance and impact-assessment practices. Dedicated bias, transparency, risk, governance, and beneficial-AI artifacts remain separate.
