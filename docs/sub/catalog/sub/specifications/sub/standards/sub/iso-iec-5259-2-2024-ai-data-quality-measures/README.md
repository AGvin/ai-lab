# ISO/IEC 5259-2:2024

ISO/IEC 5259-2:2024 is the published Part 2 standard defining a data-quality model and measures for analytics and machine learning.

## Standard boundary

Its formal data-quality measures are distinct from implementation-specific monitoring metrics, dataset scorecards, and the management, process, or governance concerns owned by other parts of the ISO/IEC 5259 series.
