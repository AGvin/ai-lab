# Semantic conventions

The semantic-conventions specification group owns identifiable formal specifications that define interoperable telemetry or data semantics through named attributes, span or event conventions, and equivalent normative vocabularies.

Semantic conventions remain distinct from transport protocols, serialization formats, validation schemas, broader standards, SDKs, instrumentation libraries, collectors, and observability products. Version and stability labels remain part of the applicable upstream specification.
