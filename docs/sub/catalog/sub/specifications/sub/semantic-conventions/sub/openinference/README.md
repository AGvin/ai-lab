# OpenInference Semantic Conventions

OpenInference is an open semantic-convention specification for AI and LLM application telemetry built on OpenTelemetry primitives.

## Specification boundary

OpenInference defines common traces, spans, attributes, and related AI-observability semantics. It is not a transport protocol, telemetry backend, observability product, or replacement for OpenTelemetry. OpenInference adds AI-specific semantic conventions on top of the broader OpenTelemetry ecosystem.

Span-kind and attribute semantics remain tied to current authoritative specification material and its stability labels. Instrumentation packages and language implementations are implementations of the specification rather than separate specification identities.
