# x402

x402 is an open internet-native payment protocol that uses HTTP `402 Payment Required` flows so clients, including applications and AI agents, can programmatically pay for resources and services.

## Protocol boundary

The current released x402 v2 specification is the normative baseline. Payment requirements and payloads, facilitator interfaces, schemes, transports, extensions, and security semantics remain version-sensitive.

Payment-network-specific schemes, facilitator services, SDK behavior, and provider integrations remain separate from the core protocol. x402 is also distinct from broader agent-commerce protocols and from other HTTP-402 payment specifications such as Machine Payments Protocol; sharing a transport primitive does not make them the same protocol.
