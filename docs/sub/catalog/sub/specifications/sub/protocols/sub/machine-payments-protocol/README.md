# Machine Payments Protocol

Machine Payments Protocol (MPP) is a protocol for machine and agent payments to web and API services.

## Protocol boundary

MPP is extensible across payment methods and service integrations. Relays, SDK or harness integrations, identity support, EVM or x402 compatibility, provider integrations, and payment-method implementations are protocol capabilities or ecosystem surfaces rather than separate protocol identities.

Protocol and SDK versions, supported payment methods or chains, integrations, live endpoints, and release status are freshness-sensitive. MPP is not itself a hosted payment service.
