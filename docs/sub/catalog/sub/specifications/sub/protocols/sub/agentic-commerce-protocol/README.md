# Agentic Commerce Protocol

Agentic Commerce Protocol (ACP) is an open specification for programmatic commerce flows among buyers, AI agents, sellers, and payment providers.

## Protocol boundary

ACP covers Agentic Checkout, delegated payment, capability negotiation, extensions, trust boundaries, and protocol versioning. Current official material identifies Stripe and OpenAI as original developers, but the specification identity is not reduced to a single producer.

Active API-version headers, schema fields, extensions, payment-handler revisions, participating platforms, and implementation status are freshness-sensitive. ACP remains distinct from the unrelated Agent Client Protocol that also uses the acronym ACP.
