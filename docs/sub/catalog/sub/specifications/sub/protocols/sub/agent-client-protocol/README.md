# Agent Client Protocol

Agent Client Protocol (ACP) is a JSON-RPC-based interoperability protocol between code editors or other clients and coding agents.

## Protocol boundary

ACP defines a client-agent interoperability contract rather than one editor or coding-agent implementation. Stable version-1 wire behavior remains distinct from explicitly experimental later protocol work. Client- or agent-specific capabilities belong to their product owners and are not protocol guarantees.

This ACP is distinct from Model Context Protocol, Agent2Agent Protocol, AG-UI, and the unrelated Agentic Commerce Protocol that also uses the acronym ACP.
