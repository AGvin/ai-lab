# Agent2Agent Protocol

Agent2Agent Protocol (A2A) is an open interoperability protocol for independently implemented AI agents to discover capabilities, communicate, coordinate, and delegate work across systems and organizational boundaries.

## Protocol boundary

The current stable specification is the normative authority. A2A reached the stable production-ready v1.0 milestone, but exact operations, bindings, task or message objects, discovery, authentication, versioning, and extension rules remain revision-sensitive.

A2A is not a generic agent framework and does not replace Model Context Protocol. A2A primarily coordinates agents with agents, while MCP primarily connects an agent or application to tools, data, and context; systems may use both.
