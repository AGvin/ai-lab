# Agent Payments Protocol

Agent Payments Protocol (AP2), also called Agentic Payment Protocol, is an open protocol for securing agent-performed payment transactions.

## Protocol boundary

AP2 defines an explicit agent-authorization model with signed mandates or receipts, verification responsibilities, and dispute evidence. The current research baseline is released revision v0.2; roles, mandates, receipts, authorization flows, and evidence semantics remain version-sensitive.

AP2 is not a complete commerce protocol or payment processor. It supplies payment-authorization and transaction-security semantics that can operate inside broader commerce flows such as Universal Commerce Protocol. SDKs, sample implementations, network integrations, and provider services remain separate identities.
