# Agent User Interaction Protocol

Agent User Interaction Protocol (AG-UI) is an open, lightweight, event-based protocol for bidirectional communication between agentic backends and user-facing applications.

## Protocol boundary

AG-UI standardizes interaction-layer concepts such as agent state, UI intent, streamed output, and user interaction flows between frontends and agents. It is distinct from Model Context Protocol and Agent2Agent Protocol: MCP primarily connects agents or applications to tools and context, A2A coordinates agents with agents, and AG-UI connects agents with user-facing applications.

Event types, transport details, SDK bindings, package versions, and framework integrations are version-sensitive implementation details and are not intrinsic protocol identity.
