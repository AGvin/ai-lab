# Universal Commerce Protocol

Universal Commerce Protocol (UCP) is an open interoperability protocol for agentic commerce across participating platforms and businesses.

## Protocol boundary

UCP defines common commerce services, capabilities, schemas, discovery or profile conventions, and transport contracts. The current research baseline is release `v2026-08-25`; individual date-versioned capabilities or services may evolve independently and must not be assumed to advance in lockstep.

UCP owns the broader commerce interaction surface, while Agent Payments Protocol supplies compatible payment-authorization and transaction-security semantics. A2A, MCP, AP2, and payment handlers are interoperable only where the current UCP specification explicitly defines that relationship; they are not interchangeable protocol identities.
