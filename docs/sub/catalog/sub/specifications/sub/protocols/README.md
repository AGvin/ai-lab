# Protocols

The protocols specification group owns identifiable formal communication and interoperability protocol contracts.

Exact methods, fields, headers, message structures, capabilities, transports, authorization rules, extensions, deprecations, and compatibility behavior are versioned normative state and must be interpreted against the active first-party specification. Product-specific clients, servers, SDKs, support matrices, and implementation bugs remain outside the protocol identity.
