# GeneBench-Pro

GeneBench-Pro is OpenAI's research-level computational-biology benchmark/dataset for judgment-heavy agent analyses across genomics, quantitative biology, translational medicine, and related domains.

## Dataset boundary

The benchmark is described as 129 synthetic problems with controlled data-generating processes. Its full benchmark identity is distinct from public distribution: OpenAI publicly releases representative case studies and has announced a separate subset for independent benchmarking rather than publishing all problems as one open corpus.

The benchmark dataset remains separate from model rankings, evaluation results, the isolated execution workspace and tool stack, and generic benchmark methodology. Question counts, public subsets, third-party access, scoring setup, and model results are freshness-sensitive.
