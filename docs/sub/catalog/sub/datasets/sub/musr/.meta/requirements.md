# Documentation Requirements

## Requirements

- Identify the original MuSR dataset and its task-domain JSON releases, not the model evaluation code, hosted provider service or study conclusions.
- Record task subset, source revision, prompts, model revision, scoring configuration, answer extraction and optional caching for reproducibility.
- Distinguish narrative task scenarios from real-world conduct or factual claims; do not treat fictional mystery content as real evidence.
- The upstream root LICENSE is MIT for covered material, without implied rights to all external datasets and model providers.
- No model calls, scoring, dataset import, dependency audit, complete rights check or whole-catalog clean pass were performed.

## Validation

- Match exactly one frozen first-party dataset candidate and the canonical parent index link.
- Keep source assets, evaluator, license scope and model results distinct; no unperformed tests, rights audits or clean gates are implied.
