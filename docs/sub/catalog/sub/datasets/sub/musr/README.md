# MuSR

**MuSR** (Multistep Soft Reasoning) is a benchmark of multi-step reasoning that demands integration of narrative facts and commonsense implications, including murder-mystery-style puzzles. The pinned upstream README places task JSON under `datasets/{domain_name}.json` and evaluation scripts under `eval/`.

## Reproducibility and rights

The project's root **MIT LICENSE** applies to covered repository materials. Third-party model providers, underlying source material and generated benchmark content require independent review. Results depend on exact task family, prompts, sampled model, scoring script and output parsing.
