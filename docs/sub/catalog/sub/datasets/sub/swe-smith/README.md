# SWE-smith

**SWE-smith** — synthetic software engineering training tasks and generated environments.

## Data and evaluation boundary

The publisher describes roughly 50k generated training instances built from real GitHub repositories using test-breaking task synthesis. Its toolkit, dataset, environment Docker images, agent trajectories and resulting trained models are separate. The hosted original monolithic dataset card says it is no longer actively updated in favor of language-specific releases.

The [pinned original source README](https://github.com/SWE-bench/SWE-smith/blob/9b74ac08118a85c39c356802f7961893af73e07f/README.md) provides the release identity and version boundary. Benchmark tasks, source materials, evaluation harnesses, hosted datasets, trained models and reported results are separately attributable.

## Rights, limitations and safety

MIT covers the original repository's granted code, not necessarily source project licenses, inherited issue text, Docker images or training trajectories. Running task-generated patches and test suites requires isolated containers and authorized source access.

This record is an evidence-backed metadata profile only: no benchmark datasets, model requests, untrusted programs, containers, real accounts, or external integrations were executed. No comprehensive license review or repository-wide CI was run.
