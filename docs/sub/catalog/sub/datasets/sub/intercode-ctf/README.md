# InterCode-CTF

**InterCode-CTF** — isolated capture-the-flag tasks for interactive coding agents.

## Data and evaluation boundary

The dedicated source README describes instances originally collected from picoCTF. Each includes task query, correct flag, source URL, tags and task-specific files; the agent interacts with a sandboxed Bash shell and submits a flag for exact-match grading. This CTF dataset is distinct from InterCode's SQL, Bash, Python suites and execution framework.

The [pinned first-party source](https://github.com/princeton-nlp/intercode/blob/c3e46d827cfc9d4c704ec078f7abf9f41e3191d8/data/ctf/README.md) establishes the identity and release scope. Related model outputs, scoring programs, downloaded task materials and historical leaderboard measurements remain separate artifacts.

## Rights, limitations and safety

The pinned InterCode repository's MIT LICENSE does not automatically grant redistribution of original picoCTF challenges, third-party binaries or authored solutions. Use only isolated authorized CTF environments; do not deploy challenge binaries on production networks or treat tasks as permission for intrusion.

No benchmark datasets were downloaded and no evaluator, model, untrusted code, harmful safety prompt or physical experiment was executed. No full rights audit or repository-wide CI was run.
