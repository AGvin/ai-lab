# MMIU

**MMIU** — vision-language reasoning across multiple related images.

## Data and evaluation boundary

The first-party ICLR 2025 project reports seven multi-image relationship types, 52 tasks, around 77k images and 11k carefully curated questions. Its external Hugging Face dataset, recommended VLMEvalKit evaluator, and archived leaderboard reports are distinct sources with version-sensitive results.

The [pinned original publisher README](https://github.com/OpenGVLab/MMIU/blob/642001df618a57d65869ef3975021deabfbcc891/README.md) establishes dataset identity and version. Training data, test assets, model weights, evaluation software, hosted services and benchmark scores remain separately attributable.
