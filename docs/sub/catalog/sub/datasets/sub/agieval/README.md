# AGIEval

AGIEval collects human admissions and qualification exam tasks for studying foundation-model reasoning. The pinned README describes v1.1 with 20 tasks (18 multiple-choice and two cloze) and corrections to selected Chinese Gaokao exam data. Model scores depend on language, selected exam, prompts and the original scoring setup.

## Dataset and evaluation boundaries

The official pinned README describes v1.1 with 20 tasks, including 18 multiple-choice and two cloze tasks; v1.1 updated Gaokao sources and corrected labels.
Question data can include passage, question, options, label and answer fields. Prompting, source exams, language, scoring and version differ by task.

## Licensing, reproducibility and responsible use

MIT repository; underlying exams have separate rights. A repository MIT license does not override original exam publisher rights. No exams were redistributed, benchmark run, rights clearance made, or full clean pass performed.
