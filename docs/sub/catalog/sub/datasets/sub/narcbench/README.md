# NARCBench

**NARCBench** — detecting multi-agent collusion under distribution shift.

## Data and evaluation boundary

The repository documents Core committee deliberations, zero-shot Transfer scenarios and steganographic Stego scenarios. Scenario/activation data are hosted separately on Hugging Face; probe training and verdict-transfer analyses are experimental pipelines rather than additional benchmark dataset identities.

The [pinned first-party README](https://github.com/aaronrose227/narcbench/blob/237fe60739502007693b6455c6c644606ab3bcbb/README.md) is the identity and version source. Data, benchmark tasks, evaluator software, trained models and published leaderboards must be attributed separately.
