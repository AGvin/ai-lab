# SOSBench

**SOSBench** — Controlled scientific safety-alignment evaluation with adversarial prompts and research-use conditions, distinct from ordinary scientific QA and harmful actionable instructions.

## Data and evaluation boundary

The publisher documents a 3,000-example training split over several sensitive scientific domains. Its safety-research benchmark, rubric, possible outputs and scoring methods are separately governed; publicly reproducing harmful prompts or model responses may spread risky material.
