# Documentation Requirements

## Requirements

- Treat LAB-Bench as one biology research evaluation dataset, not a wet-lab validation or a separate dataset identity for every task category.
- The pinned publisher README describes eight broad categories and thirty subtasks involving literature, databases, supplemental materials, figures, tables, protocols, sequences and cloning scenarios.
- Approximately 80 percent of tasks are public and 20 percent are held out for contamination monitoring; do not expose the private subset.
- Reproducibility requires exact task set, data and image revisions, model configuration, tool access and answer scoring. The evaluation harness requires Python 3.10+.
- The root source LICENSE uses CC BY-SA 4.0. Check underlying papers, figures, source publications and dataset assets independently.
- No dataset download, model evaluation, lab operation, complete rights audit or whole-catalog clean pass was carried out.

## Validation

- A unique frozen source-backed dataset identity and correctly indexed canonical profile.
- Source-data rights, code, scores and model services remain distinct; unperformed tests receive no acceptance credit.
