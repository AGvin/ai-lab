# LAB-Bench

**LAB-Bench** is a scientific biology research-task benchmark covering literature, database retrieval, figures, tables, biological protocols, sequences and related reasoning. The official README identifies eight broad categories and thirty subtasks. Approximately 80% is public; the remaining 20% is held out to detect contamination. The public benchmark and private evaluation set form one benchmark family, not separate catalog identities.

## Reproducibility and usage rights

The evaluation harness, model inputs and papers are separate resources. The publisher's root LICENSE is CC BY-SA 4.0 for covered material, but journal figures and other original sources may have additional terms. Biological task prompts do not validate actual experimental procedures. No live evaluation or complete source-rights audit was performed.
