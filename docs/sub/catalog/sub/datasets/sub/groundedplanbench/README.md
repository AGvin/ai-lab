# GroundedPlanBench

GroundedPlanBench is a released benchmark for spatially grounded long-horizon task planning in robot-manipulation scenarios.

## Dataset boundary

The released scope contains 1,009 tasks derived from 308 DROID scenes, explicit and implicit instruction variants, and action-location grounding for grasp, place, open, and close planning. V2GP training methodology, the DROID source data, robot hardware, evaluated vision-language models, and real-world validation experiments remain separate from the benchmark identity.

Task inventory, annotations, evaluation protocol, and reported model results are freshness-sensitive.
