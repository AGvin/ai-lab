# BIG-Bench Extra Hard (BBEH)

**BIG-Bench Extra Hard (BBEH)** is an independently published reasoning-evaluation dataset from Google DeepMind, designed as a harder successor to **BIG-Bench Hard** (BBH) while targeting related reasoning skills.

## Dataset scope

The [pinned publisher README](https://github.com/google-deepmind/bbeh/blob/80d12ca916b7158f22293fcf3144f4d3d854d4be/README.md) reports **4,520 examples** in the full release and **460 examples** in its mini configuration. These are two versions of the **same** BBEH dataset family, not two extra catalog identities. The repository contains evaluation code separately from the task data; the associated leaderboard is evidence of particular historical runs, not an independently verified model ranking.

The pinned repository has been archived. Repeatable experiments should record full versus mini subset, prompt templates, answer extraction, versioned scoring code and the exact model configuration.
