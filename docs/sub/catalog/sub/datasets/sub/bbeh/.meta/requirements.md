- Identify BIG-Bench Extra Hard (BBEH) as its own original reasoning dataset family, related to but distinct from BIG-Bench Hard (BBH). No duplicate identity for its full/mini configurations or official evaluation script.
- Pinned README states 4,520 full examples and 460 mini examples. Do not silently equate these subsets, BBH problems or model leaderboard results.
- The first-party repository is archived at the verified HEAD; this is a historical official snapshot, not evidence of current software maintenance or live scoring support.
- Original root LICENSE is Apache-2.0. Confirm source-level scope and separate rights for any third-party inserted tasks or separately mirrored data before redistribution.
- Record task subset, prompt, answer extractor, scoring implementation, model version and context settings. Avoid broad statements that high BBEH scores prove general reasoning abilities.
- No dataset download, evaluation script execution, model scoring, source audit, license audit beyond the pinned root or whole-catalog clean pass was performed.

## Validation
