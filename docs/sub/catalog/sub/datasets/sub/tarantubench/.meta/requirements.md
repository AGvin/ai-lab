# Documentation Requirements

## Requirements

- Pin the 100-lab v1 identity; separate generator, data and harness; require strict isolation, lab authorization and no unsafe code execution.
- Pin original first-party repository/README version and distinguish dataset, evaluation harness, external inputs, model outputs and historical results.
- Rights and safety: The pinned root MIT license covers repository material within that grant, not necessarily the proprietary generator or separately hosted data assets. Vulnerable synthetic applications must run only in isolated authorized labs with no public network exposure; benchmark access is not permission to attack third-party systems.
- Source-backed metadata-only acceptance; no data/model downloads, code execution, live services, generated output, comprehensive rights audit or independent benchmark reproduction.
- Maintain one canonical identity and resolvable parent Datasets link without duplicate acceptance gates.

## Validation

- Entity metadata, source revision, requirements and reader must be consistent.
- Do not credit unperformed YAML/schema parsing, complete renderer/cache closure, repo-wide CI or whole-catalog clean passes.
