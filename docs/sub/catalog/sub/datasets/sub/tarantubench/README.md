# TarantuBench v1

**TarantuBench v1** — isolated synthetic vulnerable web challenge evaluation for agents.

## Data and evaluation boundary

The publisher's v1 release reports 100 synthetic vulnerable web-application labs, each scored using a task-specific hidden flag. The open harness, downloadable lab JSONL, generated local Node.js applications and proprietary generation engine are separate components, with benchmark claims tied to versioned task setups.

The [pinned original publisher README](https://github.com/Trivulzianus/TarantuBench/blob/68c79bc786379d813bcb0111f86c18668f47f89a/README.md) establishes dataset identity and version. Training data, test assets, model weights, evaluation software, hosted services and benchmark scores remain separately attributable.

## Rights, limitations and safety

The pinned root MIT license covers repository material within that grant, not necessarily the proprietary generator or separately hosted data assets. Vulnerable synthetic applications must run only in isolated authorized labs with no public network exposure; benchmark access is not permission to attack third-party systems.

No dataset or model was downloaded, no benchmark or unsafe program was executed, and no complete rights audit, scientific reproduction, source code evaluation or repository-wide CI was run.
