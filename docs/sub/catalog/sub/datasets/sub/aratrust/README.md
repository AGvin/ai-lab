# AraTrust

**AraTrust** — Arabic-language trustworthiness evaluation dataset covering multiple aspects of language-model safe and reliable behavior.

## Data and evaluation boundary

The publisher card cites the 2024 AraTrust study on LLM trustworthiness in Arabic and identifies Arabic text data, with fewer than 1,000 samples in its metadata size class. It does not independently support scores, complete category counts or effectiveness claims here.

The [original publisher dataset card](https://huggingface.co/datasets/asas-ai/AraTrust) was checked on 2026-11-05 (publisher last modified 2024-05-07). An immutable HF revision SHA was not available from connected metadata; the research reference below provides additional first-party identification, not a license for unrelated material.

## Rights, limitations and safety

The dataset card reports MIT licensing, which does not automatically cover any reused Arabic-language source content or model completions. Evaluate culturally and linguistically appropriate safety outcomes; avoid extrapolating a single score to real-world trustworthiness.

**Access:** public. **Publisher-listed license:** MIT (HF metadata). No records, models, generated code, audio, images or evaluators were downloaded/executed. No complete rights audit or scientific reproduction was performed.
