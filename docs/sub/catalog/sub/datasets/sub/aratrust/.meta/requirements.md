# Documentation Requirements

## Requirements

- Pin Arabic language scope, the 2024 original research citation, publisher MIT metadata and separation of dataset content from model outputs without inventing counts.
- Preserve original first-party identity and distinguish dataset from models, grading software, training sets and externally hosted results.
- Rights and safety: The dataset card reports MIT licensing, which does not automatically cover any reused Arabic-language source content or model completions. Evaluate culturally and linguistically appropriate safety outcomes; avoid extrapolating a single score to real-world trustworthiness.
- Original publisher dataset card reviewed 2026-11-05, last modified 2024-05-07; HF metadata did not expose an immutable revision SHA.

## Validation

- Verify entity metadata, publisher card, secondary original research, requirements and navigation.
- No model testing, original dataset download, full rights audit, repository-wide schema checking, CI or clean-pass credit.
