# EVMbench

**EVMbench** — smart-contract auditing, patching and exploit evaluation.

## Data and evaluation boundary

The pinned upstream project defines detect (submitted audit report), patch (submitted code diff) and exploit (submitted transactions) modes, with separate task splits and hidden gold solutions. The official project README says maintenance moved to paradigmxyz/evmbench on April 8, 2026. This commit is a historical publisher snapshot, not the current maintenance head.

The [original publisher source](https://github.com/openai/frontier-evals) and [pinned publisher README](https://github.com/openai/frontier-evals/blob/b78dab1da774a6456b1ed9c48c9ff194ee3ff36d/project/evmbench/README.md) establish this specific release. Source data, evaluation software, model weights, scoring outputs and historical leaderboards are independently attributable.

## Rights, limitations and safety

The project/evmbench directory has Apache-2.0 despite differing parent repository terms; audited contracts, vulnerability corpora and container dependencies may have their own rights. Never run exploits or generated transactions against public networks, production chains or third-party contracts.

This is an evidence-backed metadata profile only. No benchmark inputs, model inference, untrusted code, audio, private data or security experiment was executed or downloaded. No complete rights audit or whole-repository CI was performed.
