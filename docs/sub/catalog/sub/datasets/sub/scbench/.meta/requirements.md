- Keep publisher-reported 195 total benchmark tasks distinct from six published example specifications; clarify that withheld evaluation data cannot be independently audited from the checked repository.
- Use the pinned original publisher README and retain the frozen source identity; separate the dataset from evaluation software, model weights and leaderboards.

Data provenance, de-identification and independent clinical/scientific validation are required before reuse. The publisher's benchmark results are not independently reproduced.
