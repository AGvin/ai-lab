# CORE-Bench

**CORE-Bench** — agent reproducibility of computational research experiments.

## Data and evaluation boundary

The official description gives 270 tasks from 90 papers across computer science, social science and medicine, with Python/R repositories and result questions. The benchmark's original harness is no longer actively maintained; the publisher now recommends the Holistic Agent Leaderboard harness. Encrypted task JSON and external code capsules are separate assets.

The [pinned first-party source](https://github.com/siegelz/core-bench/blob/e32a2980e72fe6eb04ee04eb749458f570625663/README.md) establishes the identity and release scope. Related model outputs, scoring programs, downloaded task materials and historical leaderboard measurements remain separate artifacts.

## Rights, limitations and safety

The pinned MIT license applies only to covered repository materials. Original papers, downloaded computational capsules, data dependencies and evaluation containers may have separate rights. Reproduction requires isolated resource-limited execution and independent scientific verification; no claims of reproduced results are warranted here.

No benchmark datasets were downloaded and no evaluator, model, untrusted code, harmful safety prompt or physical experiment was executed. No full rights audit or repository-wide CI was run.
