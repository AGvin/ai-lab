# SciAgentArena

SciAgentArena is a released cross-domain benchmark for evaluating AI agents on interactive real-world scientific-research scenarios.

## Dataset boundary

The benchmark covers approximately 200 tasks across multiple scientific domains with stepwise verification and an agent-agnostic interactive environment. Evaluated agents or models, scientific software, task-domain source material, and benchmark-harness components remain separate from the benchmark identity unless independently materialized.

Task inventory, domain coverage, verification criteria, harness versions, baselines, and reported results are freshness-sensitive. Claims about agent strengths or failures remain tied to the applicable release and evaluation configuration.
