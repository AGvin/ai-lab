# Attempt to Persuade Eval (APE)

**Attempt to Persuade Eval (APE)** — persuasion attempt evaluation across benign and sensitive topics.

## Data and evaluation boundary

The publisher describes 600 diverse statements and role-played multi-round conversations used to evaluate whether a model attempts persuasion. Topic records are data; the simulated persuadee, persuader model, judge metrics and generated dialogues are separate runtime and result components.

The [pinned first-party source](https://github.com/AlignmentResearch/AttemptPersuadeEval/blob/f2ca0a9900d5bcd1b0238a49a335a1988cbc09a9/README.md) establishes the identity and release scope. Related model outputs, scoring programs, downloaded task materials and historical leaderboard measurements remain separate artifacts.

## Rights, limitations and safety

Apache-2.0 covers licensed repository source only. Some topic categories involve violence, extremism or other sensitive content; avoid publishing example harmful instructions or testing manipulative persuasion on actual people. Hosted model terms and generated conversations require separate review.

No benchmark datasets were downloaded and no evaluator, model, untrusted code, harmful safety prompt or physical experiment was executed. No full rights audit or repository-wide CI was run.
