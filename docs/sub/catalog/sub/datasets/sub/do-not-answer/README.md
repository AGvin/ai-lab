# Do-Not-Answer

**Do-Not-Answer** — LibrAI research benchmark of harmful instructions that models should appropriately decline; human annotation, harm taxonomy, model-based evaluation and published outputs are separate resources.

## Data and evaluation boundary

The publisher describes 939 annotated requests organized in a multi-level taxonomy of five broad risk areas, twelve harm types and 61 specific harms. Scoring uses response assessment via human and model-based evaluation; an external evaluator model is not itself an additional benchmark dataset.
The [pinned first-party README](https://github.com/Libr-AI/do-not-answer/blob/460703484df354958a5e1cd7378a38fcb94a2f3e/README.md) is the primary source; the dataset is distinct from model services and result leaderboards.

## Rights, limitations and safety

The root source is Apache-2.0 for covered material, without automatically clearing all hosted datasets or annotations. The prompts may describe harmful conduct: avoid reproducing unsafe instructions in documentation or running them without a controlled safety-research protocol.

No benchmark datasets were downloaded and no models, generated programs or full repository CI were executed.
