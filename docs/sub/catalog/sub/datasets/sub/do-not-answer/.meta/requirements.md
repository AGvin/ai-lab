# Documentation Requirements

## Requirements

- Describe only the safety/refusal benchmark and high-level taxonomy; do not reproduce unsafe prompt content.
- Preserve dataset version, model outputs, human annotation and evaluator revision separately.
- Do not infer universal compliance from benchmark outcomes or code license from external content.
- No unsafe prompts executed, models invoked, comprehensive rights audit or clean pass performed.
- Keep one frozen dataset identity, source-appropriate licensing distinctions, and a valid parent category link.

## Validation

- Metadata, requirements and reader should be source-backed and consistent.
- No unperformed runtime, comprehensive rights verification, or whole-catalog clean gate credit.
