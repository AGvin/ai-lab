# MACHIAVELLI

**MACHIAVELLI** — reward-versus-ethics decisions in text adventure agents.

## Data and evaluation boundary

The original publisher describes over half a million scenes with millions of annotations in a larger game environment; the evaluated benchmark selects 30 games. Separate downloaded story content, an auxiliary artificial-conscience model, agent trajectories, game engine and historical behavior scores do not represent additional task identities.

The [pinned first-party README](https://github.com/aypan17/machiavelli/blob/ebb44e197f663603427882c609dbc9d5fb883d63/README.md) establishes the identity and release scope. Data, licensed original inputs, evaluation software, agent protocols and historical results are distinct artifacts.

## Rights, limitations and safety

MIT at the code repository root does not establish rights to all human-authored choice-game stories, annotations or separately downloaded model weights. Game licenses and character narratives require verification before redistribution; no ethical behavior, player impact or outcome guarantees can be inferred from agent scores.

This profile is source-backed metadata only. No model, benchmark, credentials, user data, generated code, security test, exploit or third-party service was executed. No full rights audit or repository-wide CI was run.
