# MedCalc-Bench

**MedCalc-Bench** — Research dataset measuring medical clinical calculation tasks from patient-note-style questions with numeric answers and worked solutions. A separate newer MedCalc-Bench-Verified project and its dataset must not be silently treated as this original release.

## Dataset and evaluation boundary

The first-party repository describes **55 medical calculation tasks**, with **10,543 training** and **1,100 evaluation instances**, each containing a synthetic or source clinical note, calculation question, final value and solution steps. A later verified dataset is separately linked as a successor; published results must identify which version was used.
The [pinned first-party README](https://github.com/ncbi-nlp/MedCalc-Bench/blob/20b10f9d66a8c3b0356ae3138533f5ec91666b6a/README.md) describes this benchmark snapshot.

## Rights and limitations

No root LICENSE was found at the pinned original repository snapshot; source visibility does not establish redistribution or commercial permissions for the questions or associated medical notes. Patient-like data and clinical calculations require appropriate privacy and safety handling. Benchmark accuracy is not a clinical calculator certification.

No dataset was downloaded, model tested, full source rights reviewed or whole-catalog clean pass executed.
