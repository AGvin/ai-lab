# AgencyBench

AgencyBench is a released benchmark/dataset for evaluating autonomous agents on long-horizon real-world workflows across multiple capability classes.

## Dataset boundary

AgencyBench combines broad task and scenario coverage, tool use, user simulation, Docker-based execution, and visual or functional evaluation. Benchmark harnesses, evaluation scripts, and sample runs remain surfaces of the same dataset identity rather than separate products.

Task and scenario counts, capability coverage, evaluation implementation, and released versions are freshness-sensitive. AgencyBench remains distinct from narrower research, operations-research, and memory or continual-learning benchmarks.
