# LongBench v2

**LongBench v2** — multi-domain reasoning over long documents and structured contexts.

## Data and evaluation boundary

The v2 release contains 503 multiple-choice questions with contexts ranging from roughly 8k to 2M words across single/multi-document QA, in-context learning, long dialogue, repository understanding and structured data. Its predecessor is maintained under a separate LongBench subdirectory; v1 and v2 results must not be mixed.

The [pinned original source README](https://github.com/THUDM/LongBench/blob/2e00731f8d0bff23dc4325161044d0ed8af94c1e/README.md) provides the release identity and version boundary. Benchmark tasks, source materials, evaluation harnesses, hosted datasets, trained models and reported results are separately attributable.

## Rights, limitations and safety

The pinned source repository has MIT terms; the separately hosted LongBench-v2 dataset carries its own license metadata and upstream document/code context rights need independent review. Context contamination, retrieval settings, model versions and inference budgets can change results.

This record is an evidence-backed metadata profile only: no benchmark datasets, model requests, untrusted programs, containers, real accounts, or external integrations were executed. No comprehensive license review or repository-wide CI was run.
