# BIG-bench (original)

**BIG-bench (original)** — broad collaborative language-model capability evaluation.

## Data and evaluation boundary

The pinned original benchmark documents more than 200 tasks covering diverse language-model capabilities, with BIG-bench Lite selecting 24 JSON tasks. BIG-Bench Hard is a different 23-task research selection. Original task files, programmatic evaluation, code dependencies and historical leaderboard scores have distinct versions and rights.

The [original publisher source](https://github.com/google/BIG-bench) and [pinned publisher README](https://github.com/google/BIG-bench/blob/092b196c1f8f14a54bbc62f24759d43bde46dd3b/README.md) establish this specific release. Source data, evaluation software, model weights, scoring outputs and historical leaderboards are independently attributable.

## Rights, limitations and safety

The archived repository provides Apache-2.0 for its covered code; individual community contributions and external benchmark materials may have additional terms. Do not run untrusted tasks without isolation or treat archived leaderboard output as current verification.

This is an evidence-backed metadata profile only. No benchmark inputs, model inference, untrusted code, audio, private data or security experiment was executed or downloaded. No complete rights audit or whole-repository CI was performed.
