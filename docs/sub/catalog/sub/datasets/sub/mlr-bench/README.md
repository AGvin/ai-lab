# MLR-Bench

**MLR-Bench** — agent performance on open-ended research proposal and experimentation tasks.

## Data and evaluation boundary

The source reports 201 research problems from 2023–2025 ICLR, ICML and NeurIPS workshop material, grouped into nine ML topics. The hosted task dataset, MLR-Agent scaffold and LLM-driven MLR-Judge are independent components; grade quality is contingent on rubric, reviewer model and environment.

The [pinned original source README](https://github.com/chchenhui/mlrbench/blob/f728d571a992d71c8b526eeb4d9ab6bb5c8cc824/README.md) provides the release identity and version boundary. Benchmark tasks, source materials, evaluation harnesses, hosted datasets, trained models and reported results are separately attributable.

## Rights, limitations and safety

MIT applies to licensed repository content but does not automatically grant rights to original workshop submissions, research source papers or hosted model outputs. Real experiments or generated programs require sandboxing and source verification; LLM review scores are not validated research impact.

This record is an evidence-backed metadata profile only: no benchmark datasets, model requests, untrusted programs, containers, real accounts, or external integrations were executed. No comprehensive license review or repository-wide CI was run.
