# Documentation Requirements

## Requirements

- Identify CyberMetric as an evaluation question dataset for cybersecurity knowledge, not vulnerability discovery software, a model, a penetration-testing tool, or an authorization to target systems.
- Pinned first-party README describes four dataset sizes: CyberMetric-80 (80), -500 (500), -2000 (2,000) and -10000 (10,000) questions, with source-derived, RAG-assisted generation and human expert validation.
- Original sources include standards, certifications, technical publications and books. Human validation of relevance does not establish that all original source excerpts are unencumbered or that generated questions are free from training-set contamination.
- No repository-root LICENSE file was found at the pinned commit. Do not infer code redistribution, dataset copying or commercial usage rights solely from public GitHub visibility. Review specific upstream hosted dataset rights before use.
- Scores require exact subset, model, answer matching, prompt, random seed and evaluation protocol. Cybersecurity knowledge accuracy does not establish hands-on security skill or safe agent behavior.
- No dataset downloaded, questions revalidated, model assessed, source rights cleared or whole-catalog clean pass was performed.

## Validation

- Match one frozen dataset candidate with a canonical indexed entity and pinned first-party evidence.
- Do not count benchmark data as proof of legal rights, runtime evaluation or repository-wide clean validation.
