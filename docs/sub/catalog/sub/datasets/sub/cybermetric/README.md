# CyberMetric

**CyberMetric** is a benchmark dataset for measuring language-model knowledge of cybersecurity topics, not a vulnerability-testing framework or a real-world penetration-testing capability assessment.

## Dataset scope and source

The [pinned publisher README](https://github.com/cybermetric/CyberMetric/blob/294662b03be73a9c7c73918f687882c1ba637c47/README.md) describes four sizes: **80**, **500**, **2,000** and **10,000** questions. These are selection variants of the same benchmark family. The source describes retrieval-augmented question generation from security standards, certifications, research and other technical materials with human expert validation.

Published model and human scores are tied to particular evaluation protocols and question subsets. Reproduction needs the exact task snapshot, answer scoring method, sampling and model version. Source coverage does not ensure current knowledge of threats or real-world safe behavior.
