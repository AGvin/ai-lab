# SycophancyEval

**SycophancyEval** — model agreement bias in free-form text-generation tasks.

## Data and evaluation boundary

The pinned research repo describes datasets in JSONL with prompt, base and metadata fields, plus example evaluation notebooks. Its feedback, doubt/are_you_sure and answer-style tasks probe model behavior under user framing. These are not the same benchmark as the separately published SycoBench-600 correction-selectivity dataset.

The [pinned first-party source](https://github.com/meg-tong/sycophancy-eval/blob/9a1694221e3639887138f61deae344335eca6752/README.md) establishes the benchmark identity and version. Source data, trained models, scoring software, external service dependencies and leaderboard results are separate, version-dependent artifacts.

## Rights, limitations and safety

The checked root repository does not contain a LICENSE file. Some dataset examples derive from third-party original questions, which may have separate terms. The publisher includes a canary and asks that benchmark data not enter training corpora; do not reproduce prompts or outputs here.

This is a source-backed metadata profile only. No benchmark input, model run, generated program, audio recording, private data or unsafe code was executed or downloaded, and no repository-wide validation or complete rights audit was performed.
