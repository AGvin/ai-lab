# MathVista

MathVista evaluates mathematical reasoning in visual contexts, with an official project site and source dataset distribution. It is a dataset identity rather than a new model, vision inference service or independently verified score record.

## Dataset and evaluation boundaries

The official README describes visual mathematical reasoning tasks, links to an official MathVista project page and AI4Math/MathVista Hugging Face dataset, and includes evaluation/leaderboard utilities.
Questions can contain images, charts and diagrams; exact image sources and any source dataset restrictions must be checked independently of benchmark-code repository rights.

## Licensing, reproducibility and responsible use

CC BY-SA 4.0 root LICENSE; multi-source image rights. Avoid equating reported leaderboard scores with independently verified performance. No test images downloaded, multimodal model run, full source-rights census or clean pass.
