# ORAgentBench

ORAgentBench is an execution-grounded benchmark for autonomous LLM agents on end-to-end operations-research workflows.

## Dataset boundary

Benchmark tasks and datasets remain distinct from reusable optimization skills bundled for experiments and from the agent frameworks or solver runtimes used during evaluation. Public and hidden evaluator boundaries, scoring thresholds, bundled adapters, solver requirements, and the released benchmark version belong to the evaluation configuration rather than to a generic OR-agent product identity.

Task inventory, leaderboard results, model results, and other release-specific evaluation details are freshness-sensitive.
