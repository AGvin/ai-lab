- Separate CyberSecEval versions 1–4, each task family, original challenge rights, safety constraints and software/harness from task data.
- Keep the frozen candidate identity distinct from software, source datasets, model outputs, and external evaluation results.

Adversarial, phishing and vulnerable-system evaluations require isolated, authorized labs; do not direct them at real systems or people.

- Maintain canonical entity metadata and parent Datasets index navigation without duplicate acceptance credit.
