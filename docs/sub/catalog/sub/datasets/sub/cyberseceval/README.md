# CyberSecEval

**CyberSecEval** — cybersecurity risks and defensive capabilities of language models.

## Data and evaluation boundary

The publisher's suite describes MITRE-related tasks and false refusals, secure code generation, prompt injection, code-interpreter security, vulnerability and phishing tests, autonomous security operations, AutoPatch, and CyberSOCEval threat-analysis tasks. These are different test families and harnesses, not one homogeneous dataset or interchangeable set of scores.

The [original publisher source](https://github.com/meta-llama/PurpleLlama) and [pinned publisher README](https://github.com/meta-llama/PurpleLlama/blob/f64eebd53003a87d9c2d2a3a712133534c214c8d/CybersecurityBenchmarks/README.md) establish this specific release. Source data, evaluation software, model weights, scoring outputs and historical leaderboards are independently attributable.

## Rights, limitations and safety

The pinned CybersecurityBenchmarks code has a MIT LICENSE, which does not automatically license all underlying challenges, third-party data or model outputs. Adversarial, phishing and vulnerable-system evaluations require isolated, authorized labs; do not direct them at real systems or people.

This is an evidence-backed metadata profile only. No benchmark inputs, model inference, untrusted code, audio, private data or security experiment was executed or downloaded. No complete rights audit or whole-repository CI was performed.
