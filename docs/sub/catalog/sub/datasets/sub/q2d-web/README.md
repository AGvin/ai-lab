# Q2D-Web

Q2D-Web is Perplexity's private evaluation benchmark for first-stage retrieval in agentic RAG, with a public methodology and leaderboard. The reported corpus has about 190 million documents and 69,721 agent-reformulated queries across ten languages.

## Use and deployment boundaries

Public rankings do not provide a downloadable corpus or redistribution rights. Compare the exact corpus/subcorpus and relevance-judgment set; full-corpus and sampled Recall@1000 results have different evaluation conditions, and production-query distribution can favor in-distribution systems.
