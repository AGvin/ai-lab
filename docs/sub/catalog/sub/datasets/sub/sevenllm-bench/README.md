# SEvenLLM-Bench

**SEvenLLM-Bench** — cyber threat intelligence comprehension and task evaluation.

## Data and evaluation boundary

The official SEevenLLM source describes distinct SEVENLLM-Instruct and SEVENLLM-Bench datasets hosted together, intended for training and evaluation of cybersecurity event understanding and task execution. GPT-based scoring, ROUGE, semantic similarity, multiple-choice and expert reviews are methods, not extra benchmark identities.

The [pinned original publisher README](https://github.com/CSJianYang/SEevenLLM/blob/a84b86aabf2b5be35a2cbbac546511883cc5ff85/README.md) establishes dataset identity and version. Training data, test assets, model weights, evaluation software, hosted services and benchmark scores remain separately attributable.

## Rights, limitations and safety

The pinned repository tree lacks a root LICENSE file. Threat reports, incident content, evaluation prompts and hosted dataset material require publisher/source rights and privacy review. This is defensive research metadata, not authorization to access systems or execute security playbooks.

No dataset or model was downloaded, no benchmark or unsafe program was executed, and no complete rights audit, scientific reproduction, source code evaluation or repository-wide CI was run.
