# V*Bench

**V*Bench** — High-resolution image understanding and small-detail localization benchmark with 191 multiple-choice questions split between attribute recognition and spatial reasoning.

## Data and evaluation boundary

The original V* authors describe a visual search benchmark for densely detailed images, rather than generic multimodal QA. An open Inspect Evals implementation documents 191 questions: 115 attribute-recognition and 76 spatial-relationship tasks. The linked model algorithm, training images, dataset records and evaluator are distinct assets.

The [original publisher dataset card](https://huggingface.co/datasets/craigwu/vstar_bench) was checked on 2026-11-05 (publisher last modified 2024-05-02).
