# Frontier-CS

**Frontier-CS** is a benchmark family for open-ended computer-science research and algorithmic problem solving by AI agents.

## Versions and benchmark boundaries

The [first-party repository README](https://github.com/FrontierCS/Frontier-CS/blob/59687e5428266a22a49cf51f981b912103bfa91d/README.md) describes the original Frontier-CS task collections and its ICML 2026 research publication. Its current news section separately announces **FrontierCS 2**, a newer project with different research tasks, and **FrontierSmith**. Those releases must not be folded into the original Frontier-CS counts or treated as identical scoring protocols.

A reported Frontier-CS result depends on the selected research or algorithmic subset, task data, allowed code/tools, resource budget and evaluator. A partial algorithmic solution and a novel research improvement are different success criteria. Model-generated code needs an isolated runtime.

## Rights and reproducibility

The root [MIT LICENSE](https://github.com/FrontierCS/Frontier-CS/blob/59687e5428266a22a49cf51f981b912103bfa91d/LICENSE) covers repository source under that grant, but imported research papers, participant code, evaluation data, datasets and hosted results can have independent rights. Protect tool credentials and do not equate public benchmark rankings with verified capability across all computer science.

No benchmark download, model run, research replication, full dependency rights audit or whole-catalog clean pass occurred.
