# Documentation Requirements

## Requirements

- Catalog the original Frontier-CS benchmark family, not one identity per task or a separate copy of FrontierCS 2 / FrontierSmith, which first-party README discusses as distinct newer projects.
- Pinned README names ICML 2026 FrontierCS and links the original benchmark tasks and code. It also announces FrontierCS 2 on 2026-10-20 with 48 research tasks in 13 domains in a separate repository; do not attribute those specific newer tasks to this original release.
- Record challenge subset, task statement, reference code and permitted execution/runtime resources. Open-ended research problems and algorithmic problems require different evaluation criteria and cannot be reduced to a single accuracy percentage without a defined protocol.
- Root LICENSE is MIT for covered repository materials. Authors' independent paper/code dependencies, hosted task archives and external datasets may have their own licenses or usage restrictions.
- Generated code and research scripts must be executed only in disposable, isolated environments with bounded network/CPU/GPU/disk and no exposed secrets.
- No task dataset download, code execution, scientific reproduction, outcome scoring, full rights check or whole-catalog clean pass was performed.

## Validation

- Match one frozen dataset candidate with a canonical indexed entity and pinned first-party evidence.
- Do not count benchmark data as proof of legal rights, runtime evaluation or repository-wide clean validation.
