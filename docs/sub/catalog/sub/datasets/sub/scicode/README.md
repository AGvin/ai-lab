# SciCode

**SciCode** evaluates model-generated scientific code on research-inspired problems in **physics, mathematics, materials science, biology and chemistry**. Its official README reports **80 main problems and 338 subproblems**, covering **16 subdomains**, with optional scientist-supplied background, reference solutions and test cases. The dataset is also published through a separate Hugging Face distribution.

## Reproducibility and rights

The root **Apache-2.0 LICENSE** governs covered repository source, not automatically all scientific article inputs, optional backgrounds or third-party libraries. Generated code must be considered untrusted and executed only in sandboxed environments with restricted credentials, files, networking and resource use.
