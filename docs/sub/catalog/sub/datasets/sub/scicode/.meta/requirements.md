# Documentation Requirements

## Requirements

- Identify SciCode's original dataset and scientific code tasks rather than its Inspect AI/OpenCompass integrations, eval harness, leaderboard or model scores.
- Pin the published scope: 80 scientific problems with 338 subproblems, 16 subdomains across five scientific disciplines.
- Record data version, model, generation settings, test dependencies, hardware/runtime, background availability and exact scoring for comparable outcomes.
- The repository root LICENSE is Apache-2.0; referenced scientific papers, code libraries and separately hosted datasets retain distinct terms.
- Never execute generated research code outside an isolated, resource-limited sandbox. No code run, evaluation, dependency audit, complete rights review or whole-catalog clean pass claimed.

## Validation

- Match exactly one frozen first-party dataset candidate and the canonical parent index link.
- Keep source assets, evaluator, license scope and model results distinct; no unperformed tests, rights audits or clean gates are implied.
