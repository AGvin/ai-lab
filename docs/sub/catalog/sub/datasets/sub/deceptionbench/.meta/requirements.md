# Documentation Requirements

## Requirements

- Differentiate controlled model deception scenarios from observed deployed behavior, keep safety task modalities distinct and preserve license/source uncertainty.
- Preserve original first-party identity and distinguish dataset from models, grading software, training sets and externally hosted results.
- Rights and safety: The public dataset card reports MIT; generated chain-of-thought, model output data and externally sourced materials may have different rights. Safety evaluations must be isolated and must not use simulated scenarios to justify deceptive treatment of real users.
- Original publisher dataset card reviewed 2026-11-05, last modified 2025-05-27; HF metadata did not expose an immutable revision SHA.

## Validation

- Verify entity metadata, publisher card, secondary original research, requirements and navigation.
- No model testing, original dataset download, full rights audit, repository-wide schema checking, CI or clean-pass credit.
