# DeceptionBench

**DeceptionBench** — Controlled evaluation of deceptive behaviors and deceptive-alignment signals in large language models; distinct from naturally occurring real-world deception.

## Data and evaluation boundary

The publisher describes English-language tasks spanning classification, QA and generation and includes controlled scenarios for model reasoning and alignment behavior. The HF card size category is below 1,000 examples; exact item count and any reproducible causal claims are not independently verified.

The [original publisher dataset card](https://huggingface.co/datasets/PKU-Alignment/DeceptionBench) was checked on 2026-11-05 (publisher last modified 2025-05-27). An immutable HF revision SHA was not available from connected metadata; the research reference below provides additional first-party identification, not a license for unrelated material.

## Rights, limitations and safety

The public dataset card reports MIT; generated chain-of-thought, model output data and externally sourced materials may have different rights. Safety evaluations must be isolated and must not use simulated scenarios to justify deceptive treatment of real users.

**Access:** public. **Publisher-listed license:** MIT (HF metadata). No records, models, generated code, audio, images or evaluators were downloaded/executed. No complete rights audit or scientific reproduction was performed.
