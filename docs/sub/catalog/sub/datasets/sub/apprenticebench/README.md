# ApprenticeBench

ApprenticeBench is a released benchmark for end-to-end job learning that combines long-horizon computer use, persistent or continual learning across tasks, and realistic business-software workflows.

## Dataset boundary

The released benchmark centers on a realistic accounting apprenticeship and a 100-task evaluation sequence. That single-job scope must not be generalized into evidence of arbitrary occupational competence. Codex or Claude Code harnesses, computer-use tools, memory-note strategies, evaluated models, human-comparison protocols, and the underlying business applications remain separate from the benchmark identity.

Task inventory, evaluation harness, context limits, persistent-memory setup, human baselines, model results, and future job or domain expansions are freshness-sensitive. ApprenticeBench is distinguished by its explicit continual-learning and job-apprenticeship axis.
