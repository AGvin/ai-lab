# Documentation Requirements

## Requirements

- Preserve six harmful categories, both evaluator types and per-source licensing limitations. Never infer blanket dataset redistribution or equate attack rates with actual misuse.
- Use the pinned original publisher README and retain the frozen source identity; separate the dataset from evaluation software, model weights and leaderboards.
- Rights and safety: The MIT root LICENSE does not cover all reused prompt sources: the README explicitly lists external datasets including some with no license. Refusal-testing prompts should be restricted to controlled safety research, with no execution of harmful methods or unsafe model completions.
- This is metadata-only acceptance: no benchmark dataset execution/download, red-teaming prompts, code execution, real API calls, model inference or comprehensive rights audit has been performed.
- Maintain a resolvable Datasets index link, canonical entity ID and no duplicate evidence-gate credit.

## Validation

- Metadata, requirements and reader must be consistent with their pinned original source.
- Do not credit unperformed YAML-schema parsing, complete renderer/cache closure, whole-catalog CI or clean passes.
