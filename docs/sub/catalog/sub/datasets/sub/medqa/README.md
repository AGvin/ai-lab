# MedQA

**MedQA** is an open-domain medical examination question-answering benchmark. The publisher README documents question banks from the US, Mainland China and Taiwan with JSONL train/dev/test splits, four-option variants for some collections, and separate English and Chinese textbook data. These are subsets or support materials of one benchmark.

## Reproducibility and usage rights

The root MIT LICENSE applies to covered repository material, not necessarily the original examination questions or externally hosted textbooks. A high exam score does not validate patient-care decisions. No dataset was downloaded, evaluation run, medical safety review or whole-catalog clean pass performed.
