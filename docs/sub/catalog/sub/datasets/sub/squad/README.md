# SQuAD

**SQuAD** — reading-comprehension question answering over passages.

## Data and evaluation boundary

The original Stanford SQuAD explorer repository documents official SQuAD 1.1 and 2.0 development-set references and hosts visualization/model prediction tooling. SQuAD 2.0 includes unanswerable cases absent in the original answer-span-only task. Its website, dataset files, model submissions, CodaLab bundles and evaluation scripts are separately versioned.

The [pinned first-party README](https://github.com/rajpurkar/SQuAD-explorer/blob/eee5fdbf62f8613a7812b03419e6b29617b74fd1/README.md) establishes the identity and release scope. Data, licensed original inputs, evaluation software, agent protocols and historical results are distinct artifacts.

## Rights, limitations and safety

MIT for the explorer repository's software does not automatically license all Wikipedia-derived passages, question annotations, hosted dataset snapshots or leaderboard predictions. Verify original source/text attribution and dataset licenses before copying full corpus; evaluation contamination and train/dev splits matter.

This profile is source-backed metadata only. No model, benchmark, credentials, user data, generated code, security test, exploit or third-party service was executed. No full rights audit or repository-wide CI was run.
