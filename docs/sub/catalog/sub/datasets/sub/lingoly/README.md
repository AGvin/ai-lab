# LINGOLY

**LINGOLY** measures linguistic reasoning on puzzles drawn from the UK Linguistics Olympiad. Its official README documents both cleaned benchmark questions and raw transcriptions, as well as full-context and no-context evaluation. These are variants of one dataset rather than independently accepted benchmark entities.

## Reproducibility and usage rights

The publisher's LICENSE explicitly distinguishes **puzzle data: CC BY-NC-ND 4.0, with original-author permission for benchmark use**, from **evaluation code: CC BY-SA 4.0**. Source visibility and archive passwords do not grant additional rights. Performance on linguistic puzzles is not evidence of general fluency. No questions were redistributed or models evaluated.
