# Documentation Requirements

## Requirements

- LINGOLY is a benchmark question collection, not a translation model or independent code-runner product.
- The first-party README distinguishes cleaned questions from transcribed raw puzzles and full-context from no-context evaluation.
- The project LICENSE separately identifies puzzle data under CC BY-NC-ND 4.0 with original-author permissions and code under CC BY-SA 4.0.
- Do not infer unlimited commercial use, redistribution or derivative rights for the source puzzle data from the code license. Archive passwords are not reuse permissions.
- Report model revision, exact questions, context condition, prompt format and grader settings for any comparable evaluation.
- No archive was extracted, model evaluated, rights clearance obtained or whole-catalog clean pass performed.

## Validation

- A unique frozen source-backed dataset identity and correctly indexed canonical profile.
- Source-data rights, code, scores and model services remain distinct; unperformed tests receive no acceptance credit.
