# MLPerf Endpoints v0.7

## Relations

- Produced by: [MLCommons](../../../producers/sub/m/sub/mlcommons/)

MLPerf Endpoints v0.7 is MLCommons' initial released benchmark framework for comparing deployed inference endpoints, with first results published July 28, 2026.

## Scope and boundaries

The v0.7 snapshot measures throughput, interactivity, P95 time to first token and concurrency for particular endpoint configurations. It is separate from traditional MLPerf Inference submission rounds, individual model datasets and the live result-visualization platform.

Version scope matters: subsequent v1.0 development documentation uses P90 and revised submission rules, which must not be applied retrospectively to v0.7. Published curves remain specific to model, workload, hardware, software and submitted configuration. The initial release's limited coverage and later roadmap do not establish universal provider comparisons or the release state of future versions.
