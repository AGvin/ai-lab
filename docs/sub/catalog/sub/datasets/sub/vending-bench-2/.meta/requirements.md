# Documentation Requirements

## Requirements

- Identify Vending-Bench 2 as Andon Labs' current benchmark for long-term coherence in AI agents through a year-long simulated vending-machine business.
- Preserve Vending-Bench 2 as the successor to deprecated Vending-Bench 1 rather than materializing the older benchmark as the current canonical peer.
- Keep simulation rules, tool inventory, run duration, scoring, leaderboard models/results, baseline behavior, arena variant, and environment revisions freshness-sensitive.
- Keep Vending-Bench Arena as a multi-agent variant of the current benchmark unless its lifecycle becomes independently useful enough for a separate canonical node.
- Keep real-world Andon Market/Café/FM experiments separate from the benchmark identity.
- Attribute business/alignment observations to the exact benchmark/run/model revision rather than generalizing them into universal economic-agent behavior.

## Validation

- The node represents Vending-Bench 2, not deprecated Vending-Bench 1 or a real vending business.
- Live leaderboard results are not frozen as durable benchmark facts.
