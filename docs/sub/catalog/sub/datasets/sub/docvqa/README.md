# DocVQA

**DocVQA** — visual question answering over scanned single-document images.

## Data and evaluation boundary

The organizer's official DocVQA dataset page defines extractive text-span answers from UCSF Industry Documents Library images. The original author's pinned GitHub README only describes baselines and the WACV 2021 paper. Dataset downloads are routed through the RRC portal, which requires login and review of challenge download terms.

The [original publisher source](https://site.docvqa.org/datasets/docvqa) and [pinned publisher README](https://github.com/mineshmathew/DocVQA/blob/618dee574c98137da83aac857d7b68934618735c/README.md) establish this specific release. Source data, evaluation software, model weights, scoring outputs and historical leaderboards are independently attributable.

## Rights, limitations and safety

No root LICENSE file was found in the checked author baseline repository. The dataset portal is not a blanket redistribution license for source document images, OCR and questions. Follow organizer and source-document permissions; avoid proprietary or private scanned documents.

This is an evidence-backed metadata profile only. No benchmark inputs, model inference, untrusted code, audio, private data or security experiment was executed or downloaded. No complete rights audit or whole-repository CI was performed.
