# Documentation Requirements

## Requirements

- Identify LongMemEval-V2 as the separately published **May 2026** long-term memory benchmark for web agents using prior environment trajectories, not the original **2024 LongMemEval** conversational assistant memory dataset with 500 questions.
- Preserve the publisher's **451 curated questions, 1,870 trajectories, five memory abilities, web/enterprise synthetic environments**, up to **500 trajectories and 115M tokens per haystack**, and small/medium evaluation tiers as source- and version-scoped, not all equally sized tasks or independent samples.
- Explain static-state recall, dynamic-state tracking, workflow knowledge, environment gotchas and premise awareness; distinguish memory retrieval/query evidence from successful live web actions, agent-framework training, or production operating procedures.
- Keep the released dataset identity separate from its evaluation scripts, AgentRunbook-R/AgentRunbook-C software baselines, proprietary model endpoints, leaderboard submissions, original LongMemEval V1 and the unrelated Hindsight/Mem0/Graphiti products.
- Source code and original dataset documentation each report Apache-2.0; publisher dataset card declares Apache-2.0 for distributed data. Do not infer unconditional third-party screenshot/website assets, model/tool outputs or sensitive production dataset rights.
- The released trajectories come from customized benchmark environments, not actual users. Explain that their synthetic enterprise records, screenshot/accessibility-tree state and benchmark labels do not establish real-world tenant isolation, data privacy, model robustness or legal clearance.
- Benchmark evaluation is compute-, provider-, latency- and configuration-sensitive. Published 2026 model comparisons are publisher experiments, not independently reproduced current leaderboards.
- The research authorship is attributed to Di Wu and collaborators with first-party paper/repository. Do not invent a legal organization producer or merge unrelated corporate provenance; add a canonical relation only with source-backed identity.
- Render from this authored metadata and reader only during the final publication cycle, after the required two consecutive clean eight-root research passes.
