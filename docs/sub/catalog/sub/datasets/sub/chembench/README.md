# ChemBench

**ChemBench** is a published chemistry-focused benchmark family for evaluating language and multimodal model competence. Its public source includes a reusable evaluation package; this catalog entry records the **benchmark and its data family**, not the Python package as a second dataset.

## Dataset versus runner

The [first-party README](https://github.com/lamalab-org/chembench/blob/45f8bad062fe552810c52be3a328d5da8597ed30/README.md) describes chemistry evaluation across configurable tasks and topics, with support for extending datasets, providers and metrics. The source also documents installation of the ChemBench Python package and obtaining some benchmark content through a hosted distribution. The package, Hugging Face-hosted data, model-provider services and leaderboard scores are different resource types.

Reported scores require a pinned task/data snapshot, prompts, answer rubrics, model revision, inference settings and scoring code. The contents of individual subtests and the multimodal task mix can evolve.

## Rights and scientific limits

The repository [MIT LICENSE](https://github.com/lamalab-org/chembench/blob/45f8bad062fe552810c52be3a328d5da8597ed30/LICENSE) applies to covered project materials, not automatically to independently sourced chemistry questions, images, journal excerpts or third-party model services. Chemistry questions may touch unsafe substances or procedures; generated answers must not be treated as vetted laboratory safety guidance.

No package installation, source-data import, evaluation, chemical safety validation or whole-catalog clean pass was carried out.
