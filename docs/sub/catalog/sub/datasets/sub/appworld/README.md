# AppWorld

**AppWorld** — multi-application tool-use and interactive coding agent benchmark.

## Data and evaluation boundary

AppWorld supplies versioned simulated applications, user worlds, test tasks and state-based evaluation. Its agent scaffolds, MCP adapters, API server, task-world runtime and baselines are distinct software or results, not extra dataset identities. Reproducible evaluation requires consistent released data and app state.

The [pinned original source README](https://github.com/StonyBrookNLP/appworld/blob/42b5bcf3cd334fee33f0c37c02070a9f5807add5/README.md) provides the release identity and version boundary. Benchmark tasks, source materials, evaluation harnesses, hosted datasets, trained models and reported results are separately attributable.

## Rights, limitations and safety

Apache-2.0 covers source within the repository license grant; separately encrypted/released task assets, scenario data and third-party dependencies must follow their own release conditions. Agent-generated programs must run only in isolated authorized environments with no real user accounts.

This record is an evidence-backed metadata profile only: no benchmark datasets, model requests, untrusted programs, containers, real accounts, or external integrations were executed. No comprehensive license review or repository-wide CI was run.
