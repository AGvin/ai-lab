# Documentation Requirements

## Requirements

- Distinguish writing dataset from judge/critic model checkpoints, trained writers, generated submissions and hosted leaderboard.
- Record exact scoring judge, date/version, prompts, generation parameters and language/task distribution for comparable results.
- Treat automated model-judge scores as method-dependent and verify any third-party writing-content rights.
- No generative writing benchmark, paid judge request, model comparison, rights audit or clean pass was performed.
- Ensure a unique frozen benchmark identity, pinned publisher sources and valid category link.

## Validation

- Confirm source and license boundaries; do not infer rights to hosted data or unperformed runtime verification.
