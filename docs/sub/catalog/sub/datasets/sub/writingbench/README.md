# WritingBench

**WritingBench** — Generative writing benchmark with evaluation dimensions, writing requests and separate critic-model-assisted grading and public leaderboard; test prompts, judge models and writing-model weights have distinct provenance.

## Dataset and evaluation boundary

The first-party README describes evaluation of **generative writing capabilities** with writing prompts, requirement-oriented scoring, model responses and leaderboard presentation. The scoring pipeline has changed evaluator models over time; a recorded score needs its exact dataset, prompt, critic/grader model and scoring configuration.
The [pinned first-party README](https://github.com/X-PLUG/WritingBench/blob/ae2d5176449b7b769815482641d35926f26793eb/README.md) describes this benchmark snapshot.

## Rights and limitations

Covered root repository material uses Apache-2.0, but external writing prompts, texts, model weights, hosted critic services and benchmark submissions may have separate rights. Automated writing quality judgments can vary by judge version and language; rankings are not stable facts across time.

No dataset was downloaded, model tested, full source rights reviewed or whole-catalog clean pass executed.
