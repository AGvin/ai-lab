# MLPerf Storage v3.0

## Relations

- Produced by: [MLCommons](../../../producers/sub/m/sub/mlcommons/)

MLPerf Storage v3.0 is MLCommons' released suite for measuring storage-system performance under representative AI and machine-learning workloads.

## Scope and boundaries

The September 2026 revision adds KV Cache and Vector Database tests and an S3 object-storage access layer alongside POSIX. These are workload and access variants inside the suite, not independent storage products.

Workload definitions, datasets, scale factors, access layers, metrics, submission classes and power measurements depend on the exact revision. Results characterize the submitted storage system and configuration; they are separate from general KV-cache concepts, vector-database products or claims about every AI workload.
