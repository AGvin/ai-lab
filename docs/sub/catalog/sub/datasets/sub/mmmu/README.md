# MMMU

MMMU, or Massive Multi-discipline Multimodal Understanding, is a concrete multimodal benchmark/dataset for college-level expert knowledge and reasoning tasks across multiple disciplines.

## Dataset boundary

MMMU remains distinct from MMMU-Pro, evaluation harnesses, leaderboards, hosted evaluation services, and generic multimodal-evaluation concepts. Subject, subfield, modality, image-type, split, and question-count claims apply only to the dataset/version supported by the cited upstream sources.

Test-answer availability, evaluation integrations, dataset revisions, and leaderboard state are mutable or version-sensitive. MMMU and MMMU-Pro results must not be compared as if they were produced from the same test set.
