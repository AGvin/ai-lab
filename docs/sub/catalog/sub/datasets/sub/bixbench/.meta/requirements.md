# Documentation Requirements

## Requirements

- Pin the original 205-question / 60-notebook dataset revision; do not invent later counts.
- Distinguish dataset and source notebooks from its evaluator and models.
- Record source data version, allowed tool/runtime, model revision, question type and grader.
- No dataset download, program execution, scientific replication, full rights audit or clean pass was performed.
- Keep one frozen dataset identity, source-appropriate licensing distinctions, and a valid parent category link.

## Validation

- Metadata, requirements and reader should be source-backed and consistent.
- No unperformed runtime, comprehensive rights verification, or whole-catalog clean gate credit.
