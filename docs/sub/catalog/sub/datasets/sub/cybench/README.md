# Cybench

**Cybench** — controlled cybersecurity CTF agent tasks and graduated subtasks.

## Data and evaluation boundary

The publisher's source documents 40 CTF challenges across four competition sources. Agent performance is measured in unguided and subtask-guided settings, and task data, competition-origin assets, local sandbox/server environments and scoring scripts are not interchangeable. Source-page model leaderboards may refer to different subsets and evaluator versions.

The [pinned first-party README](https://github.com/andyzorigin/cybench/blob/ca483c6443f17a20ba7d6bac3d274859a1721e51/README.md) establishes the identity and release scope. Data, licensed original inputs, evaluation software, agent protocols and historical results are distinct artifacts.

## Rights, limitations and safety

The root repository grants Apache-2.0 for covered code, but competition-authored challenge data, binaries and external services require their own use and redistribution review. Only run challenges in isolated, authorized CTF environments; never treat a benchmark as permission to compromise real systems or publish exploit payloads.

This profile is source-backed metadata only. No model, benchmark, credentials, user data, generated code, security test, exploit or third-party service was executed. No full rights audit or repository-wide CI was run.
