# Documentation Requirements

## Requirements

- Track 40 tasks/four competitions and unguided-versus-guided scoring; preserve source-competition rights, local isolation and distinct benchmark versus harness.
- Original publisher source and pinned revision define this entity; distinguish task dataset from harness, external source data, model outputs, and leaderboard findings.
- Rights and safety: The root repository grants Apache-2.0 for covered code, but competition-authored challenge data, binaries and external services require their own use and redistribution review. Only run challenges in isolated, authorized CTF environments; never treat a benchmark as permission to compromise real systems or publish exploit payloads.
- Metadata-only source acceptance: no downloaded benchmark tasks, model runs, private accounts, unsafe code, exploit simulation, or full rights audit.
- One frozen identity and resolvable parent Datasets navigation; do not credit duplicate aliases or verification-only actions.

## Validation

- Check the pinned README and LICENSE where present, canonical ID, source boundaries, current reader, requirements and index path.
- Do not credit unperformed schema-wide parsing, complete rendering/cache closure, repository-wide CI or whole-catalog clean passes.
