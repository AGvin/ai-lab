# Agents' Last Exam

Agents' Last Exam (ALE) is the Berkeley RDI/RDI Foundation benchmark for long-horizon, economically valuable digital work across broad occupational coverage.

## Dataset boundary

The complete expert-sourced evaluation corpus is distinct from the subset distributed publicly; public materials must not be read as containing every evaluated task or hidden reference. The `ale_run` framework, harnesses, frontier-model results, O*NET/SOC taxonomy inputs, and individual industry tasks remain separate from the benchmark identity.

Public task counts, occupational and industry coverage, hidden-evaluation policy, sandbox runtime, graders, leaderboard results, and corpus expansion are freshness-sensitive. Comparative performance claims remain tied to the applicable release and run configuration.
