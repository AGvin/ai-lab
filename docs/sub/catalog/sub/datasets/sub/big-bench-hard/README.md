# BIG-Bench Hard (BBH)

BIG-Bench Hard is a released 23-task reasoning-focused subset of the larger BIG-Bench evaluation. Its source includes task data and chain-of-thought prompt examples, which make prompt-format control essential when comparing model performance.

## Dataset and evaluation boundaries

The pinned README identifies 23 originally challenging BIG-Bench tasks, with task files in bbh/ and accompanying chain-of-thought prompts in cot-prompts/.
Published historical findings describe the effect of chain-of-thought prompting on then-evaluated models; they are not guarantees for modern models.

## Licensing, reproducibility and responsible use

MIT repository; provenance from BIG-Bench task family. Do not present the 23-task subset as all BIG-Bench or promote published historical model outputs to independent AI Lab evaluations. No run or complete rights audit.
