# MLPerf Client v2.0

## Relations

- Produced by: [MLCommons](../../../producers/sub/m/sub/mlcommons/)

MLPerf Client v2.0 is the released MLCommons benchmark suite for AI workloads on personal computers.

## Scope and boundaries

The August 2026 release combines updated LLM tests with image-generation and agentic workloads, including software-engineering and data-analyst scenarios. The image-generation category and some models have experimental status in this revision.

This is a benchmark-suite release, distinct from the tested PC, reference models and individual task datasets. Workload definitions, required versus experimental tests, accuracy gates, runtime/platform requirements, prompts and reported results must remain tied to the precise suite revision and submitted system configuration.
