# PersistBench

**PersistBench** — long-term memory retention, cross-domain leakage and correction behavior.

## Data and evaluation boundary

The publisher defines three memory conditions: cross-domain leakage, sycophantic reuse, and beneficial usage. An Inspect-native implementation is recommended over the older original runtime; dataset cases, synthetic memory scenarios, model configurations and judging outputs remain separately versioned. Do not score private user memories.

The [pinned original publisher README](https://github.com/ivaxi0s/PersistBench/blob/d2ded18be6d15ebb14008d081a44bd03c20670e4/README.md) establishes dataset identity and version. Training data, test assets, model weights, evaluation software, hosted services and benchmark scores remain separately attributable.

## Rights, limitations and safety

No root LICENSE file was found at the pinned original repository root. Real conversational memories and private user data must not be imported into benchmark tests; source inputs, generated responses and judge outputs require explicit privacy and rights assessment. Model/provider costs and deployed assistants' memory behavior are not independently validated.

No dataset or model was downloaded, no benchmark or unsafe program was executed, and no complete rights audit, scientific reproduction, source code evaluation or repository-wide CI was run.
