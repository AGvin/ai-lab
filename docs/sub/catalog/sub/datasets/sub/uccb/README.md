# UCCB

**UCCB** — Ugandan cultural and multilingual context evaluation with 1,039 curated question-answer pairs spanning 24 cultural domains.

## Data and evaluation boundary

The publisher's dataset summary reports 1,039 pairs across 24 Ugandan cultural domains and lists English plus multiple Ugandan languages. Questions reflect local context; different languages, categories, graders and model evaluations are related variants rather than new benchmark identities.

The [official dataset card](https://huggingface.co/datasets/CraneAILabs/UCCB) was reviewed 2026-11-05 (publisher updated 2025-07-27). Original dataset records and evaluation software were not downloaded; the connected metadata did not expose an immutable source revision SHA.

## Rights, limitations and safety

The publisher lists CC BY-NC-SA 4.0, requiring attribution, noncommercial use and share-alike conditions. Cultural question validity and representation require community-informed evaluation; don't infer cultural facts or community endorsement from a model score alone.

**Access:** public. **Publisher-described licensing:** CC BY-NC-SA 4.0. No harmful prompts, model responses or external experiments were executed or republished. No comprehensive rights audit was run.
