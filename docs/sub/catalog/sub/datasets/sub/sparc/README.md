# SPaRC

**SPaRC** — grid-pathfinding spatial reasoning puzzles and solution validation.

## Data and evaluation boundary

The first-party project describes 1,000 puzzle tasks, with a current CLI/Inspect evaluation interface and a 500-puzzle test subset. Its validator, step-by-step gym mode, corrected prompt rules and visual prompt variants are distinct versioned evaluation configurations.

The [pinned first-party README](https://github.com/lkaesberg/SPaRC/blob/2a5a22c74f8b0fb5e75713237a74142d9029fbd0/README.md) is the identity and version source. Data, benchmark tasks, evaluator software, trained models and published leaderboards must be attributed separately.

## Rights, limitations and safety

The root LICENCE contains MIT terms; third-party game imagery/artwork and model outputs require separate provenance and rights review. Published human/model rates and results across changed prompt definitions must not be merged as equivalent evaluations.

No image corpus, model inference, runtime evaluation or puzzle solving was performed. No complete rights audit or repository-wide validation was run.
