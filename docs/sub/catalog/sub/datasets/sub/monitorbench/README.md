# MonitorBench

**MonitorBench** — chain-of-thought monitorability over multiple reasoning tasks.

## Data and evaluation boundary

The publisher reports 1,514 test instances across 19 tasks in seven categories and two monitorability stress-test settings. Task data, monitor prompts and evaluator implementation are distinct. Some tasks have separately been integrated into Inspect Evals.

The [pinned first-party README](https://github.com/ASTRAL-Group/MonitorBench/blob/b6229e4b8ea9abcec38d61159c9cbd0f577ddf35/README.md) is the identity and version source. Data, benchmark tasks, evaluator software, trained models and published leaderboards must be attributed separately.

## Rights, limitations and safety

The pinned root MIT LICENSE covers licensed repository assets only. Third-party datasets, model traces and externally hosted reasoning outputs may carry additional terms or sensitive content. Published statistics are source claims, not independently reproduced outcomes.

No chain-of-thought traces, hidden-objective task executions, dataset downloads or model evaluations were performed. No complete rights audit or repository-wide validation was run.
