# ZeroBench

**ZeroBench** — Curated difficult visual reasoning benchmark for multimodal models, with a main set of manually reviewed questions, separate data and leaderboard scores. Previously unsolved tasks have since been solved by later systems; original promotional title is historical.

## Dataset and evaluation boundary

The official README describes a main set of **100 manually curated visual questions** designed to challenge then-current multimodal models. It includes an explicit dataset canary to help model builders avoid contamination. The pinned release notes that the benchmark is **no longer impossible**, because some questions were subsequently solved; treat published metrics as revision-specific historical measurements.
The [pinned first-party README](https://github.com/jonathan-roberts1/zerobench/blob/0debbe43deddfe54f9965a6fdfd4f70a20d8ab62/README.md) describes this benchmark snapshot.
