# MuTox

**MuTox** — multilingual toxicity annotations for speech/audio evaluation.

## Data and evaluation boundary

The final ACL Findings 2024 publication describes 20,000 audio utterances for English/Spanish and 4,000 for the other 28 languages, and a separately trained multilingual audio-toxicity detector. This supersedes the earlier January 2024 preprint description with different language counts. Human annotation, original speech-source corpora, classifier weights and later Inspect integrations are different artifacts.

The [original publisher source](https://ai.meta.com/research/publications/mutox-universal-multilingual-audio-based-toxicity-dataset-and-zero-shot-detector/) and [fixed ACL 2024 publication](https://aclanthology.org/2024.findings-acl.340/) establish this specific release. Source data, evaluation software, model weights, scoring outputs and historical leaderboards are independently attributable.

## Rights, limitations and safety

The published ACL paper and Meta release do not establish a blanket license for every audio recording, transcript or original collection. Handle speaker consent, privacy and potentially disturbing speech content carefully; do not redistribute recordings without checking the underlying corpus licenses.

This is an evidence-backed metadata profile only. No benchmark inputs, model inference, untrusted code, audio, private data or security experiment was executed or downloaded. No complete rights audit or whole-repository CI was performed.
