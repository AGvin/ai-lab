# Documentation Requirements

## Requirements

- Use final ACL Findings 2024 DOI rather than earlier preprint counts; distinguish 30-language human labels, source audio licenses and multilingual classifier weights.
- Keep the frozen candidate identity distinct from software, source datasets, model outputs, and external evaluation results.
- Rights and safe use: The published ACL paper and Meta release do not establish a blanket license for every audio recording, transcript or original collection. Handle speaker consent, privacy and potentially disturbing speech content carefully; do not redistribute recordings without checking the underlying corpus licenses.
- Metadata-only source acceptance: no benchmark dataset downloads, generated program execution, model inference, live security tests or external services were run.
- Maintain canonical entity metadata and parent Datasets index navigation without duplicate acceptance credit.

## Validation

- Verify source/revision, metadata, requirements, reader, and navigation link.
- No repository-wide YAML schema parser, complete renderer/cache closure, full rights audit, CI, or clean-group pass has been completed.
