# SentinelBench

SentinelBench is Microsoft Research's open-source benchmark for long-running monitoring agents operating in time-evolving environments where useful progress can depend on waiting for external state changes.

## Dataset boundary

The released scope contains 100 tasks across ten synthetic web environments and evaluates completion, reaction time, and resource use. Waiting strategies, browser-agent harnesses, evaluated models, synthetic applications, and monitoring-agent architectures remain separate from the benchmark identity.

Scenario inventory, event timelines, harness versions, metrics, costs, pass rates, and other reported results are freshness-sensitive and run-scoped.
