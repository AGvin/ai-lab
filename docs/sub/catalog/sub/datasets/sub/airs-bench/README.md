# AIRS-Bench

AIRS-Bench is a released AI Research Science benchmark for evaluating end-to-end AI-research capabilities of LLM agents.

## Dataset boundary

Benchmark tasks, datasets, evaluation preparation, agent-environment dependencies, and scoring belong to the AIRS-Bench evaluation surface, while external agent frameworks used to run evaluated agents retain their own identities. Baseline results are evidence tied to the applicable release rather than intrinsic model facts.

Dataset revisions, task coverage, baseline models, and reported results are freshness-sensitive.
