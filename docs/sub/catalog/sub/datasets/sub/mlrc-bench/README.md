# MLRC-Bench

**MLRC-Bench** — open-ended ML research competition problem solving by agents.

## Data and evaluation boundary

The publisher documents seven ML competition-derived research problems with proposed methods implemented in code. Agent-visible task environments, hidden test preparation, model outputs, Kaggle datasets and the MLAB runner are different assets. Compare results only within the same task, version, environment and authorized competition split.

The [original publisher source](https://github.com/yunx-z/MLRC-Bench) and [pinned publisher README](https://github.com/yunx-z/MLRC-Bench/blob/0d26417034811d2d4587646c4520cc305ea09dd6/README.md) establish this specific release. Source data, evaluation software, model weights, scoring outputs and historical leaderboards are independently attributable.

## Rights, limitations and safety

The MIT root license uses placeholder copyright fields and does not establish rights to competition-owned datasets, papers or hidden evaluations. Access to external competition data can require explicit consent; only run generated research code in isolated authorized environments.

This is an evidence-backed metadata profile only. No benchmark inputs, model inference, untrusted code, audio, private data or security experiment was executed or downloaded. No complete rights audit or whole-repository CI was performed.
