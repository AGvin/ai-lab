# APPS Coding Challenge Dataset

APPS tests program synthesis against coding problems and their tests. The official repository provides benchmark scripts and links to an external dataset archive and mirror. Treat executable generated solutions as untrusted, and record exact splits, runtime policy and generation parameters.

## Dataset and evaluation boundaries

The pinned README links the original APPS archive and separately mirrored Hugging Face dataset; the repo includes training and evaluation code but is not itself the complete downloaded archive.
Benchmark outcomes are sensitive to task split, tests, runtime timeouts, language and generation parameters.

## Licensing, reproducibility and responsible use

MIT repository; original problems separately sourced. Never execute model-generated programs without isolation. No dataset download, local execution, test corpus copyright review, benchmark score or full clean pass is claimed.
