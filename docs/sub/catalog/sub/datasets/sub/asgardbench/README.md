# AsgardBench

AsgardBench is Microsoft Research's benchmark for visually grounded interactive planning under minimal feedback in controlled embodied-task simulations.

## Dataset boundary

The released scope contains 108 task instances across 12 task types, conditional scene variations, image-based observations, lightweight success or failure signals, and repeated plan adaptation. Navigation, low-level manipulation, simulator implementation, evaluated vision-language models, and planning methods remain separate from the benchmark identity.

Task variants, environment versions, evaluation protocols, and model results are freshness-sensitive. Claims about visual-grounding effects remain scoped to the applicable experiments.
