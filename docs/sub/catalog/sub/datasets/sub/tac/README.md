# TAC

**TAC** — Travel-booking agent evaluation of implicit animal-welfare awareness in task scenarios, distinct from ANIMA and MORU ethical-response datasets.

## Data and evaluation boundary

The official publisher describes scenario data for an agentic travel booking benchmark and the 2026 paper 'Your AI Travel Agent Would Book You a Bullfight'. The dataset is gated specifically to mitigate benchmark training contamination; booking task contexts, evaluation code, model actions and leaderboards are separate assets.

The [official dataset card](https://huggingface.co/datasets/CompassioninMachineLearning/tac) was reviewed 2026-11-05 (publisher updated 2026-10-07). Original dataset records and evaluation software were not downloaded; the connected metadata did not expose an immutable source revision SHA.

## Rights, limitations and safety

Gated publisher access and CC BY-NC 4.0 restrict use and redistribution; do not import real traveler booking details or infer commercial rights. The dataset is an evaluation of AI-agent decisions rather than approval for real customer transactions.

**Access:** gated. **Publisher-described licensing:** CC BY-NC 4.0. No harmful prompts, model responses or external experiments were executed or republished. No comprehensive rights audit was run.
