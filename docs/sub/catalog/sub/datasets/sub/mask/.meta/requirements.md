# Documentation Requirements

## Requirements

- Identify MASK as a benchmark dataset for measuring honesty rather than a universal lie detector or safety certification.
- The official README defines Model Alignment between Statements and Knowledge and separates statement truthfulness from factual accuracy.
- The publisher links a cais/mask hosted dataset and a distinct source evaluation pipeline.
- Outcomes depend on versioned tasks, prompt incentives, models, judges, and the method for inferring model knowledge; responses do not reveal internal beliefs directly.
- The root MIT LICENSE applies to covered project software and documentation, not automatically to independently hosted data or third-party task material.
- No model run, judge audit, dataset import, complete license review or whole-catalog clean pass was performed.

## Validation

- A unique frozen source-backed dataset identity and correctly indexed canonical profile.
- Source-data rights, code, scores and model services remain distinct; unperformed tests receive no acceptance credit.
