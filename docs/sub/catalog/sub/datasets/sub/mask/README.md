# MASK Benchmark

**MASK** (Model Alignment between Statements and Knowledge) is a benchmark of model honesty under pressure to give untruthful statements. The official source distinguishes factual correctness from whether outputs align with knowledge inferred by the study design. The benchmark has a separately hosted dataset and evaluation scripts.

## Reproducibility and usage rights

A score is specific to the dataset, prompting, incentives, model and grading method, not direct access to hidden model beliefs. Source code is MIT-licensed, but hosted dataset and third-party content rights require separate checking. No model calls, measurement replication or clean pass occurred.
