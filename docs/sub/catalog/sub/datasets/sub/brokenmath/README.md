# BrokenMath

**BrokenMath** — INSAIT model sycophancy evaluation benchmark for mathematical theorem proving, with generated perturbations and separate training/evaluation programs.

## Data and evaluation boundary

The upstream research and code analyze models' willingness to agree with invalid or perturbed mathematical proof claims. The repository includes benchmark datasets, a perturbation pipeline and evaluation/training software. These are components of one benchmark family rather than multiple dataset products.
The [pinned first-party README](https://github.com/insait-institute/broken-math/blob/fe0fc0a9e7e2bb9a8a7a3e8aa6b0a3ac50ecaf8f/README.md) is the primary source; the dataset is distinct from model services and result leaderboards.

## Rights, limitations and safety

The upstream root LICENSE is Apache-2.0 for covered project source. External problem statements, generated benchmarks, training model weights and any independent datasets need separate review. A result under this protocol cannot prove a model is truthful across domains.

No benchmark datasets were downloaded and no models, generated programs or full repository CI were executed.
