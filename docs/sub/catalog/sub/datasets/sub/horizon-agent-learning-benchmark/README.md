# Horizon

Horizon is a long-horizon agent-learning benchmark that measures whether agents can acquire useful knowledge from long prior histories and apply it in later environment tasks.

## Dataset boundary

Public and private task boundaries, Harbor integration, submission workflow, reference agents, and scoring are parts of the benchmark ecosystem rather than separate memory-framework identities. Reference agents may implement retrieval or memory strategies without changing Horizon into a memory product or general agent harness.

Leaderboard results, task counts, dataset revisions, supported runners, and infrastructure requirements are freshness-sensitive.
