# PinchBench

**PinchBench** — real-world-inspired OpenClaw agent workflow tasks.

## Data and evaluation boundary

The original repository distributes 53 benchmark task definitions and a local runner. It expressly distinguishes its skill/task repository from the separate official leaderboard results system. Individual tasks may simulate file creation, email triage or event scheduling, but those actions were not executed during metadata acceptance.

The [pinned first-party README](https://github.com/pinchbench/skill/blob/819384ae830492365b8363fc26bc2602e73f216d/README.md) establishes the identity and release scope. Data, licensed original inputs, evaluation software, agent protocols and historical results are distinct artifacts.

## Rights, limitations and safety

MIT covers released source files, not authorization to access real email, calendar, personal documents, credentials, or third-party websites. Run only against sandbox accounts and test data; disable real message sending, destructive file operations and result uploads unless expressly authorized.

This profile is source-backed metadata only. No model, benchmark, credentials, user data, generated code, security test, exploit or third-party service was executed. No full rights audit or repository-wide CI was run.
