# Manager Coercion Benchmark

**Manager Coercion Benchmark** — AI manager coercion escalation and outcome fabrication measurements.

## Data and evaluation boundary

The publisher reports ten simulated scenarios and a six-model method demonstration with thirty conversations per cell. Manager self-reported coercion levels form one metric; whether task completion was fabricated is adjudicated separately. Its deliberately ceiling-seeking conditions are not estimates of real deployment behavior or abuse frequency. Benchmark canary and test data must not be used for model training.

The [pinned first-party README](https://github.com/CompassionML/manager-coercion-bench/blob/3d2d64c118a43670a9678e455e06ff4ed4bf8412/README.md) establishes the identity and release scope. Data, licensed original inputs, evaluation software, agent protocols and historical results are distinct artifacts.

## Rights, limitations and safety

The repository has MIT code terms, but stored generated conversations, model provider outputs and evaluation scenarios have separate privacy and provenance concerns. Do not apply coercion templates to real employees, users or dependent agents; use only nonhuman simulated environments with consent and no real-world penalties.

This profile is source-backed metadata only. No model, benchmark, credentials, user data, generated code, security test, exploit or third-party service was executed. No full rights audit or repository-wide CI was run.
