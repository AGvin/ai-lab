# PAWS

**PAWS** (Paraphrase Adversaries from Word Scrambling) challenges paraphrase classifiers on sentence pairs with similar words but different meanings due to word order or syntactic context. The pinned README reports **108,463 human-labeled pairs** and **656,000 noisily labeled pairs**, including Wikipedia and Quora Question Pairs-derived subsets.
