# Documentation Requirements

## Requirements

- Define PAWS as one paraphrase benchmark family with PAWS-Wiki, PAWS-QQP and separately described multilingual PAWS-X resources; keep test splits distinct from independent entities.
- Pin original README and root license; the Google license allows dataset use while disclaiming warranties, but third-party source text provenance requires checking.
- Evaluate pairs on paraphrase truth rather than lexical overlap alone; record subset, data split, preprocessing, model version, prompts and accuracy protocol.
- Treat data leakage, semantic ambiguity and third-party text use as limitations.
- No data download, model run, complete rights audit or whole-catalog clean pass performed.

## Validation

- Match exactly one frozen first-party dataset candidate and the canonical parent index link.
- Keep source assets, evaluator, license scope and model results distinct; no unperformed tests, rights audits or clean gates are implied.
