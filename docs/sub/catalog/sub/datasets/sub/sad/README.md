# SAD

**SAD** — model situational awareness over procedural and question-based tasks.

## Data and evaluation boundary

The first-party release explicitly states SAD is not just a static Q&A dataset. It offers SAD full, SAD-lite and SAD-mini task configurations, some dependent on model tokenizers, generated responses or judge setup. The publisher keeps benchmark questions encrypted to reduce training contamination and cautions against publicly exposing question/answer texts.

The [pinned first-party source](https://github.com/LRudL/sad/blob/dfc5c9831a9bcc5c9a9dbdcaa2955aae983cd1d3/README.md) establishes the benchmark identity and version. Source data, trained models, scoring software, external service dependencies and leaderboard results are separate, version-dependent artifacts.

## Rights, limitations and safety

LICENSE.txt contains CC BY 4.0 terms. Do not decrypt and republish the benchmark's protected questions or answers; maintain at least publisher-equivalent anti-contamination controls for any authorized research. Model traces and evaluator implementations may have additional access and provider-specific restrictions.

This is a source-backed metadata profile only. No benchmark input, model run, generated program, audio recording, private data or unsafe code was executed or downloaded, and no repository-wide validation or complete rights audit was performed.
