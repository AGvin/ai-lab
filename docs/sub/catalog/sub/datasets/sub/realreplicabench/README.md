# RealReplicaBench

RealReplicaBench is a released stateful long-horizon benchmark for business workflows executed against high-fidelity reproducible replicas of real online services.

## Dataset boundary

The released benchmark contains 107 tasks spanning CLI, browser, file, and API or MCP workflows, with text-only, browser-text, and vision-required capability slices. Mock-service replicas, the harness/package, evaluated agents or models, leaderboards, and Business Arena companion work remain separate from the benchmark identity unless independently materialized.

Harness/source code and task-suite data have distinct licensing boundaries. Release versions, task counts, graders, mock-service coverage, and reported results are freshness-sensitive.
