# WeaveBench

WeaveBench is Microsoft Research's long-horizon real-world benchmark for computer-use agents that orchestrate GUI observations and actions with CLI and code operations inside one trajectory.

## Dataset boundary

The released benchmark contains 114 tasks across eight work domains with trajectory-aware judging over deliverables, screenshots, logs, files, and action traces. Evaluated agent runtimes, desktop-control plugins, frontier models, and trajectory-judge implementations remain separate from the benchmark identity unless independently materialized.

Task inventory, judge implementation, runtime setup, leaderboards, and published results are freshness-sensitive. Model and runtime scores remain run-scoped rather than intrinsic benchmark facts.
