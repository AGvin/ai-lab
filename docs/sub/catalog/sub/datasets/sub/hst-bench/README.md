# HST-Bench

HST-Bench is a released Facebook Research benchmark dataset associated with the ICML 2026 work on scaling small agents through strategy auctions.

## Dataset boundary

The benchmark carries metadata for 753 agentic tasks across coding and deep-search workloads, including human completion-time metadata. Its repository relies on host datasets and does not imply redistribution of every host-dataset question or answer. Host datasets, enrichment scripts, evaluated agents, strategy-auction methods, and model results remain separate from the benchmark identity.

Task inventory, host-dataset access requirements, enrichment behavior, licenses, and reported results are freshness-sensitive.
