# MaCBench

**MaCBench** — Materials-science and chemistry benchmark for multimodal vision-language reasoning.

## Data and evaluation boundary

The publisher's card describes domain-specific questions involving images, text and chemistry/materials expertise. Evaluation tasks, original figures, model responses and scoring software are distinct benchmark components.

The [original publisher dataset card](https://huggingface.co/datasets/jablonkagroup/MaCBench) was checked on 2026-11-05 and reports last modification on 2025-08-11. No immutable source SHA was available, so no pinned revision is claimed.

## Rights, limitations and safety

The publisher explicitly says NOT FOR TRAINING OR FINE-TUNING; it requests use only for evaluation to protect benchmark validity. The MIT tag on the card does not alone establish licenses for every external scientific figure.

**Access:** public. **Publisher-listed license:** MIT (publisher metadata). The dataset, outputs and evaluators were not downloaded or executed. No complete rights audit was performed.
