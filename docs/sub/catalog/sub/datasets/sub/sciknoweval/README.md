# SciKnowEval

**SciKnowEval** — scientific knowledge comprehension, reasoning and application tasks.

## Data and evaluation boundary

The publisher defines five cognitive levels from knowledge recall through scientific application. The July 2025 V2 release reports 28,392 samples and 58 tasks in four scientific domains, following the earlier original release. Hosted dataset versions, paper reports, local raw_data and scoring code must be separated rather than merged into a timeless result.

The [pinned original publisher README](https://github.com/hicai-zju/SciKnowEval/blob/53addee640092d667439e9a8901bf55f2d92c9ed/README.md) establishes dataset identity and version. Training data, test assets, model weights, evaluation software, hosted services and benchmark scores remain separately attributable.

## Rights, limitations and safety

The checked original Git root has no LICENSE file. Scientific literature-derived questions, source figures, biomedical/chemical prompts and hosted dataset records require independent access and redistribution review. Scores do not establish scientific validity or safety for practical clinical/laboratory use.

No dataset or model was downloaded, no benchmark or unsafe program was executed, and no complete rights audit, scientific reproduction, source code evaluation or repository-wide CI was run.
