# AssistantBench

**AssistantBench** evaluates whether an AI agent can complete realistic, time-consuming web information tasks. It was introduced in research on web agents and should not be confused with the separate SeePlanAct (SPA) agent or a commercial web automation service.

## Dataset and evaluation boundary

The [upstream README](https://github.com/oriyor/assistantbench/blob/2ce557dca1fca5d746d1dee07dfa86018802763c/README.md) points to the [published AssistantBench dataset](https://huggingface.co/datasets/AssistantBench/AssistantBench) and an independently maintained leaderboard. Task answers depend on changing public websites, geography, time and permitted access; the same web question may have a different correct answer on a different date.

SPA is introduced by the paper as an agent for these tasks, but an agent architecture and benchmark data are not separate copies of the same dataset. Score comparisons need consistent answer revision, browser/search tools, time, model and evaluator.
