# OR-Bench

**OR-Bench** — Benchmark of language model over-refusal on superficially harmful-looking but benign requests, with adversarial prompt generation, hosted example datasets and separate inference/leaderboard services.

## Dataset and evaluation boundary

The first-party README describes a pipeline that generates superficially unsafe-looking requests and rewrites them into benign test prompts. Its purpose is to measure **unnecessary refusals** rather than encourage harmful compliance; the hosted test data, prompt generator and model-ranking leaderboard are distinct resources.
The [pinned first-party README](https://github.com/justincui03/or-bench/blob/4fad1f9e4d4ba368777585fa1f5b869b6d4442fa/README.md) describes this benchmark snapshot.

## Rights and limitations

The repository root LICENSE is Apache-2.0 for covered code. Additional prompt corpora and hosted evaluations can have separate rights and policy requirements. Do not run or redistribute harmful-looking prompt material outside controlled research, and do not treat a low refusal rate as a general safety certificate.

No dataset was downloaded, model tested, full source rights reviewed or whole-catalog clean pass executed.
