# ContractBench

**ContractBench** — agent compliance with API artifact validity and integrity contracts.

## Data and evaluation boundary

The paper suite includes 33 task templates spanning expiration/backoff and integrity checks for presigned URLs, HMAC signatures, OAuth flows, CSRF tokens and state chains. Programmatic validators inspect local simulated server behavior; agent scaffold and serving conditions affect observed results.

The [pinned first-party README](https://github.com/SecurityLab-UCD/ContractBench/blob/44858abacaa9291fd8ae7f3c5c23b5911270d836/README.md) is the identity and version source. Data, benchmark tasks, evaluator software, trained models and published leaderboards must be attributed separately.

## Rights, limitations and safety

The pinned root MIT license covers granted source material, not real-world authentication systems or user credentials. Use only mock/local test servers, do not route any real secrets through benchmark tasks, and do not extrapolate published leaderboard results to production compliance.

No API keys, remote services, user tokens, benchmark tasks or model calls were executed. No complete rights audit or repository-wide validation was run.
