# FRAMES

**FRAMES** — Google multi-hop factuality, retrieval and reasoning evaluation built around 824 questions.

## Data and evaluation boundary

The original publisher specifies 824 demanding questions with evidence from 2-15 Wikipedia articles. Questions, supporting sources, gold answers, retrieved passages, evaluation software and historical model scores are separate artifacts.

The [original publisher dataset card](https://huggingface.co/datasets/google/frames-benchmark) was checked on 2026-11-05 and reports last modification on 2024-10-15. No immutable source SHA was available, so no pinned revision is claimed.

## Rights, limitations and safety

Publisher metadata lists Apache-2.0 for its covered dataset material; Wikipedia source text retains its own attribution and reuse conditions. Do not assume access to Wikipedia supports unlicensed reuse of all original pages or independently validate model claims.

**Access:** public. **Publisher-listed license:** Apache-2.0. The dataset, outputs and evaluators were not downloaded or executed. No complete rights audit was performed.
