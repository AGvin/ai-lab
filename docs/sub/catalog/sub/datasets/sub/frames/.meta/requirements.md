# Documentation Requirements

## Requirements

- Preserve publisher identity, source license metadata (Apache-2.0), source task boundaries and access status.
- Publisher metadata lists Apache-2.0 for its covered dataset material; Wikipedia source text retains its own attribution and reuse conditions. Do not assume access to Wikipedia supports unlicensed reuse of all original pages or independently validate model claims.
- Distinguish benchmark data, external source materials, evaluation harness and generated model responses.
- Original publisher card checked 2026-11-05 and last modified 2024-10-15; no immutable Git source SHA available through current metadata.

## Validation

- Check source card, canonical entity, requirements, reader, license notes and Datasets navigation.
- No dataset download, model inference, comprehensive rights audit, CI, full schema parsing or clean-group pass claimed.
