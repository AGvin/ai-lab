# JudgeBench

**JudgeBench** — Objective-correctness benchmark of challenging paired responses for testing LLM-as-a-judge models.

## Data and evaluation boundary

The publisher describes two dataset splits, with the GPT split containing 350 unique GPT-4o-generated response pairs. Its other split is separate and has no count asserted here. Questions, paired answers, correctness labels, judge prompts, models and leaderboard scores are separately versioned.

The [original publisher dataset card](https://huggingface.co/datasets/ScalerLab/JudgeBench) was checked on 2026-11-05 and reports last modification on 2024-10-09. No immutable source SHA was available, so no pinned revision is claimed.

## Rights, limitations and safety

The official card lists MIT but provider-generated outputs and original questions can have independent terms. Evaluation must control for answer leakage, judge bias, and whether original scoring criteria remain valid.

**Access:** public. **Publisher-listed license:** MIT (publisher metadata). The dataset, outputs and evaluators were not downloaded or executed. No complete rights audit was performed.
