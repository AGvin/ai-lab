# Documentation Requirements

## Requirements

- Preserve 600 source questions versus 555 shared-intersection results and differentiate MIT code from CC BY 4.0 data and provider-specific outputs.
- Pin original first-party repository/README version and distinguish dataset, evaluation harness, external inputs, model outputs and historical results.
- Rights and safety: Root LICENSE is MIT for software, while DATA_LICENSE expressly applies CC BY 4.0 to dataset questions, raw model logs and generated figures/tables, subject to attribution. Scientific result tables are original publisher findings; do not generalize the 555-item comparison as 600 complete model evaluations.

- Maintain one canonical identity and resolvable parent Datasets link without duplicate acceptance gates.

## Validation

- Entity metadata, source revision, requirements and reader must be consistent.
