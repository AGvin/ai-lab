# SycoBench-600

**SycoBench-600** — LLM pressure resistance and acceptance of valid corrections.

## Data and evaluation boundary

The publisher releases 600 English MCQs with misleading user-pressure styles and a matched correct-suggestion condition. Paper result tables use a 555-question shared intersection across seven models because one provider could not rerun 45 fixed items. The dataset, raw model logs, parser, Inspect adapter and historical results are separate artifacts.

The [pinned original publisher README](https://github.com/debu-sinha/sycobench-600/blob/3b2d3680b0a6d456e618206e6281904c87cb49dd/README.md) establishes dataset identity and version. Training data, test assets, model weights, evaluation software, hosted services and benchmark scores remain separately attributable.

## Rights, limitations and safety

Root LICENSE is MIT for software, while DATA_LICENSE expressly applies CC BY 4.0 to dataset questions, raw model logs and generated figures/tables, subject to attribution. Scientific result tables are original publisher findings; do not generalize the 555-item comparison as 600 complete model evaluations.

No dataset or model was downloaded, no benchmark or unsafe program was executed, and no complete rights audit, scientific reproduction, source code evaluation or repository-wide CI was run.
