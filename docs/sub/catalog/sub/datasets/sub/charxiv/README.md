# CharXiv

**CharXiv** — Princeton chart understanding multimodal benchmark; chart images and questions, the hosted dataset, evaluator, and historical model leaderboard are distinct resources.

## Data and evaluation boundary

The official README identifies CharXiv v1.0, evaluation tooling, a dataset distribution and leaderboard. Tasks assess interpretation of charts and visual numerical reasoning, not broad web browsing or arbitrary image recognition. Comparison depends on chart preprocessing, prompts, model revision and grading rules.
The [pinned first-party README](https://github.com/princeton-nlp/CharXiv/blob/7ebe88f78dee387691551f071abcb2b9e1a8025b/README.md) is the primary source; the dataset is distinct from model services and result leaderboards.

## Rights, limitations and safety

The project root LICENSE is Apache-2.0 for covered source; individual chart figures, originating papers, image copies and hosted dataset terms may differ. Avoid treating historic leaderboard values as live independent verification.

No benchmark datasets were downloaded and no models, generated programs or full repository CI were executed.
