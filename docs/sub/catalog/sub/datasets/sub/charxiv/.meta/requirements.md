# Documentation Requirements

## Requirements

- Pin CharXiv v1.0 and specific image/task distribution before cross-model scores.
- Preserve distinction between chart images, source scholarly figures, software scorer and model outputs.
- Verify attribution and source content rights independently of covered source code.
- No images downloaded, models evaluated, copyright review completed or clean pass performed.
- Keep one frozen dataset identity, source-appropriate licensing distinctions, and a valid parent category link.

## Validation

- Metadata, requirements and reader should be source-backed and consistent.
- No unperformed runtime, comprehensive rights verification, or whole-catalog clean gate credit.
