# WildClawBench

**WildClawBench** — end-to-end agent work across browser, code and communication tools.

## Data and evaluation boundary

The publisher describes 60 original end-to-end workflow tasks tested in four agent harnesses: OpenClaw, Claude Code, Codex CLI and Hermes Agent. Task data, Harbor-formatted mirrors, agent trajectories and leaderboard reruns are separately versioned; model scores vary with runtime and harness conditions.

The [pinned original publisher README](https://github.com/internlm/WildClawBench/blob/1adb2c8bea3966916bff5abaf160d6bc83e2b7ba/README.md) establishes dataset identity and version. Training data, test assets, model weights, evaluation software, hosted services and benchmark scores remain separately attributable.

## Rights, limitations and safety

The pinned root MIT license covers granted software but does not automatically permit redistribution of third-party media or emails used in task simulations. Real account access, browser automation, sensitive memory data and token handling must be isolated and strictly authorized; no live external services or user mailboxes were accessed.

No dataset or model was downloaded, no benchmark or unsafe program was executed, and no complete rights audit, scientific reproduction, source code evaluation or repository-wide CI was run.
