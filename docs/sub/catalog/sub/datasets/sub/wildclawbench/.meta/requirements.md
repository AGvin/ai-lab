# Documentation Requirements

- Keep 60 original tasks and four harnesses distinct from dataset mirrors, trajectories and leaderboard results. Do not imply benchmark access authorizes production account automation.
- Pin original first-party repository/README version and distinguish dataset, evaluation harness, external inputs, model outputs and historical results.
- Rights and safety: The pinned root MIT license covers granted software but does not automatically permit redistribution of third-party media or emails used in task simulations. Real account access, browser automation, sensitive memory data and token handling must be isolated and strictly authorized; no live external services or user mailboxes were accessed.

- Maintain one canonical identity and resolvable parent Datasets link without duplicate acceptance gates.

## Validation

- Entity metadata, source revision, requirements and reader must be consistent.
