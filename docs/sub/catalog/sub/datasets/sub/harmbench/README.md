# HarmBench

**HarmBench** — robust refusal and automated red-teaming evaluation.

## Data and evaluation boundary

The published suite compares automated red-teaming methods against target models, and also models against common red-teaming methods. Its original paper evaluates 18 attack methods and 33 target LLMs/defenses. Prompt datasets, classifiers, test-case generation scripts and reported scores must remain separately attributed.

The [pinned first-party source](https://github.com/centerforaisafety/HarmBench/blob/8e1604d1171fe8a48d8febecd22f600e462bdcdd/README.md) establishes the identity and release scope. Related model outputs, scoring programs, downloaded task materials and historical leaderboard measurements remain separate artifacts.

## Rights, limitations and safety

The pinned root MIT license covers granted code only, not automatically every curated harmful prompt, other source datasets or separately hosted model weights. Use strictly controlled safety research; no harmful completions, attacks, guardrail bypasses or unauthorized endpoint testing.

No benchmark datasets were downloaded and no evaluator, model, untrusted code, harmful safety prompt or physical experiment was executed. No full rights audit or repository-wide CI was run.
