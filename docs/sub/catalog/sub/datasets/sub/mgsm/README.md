# MGSM

**MGSM** — human-translated multilingual grade-school mathematical reasoning.

## Data and evaluation boundary

The first-party MGSM README identifies 250 grade-school math questions translated by human annotators into Spanish, French, German, Russian, Chinese, Japanese, Thai, Swahili, Bengali and Telugu. Original English records and multilingual few-shot exemplars are present separately. Do not count each language rendering as an independent benchmark identity.

The [pinned first-party source](https://github.com/google-research/url-nlp/blob/452a21ad3dae5668c06ceeac21ff073e1e40f9be/mgsm/README.md) establishes the benchmark identity and version. Source data, trained models, scoring software, external service dependencies and leaderboard results are separate, version-dependent artifacts.

## Rights, limitations and safety

The pinned MGSM subdirectory includes a CC BY 4.0 LICENSE, requiring attribution. The containing Google Research URL-NLP repository is archived, so the exact source revision should be maintained; language-specific evaluation settings and original GSM8K provenance remain distinct.

This is a source-backed metadata profile only. No benchmark input, model run, generated program, audio recording, private data or unsafe code was executed or downloaded, and no repository-wide validation or complete rights audit was performed.
