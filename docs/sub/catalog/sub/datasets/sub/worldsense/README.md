# WorldSense

**WorldSense** — synthetic language-grounded reasoning and generalization tasks.

## Data and evaluation boundary

The official source distributes 87,048 test records across six main problem variants in the standard benchmark, plus distinct memorization and out-of-distribution sets. Test records, generated training sets, baseline model result files and analysis scripts are separate; historical GPT-3.5/GPT-4/Llama-2 comparisons reflect the publisher's 2023 setup.

The [pinned original publisher README](https://github.com/facebookresearch/worldsense/blob/bd81d945077f169cf95ff39207f788f86e4645e9/README.md) establishes dataset identity and version. Training data, test assets, model weights, evaluation software, hosted services and benchmark scores remain separately attributable.
