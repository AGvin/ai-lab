# Humanity's Last Exam

Humanity's Last Exam (HLE) is a concrete multimodal frontier academic-knowledge benchmark/dataset distributed by the upstream project.

## Dataset boundary

The benchmark spans broad subject coverage and mixed question formats while remaining distinct from example inference or evaluation scripts, leaderboard results, model providers, and generic benchmark concepts. Published contamination controls such as a canary can help detect exposure but do not prove that a model was never exposed to benchmark material.

Dataset revisions, question counts, scoring configuration, public availability, and results are version-sensitive. Scores should be interpreted only with matching prompts, models, graders, and dataset revisions.
