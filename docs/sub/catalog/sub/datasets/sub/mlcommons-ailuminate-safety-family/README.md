# MLCommons AILuminate

**MLCommons AILuminate** — standardized safety prompt assessment and benchmarking.

## Data and evaluation boundary

The official pinned README describes 1,200 v1.0 demo prompts, representing ten percent of the 12,000 public-practice prompts, alongside 12,000 private benchmark prompts across twelve hazard categories. The source also documents an assessment standard and separately managed evaluation models. Later v1.1 description is not assumed to use the same distribution or metrics.

The [original publisher source](https://github.com/mlcommons/ailuminate) and [pinned publisher README](https://github.com/mlcommons/ailuminate/blob/769cc2be9d20c8d4fb26ce53b68865ed41dfb8e2/README.md) establish this specific release. Source data, evaluation software, model weights, scoring outputs and historical leaderboards are independently attributable.

## Rights, limitations and safety

The root LICENSE.md is Apache-2.0 for repository-covered software, whereas the v1.0 demo prompts are explicitly CC BY 4.0 in the README. Private and member-controlled practice sets remain access-restricted; do not publish sensitive question text, reconstruct private test items or contaminate training.

This is an evidence-backed metadata profile only. No benchmark inputs, model inference, untrusted code, audio, private data or security experiment was executed or downloaded. No complete rights audit or whole-repository CI was performed.
