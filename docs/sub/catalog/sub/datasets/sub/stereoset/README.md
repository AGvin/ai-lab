# StereoSet

**StereoSet** is a benchmark of stereotypical bias in pretrained language models. The pinned publisher README describes its evaluation scripts, development gold file, model predictions and a leaderboard, while noting the original repository is **no longer actively maintained** and directing users to the newer Bias Bench repository for updated code and the full test set.

## Reproducibility and rights

No repository-root LICENSE was found at the pinned source revision, so public visibility **does not establish commercial, redistribution or derivative rights** for the dataset or code. Results are specific to the prompt set, protected social contexts, model versions and evaluation method; bias scores do not prove an individual's qualities or a model's overall fairness.
