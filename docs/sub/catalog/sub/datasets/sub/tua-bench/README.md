# TUA-Bench

TUA-Bench, or Terminal-Use Agent Benchmark, is a released benchmark for evaluating general-purpose terminal-use agents on realistic command-line tasks.

## Dataset boundary

TUA-Bench remains distinct from Terminal-Bench, Long-Horizon Terminal-Bench, SWE-bench, and generic shell-agent tooling. Its task design, evaluation harness, environment and runtime assumptions, and results belong to the benchmark's released evaluation configuration. Harbor-compatible execution, Docker or Podman support, example agents, and model-provider settings are execution surfaces rather than separate benchmark identities.

Task inventory, harness versions, environment backends, evaluation settings, and leaderboard results are freshness-sensitive and run-scoped.
