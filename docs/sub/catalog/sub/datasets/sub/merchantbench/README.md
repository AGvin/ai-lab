# MerchantBench

MerchantBench is a released long-horizon benchmark for evaluating LLM-agent coherence in persistent seller-side e-commerce operations.

## Dataset boundary

The benchmark models a 365-day simulated store with order-level dynamics, delayed outcomes, supplier changes, cash-flow constraints, and final operational and economic evaluation. The simulator, SDK, evaluation harness, baselines, and tests are surfaces of the same benchmark rather than separate production-commerce identities.

Scenario configuration, baselines, evaluator details, benchmark versions, and published results are freshness-sensitive. Long-horizon coherence findings remain tied to the benchmark design rather than becoming generic claims about agent memory.
