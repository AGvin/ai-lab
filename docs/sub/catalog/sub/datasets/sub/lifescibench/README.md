# LifeSciBench

LifeSciBench is OpenAI's expert-authored evaluation of realistic life-science research tasks. The published scope includes 750 tasks across seven workflows and seven biological domains, created and reviewed with practicing life scientists.

## Task and scoring scope

Tasks combine a scientific request, relevant context or artifacts, and a free-response answer. Expert-written rubrics assess whether an answer addresses the problem with appropriate evidence, detail, caveats, and formatting. Supporting material can include figures, documents, tables, sequence or structure files, and web references.

Use the benchmark to investigate bounded research-task capabilities. The tasks, supplied artifacts, rubrics, response grader, and evaluated models have distinct roles. Rubric credit and a task's pass threshold also describe different aspects of performance.

## Reproduction and limits

Record the task and artifact release, workflow/domain taxonomy, public-access conditions, scoring rubric and threshold, evaluator configuration, and model/tool setup before comparing results. Artifact access and grading revisions can alter the evaluation. Check the publication's release details rather than assuming that a model-access or contributor link provides benchmark data.

Task performance does not establish experimental validity, autonomous scientific discovery, or usefulness across a live research program. Evaluate those outcomes separately before making research or product decisions.
