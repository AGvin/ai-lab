# VisualWebArena

VisualWebArena is the separately published 2024 benchmark for multimodal web agents solving visually grounded tasks in controlled websites.

## Task and evaluation boundary

The first-party benchmark contains 910 visual tasks. Its 233 human trajectories form a subset, not the full evaluation corpus. Website images and visually grounded success conditions distinguish it from the original WebArena benchmark.

Reproduce the self-hosted environments and pin task data, website state, evaluator, observation mode and model configuration. Original WebArena's 812-task count and annotation version do not transfer to this benchmark. Scores from VisualWebArena, WebArena-Infinity and other suites require matched protocols before comparison.
