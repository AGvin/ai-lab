# WikiWebFacts

**WikiWebFacts** — Russian short-answer factual question answering based on encyclopedic and web knowledge, distinct from HardMultiQA.

## Data and evaluation boundary

The publisher identifies Russian text-only short-answer QA in Parquet with a 1k-10k sample size category. Exact question counts and model scores are not verified.

The [original publisher dataset card](https://huggingface.co/datasets/yandex/WikiWebFacts) was checked on 2026-11-05 and reports last modification on 2026-09-18. No immutable source SHA was available; no pinned revision is claimed.

## Rights, limitations and safety

The publisher marks this dataset gated and CC BY-SA 4.0. It voluntarily asks users to share links rather than publish mirrored test items to reduce contamination, explicitly without restricting existing license rights.

**Access:** gated. **Publisher-listed license:** CC BY-SA 4.0. No source examples, models or evaluation tools were downloaded or executed, and no comprehensive rights audit was performed.
