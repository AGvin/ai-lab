# Bias Benchmark for QA (BBQ)

BBQ is a question-answering bias dataset contrasting ambiguous contexts with contexts that provide the information needed for a correct response. The design can reveal stereotype-driven guessing and contradictions between a known answer and biased predictions; a single metric cannot certify general fairness.

## Dataset and evaluation boundaries

The pinned README describes bias assessment across nine social dimensions, with separate under-informative and adequately-informative contexts.
Dataset files are JSONL by category; the README describes 11 JSONL category files. Counts are repository-version-specific.

## Licensing, reproducibility and responsible use

CC BY 4.0 (repository LICENSE); sensitive bias examples. Handle protected-group stereotype content as sensitive evaluation material, not training instructions or endorsements. No fairness certification, complete demographic validity audit, test run or clean pass.
