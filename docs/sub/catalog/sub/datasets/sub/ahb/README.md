# Adversarial Humanities Benchmark (AHB)

**Adversarial Humanities Benchmark (AHB)** — refusal robustness against humanities-inspired adversarial reformulations.

## Data and evaluation boundary

The first-party release contains transformed text-only evaluation prompts and metadata derived from MLCommons AILuminate source prompts. The original source prompts and private transformation method are not part of this public release. Its Hugging Face test split is an evaluation artifact, not training data.

The [pinned first-party README](https://github.com/icaro-lab/ahb/blob/4b7b631245fa300df98d2c310e83273ed0d4a207/README.md) is the identity and version source. Data, benchmark tasks, evaluator software, trained models and published leaderboards must be attributed separately.

## Rights, limitations and safety

The repository carries an MIT LICENSE for its covered software; source prompt rights, released dataset terms and downstream redistribution require separate review. Safety-oriented adversarial prompts should not be copied into training corpora or used to generate unsafe completions.

No harmful prompts, evaluation calls, benchmark data or model outputs were executed. No complete rights audit or repository-wide validation was run.
