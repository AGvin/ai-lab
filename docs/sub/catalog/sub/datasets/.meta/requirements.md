# Documentation Requirements

## Requirements

- Present `datasets/` as the canonical catalog owner for concrete datasets used, evaluated, or referenced by AI Lab documentation.
- Keep dataset identity, provenance, licensing, version or snapshot scope, and durable source-backed facts with concrete dataset profiles rather than duplicating them in unrelated concept or evaluation pages.
- Keep the index honest about current materialization; do not imply a concrete dataset inventory exists when none is materialized.
- Keep the page concise and ready to link concrete dataset profiles as evidence justifies adding them.

## Validation

- The page contains no temporary-placeholder or RC wording.
- The page does not claim a concrete dataset inventory that is not materialized.
- Future listed dataset links resolve to canonical dataset nodes.
