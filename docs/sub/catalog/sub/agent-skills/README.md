# Agent Skills

Agent Skills are portable packages of instructions and optional scripts, references, and assets that compatible AI hosts can discover and load for repeatable work.

AI Lab catalogs a skill as a standalone entity only when independent publication or another independent canonical identity is verified. Skills represented only inside a collection stay with that collection instead of being duplicated as separate catalog pages.

## Collections

- [Agent Skill Collections](./sub/collections/) — selected repositories and coordinated bundles of Agent Skills.

No independently published standalone skill is currently materialized in this catalog.
