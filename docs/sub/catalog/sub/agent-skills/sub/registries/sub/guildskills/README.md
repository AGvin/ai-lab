# GuildSkills

GuildSkills is an independent cross-agent registry and discovery service for skills using the open Agent Skills / `SKILL.md` format.

Discovery, installation, supported agents, publishing, validation, and registry behavior are freshness-sensitive. Registry interoperability does not redefine the formal Agent Skills specification or any host product's concrete support behavior, and inclusion is not an endorsement or security guarantee.
