# GuildSkills

GuildSkills is an independent cross-agent registry and discovery service for skills using the open Agent Skills / `SKILL.md` format.

Discovery, installation, supported agents, publishing, validation, and registry behavior are freshness-sensitive. Registry interoperability does not redefine the formal Agent Skills specification or any host product's concrete support behavior, and inclusion is not an endorsement or security guarantee.

## Installation and trust boundaries

The free directory is distinct from its advertised paid Quality Score and desktop installation features. Rankings, client-compatibility claims, and feature availability come from the registry operator, not independent verification.

**Windows installer caution:** GuildSkills states that its Windows desktop installer is not code-signed and advises visitors to bypass a Microsoft Defender SmartScreen warning. That suggestion is not a safety clearance. Do not override an operating-system warning merely to install an unverified client; independently verify the publisher, package provenance and integrity, or inspect and install trusted skills through a supported manual workflow instead.
