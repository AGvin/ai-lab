# Documentation Requirements

## Requirements

- Present AgentSkills.to as an independent Agent Skills marketplace/directory oriented toward discovering skills usable across multiple coding/agent clients.
- Keep current client-support, categories, installation instructions, ranking, publishing/submission, and marketplace behavior tied to current first-party evidence.
- Distinguish marketplace discovery from the canonical identity and authority of each indexed skill or source repository.
- Do not present listing or popularity as proof of safety, quality, or compatibility.
