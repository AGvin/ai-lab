# Documentation Requirements

## Requirements

- Present agentskills.codes as an independent public registry/directory for discovering installable Agent Skills.
- Keep claims about indexed inventory, categories, supported clients, installation mechanisms, validation, ranking, or moderation tied to current first-party site evidence.
- Distinguish the registry from the upstream repositories and publishers whose skills it indexes.
- Do not infer endorsement, safety, or compatibility merely from registry presence.

## Freshness

- Re-verify registry scope, inventory, installation behavior, client support, and trust/moderation features before substantive edits.

## First-party registry surface and security grade comparison — 2026-11-09

- The [first-party homepage](https://agentskills.codes/) markets a changing index and daily scans, four named agent clients (Claude Code, Codex, GitHub Copilot and Antigravity), `npx degit` source copy into agent-specific skill directories, and per-skill GitHub/license/commit links. Static `clean` / `review` / `warn` grades are **provider-generated indicators**, not a validated sandbox, code audit, signature, or permission approval.
- Its [contact/footer](https://agentskills.codes/contact) says the registry site itself is MIT licensed. That claim does **not** grant MIT rights to every independently attributed third-party skill or source asset; audit the exact upstream path and skill license before copying, vendoring or redistribution.
- The site shows a mutable inventory total and daily recrawl marketing, but the accessible indexed first-party page may be a cached snapshot without a dated crawl manifest. Do not treat that displayed count or any per-skill `last commit` field as a synchronized, independently verified as-of-2026-11-09 inventory.
- Individual skills inherit an agent's configured filesystem/network/shell permissions after installation. Verify the chosen original repository, scripts and requested operations before running its one-line install. No registry installer, index API, source code, or skill was executed in this review.
