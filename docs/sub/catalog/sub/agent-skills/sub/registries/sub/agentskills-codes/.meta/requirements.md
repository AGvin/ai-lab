# Documentation Requirements

## Requirements

- Present agentskills.codes as an independent public registry/directory for discovering installable Agent Skills.
- Keep claims about indexed inventory, categories, supported clients, installation mechanisms, validation, ranking, or moderation tied to current first-party site evidence.
- Distinguish the registry from the upstream repositories and publishers whose skills it indexes.
- Do not infer endorsement, safety, or compatibility merely from registry presence.

## Freshness

- Re-verify registry scope, inventory, installation behavior, client support, and trust/moderation features before substantive edits.
