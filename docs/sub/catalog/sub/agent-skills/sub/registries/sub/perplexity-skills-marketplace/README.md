# Perplexity Skills Marketplace

Perplexity Skills Marketplace is a discovery and installation registry for reusable Computer skills, including public and organization-managed skills.

## Use and deployment boundaries

Public browsing and Enterprise administration are different access levels. Inspect the selected skill's publisher, instructions and requested access; organization approval does not establish code safety or grant unrelated application permissions.
