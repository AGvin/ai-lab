# Perplexity Skills Marketplace

Perplexity Skills Marketplace is a discovery and installation registry for reusable Computer skills, including public and organization-managed skills.

## Use and deployment boundaries

Public browsing and Enterprise administration are different access levels. Inspect the selected skill's publisher, instructions and requested access; organization approval does not establish code safety or grant unrelated application permissions.

## Current distribution and rights boundary

The later [2026-11-06 Agent Plugins release](https://www.perplexity.ai/changelog/teammates-fully-local-computer-on-mac-and-voice-mode) adds packages that install **skills and connectors together**, including supported GitHub/ZIP imports. Agent Plugins are a distribution/integration surface, not a new identity for the Skills Marketplace or each listed skill. Enterprise administrators can configure which roles may add plugins or use their connectors; installation alone does not authorize connected accounts, external data sharing or live side effects.

Perplexity's [consumer Terms](https://www.perplexity.ai/en-GB/hub/legal/terms-of-service) distinguish user-submitted content rights from service and third-party material and explicitly separate Enterprise/API contracts. A marketplace listing does not license every third-party skill or prove execution safety. Verify publisher rights, the applicable account/contract and permissions for each skill or plugin. No authenticated installation or runtime testing was performed.
