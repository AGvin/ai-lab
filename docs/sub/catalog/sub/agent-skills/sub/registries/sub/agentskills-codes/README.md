# agentskills.codes

agentskills.codes is an independent public registry and directory for discovering installable Agent Skills.

Registry inventory, categories, supported clients, installation mechanisms, validation, ranking, and moderation are mutable and must remain tied to current first-party evidence. Registry presence does not imply endorsement, safety, or compatibility, and the registry remains distinct from the upstream publishers and repositories whose skills it indexes.

## Official resource

- [agentskills.codes](https://agentskills.codes/)

## Registry freshness and installation boundaries

The operator's [homepage](https://agentskills.codes/) advertises daily static scans, source-linked SKILL.md entries and `npx degit` commands for multiple coding agents. The registry's trust grades (`clean` / `review` / `warn`) are marketing-facing **static checks**, not a runtime isolation or security guarantee. Installing a skill gives its instructions the agent's actual available permissions; review the exact publisher source and code before installing.

The [registry footer](https://agentskills.codes/contact) calls the **registry** MIT-licensed, but indexed skills retain their individual original-source licensing and rights. Current skill totals, last-commit data and scanner freshness are mutable provider-reported figures, not independently certified counts. No skill, package or installer was run.
