# SkillHub

SkillHub, available at skill-marketplace.com, is an independent open-source Agent Skills marketplace and aggregation platform.

Source aggregation, search and discovery, installation, supported clients, quality or security signals, hosting or deployment, and marketplace behavior are mutable. The aggregator remains distinct from the original repositories and publishers whose skills it exposes, and aggregation, ranking, or scanning does not prove safety or quality.
