# SkillHub

SkillHub, available at skill-marketplace.com, is an independent open-source Agent Skills marketplace and aggregation platform.

Source aggregation, search and discovery, installation, supported clients, quality or security signals, hosting or deployment, and marketplace behavior are mutable. The aggregator remains distinct from the original repositories and publishers whose skills it exposes, and aggregation, ranking, or scanning does not prove safety or quality.

## Source identity, sync status and rights

The [first-party source](https://github.com/dukelyuu/skills-marketplace) links to this exact hosted domain and documents a React/FastAPI/SQLite marketplace, GitHub-source synchronization, an editor and optional repository integration credentials. Its [source-management view](https://www.skill-marketplace.com/sources) distinguishes **Active**, **Syncing** and **Pending** repositories, including never-synchronized entries. Marketplace totals and safety badges are not evidence that every listed repository has been fetched or independently reviewed.

**License inconsistency:** the publisher's GitHub README carries an **MIT** badge, but its License section and actual root [LICENSE](https://github.com/dukelyuu/skills-marketplace/blob/main/LICENSE) say **Apache-2.0**. The operator should reconcile that discrepancy; neither claim grants permission to redistribute third-party skills or their assets. Check the selected source repository's own rights before copying or installing anything.

Running the source aggregator entails optional GitHub token access and local dependencies; hosted search, editing, automatic syncing and downloaded code have separate trust and authorization boundaries. This is a static publisher-source and page review, **not** a verified live inventory, installer safety audit or executed deployment.
