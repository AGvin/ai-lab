# AgentSkills.to

AgentSkills.to is an independent Agent Skills marketplace and directory oriented toward discovering skills usable across multiple coding and agent clients.

Supported clients, categories, installation instructions, ranking, submission or publishing behavior, and marketplace mechanics are mutable. Marketplace discovery remains distinct from the canonical identity and authority of each indexed skill or source repository, and listing or popularity is not evidence of safety, quality, or compatibility.

## Official resource

- [AgentSkills.to](https://www.agentskills.to/)

## Marketplace freshness, privacy and author rights

The [original marketplace](https://www.agentskills.to/) advertises a cross-agent skill index; its `4K+` homepage total is not reconcilable directly with the much larger sum of displayed category totals. Treat counts, compatibility, popularity and install numbers as operator claims, not a verified de-duplicated inventory. The [About page](https://www.agentskills.to/about) says the collection is community-contributed and includes scripts and workflows; listing does not certify code safety.

The [Privacy Policy](https://www.agentskills.to/privacy) says submitted skills and profiles may be public, while account/GitHub information and analytics may be collected. Do not upload confidential material or credentials in the belief that marketplace submission is private. The linked [Terms page](https://www.agentskills.to/terms) could not be independently retrieved for this check. **No universal redistribution or copyright clearance is inferred** from the Privacy Policy, site listing or open-source marketing; check each selected author's original source license and the applicable publisher upload terms.
