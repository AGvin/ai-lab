# skills.sh

skills.sh is a public Agent Skills discovery index and leaderboard. The separate [Vercel Skills CLI](../../../../../software/sub/development-tools/sub/agentic-development-systems/sub/vercel-skills-cli/) is independently installable software for discovering, installing and updating skills; neither is the Vercel Agent Skills collection.

## Registry boundary

The registry indexes published skills, while the independent CLI handles local installation and management. Local paths, updates, agent selection and telemetry depend on the pinned CLI release and belong to its own software documentation.

Ranking, telemetry, supported agents, scanning behavior, commands, and installation or update semantics are mutable. Security or scanning signals are registry features rather than guarantees of skill quality or trustworthiness.

## Packs, privacy and content rights

The official [Skills Packs documentation](https://www.skills.sh/docs/packs) allows bundled skills from public listings, connected repositories and private files or archives. **Packs are unlisted, not access-controlled:** anyone with a pack URL can view and install its contents without authentication. Do not put credentials, confidential instructions or private material in a shared pack; confirm the right to redistribute included third-party work before sharing.

The official [skills.sh Terms](https://www.skills.sh/terms) say indexed skills remain owned by their original authors and are distributed under their source-repository licenses. The [MIT license of the separate Skills CLI](https://github.com/vercel-labs/skills/blob/main/LICENSE) is not a license for every listed skill or uploaded pack. Installation or audit badges do not independently establish a skill's safety, ownership or rights.
