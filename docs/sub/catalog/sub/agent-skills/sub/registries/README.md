# Agent Skill Registries

Agent Skill registries are identifiable multi-source services, directories, marketplaces, or installer-backed indexes for discovering, evaluating, distributing, or installing Agent Skills.

A registry aggregates or indexes skills from multiple independent sources; a publisher-owned repository collection belongs under `collections/` instead. Registry inventory, supported clients, ranking, scanning or trust signals, installation interfaces, telemetry, and private-registry behavior are mutable service facts and do not prove skill quality, safety, or compatibility.
