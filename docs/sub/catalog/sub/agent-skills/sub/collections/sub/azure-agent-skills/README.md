# Azure Agent Skills

Azure Agent Skills is the MicrosoftDocs-maintained collection of production-oriented Agent Skills for Azure cloud development, built from and linked to current Microsoft Learn documentation.

## Producer

- [Microsoft](../../../../../producers/sub/m/sub/microsoft/)

## Collection boundary

Azure Agent Skills is distinct from the `microsoft/skills` collection: it has its own repository, docs-to-skills generation and catalog pipeline, Azure-service knowledge focus, and multi-assistant plugin packaging. Individual generated Azure service skills remain contents of this collection rather than separate catalog entities by default.

Skill inventory and counts, generated timestamps, bundles, plugin manifests, installation commands, supported assistants, documentation dependencies, and experimental host-feature requirements are freshness-sensitive.
