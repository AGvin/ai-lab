- The document skills can be installed as a collection, but their runtime requirements differ by file format.
- They do not form a mandatory cross-skill chain; install only the formats required by the host when selective installation is supported.
- Each selected skill depends on bundled scripts and external document-processing libraries or command-line tools documented on its own page.
