## Collection

AWS Labs publishes healthcare and life-sciences instruction and pipeline guidance under MIT-0. Skill/domain counts and harness support are mutable. Repository evaluation figures are publisher-reported and were not reproduced. These demonstrations do not establish clinical suitability; keep sensitive health data access and scientific output review separate.

## Skill types and evaluation

**Reasoning skills** provide scientific and clinical methods or decision frameworks; **pipeline skills** contain tool-specific commands, parameter references and workflow patterns. Example domains include variant interpretation, clinical HL7/FHIR parsing and research pipelines. Skill and domain counts change; individual skills are collection inventory, not automatic peer catalog entities.

The [publisher's technical evaluation](https://github.com/awslabs/hcls-agent-skills/blob/4603541c396cdd845dbae554800a65132d12bb63/eval/TECHNICAL_REPORT.md) reports **410 prompts** (380 single-skill and 30 cross-skill), with Claude Opus 4.7 as an automated judge. The source reports **69.5%** wins with an agentic CLI harness and **85.9%** with a clean SDK harness. These are publisher-run, unreplicated response comparisons; they do not prove clinical accuracy, patient outcomes or production reliability.

## Safety and distribution boundary

The [upstream README](https://github.com/awslabs/hcls-agent-skills/blob/4603541c396cdd845dbae554800a65132d12bb63/README.md) expressly labels this collection **demonstrative, not for clinical use or production**, and not a replacement for professional medical advice, diagnosis or treatment. A qualified domain reviewer must assess scientific outputs. Protected health information must not be exposed to unapproved tools; HIPAA obligations, any required AWS Business Associate Addendum (BAA), and secure service configurations are independent decisions.

The checked [root license](https://github.com/awslabs/hcls-agent-skills/blob/4603541c396cdd845dbae554800a65132d12bb63/LICENSE) provides MIT-0 terms for covered source files; it does not grant patient-data access, third-party asset rights, or credentials/permissions for cloud operations.
