# Awesome GitHub Copilot

Awesome GitHub Copilot is a GitHub-organization-maintained, community-contributed collection of custom agents, instructions, Agent Skills, plugins and other Copilot customizations. This catalog entry covers its **Agent Skills collection**, rather than treating every bundled skill or other asset as a separate canonical collection.

## Collection and trust boundary

The upstream `skills/` directory and [Agent Skills index](https://github.com/github/awesome-copilot/blob/main/docs/README.skills.md) publish skills with `SKILL.md` instructions and optional scripts, references or templates. The upstream documentation describes GitHub CLI installation (`gh skills install github/awesome-copilot <skill-name>`, requiring GitHub CLI 2.90.0 or newer at the reviewed revision). The collection changes over time, so the selected skill, installation command and host compatibility need a fresh check.

GitHub maintains and distributes the repository, but its contents are community-contributed; the repository explicitly warns users to inspect third-party customizations. The repository-root MIT license does not independently verify each bundled third-party asset or dependency. Review the selected skill's instructions, scripts, permissions, rights and supply chain, and pin a reviewed revision before executing it with project data or credentials. Installation is not authorization for external effects. GitHub Copilot, the Copilot plugin marketplace and the collection's non-skill assets retain distinct identities.
