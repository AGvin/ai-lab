# Shopify Agent Skills

Shopify Agent Skills is Shopify’s first-party collection of instructions and supporting material for coding agents working with Shopify APIs and development tools. It covers areas such as Admin and Storefront APIs, customer accounts, Functions, Hydrogen, Liquid and extension interfaces. Individual skill folders are selectable content within this collection.

## Generated distribution

The repository is generated from an upstream source and does not accept direct pull requests. Skills include documentation-search and validation scripts, API-specific configuration and schema or reference assets. That Shopify-specific layout is not a universal Agent Skills format requirement. Use the current repository’s installation instructions: its documented CLI is `npx skill`, whose name must not be silently replaced with a different tool.

## Permissions and applicability

Installing instructions or passing a validation script does not authorize a merchant store, prove compatibility with every API version or replace app permission checks. Inspect the selected scripts, pin relevant API/schema versions and grant scoped credentials separately. The inspected repository root did not supply a blanket license document; do not infer unrestricted redistribution from public visibility. Shopify’s hosted commerce services, SDKs and third-party extensions retain their own boundaries.
