# Alibaba Cloud Skills

Alibaba Cloud Skills is Alibaba Cloud's official repository-backed Agent Skills collection for Alibaba Cloud products and related general-purpose workflows.

## Producer

- [Alibaba Cloud](../../../../../producers/sub/a/sub/alibaba-cloud/)

## Collection boundary

The collection preserves separate stable and preview release channels. Alibaba Cloud services, Qwen models, MCP servers, CLI tools, and individual skill contents remain separate identities unless independently materialized elsewhere.

Exact skill inventory, stable and preview versions, installation commands, supported agents, repository layout, and product coverage are freshness-sensitive.
