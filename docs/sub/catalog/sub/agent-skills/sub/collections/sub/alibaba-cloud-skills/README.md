# Alibaba Cloud Skills

Alibaba Cloud Skills is Alibaba Cloud's official repository-backed Agent Skills collection for Alibaba Cloud products and related general-purpose workflows.

## Producer

- [Alibaba Cloud](../../../../../producers/sub/a/sub/alibaba-cloud/)

## Collection boundary

The collection preserves separate stable and preview release channels. Alibaba Cloud services, Qwen models, MCP servers, CLI tools, and individual skill contents remain separate identities unless independently materialized elsewhere.

Exact skill inventory, stable and preview versions, installation commands, supported agents, repository layout, and product coverage are freshness-sensitive.

## Installation, credentials and rights

The [publisher README](https://github.com/aliyun/alibabacloud-aiops-skills/blob/4a4e9c62d4690949af094d29546ed852309f7ca9/README.md) distinguishes the stable `master` release from a `preview` channel and documents `npx skills add aliyun/alibabacloud-aiops-skills`. The source's skills list is still a placeholder, so no complete stable/preview inventory is certified here. Installation does not authenticate Alibaba Cloud resources or authorize changes to infrastructure or billing.

**License unresolved:** the same first-party README labels the collection **Apache-2.0** in its License section but says its skills are under **MIT** in the Legal section. No root `LICENSE` file was found in the inspected revision. Neither label is adopted as a verified universal grant. Obtain publisher clarification and inspect the selected skill, dependencies and applicable service terms before redistribution or other license-sensitive use.

**Credential safety:** Alibaba Cloud says AccessKeys and CLI-profile credentials are intended for local personal testing; for cloud-hosted workloads it recommends ECS RAM role credentials. Never expose credentials to untrusted instructions, chat transcripts or source control. Use least-privilege cloud roles and separately authorize all operational changes. No skill was installed or executed for this catalog record.
