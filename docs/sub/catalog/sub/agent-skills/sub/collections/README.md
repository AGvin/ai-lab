# Agent Skill Collections

Selected repositories and coordinated bundles that publish or distribute Agent Skills. Each collection page owns its collection identity, distribution context, and the selected collection-owned skills represented in AI Lab.

## Collections

- [Alibaba Cloud Skills](./sub/alibaba-cloud-skills/) — Alibaba Cloud's official repository-backed Agent Skills collection for Alibaba Cloud products and related general-purpose workflows.
- [Anthropic Skills](./sub/anthropic-skills/) — Anthropic's public repository of skills for Claude.
- [Agent Toolkit for AWS Skills](./sub/aws-agent-toolkit-skills/) — the official AWS-supported Agent Skills collection packaged within Agent Toolkit for AWS.
- [Awesome GitHub Copilot](./sub/awesome-copilot/) — GitHub's community-contributed collection of Agent Skills and other Copilot customization resources.
- [Azure Agent Skills](./sub/azure-agent-skills/) — the MicrosoftDocs-maintained collection for Azure cloud development.
- [Cloudflare Skills](./sub/cloudflare-skills/) — Cloudflare's official collection for the Cloudflare Developer Platform and related products.
- [Composio Awesome Claude Skills](./sub/composio-awesome-claude-skills/) — Composio-maintained, community-contributed Agent Skills directory and repository bundles.
- [Google Agent Skills](./sub/google-skills/) — Google's official repository-backed collection for Google products and technologies.
- [Hugging Face Skills](./sub/hugging-face-skills/) — Hugging Face's official collection for Hub and AI/ML workflows.
- [JetBrains Skills](./sub/jetbrains-skills/) — JetBrains-curated skills with upstream source attribution and security filtering.
- [Matt Pocock Skills](./sub/matt-pocock-skills/) — composable engineering and productivity skills from Matt Pocock.
- [Microsoft Skills](./sub/microsoft-skills/) — Microsoft's official repository-backed collection for Azure SDK and Microsoft Foundry development workflows.
- [MongoDB Agent Skills](./sub/mongodb-agent-skills/) — MongoDB instructions for database design, query development and schema work.
- [Neon Agent Skills](./sub/neon-agent-skills/) — Neon instructions for database development and deployment workflows.
- [NVIDIA Skills](./sub/nvidia-skills/) — NVIDIA's verified Agent Skills catalog and governance-oriented tooling.
- [OpenAI Skills](./sub/openai-skills/) — the deprecated `openai/skills` repository retained as the source of selected historical/system skills, with current Codex plugin examples moved to OpenAI Plugins.
- [Perplexity API Platform Skills](./sub/perplexity-api-platform-skills/) — Perplexity's API integration and search-development skills.
- [Ponytail](./sub/ponytail/) — Dietrich Gebert's coordinated Agent Skill collection focused on minimizing unnecessary implementation complexity.
- [Prisma Skills](./sub/prisma-skills/) — Prisma's first-party ORM, database migration and deployment guidance.
- [Redis Agent Skills](./sub/redis-agent-skills/) — Redis data-structure, search, caching and operations guidance.
- [Shopify Agent Skills](./sub/shopify-agent-skills/) — Shopify API and app-development guidance.
- [Stripe Agent Skills](./sub/stripe-agent-skills/) — Stripe's official integration and API development skills.
- [Supabase Agent Skills](./sub/supabase-agent-skills/) — Supabase and PostgreSQL development guidance.
- [Superpowers](./sub/superpowers/) — a coordinated software-development methodology built from composable Agent Skills.
- [Trail of Bits Skills](./sub/trail-of-bits-skills/) — security analysis, code auditing and verification Agent Skills published as Trail of Bits' plugin marketplace.
- [Vercel Agent Skills](./sub/vercel-agent-skills/) — Vercel's first-party coding-agent guidance.
- [Wan Agent Skills](./sub/wan-agent-skills/) — Wan Team's model-generation skills for Wan and Model Studio.
