# Skill Card Generator

> **Temporary catalog summary:** This short description is a placeholder for a future reviewed skill profile.

Skill Card Generator creates a draft NVIDIA governance card for an existing Agent Skill directory and validates the resulting review artifact.

## Dependencies

- Required Agent Skills: none.
- Collection/setup requirement: selective installation is supported.
- Runtime/tool dependencies: Python 3, `jinja2`, file read/write access, and permission to run the three bundled scripts.
- Bundled resources: discovery, rendering, and validation scripts; style guide, template, and governance catalogs.
- Used by: governance and review workflows for other skills.
