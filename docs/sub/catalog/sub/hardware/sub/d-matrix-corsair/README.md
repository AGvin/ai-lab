## Exact product scope

d-Matrix Corsair is an N6-process SRAM-centric digital-in-memory-compute inference accelerator platform using LPDDR5. Its hardware is supplied in card, server and rack configurations; SquadRack additionally integrates JetStream networking and Aviator software. In June 2026 d-Matrix announced full production and intended volume shipments to select qualified customers, not proof of unrestricted retail stock. Vendor heterogeneous GPU/Corsair speed claims and July Qwen3 full-model execution are scoped demonstrations, not universal end-to-end inference benchmarks.

- Produced by [d-Matrix](../../../producers/sub/d/sub/d-matrix/).
