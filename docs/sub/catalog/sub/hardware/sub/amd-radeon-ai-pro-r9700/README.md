## Hardware identity and original-source qualification

Discrete RDNA 4 workstation/local-AI card with 32 GB dedicated GDDR6, 640 GB/s peak memory bandwidth, PCIe 5.0 x16, 300 W total board power and 12V-2x6 power connector. Active-cooled R9700 differs from passive-cooled R9700S. AMD lists memory ECC support for Linux only; precise driver, software, thermal and partner-board support remain configuration-specific. Vendor TOPS are not measured model tokens/s; no legal, ownership or deployment clearance.

- Produced by [Advanced Micro Devices, Inc.](../../../producers/sub/a/sub/advanced-micro-devices-inc/).
