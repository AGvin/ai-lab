## Original hardware scope

AMD Instinct MI350P is a CDNA 4 PCIe 5.0 x16 server add-in accelerator, with 144 GB HBM3E memory, up to 4 TB/s peak memory bandwidth, and 600 W maximum board power (configurable to 450 W). The full-height dual-slot card uses passive server cooling and a 12V-2x6 power connector. It is separate from the 288 GB OAM-form MI350X/MI355X products and their eight-module platforms; qualified host airflow, power, ROCm release and model workload remain configuration-sensitive. Vendor specification is not a benchmark, ownership clearance or retail-availability confirmation.

- Produced by [Advanced Micro Devices, Inc.](../../../producers/sub/a/sub/advanced-micro-devices-inc/).
