# Intel Arc B580

Intel Xe2/Battlemage desktop consumer GPU, distinct from Arc Pro B50/B60/B65 workstation products.

## Manufacturer specifications

- 12 GB GDDR6, 192-bit bus, published 456 GB/s memory bandwidth.
- 20 Xe-cores and 160 XMX engines.
- 190 W total board power; PCIe 4.0 x8.

## AI workload and deployment boundaries

Consumer driver features and 12 GB VRAM differ from Arc Pro models. Peak INT8 figures are not independently measured inference speed; verify model fit and supported software.

The listed specifications are manufacturer-published claims reviewed on 2026-11-05. They are not independent AI workload benchmarks, purchase availability checks or full driver compatibility testing.
