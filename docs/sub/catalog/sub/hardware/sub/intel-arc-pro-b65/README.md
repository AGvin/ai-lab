# Intel Arc Pro B65

Intel Arc Pro B65 Xe2/Battlemage workstation GPU, distinct from Arc Pro B60 despite 20 Xe-cores.

## Manufacturer specifications

- 32 GB GDDR6, 256-bit interface, published 608 GB/s bandwidth.
- 20 Xe-cores and 160 XMX engines.
- PCIe 5.0 x16 and 200 W total board power.

## AI workload and deployment boundaries

B65 memory and PCIe interface are not B60's. Peak TOPS are theoretical, not measured tokens/s; verify host lanes, drivers and board cooling.

The listed specifications are manufacturer-published claims reviewed on 2026-11-05. They are not independent AI workload benchmarks, purchase availability checks or full driver compatibility testing.
