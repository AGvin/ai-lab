## Hardware identity

Intel Arc Pro B70 is a launched Xe2/Battlemage professional discrete graphics card with 32 GB GDDR6, 608 GB/s graphics memory bandwidth, PCIe 5.0 x16, ECC support and 230 W Intel reference-card TBP. Board partner power limits can differ, so this is not a promise for every B70 card; oneAPI, OpenVINO, IPEX and real model workload support require environment-specific verification. It is not an Intel Gaudi datacenter accelerator; nominal TOPS do not establish measured LLM throughput. Ownership, availability and legal control remain unverified.

- Produced by [Intel](../../../producers/sub/i/sub/intel/).
