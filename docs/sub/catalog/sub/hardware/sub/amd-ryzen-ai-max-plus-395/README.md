## Hardware identity and original-source qualification

Non-PRO Strix Halo processor with 16 Zen 5 CPU cores, 32 threads, Radeon 8060S integrated graphics with 40 graphics cores and an XDNA 2 NPU rated up to 50 TOPS. Up to 128 GB LPDDR5x-8000 on a 256-bit memory interface is system memory shared with the GPU, not 128 GB of dedicated video memory. AMD lists default 55 W TDP and configurable 45-120 W; OEM firmware and memory allocation vary. Do not conflate with PRO 395 or the complete Halo Developer Platform. Runtime and ownership checks remain pending.

- Produced by [Advanced Micro Devices, Inc.](../../../producers/sub/a/sub/advanced-micro-devices-inc/).
