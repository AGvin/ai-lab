# Intel Gaudi 3 AI Accelerator

Intel Gaudi 3 is Intel's third-generation Gaudi AI accelerator hardware family and product identity for AI workloads.

## Hardware boundary

The family includes released PCIe, OAM, and system forms without making every board or system configuration a separate peer identity by default. Exact form factor or SKU, accelerator count, HBM capacity and bandwidth, supported precisions, networking or topology, software release, model artifact, workload, context, batch or concurrency, and benchmark method must remain attached to the applicable configuration.

Comparative performance, runtime support, pricing, availability, partner systems, and benchmark numbers are freshness- and configuration-sensitive.
