# AMD Radeon PRO W7900

AMD RDNA 3 professional workstation graphics card, not the Radeon PRO W7800 family or an Instinct CDNA accelerator.

## Manufacturer specifications

- 48 GB GDDR6, 384-bit interface, published up to 864 GB/s bandwidth.
- 96 compute units and 192 AI accelerators.
- 295 W total board power and PCIe 4.0 x16 interface.

## AI workload and deployment boundaries

Peak performance metrics and pro-graphics certifications are not proof of supported ROCm kernels or LLM serving performance. Verify exact card, PSU, driver, OS and memory budget.

The listed specifications are manufacturer-published claims reviewed on 2026-11-05. They are not independent AI workload benchmarks, purchase availability checks or full driver compatibility testing.
