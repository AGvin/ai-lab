# Documentation Requirements

## Requirements

- Identify AMD Radeon RX 7900 XTX as the released discrete RDNA 3 Radeon GPU SKU with 24 GB GDDR6 memory, distinct from RX 7900 XT and AMD Instinct enterprise accelerators.
- Preserve exact board/SKU identity, memory capacity and bandwidth, official recommended PSU and cooling considerations, and hardware encoder capabilities as applicable to this SKU.
- Keep AMD ROCm and inference-framework support, supported operating systems, kernel/driver versions, exact GPU architecture targets, containers, and model workload compatibility freshness-sensitive and platform-specific.
- Do not infer parity with NVIDIA CUDA application support solely from the nominal 24 GB memory or aggregate compute specifications.
- Avoid unqualified throughput comparisons: inference speed depends on runtime/backend, quantization/precision, batch/context, host, thermal limits and configured power.
- Link AMD as the producer with reciprocal relations, not as an independent model/API provider.

## Validation

- The product is distinct from other Radeon SKUs and AMD Instinct hardware.
- 24 GB memory capacity is grounded in AMD's published exact SKU specification.
- AMD software ecosystem and measured workload compatibility claims are scoped to verified runtime versions.
- AMD producer provenance resolves bidirectionally.
