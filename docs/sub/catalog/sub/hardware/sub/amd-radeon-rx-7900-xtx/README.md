## Hardware identity and original-source qualification

Released RDNA 3 desktop Radeon graphics card with 24 GB dedicated GDDR6 and 355 W typical board power. AMD's 800 W minimum PSU recommendation is based on a reference Ryzen 9 5900X system, not every partner board or host. This is not a Radeon PRO workstation GPU or Instinct OAM accelerator.
