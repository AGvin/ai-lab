# AMD Instinct MI455X

AMD Instinct MI455X is a released MI400 Series data-center GPU product based on AMD's CDNA 5 generation.

## Hardware boundary

MI455X remains distinct from AMD Helios rack-scale systems or reference designs, CDNA 5 architecture concepts, cloud instances, ROCm/runtime software, and the broader MI400 family. HBM4 memory, bandwidth, numeric-format, interconnect, power, and other specifications belong only to the applicable MI455X product or SKU scope. Release of MI455X does not imply that other announced MI400 products are also released.

System integration, runtime compatibility, lifecycle, availability, pricing, and workload performance are mutable deployment facts.
