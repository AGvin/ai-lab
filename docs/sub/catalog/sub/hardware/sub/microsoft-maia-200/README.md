# Microsoft Maia 200

## Relations

- Produced by: [Microsoft](../../../producers/sub/m/sub/microsoft/)

Microsoft Maia 200 is Microsoft's second-generation first-party AI accelerator, designed primarily for large-scale inference.

## Scope and boundaries

Microsoft's January 26, 2026 announcement describes TSMC 3 nm fabrication, native FP8/FP4 tensor cores, 216 GB of HBM3e at 7 TB/s, and 272 MB of on-chip SRAM. It also describes an Ethernet-based scale-up network and production deployment in Microsoft's datacenter fleet.

Maia 200 is hardware, separate from Azure and Microsoft Foundry services, the surrounding server systems and the models running on it. Fleet deployment does not establish standalone retail availability. Microsoft-stated throughput and efficiency comparisons depend on precision, workload and comparison configuration; deployment regions, SDK access and customer-facing service exposure require current verification.
