# Intel Arc Pro B50

Intel Xe2/Battlemage workstation discrete GPU, distinct from the B60/B65 and consumer Arc B580.

## Manufacturer specifications

- 16 GB GDDR6, 128-bit bus, published 224 GB/s memory bandwidth.
- 16 Xe-cores, 128 XMX engines, nominal 70 W total board power.
- PCIe 5.0 x8; vendor specifies ECC support.

## AI workload and deployment boundaries

The nominal board-power figure is not whole-system draw. Peak dense INT8 TOPS are not validated LLM tokens/s; check model, precision, driver, host, cooling and framework support.

The listed specifications are manufacturer-published claims reviewed on 2026-11-05. They are not independent AI workload benchmarks, purchase availability checks or full driver compatibility testing.
