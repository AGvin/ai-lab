# NVIDIA Vera CPU

NVIDIA Vera CPU is a concrete data-center CPU product for agentic AI, reinforcement learning, data processing, and host-CPU workloads.

## Hardware boundary

Vera CPU remains distinct from Vera CPU Rack, Vera Rubin NVL72, complete server or rack platforms, hosted cloud instances, and reusable architectural concepts such as Olympus cores or NVLink-C2C. Core and thread counts, cache, memory, interconnect, power, form factor, and confidential-computing facts apply only at the exact component scope supported by current first-party documentation.

Shipping status, partner deployments, benchmarks, configuration ranges, cloud availability, pricing, and software support are freshness-sensitive.
