# NVIDIA RTX PRO 6000 Blackwell Workstation Edition

NVIDIA RTX PRO 6000 Blackwell Workstation Edition is a professional desktop GPU for AI development, inference, visualization and related workstation workloads. NVIDIA specifies 96 GB of GDDR7 memory with ECC, PCIe Gen5 x16 connectivity and 600 W maximum power for this edition.

## Deployment boundaries

The Workstation Edition uses an active double-flow-through thermal design. The RTX PRO 6000 Server Edition and Max-Q Workstation Edition share family branding but have different power and cooling specifications; those variants are not interchangeable with this catalog identity.

Validate chassis clearance, airflow, power delivery, connectors, CPU and driver/runtime support for the actual workstation. FP4/FP8 and other accelerated paths depend on software implementation and model format. Published AI TOPS are theoretical vendor metrics with precision and sparsity conditions, not measured LLM token throughput. Model weights, cache and runtime allocations compete for physical GPU memory. Virtualization, enterprise software entitlement and partition support require an edition- and software-specific check.
