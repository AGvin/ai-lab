# OpenAI Jalapeño Intelligence Processor

Jalapeño is OpenAI's first Intelligence Processor, an LLM-inference accelerator co-developed with Broadcom and publicly unveiled in June 2026 after first-generation silicon was delivered to OpenAI leadership.

## Hardware boundary

OpenAI is the canonical product producer; Broadcom's co-development and manufacturing role is provenance context rather than a symmetric producer relation. The delivered and unveiled accelerator is a concrete product, but planned gigawatt-scale deployment is not current installed capacity. Jalapeño also remains distinct from complete OpenAI data-center systems and hosted inference services.

Performance-per-watt claims are vendor-reported. Future generations, deployment scale, performance figures, process or manufacturing details, and availability are mutable source-scoped facts.
