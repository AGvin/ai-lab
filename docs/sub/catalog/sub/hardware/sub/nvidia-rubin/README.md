# NVIDIA Rubin GPU

NVIDIA Rubin GPU is a concrete Rubin-generation data-center GPU component in production.

## Hardware boundary

Rubin GPU remains distinct from Vera CPU, Vera Rubin NVL72, HGX or DGX Rubin systems, other rack-scale platforms, cloud instances, and CUDA/runtime software. Memory technology and capacity, compute formats, interconnect, power, and other GPU facts belong only to the component scope supported by first-party sources; complete Vera Rubin system properties are not automatically intrinsic Rubin-GPU properties.

System shipping or ramp state, runtime compatibility, cloud availability, pricing, and workload performance are mutable deployment facts.
