# Hardware

The hardware catalog owns identifiable products and product families with durable practical value for AI training, inference, evaluation, data processing, and related workloads.

Hardware identity remains distinct from processor or GPU architecture concepts, complete server or rack platforms, hosted cloud services, driver/runtime software, and deployment recommendations. SKU and form-factor boundaries matter: memory, bandwidth, numeric formats, interconnects, partitioning, power, host requirements, and support may differ materially between variants. Availability, software compatibility, cloud access, pricing, and benchmark performance are mutable facts.

The materialized set below is curated rather than exhaustive.
