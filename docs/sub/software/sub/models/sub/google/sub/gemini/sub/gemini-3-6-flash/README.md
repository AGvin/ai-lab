# Gemini 3.6 Flash

Gemini 3.6 Flash is Google's stable, speed-oriented Gemini model for rapid agentic and coding workflows.

## Translations

- English
- [Українська](./l10n/uk_UA/)

## Official profile

- Stable model code: `gemini-3.6-flash`
- Access form: Gemini API and Google AI Studio
- Input modalities: text, image, video, audio, and PDF
- Output modality: text
- Input token limit: 1,048,576
- Output token limit: 65,536

The official page lists caching, code execution, file search, function calling, Google Maps grounding, search grounding, structured outputs, thinking, and URL context as supported. Computer use is preview.

## Limitations

Audio generation, image generation, and the Live API were not supported at verification time. Preview capabilities and consumption options can change independently of the stable model identity.

Google provides this as a hosted model. The cited page does not provide downloadable weights or local hardware guidance.

## Selection guidance

Consider Gemini 3.6 Flash for fast agent loops, code generation, multimodal document or media input, and workflows that need hosted tools. Validate preview features and output quality against the production workload.

## Evidence

The stable code, specifications, capabilities, and availability were verified on 2026-07-25.
