# Gemma Model Family

Gemma is Google's family of open-weight language and multimodal models for local, self-hosted, edge, research, and application workflows.

## Scope

This page owns the Gemma family taxonomy. Exact parameter counts, modalities, architectures, context lengths, artifacts, licenses, and deployment characteristics belong to generation and concrete-model pages.

## Generations

- [Gemma 4](./sub/gemma-4/) — dense and Mixture-of-Experts multimodal models spanning edge, laptop, workstation, and server-oriented sizes.

Add older or specialized Gemma generations only when current comparisons or practical documentation require their exact identities.

## Selection boundary

`Gemma` is a family name, not an exact deployment identity. Record the exact generation, model, instruction-tuned or pre-trained variant, artifact, runtime, precision, and modality configuration in every evaluation.
