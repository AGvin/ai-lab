## Provider boundary

Microsoft develops model families and publishes official research, release information, and downloadable artifacts. Azure AI hosting, third-party inference providers, quantizations, and runtime integrations are access or deployment dimensions rather than replacement model identities.

## Model families

- [Phi](./sub/phi/) — compact language, reasoning, and multimodal models designed for resource-conscious deployment and task-specific use.
