# Phi-4 Model Generation

Phi-4 is a Microsoft model generation containing text, reasoning, and multimodal variants with different operating requirements and intended uses.

## Translations

- English
- [Українська](./l10n/uk_UA/)

## Exact models

- [Phi-4 Mini Instruct](./sub/mini-instruct/) — a 3.8B-parameter dense instruction-tuned language model for constrained, latency-sensitive, multilingual, reasoning, and mixed general-purpose workloads.

Other Phi-4 variants should receive canonical pages only when a comparison or practical note depends on their exact identity.

## Selection boundary

A shared generation name does not make the text, reasoning, and multimodal variants interchangeable. Record the exact model, model type, modalities, context, license, and deployment artifact in every evaluation.
