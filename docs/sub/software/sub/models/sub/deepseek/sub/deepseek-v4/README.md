# DeepSeek V4

DeepSeek V4 is DeepSeek's model family for long-context reasoning and agentic workloads.

## Shared family facts

DeepSeek announced V4 as an open-weight family with Flash and Pro versions. Official services provide a one-million-token context and thinking and non-thinking modes for both versions.

API identifiers, output limits, prices, parameter counts, and artifact details belong to concrete child pages.

## Concrete models
