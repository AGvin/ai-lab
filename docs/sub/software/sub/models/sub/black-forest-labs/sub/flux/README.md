# FLUX

FLUX is a Black Forest Labs image-generation model family with variants that differ in quality target, inference speed, license, access, and deployment mode.

## Translations

- English
- [Українська](./l10n/uk_UA/)

## Scope

Document each exact FLUX variant separately. Do not transfer license, output rights, memory requirements, inference-step guidance, or quality findings between `schnell`, `dev`, hosted, fine-tuned, or converted artifacts without evidence.

## Documented versions

- [FLUX.1-schnell](./sub/flux-1-schnell/) — downloadable Apache-2.0 text-to-image model optimized for generation in a small number of steps.

## Evaluation dimensions

- prompt adherence and composition;
- typography, anatomy, consistency, and defect rate;
- target resolution and aspect ratio;
- inference steps, scheduler, precision, and seed behavior;
- peak VRAM and host RAM;
- load, warm-up, and terminal-image latency;
- accepted-result rate and candidate budget;
- license, input rights, output use, provenance, and disclosure requirements.
