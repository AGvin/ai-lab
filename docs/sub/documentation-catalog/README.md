## Software

[`software/`](../software/) covers software used to build, run, coordinate, evaluate, or interact with AI systems.

- [`development/`](../software/sub/development/) — AI-assisted software development tools and workflows, including editors, structured delivery systems, code-review utilities, and application-security tools.
- [`inference/`](../software/sub/inference/) — runtimes and tools for local or self-hosted model execution.
- [`workflow-engines/`](../software/sub/workflow-engines/) — systems for composing, executing, and sharing AI workflows.
- [`agents/`](../software/sub/agents/) — AI systems whose primary documented role is autonomous or semi-autonomous agent behavior.
- [`agent-orchestration/`](../software/sub/agent-orchestration/) — frameworks, runtimes, and control planes for coordinating or running agents.
- [`assistants/`](../software/sub/assistants/) — conversational AI assistants and assistant products.
- [`automation/`](../software/sub/automation/) — automation tools with AI-related or AI-adjacent use cases.
- [`model-platforms/`](../software/sub/model-platforms/) — platforms for discovering, hosting, evaluating, or distributing models and related assets.
- [`models/`](../software/sub/models/) — canonical provider, family, generation, version, and model-artifact documentation.

## Notes

[`notes/`](../notes/) contains conceptual material, terminology, evidence resources, decision support, and repository research records that are not themselves software documentation.

### Concepts

[`concepts/`](../notes/sub/concepts/) explains foundational and practical AI concepts, grouped by topic and reading priority.

- [`model-classification/`](../notes/sub/concepts/sub/model-classification/) — independent model scale, frontier-position, and ecosystem-maturity dimensions.
- [`model-architectures/`](../notes/sub/concepts/sub/model-architectures/) — dense, sparse, and mixture-of-experts model organization.
- [`foundations-and-architecture/`](../notes/sub/concepts/sub/foundations-and-architecture/) — foundational AI, machine-learning, transformer, attention, and encoder-decoder concepts retained during the staged redesign.
- [`model-usage-and-generation/`](../notes/sub/concepts/sub/model-usage-and-generation/) — tokens, context windows, prompting, structured output, sampling, reasoning models, and generation constraints.
- [`retrieval-and-knowledge/`](../notes/sub/concepts/sub/retrieval-and-knowledge/) — RAG, embeddings, search, chunking, reranking, grounding, citations, and knowledge graphs.
- [`agents-and-automation/`](../notes/sub/concepts/sub/agents-and-automation/) — AI agents, agentic workflows, tools, state, memory, planning, verification, skills, plugins, MCP, and multi-agent systems.
- [`inference-and-serving/`](../notes/sub/concepts/sub/inference-and-serving/) — model loading, quantization, serving, CPU and GPU inference, latency, throughput, caching, and batching.
- [`training-and-adaptation/`](../notes/sub/concepts/sub/training-and-adaptation/) — pretraining, fine-tuning, LoRA, QLoRA, datasets, preference optimization, distillation, and pruning.
- [`multimodal-and-generative-media/`](../notes/sub/concepts/sub/multimodal-and-generative-media/) — image, audio, video, diffusion, vision-language, and multimodal workflows.
- [`safety-privacy-and-reliability/`](../notes/sub/concepts/sub/safety-privacy-and-reliability/) — prompt injection, privacy, trust boundaries, sandboxing, provenance, guardrails, and alignment.
- [`evaluation-and-operations/`](../notes/sub/concepts/sub/evaluation-and-operations/) — evals, model selection and routing, observability, cost, latency, quality trade-offs, and reproducibility.
