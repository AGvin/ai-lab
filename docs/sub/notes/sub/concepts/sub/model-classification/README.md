## Classification-axis pedagogy residual

Useful independent axes include:

- **model scope or modality** — broad input/output/use class;
- **language-model scale** — relative model scale and operational footprint;
- **capability-frontier position** — whether dated evidence places the model near a leading capability boundary;
- **ecosystem maturity** — adoption, tooling/documentation maturity, and operational familiarity;
- **parameter-activation architecture** — dense, sparse, MoE, or another computation/activation organization;
- **deployment mode** — local, self-hosted, or provider-hosted operation;
- **access/licensing** — how the model/service can be accessed, modified, or redistributed.

These axes are not interchangeable. A quantized artifact does not become an SLM merely because it is smaller; dense/sparse/MoE does not determine model scale or hardware fit; deployment location does not determine scale; and `mainstream` describes ecosystem maturity rather than quality, safety, size, or frontier status.

Concrete frontier/maturity labels for named models remain mutable evidence/catalog/selection facts rather than timeless classification truth.
