## Comparison and decision-support residual

Model-selection tables should expose frontier status only when it materially changes the decision being made. A compact comparison surface may use values such as:

- `Supported` — current evidence supports the stated frontier claim for the bounded scope;
- `Not supported` — available evidence does not support the claim;
- `Unclear` — evidence is incomplete, conflicting, stale, or too narrow;
- `Not assessed` — the comparison did not evaluate frontier position.

Keep the supporting date, evidence, assumptions, and limitations outside the compact status value or link the value to a focused evidence record. This comparison vocabulary and its lifecycle remain migration source material until their exact evidence/evaluation or model-selection owner is verified.
