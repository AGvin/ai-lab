## Swarm and pattern-selection residual

Use handoff-oriented coordination when the receiving specialist should genuinely become the active owner of a conversation/task phase rather than merely return a bounded result to a retained manager. This can fit service triage, multilingual/jurisdiction-specific workflows, incident escalation between operational roles, or specialist-user interaction where tools/permissions differ by active role.

A decentralized swarm-like topology can reduce dependence on one large central orchestrator, but it increases the importance of explicit ownership, allowed transition edges, termination, fencing of stale owners, context minimization, and loop detection. Local handoff rules do not remove the need for global policy, authorization, and terminal conditions.

Prefer manager-worker delegation when specialists only need to return subresults, a central owner must coordinate global dependencies/budgets/resources, or irreversible actions require a centralized approval boundary. Prefer a simpler single-agent or deterministic workflow when ownership transfer adds no material value.
