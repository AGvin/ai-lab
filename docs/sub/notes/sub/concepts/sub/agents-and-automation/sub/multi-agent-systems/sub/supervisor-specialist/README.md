## Variant-fit residual

Use the supervisor-specialist form when one stateful user-facing supervisor should retain conversation/global ownership while repeatedly invoking a stable set of focused specialists as bounded tools. This can be useful for assistants spanning several domains where specialist context and permissions should remain isolated but one controller must preserve user intent and synthesize the final result.

Prefer a one-step router when dispatch is the only required decision, a handoff when ownership genuinely transfers, a broader orchestrator-worker pattern when the controller must dynamically build/manage a project graph, or a deterministic workflow when the sequence is already known.

Specialists can often remain stateless between calls, but durable specialist state may be introduced deliberately when justified by the workload. Context isolation lowers cost/leakage risk while creating omission risk, so the supervisor must pass enough authoritative constraints/evidence for the bounded task rather than either broadcasting everything or over-minimizing blindly.
