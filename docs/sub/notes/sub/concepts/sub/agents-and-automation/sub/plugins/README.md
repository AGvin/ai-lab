## Formal and platform residual

Current plugin ecosystems do not share one universal package representation. Formal Agent Plugins and vendor-specific plugin contracts can define different manifests or modules, component directories, hooks, commands, marketplaces, extensions, permissions, load order, update behavior, compatibility rules, and publication requirements.

Concrete current examples represented by this source include OpenAI, Claude Code, Cursor, and OpenCode plugin ecosystems. Their exact package layouts, manifests, lifecycle hooks, permissions, marketplace behavior, commands, supported components, and compatibility are mutable host/platform facts rather than reusable concept or learning truth.

These normative and mutable details must remain source-backed and move only after their exact specification/platform/catalog/evidence owners are selected.
