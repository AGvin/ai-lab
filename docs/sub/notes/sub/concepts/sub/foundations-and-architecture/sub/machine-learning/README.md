## Learning-paradigm residual

Common learning paradigms include:

- **Supervised learning:** learns from labeled input-output examples.
- **Unsupervised learning:** discovers structure without explicit target labels.
- **Self-supervised learning:** creates learning signals from the data itself.
- **Reinforcement learning:** learns behavior from rewards and interaction.

These concise distinctions remain migration source material until their exact selected concept or learning destinations are materialized and preservation is verified.

## Practical-use residual

Machine learning is useful when rules are difficult to write but representative data and measurable outcomes exist. Typical applications include classification, recommendation, forecasting, anomaly detection, speech recognition, and generative models.

Treat these as application-selection examples rather than part of the canonical ML definition.

## Data, evaluation, and operational residual

A model may fit historical data while failing after conditions change. Data quality, label quality, leakage, class imbalance, and evaluation design can materially affect results and may matter more than increasing algorithm complexity.

Practical safeguards include evaluating beyond training examples, distinguishing correlation from causal evidence, monitoring for data drift after deployment, and establishing a simple baseline before selecting a more complex model.
