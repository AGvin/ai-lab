# Documentation Requirements

## Requirements

- Use the reader-facing title `Human-AI Interaction`.
- Present this domain as canonical reusable knowledge about how people understand, use, collaborate with, rely on, supervise, intervene in, and are affected by AI systems through interfaces and shared work.
- Distinguish human-AI interaction from model architecture, AI-system autonomy, governance/accountability, and concrete product UX; these concerns interact but have separate canonical owners.
- Keep collaboration/teaming, reliance/trust, cognitive factors, oversight/intervention, anthropomorphism/social response, and interfaces/interaction as distinct selected concerns rather than reducing the domain to chat interfaces or human approval.
- Explain that human roles can vary across design, operation, decision-making, oversight, review, escalation, and affected-party contexts; one generic `human` role is insufficient when responsibilities materially differ.
- Treat human behavior as part of the system context: automation bias, overreliance, under-reliance, cognitive workload, misunderstanding, interface design, and organizational conditions can influence outcomes alongside model behavior.
- Render the standard direct-child navigation from the validated materialized child set when reader-facing rendering is activated.
- Keep concrete product interfaces, organizational policies, legal duties, user studies/results, domain-specific procedures, and project UX decisions with their applicable catalog, governance, evidence, learning, or project owners.
- Use the canonical entity references as research inputs for human-role and human-AI configuration boundaries when reader-facing rendering is activated.

## Validation

- The page does not equate human-AI interaction with prompting, chat UX, or oversight alone.
- Human roles and responsibilities are not collapsed into one undifferentiated reviewer/user role.
- Human presence is not treated as an automatic guarantee of system quality or safety.
- Direct-child navigation contains only currently materialized selected descendants.
