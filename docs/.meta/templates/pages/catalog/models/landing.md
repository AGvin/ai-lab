
# Models Catalog Landing Page

## Description

Entry page for canonical factual model documentation.

## Purpose

Orient readers to producer-namespaced model families, optional series, concrete models, versions, artifacts, lineage, and source-backed technical facts.

## Use When

Use for `catalog/models/`.

## Do Not Use When

Do not use for model recommendations, rankings, user scenarios, fixed-hardware selection, software/service choice, or benchmark-result ownership.

## Owns

- factual model-catalog orientation;
- producer -> family -> optional series -> model -> version/artifact identity boundary;
- child navigation to materialized model-domain producer/steward namespaces;
- boundary to canonical producer profiles and external decision support.

## Does Not Own

- recommendation conclusions or scenario routes;
- full producer organization profiles;
- provider/service or runtime/software identity;
- abstract model concepts or pedagogy.

## Expected Inputs

Requirement-approved factual orientation, validated direct-child projection, and canonical ownership-boundary explanation.

## Composition

1. default header;
2. concise factual model-catalog orientation;
3. producer-first identity boundary;
4. child navigation to materialized producer/steward namespaces;
5. concise links/boundaries to producer profiles and decision support when useful.
