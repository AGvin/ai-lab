# Model Selection Landing Page

## Description

Entry page for task-oriented model decision support.

## Purpose

Explain how AI Lab approaches model selection and help readers navigate to materialized task or model-team decision areas.

## Use When

Use for `catalog/models/selection/`.

## Do Not Use When

Do not use for canonical model reference facts, one concrete selection guide, or a generic catalog category.

## Owns

- selection methodology at orientation level;
- assignment-first decision framing;
- evidence-state and exact-identity expectations;
- navigation to materialized selection areas;
- boundary back to canonical Model Reference.

## Does Not Own

- complete model profiles;
- universal rankings;
- copied mutable pricing/availability as durable facts;
- full evaluation results belonging to specific guides.

## Expected Inputs

Requirement-approved methodology summary, materialized selection destinations, explicit reference link/boundary, and common evidence/decision principles.

## Composition

1. default header;
2. concise assignment-first selection orientation;
3. common evidence and exact-identity principles;
4. primary navigation to task/model-team areas;
5. explicit link back to canonical reference facts.

## Variants

The number of task areas may change. Only reviewed, materialized areas appear; empty conceptual skeletons are not rendered.

## Representative Example

- `docs/sub/catalog/sub/models/sub/selection/`

## Anti-patterns

- presenting one universal best-model list;
- duplicating canonical model descriptions;
- treating provider claims as independent AI Lab evidence.
