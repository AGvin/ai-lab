
# Model Selection Guide Page

## Description

Reusable decision-support page for a concrete task family, model-team problem, portfolio decision, or other bounded model-selection assignment.

## Purpose

Lead a reader from an explicit assignment and constraints through evidence and trade-offs to a bounded, reviewable recommendation or evaluation route.

## Use When

Use when the primary job is choosing, evaluating, routing, or combining exact model identities for a defined purpose.

## Does Not Own

- canonical model facts from `catalog/models/`;
- provider claims presented as independent verification;
- unrelated infrastructure architecture;
- universal model qualities detached from assignment conditions.

## Composition

1. default header;
2. assignment and success criteria;
3. material constraints and assumptions;
4. evaluation dimensions and evidence rules;
5. exact candidates or portfolio roles linked to canonical model facts;
6. trade-offs, limitations, and conflicts;
7. bounded recommendation, shortlist, escalation route, or unresolved outcome;
8. re-evaluation triggers and date-sensitive assumptions.
