
# Model Selection Landing Page

## Description

Entry page for model-specific decision support.

## Purpose

Route readers to task/need/portfolio decision guides or model selection for already-owned/fixed hardware.

## Use When

Use for `decision-support/selection/models/`.

## Do Not Use When

Do not use for canonical model facts, combined-context scenarios, hardware purchasing, software/service selection, or complete solution architecture.

## Owns

- model-selection methodology at orientation level;
- distinction between `decision-guides/` and `hardware/`;
- evidence-state and exact-identity expectations;
- boundary to sibling `decision-support/scenarios/` and canonical `catalog/models/`.

## Composition

1. default header;
2. concise model-selection orientation;
3. routing between task/need/portfolio and fixed-hardware journeys;
4. common evidence and exact-identity principles;
5. child navigation to materialized model-selection areas;
6. links to scenarios and canonical model facts when useful.
