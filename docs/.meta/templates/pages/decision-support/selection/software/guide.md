# Software Selection Guide Page

## Description

Reusable decision-support page for one bounded software-adoption question.

## Purpose

Compare software alternatives across the dimensions that materially affect a declared reader decision.

## Owns

- decision scope and acceptance criteria;
- comparison dimensions and trade-offs;
- bounded shortlist/recommendation;
- operational review and re-evaluation triggers.

## Does Not Own

- canonical software identity or intrinsic facts;
- generic software taxonomy;
- unsupported popularity, cost, licensing, deployment, or security claims.
