# Software Selection Landing Page

## Description

Entry page for decision support where software is the known selection target.

## Purpose

Route readers to substantive software-adoption decisions without mirroring the factual software catalog.

## Owns

- software-selection orientation;
- navigation to materialized software decision leaves;
- boundary to canonical `catalog/software/` facts and general scenarios.

## Does Not Own

- factual software profiles;
- empty taxonomy branches created for symmetry.
