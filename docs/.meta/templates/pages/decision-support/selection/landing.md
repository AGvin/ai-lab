
# Selection Landing Page

## Description

Entry page for decision support where the class of thing being selected is known.

## Purpose

Route readers to materialized selection targets without mirroring factual catalog taxonomies.

## Use When

Use for `decision-support/selection/`.

## Owns

- known-target selection orientation;
- child navigation to substantive materialized targets;
- boundary to sibling combined-context scenarios.

## Does Not Own

- canonical entity profiles;
- empty future targets created for symmetry.
