
# Decision Support Scenarios Index Page

## Description

Index page for the scenario root and its audience/decision-scale groups.

## Purpose

Help readers navigate from a combined real-world situation to a materialized scenario whose context genuinely changes the recommended route.

## Use When

Use for `decision-support/scenarios/` and its `personal/`, `professionals/`, `teams/`, and `organizations/` group nodes.

## Do Not Use When

Do not use for a concrete scenario leaf, known-target selection guide, or canonical catalog entity.

## Owns

- scenario method or audience-group boundary appropriate to the current node;
- concise explanation of dimensions that distinguish scenarios;
- validated child navigation;
- routing to known-target selection when one entity class becomes the primary decision.

## Does Not Own

- detailed recommendations belonging to child scenarios;
- canonical model/software/service/hardware facts;
- unmaterialized logical scenario destinations.
