## Current scope

The RC currently concentrates on the processed `catalog/` and `project/` architecture. Other durable knowledge areas — including concepts, learning material, reusable workflows, evidence, decision support, research, and reference material — remain subject to ongoing ownership and migration work rather than being represented as empty placeholder branches.

The complete taxonomy is intentionally not duplicated on this landing page. Use the Documentation Catalog for reader-oriented discovery and the Documentation Tree for the exhaustive implemented hierarchy.
